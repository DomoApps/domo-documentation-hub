## Neue Funktionen und Verbesserungen

Die folgenden Verbesserungen sind Teil der Version Juli 2022:

- String-Filterwerte in Dashboards und Karten-Visualisierungen werden jetzt in numerisch absteigender Reihenfolge angezeigt.
- Sie können Kartentitel auf Dashboard-Ebene bearbeiten, indem Sie den Dashboard-Bearbeitungsmodus aufrufen, **Inhalt bearbeiten** für die zu bearbeitende Karte auswählen und dann **Kartentitel und -beschreibung bearbeiten** auswählen.
- Datumsbereiche sind jetzt in Drill-Ansichten verfügbar.

Die folgenden Funktionen sind Teil der Version Juli 2022:

#### FIXED-Funktionen

Mit FIXED-Funktionen können Sie Unterabfrage-Berechnungen für flexiblere Datengruppierung, -verknüpfung und -vergleiche erstellen. Sie können auf FIXED-Funktionen neben anderen verfügbaren Funktionen im Beast Mode-Editor zugreifen. FIXED-Funktionen sind nur für nicht-föderierte DataSets verfügbar.

Weitere Informationen finden Sie unter [Beast Mode FIXED-Funktionen](/s/article/4408174643607).

#### Community-erstellte Konnektoren

Community-erstellte Konnektoren ermöglichen es Konnektor-Entwicklern, Konnektoren in Domo zu erstellen, zu aktualisieren und zu unterstützen. Wenn ein Konnektor als Community-erstellt veröffentlicht wurde, ist der Code für alle Kunden im Appstore verfügbar. Jeder Domo-Benutzer mit Zugriff auf den Appstore und Konnektoren kann Code in die IDE kopieren, um einen Konnektor aus einem Community-erstellten Konnektor zu erstellen.

Weitere Informationen finden Sie unter [Community-erstellte Konnektoren](/s/article/4571739374487).

#### Dashboards: Interaktion „Zu Kartendetails wechseln"

Mit der neuen Interaktionsoption „Zu Kartendetails wechseln" für Dashboards können Sie bestimmten Karten oder Daten-Apps, die so konfiguriert sind, immer den Vollbildmodus zu verwenden, eine größere Ansicht priorisieren. Die mobile Erfahrung kann jetzt unabhängig vom Desktop konfiguriert werden, sodass die Web-Erfahrung nicht beeinträchtigt wird.

Weitere Informationen finden Sie unter [Mobile Layout bearbeiten](/s/article/1500010172542).

#### Neue DDX Bricks

Neue DDX Bricks ermöglichen es Ihnen, Ihre benutzerdefinierten Lösungen schnell zu erstellen. Finden Sie diese neuen DDX Bricks im Appstore.

- DDX D3 Venn Diagram
- DDX Filtered Single Image
- DDX Form and DataSet
- DDX HTML Table Header
- DDX HTML Table with Nested Charts
- DDX Ten DataSets
- DDX Top 10 Images
- DDX Phoenix Cumulative Percentile
- DDX Phoenix Gradient Single Bar
- DDX Phoenix Percentile

Weitere Informationen finden Sie unter [DDX Bricks](/s/article/4423762260375).

#### Finance-App-Updates

In der Domo Finance-App können Sie jetzt die neuesten Daten links anzeigen, anstatt Benutzer zwingen zu müssen, ganz nach rechts zu scrollen, um die neuesten Daten zu sehen.

Der Spaltenname „Verhältnis" ist jetzt „% von [Spalte]". Dadurch können Benutzer einfacher erkennen, wogegen das Verhältnis basierend auf der App-Konfiguration berechnet wird.

**Standardansichten**

Mit Standardansichten können Administratoren verschiedene Abschnitte erweitern, Filter und Datumsbereiche einrichten und diese Ansicht als Standard speichern, wenn ein Benutzer die App öffnet.

**Nicht-standardmäßige Kalender**

Mit Nicht-standardmäßigen Kalendern können Sie „Numerische Perioden" aktivieren, was Monatsnamen durch Periodennummern ersetzt und so beliebige Varianten nicht-standardmäßiger Kalender ermöglicht, und Benutzer diese Perioden mithilfe von ETL konfigurieren können. Diese Funktion ermöglicht auch berechnete Trends im DataSet, sodass Sie Durchschnittstrends statt Summentrends anzeigen können.

Weitere Informationen finden Sie unter [Domo Finance](/s/article/1500003993182).

#### Produktfeedback-Prozess

Sie können jetzt Feedback im Ideas Exchange des Dojo klarer kommunizieren, indem Sie Multimedia hinzufügen. Sie können sehen, ob ein anderer Benutzer bereits dasselbe Feedback eingereicht hat. Das Produkt-Team von Domo kann direkt auf das Feedback antworten. Der neue Prozess ermöglicht es auch anderen Domo-Benutzern, Ihr Feedback einzusehen, Erkenntnisse bereitzustellen und für gute Ideen zu stimmen. Diese Community-Zusammenarbeit hilft dabei, Domos Entwicklungs-Roadmap voranzutreiben.

Um auf die Funktion zuzugreifen, gehen Sie zur Domo-Navigationsleiste: Wählen Sie **Mehr** > **Feedback**. Wählen Sie im angezeigten Modal **Produktfeedback** aus.

## Neue Diagrammtypen

Finden Sie diese neuen Diagrammtypen in der Diagrammauswahl in Analyzer:

#### Bump-Diagramm

Mit Bump-Diagrammen können Sie schnell Rangänderungen im Laufe der Zeit sehen. Die Rangänderung wird stärker betont als die numerischen Wertänderungen.

Weitere Informationen finden Sie unter [Bump-Diagramm](/s/article/7508267092119).

<Frame>![release_3_bump_chart.png](/images/kb/0EM5w000005vXnc.png)</Frame>

#### Risiko-Heatmap

Mit Risiko-Heatmaps können Sie die Wahrscheinlichkeit und mögliche Auswirkung identifizierter Risiken bewerten und die Risiken dann in einem farbigen Raster anzeigen.

Weitere Informationen finden Sie unter [Risiko-Heatmap](/s/article/7506837994007).

<Frame>![release_4_risk_heat_map.png](/images/kb/0EM5w000005vXna.png)</Frame>

#### Facettiertes Balkendiagramm

Mit den zusätzlichen Dimensionen, die mit facettierten Balkendiagrammen verfügbar sind, können Sie viele Diagramme zu einem kombinieren und dabei Platz sparen, indem die X-Achse nicht repliziert wird.

Weitere Informationen finden Sie unter [Facettiertes Balkendiagramm](/s/article/7508982399767).

## Beta-Funktionen

Wenn Sie Interesse an der Teilnahme an der Beta für eine bestimmte Funktion haben, wenden Sie sich bitte an Ihren Domo Customer Success Manager (CSM), Technical Consultant (TC) oder Account Executive (AE). Wenn Sie keine Kontaktinformationen für Ihren Vertreter haben, wenden Sie sich per E-Mail an den technischen Support unter [support@domo.com](mailto:support@domo.com).

<Note>**Hinweis:** Je nach Funktion müssen Sie möglicherweise eine Schulung absolvieren, bevor Sie diese Funktion nutzen können.</Note>

#### Passwort-Sperrliste

Mit der Passwort-Sperrliste können Sie sich gegen nicht autorisierten und geleakten Anmeldedaten-Missbrauch schützen. Sie können auch die Anzahl der Schulungs-, Test- und Demo-Passwörter in der Produktion begrenzen und Passwörter oder Passwort-Elemente angeben, die in Ihrer Domo-Instanz nicht verwendet werden dürfen.

Weitere Informationen finden Sie unter [Passwortanforderungen festlegen.](/s/article/360042934474)
