## Einführung

In diesem Artikel wird erläutert, wie Sie das Migrationsbanner der linken Navigation verstehen und Ihre Benutzer zur neuen linken Navigation migrieren, bevor Domo die obere Navigation deaktiviert.

---


## Erforderliche Zugriffsrechte

Um das Migrationsbanner anzuzeigen und Benutzer zur neuen linken Navigation zu überführen, müssen Sie über die Administratorrolle verfügen. Insbesondere ist dafür das Zugriffsrecht **Alle Unternehmenseinstellungen verwalten** erforderlich, das standardmäßig in der Standard-Administratorrolle enthalten ist.

## Das Migrationsbanner verstehen

Wenn Sie Domo-Administrator sind, wird in Ihrer Instanz ein Banner angezeigt, das Sie dazu auffordert, die neue Navigation zu aktivieren. Wir empfehlen, Ihre Benutzer vor dem Stichtag zu migrieren, um einen reibungslosen Übergang zu gewährleisten.

<Frame>![Navigationsbanner](/images/kb/navigation-migration1.png)</Frame>

## Benutzer zur neuen linken Navigation migrieren

Führen Sie diese Schritte aus, um Ihre Benutzer zur neuen linken Navigation zu migrieren:

1. Wählen Sie **Mehr erfahren** im Benachrichtigungsbanner, um die Einstellungen der Neuen Navigation zu öffnen.

   <Frame>![Navigationsbanner](/images/kb/navigation-migration2.png)</Frame>

   <Note>**Hinweis:** Wenn Sie das Banner schließen, können Sie auch **Mehr** > **Administrator** in der oberen Navigation auswählen und dann unter **Unternehmenseinstellungen** die Option **Neue Navigation** auswählen, um auf das Aktivierungstool zuzugreifen.</Note>

   <Frame>![Navigationsbanner](/images/kb/navigation-migration3.png)</Frame>
   <Frame>![Navigationsbanner](/images/kb/navigation-migration4.png)</Frame>

2. Die folgenden Optionen stehen zur Verfügung, um Sie bei der Migration der Benutzer zur neuen Navigation zu unterstützen:

   - **In Ihrer Instanz nicht aktiviert —** Diese Option deaktiviert die neue Navigation für alle Benutzer in Ihrer Instanz. Dies ist das Standardverhalten, wenn die neue Navigation noch nicht aktiviert wurde.
   - **Für alle aktiviert —** Aktiviert die Navigation für alle Benutzer in Ihrer Instanz.
   - **Für Administratoren aktiviert —** Aktiviert die Navigation für alle Administratorbenutzer in Ihrer Instanz. Diese Option gewährt allen Administratoren, die die Seite „Unternehmenseinstellungen“ anzeigen können, Zugriff auf das Aktivierungstool der Navigation.
   - **Für eine bestimmte Gruppe aktiviert —** Aktiviert die Navigation für eine bestimmte Gruppe.
   
   <Frame>![Navigationsbanner](/images/kb/navigation-migration5.png)</Frame>

3. Um Ihre Änderungen zu speichern, wählen Sie **Speichern** in der oberen rechten Ecke. Eine Bestätigungsmeldung wird angezeigt. Wählen Sie **Aktivieren**, um zu bestätigen. Die Änderung wird sofort wirksam.

   <Frame>![Navigationsbanner](/images/kb/navigation-migration6.png)</Frame>
