## Nuevas funciones y mejoras

### Opciones avanzadas de programación para Conectores

Las nuevas opciones avanzadas de programación para Conectores le permiten controlar mejor la orquestación de su flujo de datos al proporcionar opciones adicionales para actualizar sus datos.

Por ejemplo, si su sistema de origen publica datos cada 3 horas, ya no tendrá que esperar cada 4 horas para que los datos se actualicen en Domo, lo que le permite tener los datos más recientes en su instancia cuando los necesite.

### Marca Domo AI Pro

Hemos dividido nuestras funciones de IA en dos niveles: Domo AI y Domo AI Pro. Esto garantiza que pueda aprovechar nuestras capacidades avanzadas de IA manteniendo el control sobre el costo y el uso.

Las funciones de uso frecuente permanecen gratuitas como parte de su contrato de Domo:

- Beast Mode Assistant
- Editor de SQL en el editor de vistas de DataSet
- Ícono de SQL en Magic - Extracción, transformación y carga
- Asistentes de IA de Magic - Extracción, transformación y carga

Domo AI Pro incluye funciones de IA de valor agregado y personalizables con precio basado en el consumo:

- Tareas de agentes de IA en Flujos de trabajo
- Íconos de generación de texto de Magic - Extracción, transformación y carga
- Llamadas directas a la API de servicios de IA
- Análisis impulsado por IA en Jupyter
- AI Playground para experimentar y crear prototipos
- Servicios de IA (resumen de texto, texto a SQL, generación de texto, imagen a texto)

También hemos añadido la tarjeta de tasa de consumo de IA para proporcionar una vista detallada de cómo los distintos modelos y funciones de IA afectan el uso de crédito. Esta tarjeta lista los SKU para el uso de funciones y la tasa de crédito correspondiente.

Aprenda más sobre [cómo se consumen los créditos para las funciones individuales](https://domo-support.domo.com/s/article/000005918?language=en_US).

_Los administradores pueden acceder a la tarjeta de tasa navegando a Configuración de administrador > Configuración de la empresa > Utilización de crédito > Tarjeta de tasa (requiere el permiso "Ver informes de crédito")._

### Mejora del filtrado booleano para la Integración en la nube

Los filtros booleanos para la Integración en la nube ahora se traducen automáticamente a los tipos de datos y la sintaxis precisos requeridos por el motor de nube o base de datos conectado.

Esta actualización aumenta la confiabilidad al eliminar errores causados por tipos de datos incompatibles y proporciona resultados más precisos.

### Magic - Extracción, transformación y carga

### Inhabilitar íconos

La capacidad de inhabilitar o "comentar" íconos en DataFlows ahora está disponible en Magic - Extracción, transformación y carga. Esta función le permite seleccionar uno o varios íconos para inhabilitarlos, de modo que no se tengan en cuenta durante la ejecución del DataFlow.

Además de inhabilitar íconos, también puede resaltar todos los íconos anteriores o posteriores a un ícono seleccionado e inhabilitarlos individualmente desde sus paneles de configuración.

Aprenda cómo [inhabilitar íconos en Magic - Extracción, transformación y carga](https://domo-support.domo.com/s/article/000005901?language=en_US).

### Íconos de entrada fija

El ícono de entrada fija le permite agregar datos directamente en el lienzo de Magic - Extracción, transformación y carga de forma rápida. Puede agregar datos manualmente, copiando y pegando desde otras fuentes, o cargando archivos de Excel y CSV. También puede utilizar la generación con tecnología de IA para crear columnas individuales o DataSets completos con datos de muestra realistas. Todos los datos de entrada se almacenan dentro de la definición del DataFlow y se pueden utilizar como entrada para las transformaciones posteriores en el mismo DataFlow.

El ícono de entrada fija permite:

- Creación de prototipos y pruebas más rápidas
- Mayor flexibilidad en la entrada de datos
- Mayor autonomía para los usuarios no técnicos
- Generación de datos de muestra realistas

Aprenda cómo usar el [ícono de entrada fija en Magic - Extracción, transformación y carga](/s/article/360045402273#fixed-input-tile).

### Ícono de expansión JSON

El nuevo expansor JSON le permite expandir datos en formato JSON de una sola columna a múltiples columnas sin necesidad de un análisis sintáctico complejo.

Esta función le permite acceder a los datos de columnas de forma confiable mediante un proceso de expansión jerárquica fácil de usar.

Aprenda cómo usar el [ícono de acción JSON Expand](https://domo-support.domo.com/s/article/000006036?language=en_US).

### SSO - Conmutador de lista de inicio de sesión directo

El nuevo conmutador "Aplicar lista de inicio de sesión directo" desvincula la aplicación de la lista de inicio de sesión directo de la configuración de SAML y hace que la configuración y el comportamiento sean claros: cuando está activado, se aplica la lista de inicio de sesión directo. La lista de inicio de sesión directo solo se puede aplicar cuando al menos un protocolo SSO (OIDC o SAML) está habilitado.

Si la lista de inicio de sesión directo está activada, el enlace "Usar inicio de sesión directo" aparece en la página de inicio de sesión de Domo.

Aprenda más sobre el [conmutador de lista de inicio de sesión directo](https://domo-support.domo.com/s/article/000005827?language=en_US#configure_sso_with_saml).

<Note>
  **Nota:** Esta mejora en el método de configuración de la lista de inicio de sesión directo no afecta el flujo de autenticación y de inicio de sesión de usuarios efectivo. Si la instancia de Domo estaba configurada previamente para aplicar la lista de inicio de sesión directo (según la configuración del ajuste "Experiencia de inicio de sesión del usuario" de SAML), entonces el nuevo ajuste "Aplicar lista de inicio de sesión directo" está activado; de lo contrario, el ajuste está desactivado y todos los usuarios pueden iniciar sesión en Domo con sus credenciales de Domo.
</Note>

### App Catalyst

App Catalyst le permite crear al instante aplicaciones Domo Pro-Code usando indicaciones de ejemplo o añadiendo las suyas propias. Integre las aplicaciones generadas con sus DataSets de Domo y agréguelas a tableros o aplicaciones de App Studio.

Después de crear su aplicación, puede ver y editar el código de la aplicación generada, obtener una vista previa de la interfaz de usuario, guardar y publicar su aplicación para que otros la usen.

### Tablas editables y tablas vinculadas

Dos nuevas funciones de tabla están disponibles en App Studio y Worksheets.

Las tablas editables le permiten insertar una tabla similar a una hoja de cálculo donde puede ingresar datos, agregar columnas y filas, crear cálculos, copiar y pegar, y filtrar.

Las tablas vinculadas le permiten combinar los datos existentes de Domo con nuevas columnas para casos de uso comunes, como la previsión financiera y la elaboración de presupuestos.

### DomoStats para PDP de filas

<Frame>
  ![](/images/kb/ka0Vu000000cPJxfeoid-00N5w00000Ri7BUrefid-0EMVq00000Fj424.png)

Los nuevos informes de DomoStats para PDP de filas le permiten ver metadatos sobre todas las políticas PDP de filas existentes en su instancia, incluida información sobre políticas, condiciones de las políticas y asignaciones de políticas.

### Magic - Extracción, transformación y carga en BigQuery

### Sintaxis SQL nativa

<Frame>
  ![](/images/kb/ka0Vu000000cPJxfeoid-00N5w00000Ri7BUrefid-0EMVq00000FjNFx.png)
</Frame>

El ícono de sintaxis SQL nativa le permite usar la sintaxis SQL nativa de BigQuery para transformar sus datos según sus casos de uso en Magic - Extracción, transformación y carga. Este ícono le brinda más flexibilidad con respecto a las limitaciones del entorno de BigQuery y los casos en los que no desea refactorizar su SQL de BigQuery en Magic - Extracción, transformación y carga.

#### Soporte para procesamiento de subconjuntos

El soporte para procesamiento de subconjuntos le permite seleccionar los métodos de salida (incluidos Partición, Añadir y Actualización e inserción) para sus DataSets de BigQuery en Magic - Extracción, transformación y carga.

### Configuraciones de navegación

Las configuraciones de navegación permiten a los administradores crear una experiencia de navegación personalizada para su instancia agregando objetos de Domo, incluidas aplicaciones, un espacio de trabajo o carpeta de inicio, y tableros, a la navegación izquierda de los usuarios para acceder al contenido.

Los administradores también pueden crear diferentes configuraciones para distintos grupos o usuarios y bloquear qué usuarios pueden personalizar su contenido.

La pestaña de esquema para DataSets y modelos de datos le permite formatear y cambiar el orden de los campos, e incluir descripciones y etiquetas de campos para los usuarios posteriores.

También puede acceder y activar los campos de IA, y agregar contexto y sinónimos en la pestaña de esquema.
