### 

## Version du 1er octobre 2025

### Composants d'application

**Mises à jour :**

- Ajouter de nouvelles lignes dans les tableaux liés.
- Renommer les en-têtes de colonnes en tapant directement dedans sans avoir à double-cliquer d'abord.

**Problèmes résolus :**

- Les calculs masqués n'étaient pas correctement supprimés des cartes.
- Les colonnes calculées dans les tableaux modifiables ne peuvent désormais être modifiées que dans la barre de l'éditeur de formules, ce qui évite les modifications involontaires dues à des actions telles que le double-clic, le copier-coller ou le remplissage par glissement.
- Le masquage d'une colonne clé dans un tableau lié provoquait des problèmes lors de la deuxième modification d'une application.

### App Studio

**Problèmes résolus :**

- Le bouton « Plus » dans le menu de navigation gauche ne répondait pas comme prévu.
- La désactivation du paramètre « Autoriser la date globale » dans App Studio ne fonctionnait pas comme prévu. Cette mise à jour garantit que le texte intelligent respecte le paramètre de date globale, même lorsqu'il n'est pas désactivé sur une carte spécifique.
- Tout le contenu au-dessus de la ligne de non-défilement était repoussé lors de l'enregistrement d'une application dans App Studio.
- Les mises en page du contenu dans App Studio sont centrées lors de l'utilisation d'une largeur fixe.

### Cartes

**Problèmes résolus :**

- Le texte intelligent dans App Studio ne référençait pas les filtres de page persistés jusqu'à ce que l'utilisateur clique sur la carte.
- Les cartes Notebook n'affichaient pas les valeurs de variables correctes.

### Intégrations dans le cloud

**Mises à jour :**

- Ajout d'un bouton Retour sur les pages de création d'intégration pour tous les moteurs d'intégration dans le cloud. Ce bouton amène l'utilisateur à la page « Gérer les intégrations ».

**Problèmes résolus :**

- Le point de terminaison de mise à jour d'intégration renvoyait un nouvel état d'intégration non valide après la mise à jour d'une intégration.

### Connecteurs

**Problèmes résolus :**

- Les données étaient écrites incorrectement dans Google Sheets lorsqu'un filtre était appliqué. La correction garantit que le filtre est effacé avant d'écrire les données dans la feuille.
- Le connecteur Cvent REST a rencontré une erreur de « mémoire insuffisante » lors du traitement du rapport « meeting\_request\_forms ».

### Tableaux de bord

**Problèmes résolus :**

- Les variables dans le texte intelligent des cartes de tableau de bord n'affichaient pas les valeurs correctement.
- Les filtres de page ne fonctionnaient pas sur les tableaux de bord lorsque les filtres de date globaux étaient désactivés.

### Notifications

**Problèmes résolus :**

- Le bouton d'abonnement n'était visible que sur votre propre profil, et non sur les profils des autres utilisateurs.

### Rapports planifiés

**Mises à jour :**

- Le sélecteur de la zone Rapports est désormais développé pour offrir plus d'espace pour les options.
