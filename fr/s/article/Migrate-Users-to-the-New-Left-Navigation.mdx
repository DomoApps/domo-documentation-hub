## Introduction

Cet article explique comment comprendre le bandeau de migration de la navigation de gauche et migrer vos utilisateurs vers la nouvelle navigation de gauche avant que Domo ne désactive la navigation supérieure.

---


## Droits requis

Pour afficher le bandeau de migration et faire passer les utilisateurs vers la nouvelle navigation de gauche, vous devez disposer du rôle d'administrateur. Plus précisément, cela nécessite le droit **Gérer tous les paramètres de l'entreprise**, qui est inclus par défaut dans le rôle d'administrateur par défaut.

## Comprendre le bandeau de migration

Si vous êtes administrateur Domo, un bandeau apparaît dans votre instance pour vous inviter à activer la nouvelle navigation. Nous vous recommandons de migrer vos utilisateurs avant la date limite afin de garantir une transition fluide.

<Frame>![Bandeau de navigation](/images/kb/navigation-migration1.png)</Frame>

## Migrer les utilisateurs vers la nouvelle navigation de gauche

Suivez ces étapes pour migrer vos utilisateurs vers la nouvelle navigation de gauche :

1. Sélectionnez **En savoir plus** dans le bandeau de notification pour ouvrir les paramètres de Nouvelle navigation.

   <Frame>![Bandeau de navigation](/images/kb/navigation-migration2.png)</Frame>

   <Note>**Remarque :** Si vous fermez le bandeau, vous pouvez également sélectionner **Plus** > **Administrateur** dans la navigation supérieure, puis sélectionner **Nouvelle navigation** sous **Paramètres de l'entreprise** pour accéder à l'outil d'activation.</Note>

   <Frame>![Bandeau de navigation](/images/kb/navigation-migration3.png)</Frame>
   <Frame>![Bandeau de navigation](/images/kb/navigation-migration4.png)</Frame>

2. Les options suivantes sont disponibles pour vous aider à migrer les utilisateurs vers la nouvelle navigation :

   - **Non activée dans votre instance —** Cette option désactive la nouvelle navigation pour tous les utilisateurs de votre instance. Il s'agit du comportement par défaut si la nouvelle navigation n'a pas encore été activée.
   - **Activée pour tout le monde —** Active la navigation pour tous les utilisateurs de votre instance.
   - **Activée pour les administrateurs —** Active la navigation pour tous les utilisateurs administrateurs de votre instance. Cette option accorde à tous les administrateurs qui peuvent afficher la page Paramètres de l'entreprise l'accès à l'outil d'activation de la navigation.
   - **Activée pour un groupe spécifique —** Active la navigation pour un groupe spécifique.
   
   <Frame>![Bandeau de navigation](/images/kb/navigation-migration5.png)</Frame>

3. Pour enregistrer vos modifications, sélectionnez **Enregistrer** dans le coin supérieur droit. Un message de confirmation apparaît. Sélectionnez **Activer** pour confirmer. La modification prend effet immédiatement.

   <Frame>![Bandeau de navigation](/images/kb/navigation-migration6.png)</Frame>
