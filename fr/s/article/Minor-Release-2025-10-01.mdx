## Version du 1er octobre 2025

### App Components

- Ajoutez de nouvelles lignes dans les Linked Tables.
- Les colonnes calculées dans les Editable Tables ne peuvent désormais être modifiées que dans la barre de l'éditeur de formules, ce qui évite les modifications involontaires dues à des actions comme le double-clic, le copier-coller ou le glissement de remplissage.
- Les calculs masqués n'étaient pas correctement supprimés des cartes.
- Masquer une colonne clé sur une Linked Table causait des problèmes lors de la modification d'une application une deuxième fois.
- Renommez les en-têtes de colonne en y saisissant directement du texte sans avoir à double-cliquer dessus au préalable.

### App Studio

- Tout le contenu au-dessus de la ligne de non-défilement était expulsé lors de l'enregistrement d'une application dans App Studio.
- Les mises en page de contenu dans App Studio sont centrées lors de l'utilisation d'une largeur fixe.
- Le bouton "More" du menu de navigation de gauche ne répondait pas comme prévu.
- La désactivation du paramètre "Allow global date" dans App Studio ne fonctionnait pas comme prévu ; le texte intelligent respecte désormais le paramètre de date globale même lorsqu'il n'est pas désactivé sur une carte spécifique.

### Cartes

- Les Notebook Cards n'affichaient pas les valeurs de variable correctes.
- Le texte intelligent dans App Studio ne référençait pas les filtres de page persistants tant que l'utilisateur ne cliquait pas sur la carte.

### Intégrations dans le cloud

- Un bouton de retour a été ajouté sur les pages de création d'intégration pour tous les moteurs d'intégration dans le cloud. Ce bouton amène l'utilisateur à la page "Manage Integrations".
- Le point de terminaison Integration Update renvoyait un nouvel état d'intégration non valide après la mise à jour d'une intégration.

### Connecteurs

- Les données étaient écrites de manière incorrecte dans Google Sheets lorsqu'un filtre était appliqué ; le filtre est désormais effacé avant que les données ne soient écrites dans la feuille.
- Le connecteur Cvent REST manquait de mémoire lors du traitement du rapport `meeting_request_forms`.

### Tableaux de bord

- Les filtres de page ne fonctionnaient pas sur les tableaux de bord lorsque les filtres de date globale étaient désactivés.
- Les variables dans le texte intelligent des cartes de tableau de bord n'affichaient pas correctement les valeurs.

### Notifications

- Le bouton d'abonnement n'était visible que sur votre propre profil, et non sur les profils des autres utilisateurs.

### Rapports planifiés

- Le sélecteur de la zone Rapports est désormais agrandi pour offrir plus d'espace aux options.
