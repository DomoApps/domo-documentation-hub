## Version du 22 octobre 2026

### AI Labs

- Ajoute la prise en charge de nouveaux types d'autorisation d'identité dans le ciblage des politiques PDP pour Files, permettant un contrôle plus granulaire de l'accès des utilisateurs et des groupes dans les fonctionnalités de données non structurées d'AI Labs.
- Ajoute la prise en charge d'OAuth et de l'identifiant de ressource MCP par défaut dans AI Labs.
- Les administrateurs disposent d'un meilleur contrôle sur les autorisations d'accès aux données pour les données non structurées dans AI Labs grâce aux Personalized Data Permissions (PDP) pour les API FileSet.
- Les mosaïques AI Agent dans les flux de travail n'affichaient pas d'aperçus de sortie lorsqu'un DataSet était ajouté comme source de connaissances.
- La suppression d'un client OAuth 2.1 met fin aux sessions actives et à l'accès de ce client.
- Les modèles DomoGPT Medium v2.2 et v3 ne fonctionnaient pas correctement dans les mosaïques AI Labs de Magic ETL.
- Résout les problèmes de connectivité avec les services IA dans l'AI Library.
- Les compétences de l'AI Library étaient temporairement indisponibles et ont été restaurées.
- La carte Sandbox Repository Toolkit dans l'AI Library affichait un espace gris vide au lieu de son icône.

### AI Services

- Une nouvelle option de fournisseur IA est disponible dans AI Services.

### Alertes

- Les alertes DataSet planifiées sur des DataSets compatibles PDP n'avertissaient pas les abonnés lorsque le seuil de l'alerte était franchi.

### App Platform

- Les DataSets AppDB pouvaient afficher des écarts de nombre de lignes lorsque la table de données sous-jacente était manquante ; les DataSets concernés la reconstruisent désormais automatiquement.

### App Studio

- Les administrateurs peuvent contrôler la visibilité des options de planification dans Report Builder.
- Les graphiques en boîte étaient affichés à tort comme des graphiques à barres après l'application d'un filtre.
- Les applications personnalisées qui réappliquaient un filtre pouvaient effacer le filtre de page qu'elles tentaient de définir, ce qui amenait les cartes à afficher des données non filtrées ; vous pouvez de nouveau supprimer un filtre appliqué par une autre carte sur la même page d'un seul clic.
- Dans App Studio, les utilisateurs ne pouvaient pas réorganiser les onglets de navigation lorsque le chat IA était désactivé.
- Certains graphiques s'affichaient vides après le chargement d'une application App Studio.

### Authentification

- Les organisations utilisant SCIM peuvent désormais déprovisionner automatiquement les utilisateurs via des requêtes patch.

### Buzz

- Les boutons de la fenêtre contextuelle de suppression d'utilisateur cessaient de répondre dans les sujets Buzz privés et les discussions de groupe.

### Cartes

- Les filtres et contrôles de carte n'affichaient pas de valeurs lorsque la carte utilisait à la fois un filtre d'agrégation et un regroupement piloté par des variables.
- Les boutons prédéfinis du sélecteur de dates devenaient non sélectionnables et la mise en page se compressait lorsqu'ils étaient développés dans les filtres de carte.
- La modification des filtres de plage de dates dans Analyzer pouvait décaler les dates d'un jour pour les utilisateurs de certains fuseaux horaires, affectant la fenêtre contextuelle de filtre de colonne et le panneau Plage de dates et s'aggravant à chaque modification.
- Les utilisateurs avec le rôle Editor ne pouvaient pas charger une nouvelle version d'une Doc Card dont ils n'étaient pas propriétaires ; les utilisateurs disposant d'autorisations de modification peuvent désormais charger de nouvelles versions sans avoir besoin d'autorisations de suppression sur le fichier.
- Les cartes de tableau affichaient des valeurs décimales brutes au lieu d'appliquer la mise en forme numérique configurée (comme les pourcentages, les devises ou les nombres abrégés) pour les colonnes décimales de haute précision.

### Connecteurs

- La connexion de très grandes tables PostgreSQL (plus de 100 M de lignes) dans Cloud Amplifier échouait avec une erreur "Unable to find a Schema" ; les tables se connectent désormais immédiatement, le nombre de lignes étant calculé en arrière-plan.
- Le connecteur Snowflake Writeback échouait avec une erreur de compilation SQL lorsque les DataSets contenaient des noms de colonne en conflit avec des noms de colonne réservés.

### Consommation

- Ajoute un nouveau type de portefeuille Partner-Reseller aux comptes de Consommation, élargissant les options de type de compte disponibles pour gérer les relations avec les partenaires et les revendeurs.

### Tableaux de bord

- Les cartes de Notebook et de tableau exportées au format PDF ou PowerPoint pouvaient être coupées par des marges supplémentaires.

### Data Center

- Les DataSet Views Redshift de Cloud Amplifier échouaient avec une erreur "column does not exist" lorsque les identifiants contenaient des caractères minuscules ou pleine largeur.
- La boîte de dialogue de partage de compte ne s'affichait pas lorsqu'un groupe précédemment partagé n'existait plus ; vous pouvez désormais afficher tous les utilisateurs et groupes partagés et supprimer les partages restants vers des groupes supprimés.

### Traitement des données

- Les DataFlows Magic ETL pouvaient rester bloqués au statut PREPARING ou EXPORTING jusqu'à 24 heures au lieu de se terminer normalement.

### Requête de données

- Les clients ne pouvaient pas créer plusieurs comptes Databricks M2M OAuth ; les comptes affichent désormais un nom distinctif basé sur l'hôte du workspace et l'ID client du service principal, ce qui permet des comptes distincts pour différents environnements.

### Embed

- Les administrateurs ne pouvaient pas ajouter d'origines basées sur localhost à la liste Authorized Private Embed Domains, car le bouton Ajouter restait désactivé pour les URL sans point dans le domaine.

### Mobile

- Définit la version minimale prise en charge de l'application sur 4.38 pour iOS et 4.38.3 pour Android pour la compatibilité avec les certificats mis à jour.

### Performances

- Certains événements de la page de détails des DataSet pouvaient provoquer des ralentissements de l'instance lorsqu'ils étaient transmis à de nombreux utilisateurs à la fois.

### Publish

- La création de nouvelles cartes dans Publish entraînait une erreur lorsque les composants d'application n'avaient pas d'abonnement aux données.
- L'exportation d'une vue couvrant plusieurs DataSets via Domo Publish échouait.
- Les cartes de Notebook dans les publications Domo Everywhere supprimaient incorrectement des DataSets lors de l'utilisation de nombres récapitulatifs et de texte dynamique avec plusieurs DataSets.

### Rapports planifiés

- Les doubles crochets dans la ligne d'objet d'un Rapport planifié empêchaient l'enregistrement du rapport.

### Tâches et projets

- Les utilisateurs tentant d'accéder à des projets privés qu'ils ne sont pas autorisés à voir reçoivent désormais un message d'accès refusé approprié au lieu d'une erreur.

### Flux de travail

- Dans les flux de travail, les caractères HTML dans les actions Send Email n'étaient pas correctement échappés, ce qui amenait les entrées de texte à conserver des barres obliques échappées pouvant rompre la mise en forme des e-mails.
