## Version du 5 novembre 2026

### AI Labs

- Ajoute un nouveau rapport DomoStats, "AI Operations", avec des métriques d'utilisation et de performances pour les fonctionnalités IA.
- Les administrateurs peuvent activer ou désactiver le toolkit Domo SQL dans AI Services.
- Les tâches de traitement de données non structurées d'AI Labs pouvaient échouer sans afficher d'informations sur l'erreur.
- Les cartes d'AI Library affichaient un espace gris vide au lieu d'icônes lorsqu'elles étaient intégrées via Domo Everywhere ou dans des publications.
- Contrôlez Automated Insights et les métriques indépendamment dans AI Labs.
- Les agents et toolkits personnalisés dans AI Labs fonctionnent désormais indépendamment de Conversation par IA.
- Introduit Conversation par IA V2 avec des rapports de consommation améliorés et un affichage mis à jour du badge Pro.
- Recherchez des FileSets par leur ID.
- La carte Report Builder Toolkit dans l'AI Library n'avait pas d'icône.

### AI Services

- Ajoute des noms d'affichage au suivi de l'utilisation d'AI Services pour améliorer l'identification des fonctionnalités dans les analyses.
- Les mosaïques AI Agent dans les flux de travail ne pouvaient pas accéder à certains types de fichiers depuis Document Collections en tant que sources de connaissances.
- Le journal d'activité des paramètres AI Agent affichait "Ai chat tool" dans les colonnes Type et Event au lieu du nom spécifique de l'outil qui avait été modifié.
- La mosaïque Agent dans les flux de travail pouvait échouer lors de l'utilisation de sorties structurées.
- La fonctionnalité Automated Insights était incorrectement masquée ou inaccessible dans certaines parties de l'interface.

### Alertes

- Les alertes sur les DataSets avec Personalized Data Permissions activées n'envoyaient pas de notifications aux abonnés lorsque le seuil de l'alerte était franchi.
- Les alertes DataSet avec Personalized Data Permissions (PDP) configurées dans un contexte partagé n'envoyaient pas de webhooks, empêchant le déclenchement des campagnes comme prévu.
- La boîte de dialogue de partage de certaines alertes de colonne restait bloquée sur "Searching" et empêchait l'ajout de nouveaux utilisateurs ou groupes sur les DataSets avec Personalized Data Permissions lorsque plus de 200 utilisateurs avaient accès via des politiques PDP.
- Les utilisateurs disposant du droit "Use Alerts" ne pouvaient pas voir ni recevoir les alertes partagées avec eux s'ils n'avaient pas accès au DataSet sous-jacent.

### App Platform

- La création d'une carte à partir de l'Asset Library ignorait l'écran de câblage pour les conceptions nécessitant des mappages de flux de travail, des mappages Code Engine ou une configuration de brick de l'éditeur de code, produisant des cartes incomplètes ; l'écran de câblage apparaît désormais lorsque ces éléments nécessitent une configuration.
- Les DataSets Change Data Capture (CDC) existants utilisent désormais les paramètres d'analyse par défaut mis à jour.
- Les DataSets à faible latence créés par des non-propriétaires n'étaient pas visibles pour le propriétaire du DataSet, uniquement pour les utilisateurs administrateurs.
- Les requêtes vers les DataSets à partir d'applications personnalisées pouvaient échouer avec une erreur.
- Le Pro-Code Editor générait des alias de colonne entièrement en minuscules au lieu de conserver la casse d'origine des noms de colonne du DataSet.

### App Studio

- Les graphiques en boîte à moustaches dans App Studio s'affichaient comme des graphiques à barres après l'application d'un filtre, n'affichant que les valeurs maximale et minimale au lieu de la distribution complète de la boîte à moustaches.
- Les Editable Tables dans App Studio pouvaient ne pas accepter la saisie lorsque la casse du nom de colonne du schéma du DataSet était modifiée.
- Dans App Studio, les composants Grid et List affichaient un message "Power from data to configure search" même lorsqu'un DataSet était déjà connecté, empêchant les utilisateurs de configurer les colonnes de recherche et de tri.
- Les cartes de tableau dans les rapports planifiés App Studio perdaient la mise en forme de leur thème, comme les couleurs de ligne alternées, et affichaient des quadrillages inattendus.
- Les utilisateurs disposant de l'autorisation "Edit Data in Editable Table Cells" ne pouvaient pas modifier les cellules des tableaux modifiables App Studio utilisant des DataSets liés et avaient auparavant besoin de l'autorisation "Edit Cards" comme solution de contournement.

### Buzz

- Les boutons de la boîte de dialogue "Remove user from conversation" dans les sujets Buzz privés et les discussions de groupe ne répondaient pas, empêchant la suppression des utilisateurs des conversations.

### Cartes

- Les cartes restaient bloquées dans un état "Loading" ou "Filtering" et ne parvenaient pas à afficher les données lors du premier chargement des tableaux de bord.
- Les cartes regroupées par mois affichaient des étiquettes de mois en anglais (comme "2026-Jan") au lieu d'étiquettes localisées (comme "2026年1月") pour les utilisateurs non anglophones, affichant parfois "Data Not Available".
- Les variables de date et les comparaisons DATETIME n'appliquaient pas correctement le fuseau horaire de l'entreprise ; les dates se calculent désormais dans le bon fuseau horaire au premier chargement, et les colonnes Snowflake TIMESTAMP avec des informations de fuseau horaire ne sont plus décalées deux fois.
- Les boutons prédéfinis du sélecteur de dates développé sur les cartes cessaient de répondre et pouvaient se compresser en une ligne verticale après plusieurs clics.
- Les cartes de tableau affichaient des valeurs décimales brutes au lieu du format numérique configuré pour les colonnes décimales de haute précision ; elles appliquent désormais les paramètres de précision décimale, de mise en forme en pourcentage et de séparateur de milliers tels qu'ils sont configurés.
- Les utilisateurs disposant d'autorisations Editor ne pouvaient pas charger de nouvelles versions des Document Cards dont ils n'étaient pas propriétaires même lorsqu'ils disposaient d'un accès en modification ; les tentatives de téléchargement échouaient silencieusement ou renvoyaient une erreur d'autorisation.
- Les filtres de contrôle de variable appliqués dans les applications App Studio n'étaient pas appliqués lors de l'exportation des cartes par e-mail, ce qui faisait que les valeurs s'affichaient comme zéro dans l'exportation.

### Connecteurs

- La création d'un compte de connecteur TikTok Business pouvait échouer si le nom d'affichage TikTok contenait un emoji.
- Dans le connecteur JSON No Code, les modifications de configuration effectuées avec l'assistant IA étaient perdues lors du retour à une étape précédente.
- Le téléchargement de plusieurs fichiers consécutifs dans le connecteur File Upload pouvait provoquer le gel de l'interface et l'empêcher de passer à l'écran d'aperçu.

### Data Center

- Les DataSet Views créées à partir de DataSets fédérés ne pouvaient pas être modifiées et affichaient l'erreur "Something went wrong while trying to edit this view".
- La boîte de dialogue de partage de compte ne s'ouvrait pas si un groupe précédemment partagé avait été supprimé ; elle affiche désormais tous les utilisateurs et groupes partagés et permet de supprimer les partages vers des groupes supprimés.

### Traitement des données

- Les DataFlows Magic ETL pouvaient rester bloqués au statut PREPARING ou EXPORTING jusqu'à 24 heures lorsque de nombreux DataFlows étaient déclenchés en même temps, par exemple lorsque plusieurs DataSets Snowflake se mettaient à jour simultanément ; les DataFlows concernés se terminent ou échouent désormais avec un statut clair au lieu de rester bloqués.

### Requête de données

- Les calculs Beast Mode utilisant des fonctions FIXED dans des clauses CASE WHEN pouvaient générer une erreur "invalid column", empêchant le rendu de la carte.
- Change Data Capture (CDC) ne produisait pas de DataSets dans certains cas.

### Embed

- Les tableaux de bord intégrés étaient coupés en bas, empêchant les utilisateurs de voir les parties inférieures des cartes, les barres de défilement des tableaux et les étiquettes des axes.
- Les sélections de segment et de variable dans les applications App Studio intégrées ne filtraient pas les cartes dépendantes ; les sélections s'appliquent désormais correctement dans les intégrations privées et publiques.
- L'icône de filtre n'apparaissait pas sur les cartes développées dans les intégrations privées même lorsque le filtrage était activé ; vous pouvez désormais ajouter des filtres directement aux cartes dans les applications App Studio intégrées.

### Données fédérées

- Les cartes et les Rapports planifiés utilisant des DataSets BigQuery ne se chargeaient pas avec des erreurs "Invalid field name" lorsque les noms de colonne contenaient des caractères spéciaux tels que des barres obliques, des parenthèses ou des virgules, affectant à la fois les DataSets BigQuery fédérés et les intégrations BigQuery Cloud Amplifier.

### Personalized Data Permissions

- Certaines politiques de ligne PDP dans un DataSet n'apparaissaient pas dans le tableau DomoStats Row Assignment, même après l'exécution du DataSet.

### Publish

- Les DataSets pouvaient ne pas se publier vers les instances Domo Everywhere, affichant un message d'erreur générique demandant aux utilisateurs de réessayer.
- Les options de variable dans les instances d'abonnés Publish n'apparaissaient pas correctement sur les cartes développées même si elles s'affichaient correctement dans le panneau de contrôle au niveau de la page ; toutes les options configurées se publient et s'affichent désormais de manière cohérente dans les deux vues.

### Sandbox

- Dans Sandbox, la promotion et la liaison d'un référentiel sur la même instance pouvaient échouer avec une erreur inattendue.

### Rapports planifiés

- Les doubles crochets ([[]]) dans les lignes d'objet des e-mails de Rapport planifié empêchaient l'activation du bouton Planifier, bloquant les utilisateurs pour enregistrer le rapport.

### Flux de travail

- Le bloc Query DataSet dans Workflows affichait les types de colonne de sortie comme "Object" au lieu de leurs types de données réels (tels que Text ou Date-Time), empêchant les utilisateurs de configurer les actions en aval.

### Espaces de travail

- Les Espaces de travail pouvaient disparaître après l'actualisation de la page lorsque l'utilisateur n'appartenait qu'à des groupes masqués ou inactifs.
