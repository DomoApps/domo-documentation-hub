## はじめに

Domoワークフローは、Domo AIサービスレイヤー、特にAIプレイグラウンドの各種サービスと統合されます。標準オプションと高度なオプションが用意されています。

お使いのインスタンスでこれらのサービスを有効にするには、[ai@domo.com](mailto:ai@domo.com)にお問い合わせください。

AIサービスレイヤーの詳細については[こちら](/s/article/000005279)を、AIプレイグラウンドの詳細については[こちら](/s/article/000005236)を参照してください。

Domo.AIの詳細については、[こちら](https://ai.domo.com/)を参照してください。

## ワークフロー内のAIサービスレイヤーにアクセスする

インスタンスでAIサービスレイヤーを有効にした後で、AIサービスレイヤー（標準オプションと高度なオプションの両方）にアクセスするには、次の手順を実行します。

1. ナビゲーションヘッダーで、**［その他］**>**［ワークフロー］**を選択してワークフローのランディングページを表示します。
2. 既存のワークフローを選択するか、**［+新しいワークフロー］**を選択します。
3. この記事で、[標準のAIサービスレイヤー統合](#standard-ai-service-layer-integration)または[高度なAIサービスレイヤー統合](#advanced-ai-service-layer-integration)のいずれかの説明に進み、記載されている手順を実行します。

<Frame>![workflows landing page.jpg](/images/kb/0EMVq000000BuTV.jpg)</Frame>

## 標準のAIサービスレイヤー統合

新規または既存のワークフローを開いた後、以下の手順を実行して標準のAIサービスレイヤー関数を追加します。

1. （条件付き）新しいワークフローの場合は、最初に［開始］タイプを選択します。
2. **［追加］**>**［サービスタスク］**の順に選択します。
3. キャンバス右側の設定パネルにある**［マッピング］**タブで、**［関数を確認］**を選択し、使用可能なパッケージを表示させます。  
     

   <Frame>![explore functions.jpg](/images/kb/0EMVq000000CE7F.jpg)</Frame>

      
     
   **［パッケージ］**モーダルが表示されます。
4. モーダルで検索バーを使い、「**Domo AI Services Layer**」と入力してパッケージを探します。
5. 検索バーで［Domo AI Services Layer］オプションを見つけます。  
     

   <Frame>![domo ai services layer.jpg](/images/kb/0EMVq000000CEFJ.jpg)</Frame>
6. ［Domo AI Services Layer］を選択すると、利用可能な関数が表示されます。次の中から、フローに追加するものを選択します。
   - Ask for SQL Query
   - Ask for Text
   - Ask for Beast Mode
   - Ask for Summary  
       

     <Frame>![Screenshot 2024-01-12 at 1.43.41 PM.png](/images/kb/0EMVq000000CENN.jpg)</Frame>

### Ask for SQL Query

Ask for SQL Query関数を使用すると、自然言語による質問を正確なSQLクエリに変換できます。AIプレイグラウンドのテキストからSQL機能と同様に、出力されるSQLクエリのパラメーターを入力してマッピングしたり、入力と出力をテストしたりできます。

<Frame>![Screenshot](/images/kb/0EMVq000000BugP.jpg)</Frame>

### Ask for Text

Ask for Text関数を使用すると、ニーズに合わせてプロンプト固有の応答を生成できます。出力されるテキストクエリのパラメーターを入力してマッピングしたり、入力と出力をテストしたりできます。

<Frame>![testing for text.jpg](/images/kb/0EMVq000000Bui1.jpg)</Frame>

### Ask for Beast Mode

Ask for Beast Mode関数を使用すると、自然言語による質問を正確なBeast Modeクエリに変換できます。出力されるBeast Modeクエリのパラメーターを入力してマッピングしたり、入力と出力をテストしたりできます。

<Frame>![testing for beast mode.jpg](/images/kb/0EMVq000000Bujd.jpg)</Frame>

### Ask for Summary

Ask for Summary関数を使用すると、プロンプトを要約できます。出力される要約クエリのパラメーターを入力してマッピングしたり、入力と出力をテストしたりできます。

<Frame>![Screenshot](/images/kb/0EMVq000000BulF.jpg)</Frame>

## 高度なAIサービスレイヤー統合

新規または既存のワークフローを開いた後、以下の手順を実行して高度なAIサービスレイヤー関数を追加します。

1. 新しい操作を追加し、**［関数を確認］**を選択します。
2. 検索バーで**［Domo AI Services Layer – Advanced］**オプションを見つけます。
3. **［Domo AI Services Layer – Advanced］**を選択すると、利用可能な関数が表示されます。次の中から、追加するものを選択します。
   - [Ask for SQL payload](#ask-for-sql-payload)
   - [Ask for text payload](#ask-for-text-payload)
   - [Ask for Beast Mode payload](#ask-for-beast-mode-payload)
   - Ask for summary payload

高度なオプションでは、標準オプションよりも詳細な設定が可能です。

<Frame>![Screenshot](/images/kb/0EMVq000000ButJ.jpg)</Frame>

### Ask for SQL Payload

Ask for SQL Payload関数は、自然言語による質問を正確なSQLクエリに変換し、ペイロードを返します。また、より詳細な入力オプションや出力オプションを利用できます。次の入力パラメーターを定義できます。

- dataset
- input prompt
- model
- modelConfiguration
- parameters
- promptTemplate

また、次の出力パラメーターと出力のマッピングも定義できます。 

<Frame>![Screenshot](/images/kb/0EMVq000000BvKj.jpg)</Frame>

### Ask for Text Payload

Ask for Text Payload関数は、ニーズに合わせてプロンプト固有の応答を生成し、ペイロードを返します。また、より多くの入力オプションや出力オプションを利用できます。 この関数を使用すると、次のマッピングを設定できます。

- input prompt
- model
- modelConfiguration
- parameters
- promptTemplate

次の出力パラメーターもマッピングできます。

- generatedText
- isCustomerModel
- modelId
- prompt

<Frame>![Screenshot](/images/kb/0EMVq000000BvPZ.jpg)</Frame>

### Ask for Beast Mode Payload

Ask for Beast Mode Payload関数は、自然言語による質問を正確なBeast Mode計算に変換し、ペイロードを返します。また、より多くの入力オプションや出力オプションを利用できます。この関数を使用すると、次のパラメーターをマッピングできます。

- chatContext
- dataSet
- input prompt
- modelConfiguration
- parameters
- promptTemplate
- system

次の出力パラメーターもマッピングできます。

- beastMode
- isCustomerModel
- modelId
- prompt
- choices

### <Frame>![Screenshot](/images/kb/0EMVq000000BvRB.jpg)</Frame>

### Ask for Summary Payload

Ask for Summary Payload関数は、プロンプトを要約し、ペイロードを返します。この関数を使用すると、次の[入力パラメーター](#input-parameters)をマッピングできます。必須パラメーターにはアスタリスク（\*）が付いています。

- chatContext
- chunkingConfiguration
- model
- modelConfiguration
- parameters
- prompt\*
- promptTemplate
- sizeBoundary
- summarizationOutputStyle
- summarizationStrategy
- system

Ask for Summary Payloadでは、次の[出力パラメーター](#output-parameters)をマッピングできます。

- choices
- isCustomerModel
- modelId
- prompt
- summary

## 入力パラメーターリファレンス

| パラメーター | データタイプ | 定義 |
| --- | --- | --- |
| chatContext |  | 現在のリクエストで考慮される、AIとユーザー間のメッセージ履歴のリスト。 |
| chunkingConfiguration |  | 大きなドキュメントでは、ドキュメントが長すぎてコンテキストウィンドウに収まらない場合があるため、各リクエストにすべてのテキストを含めることはできません。チャンク構成は、ドキュメントをいくつかの小さなパーツやチャンクに分割する方法を示すのに役立ちます。   |  |  | | --- | --- | | `chunkOverlap` | テキストを重複させることができ、ドキュメント内のチャンクをどのような方法でグループ分けするかにおいて、文脈を与えるのに役立ちます。整数値は、連続するチャンク間の重複のサイズを定義します。 | | `disallowIntermediateChunks` | 非常に長いテキストを要約しようとすると、チャンクが要約され、まとめられてもなお、テキストがまだ長すぎることがあります。こうしたケースでは、`disallowIntermediateChunks`をfalseに設定しない限り、要約の要約を得ることになります。 | | `maxChunkSize` | チャンクの最大サイズを指定する整数値 | | `separators` | チャンクの分割を最も望ましい方法から最も望ましくない方法へと順番に実行するために使用される、String値のリスト。 例えば、["\n\n", "\n", ".", ""] は、連続する2つの改行を最初に（最大チャンクサイズの範囲内で）分割し、次に単一の改行、それからピリオド、その後に任意の文字で区切ります。 | | `separatorType` | 事前定義済みのセパレーターのタイプ。デフォルトはTextで、HTML、JavaScript、Pythonが含まれています。 | |
| dataSet |  | リクエストで使用されるDataSetのID。 |
| generatedText |  | プロンプトを格納するオブジェクト。 |
| isCustomerModel |  |  |
| model | text | リクエストの送信先のAI。  例：GPT-4、Claude 2.1 |
| modelConfiguration |  | 選択した言語モデルのカスタム構成パラメーターを含むマップ。 |
| modelId |  |  |
| sizeBoundary |  | 最小長と最大長の間の境界として表される出力テキストの望ましい長さ。 |
| parameters |  | promptTemplateに挿入できる変数。 |
| prompt | text | 関数の実行に必要な指示のためのフィールド。 |
| promptTemplate | text | プレースホルダー変数をサポートするテキストのテンプレート。これによりユーザーは、大規模言語モデルへの入力を簡単に整理できます。  例： `Summarize the following text to be no longer than ${max_word_count} words: ${input}` |
| SQL |  | SQLでのリクエストの出力。 |
| summarizationOutputStyle |  | 箇条書き、番号付き、または段落 |
| summarizationStrategy |  | 与えられた入力を要約する際に従う手法。現在利用可能な手法には、STUFFINGやMAP\_REDUCEなどがあります。 |
| system |  | モデルのシステムプロンプトを設定できます。 |
