## はじめに

Procore Analytics API（クラウドコネクター）は、Delta Shareプロトコルを使用して、分析とレポート作成に適したProcoreデータへのセキュアな読み取り専用アクセスを提供します。トランザクションREST呼び出しではなく大量のデータ消費を想定して設計されているため、BIツール、データウェアハウス、カスタム分析システムを、共有認証情報を使用してProcoreの構造化DataSetに直接接続できます。

APIへのアクセスは、会社で使用可能なProcoreデータを認証および定義するBearerトークン、エンドポイント、共有を使用して確立されます。接続されると、schemaNameとtableNameを指定してデータを取得できます。スキーマはデータの論理グループを表し、テーブルは特定のDataSetを表します。これらのパラメーターを使用すると、Procoreで有効になっているモジュールに応じて、プロジェクト、予算、コミットメント、請求書、RFI、提出物、ログなどのプロジェクト/財務/業務データを含む完全なテーブルを抽出できます。この設定により、一貫性と拡張性に優れたデータ抽出が可能になるため、分析およびレポート作成のユースケースに最適です。

Procore Analyticsアカウントには、Data Centerから接続します。このトピックでは、Procore Analyticsコネクターのユーザーインターフェースに固有のフィールドとメニューについて説明します。DataSetの追加、更新スケジュールの設定、およびDataSet情報の編集方法については、「[コネクターを使用してDataSetを追加する](/s/article/360042926274)」を参照してください。

## 必要条件

Procore Analyticsアカウントに接続してDataSetを作成するには、以下が必要です。

- Bearerトークン
- エンドポイント
- 共有

### データアクセス認証情報を生成する

Procoreデータには、Delta Shareトークンメソッドを使用してアクセスできます。アクセストークンは、データにアクセスするために適切なデータコネクターに入力する数字列です。

アクセストークンを生成するには、次の手順に従います。

<Note>

**注記：**

- 会社のProcoreアカウントで、Procore Analyticsツールを会社レベルで有効にしておく必要があります。
- アクセストークンを生成するには、Procore Analyticsツールへの管理者レベルのアクセス権が必要です。

</Note>

1. Procoreにログインします。
2. ナビゲーションバーの右上にある**アカウントとプロフィール**のアイコンをクリックします。  

   <Frame>![スクリーンショット](/images/kb/0EMVq00000FdgZp.jpg)</Frame>
3. **［My Profile Settings］**をクリックします。
4. **［Choose Your Connection with Procore Analytics］**で、Delta Shareオプションを使用して個人用アクセストークンを生成します。
5. **［Delta Share Token］**を選択して有効期限を選択します。  

   <Frame>![スクリーンショット](/images/kb/0EMVq00000FYyU9.jpg)</Frame>
6. **［Generate Tokens］**をクリックします。

   <Note>**注記：** Procoreではユーザー用のトークンは保存されないため、今後の参照用にトークンをコピーして保存しておくことを推奨します。</Note>

7. データへのアクセスと統合を開始するには、［Bearer Token］、［Share Name］、［Delta sharing server URL］（コネクターのエンドポイント/ベースURL）、［Share Credentials Version］を使用します。
   - **注記：**
     - トークンは1時間後、またはページから移動すると消えます。新しいトークンを生成するには、ステップ1に戻ります。
     - データが表示されるまでに最大24時間かかる場合があります。
     - この処理中はトークンを再生成しないでください。トークンに問題が発生する可能性があります。

   <Frame>![スクリーンショット](/images/kb/0EMVq00000FYycD.jpg)</Frame>

## Procore Analyticsアカウントに接続する

このセクションでは、Procore Analyticsコネクターページの**［認証情報］**ペインと**［詳細］**ペインのオプションについて説明します。このページのほかのペインの項目である**［スケジュール設定］**や**［DataSetに名前を付け、説明を入力］**に関しては、ほとんどのタイプのコネクターで共通しています。詳細については、「[コネクターを使用してDataSetを追加する](/s/article/360042926274)」を参照してください。

## ［認証情報］ペイン

このペインには、Procore Analyticsアカウントに接続するための認証情報の入力フィールドが含まれています。以下の表では、各フィールドに必要な内容を説明しています。  

| フィールド   | 説明                         |
| ------------ | ---------------------------- |
| Bearer Token | Bearerトークンを入力します。 |
| Endpoint     | エンドポイントを入力します。 |
| Share        | 共有を入力します。           |

有効なProcore Analytics認証情報を一度入力しておくと、いつでも同じアカウントを使用して新しいProcore Analytics DataSetを作成することができます。コネクターアカウントは、Data Centerの**［アカウント］**タブで管理することができます。このタブの詳細については、「[コネクター/アダプターアカウントを管理する](/s/article/360042926054)」を参照してください。

## ［詳細］ペイン

| メニュー    | 説明                     |
| ----------- | ------------------------ |
| Schema Name | スキーマ名を入力します。 |
| Table Name  | テーブル名を入力します。 |
