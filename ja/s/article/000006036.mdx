## はじめに

JSON Expand操作を使用すると、列に格納されているJSONデータを構造化された表形式の出力に変換できます。

この操作は、JSONデータを格納しているソース列を取得し、データの構造と一致する設定可能なJSON操作ツリーを適用します。フィールドの展開方法や、書式設定、列への配置方法をコントロールして、後工程での変換に適した行と列を作成できます。

---

## JSON操作の基礎

JSON Expand操作は、JSONデータを格納しているソース列から開始します。

ソース列には、ルートレベルのJSON操作を1つ含めることができます。デフォルトでは、列操作が選択されています。

展開操作には、ネストされた展開操作や列レベルの操作を追加できます。

列レベルの操作はJSON操作ツリーの葉ノードを表し、ネストされた操作を含めることはできません。

操作ツリーの各レベルでは、［行に展開する］操作は1つだけ存在できます。

JSON Expand操作には、次の3つの主な操作タイプがあります。

- **展開**
- **抽出**
- **列に配置**

<Frame>![スクリーンショット](/images/kb/0EMVu00000TbQNp.jpg)</Frame>

### 展開操作

展開操作は、JSONオブジェクトまたはJSON配列のいずれかで実行できます。ネストされた操作は、展開されるオブジェクトまたは配列のすべての要素に適用されます。

- **配列を行に変換（JSON配列）—** ［配列を行に変換］はJSON配列を取得し、配列内のインデックスごとに新しい行を作成します。
- **オブジェクトを行に変換（JSONオブジェクト）—** ［オブジェクトを行に変換］はJSONオブジェクトを取得し、キーと値のペアごとに新しい行を作成します。出力には次の項目が含まれます。
  1. オブジェクトキーの列
  2. 対応する値の列

### 抽出操作

これらはJSON配列またはJSONオブジェクトのいずれかで実行され、各インデックス/キーの列レベルの設定を可能にします。

- **配列を列に変換（JSON配列）—** ［配列を列に変換］を使用すると、JSON配列の各インデックスに新しいJSON操作を設定できます。
- **オブジェクトを列に変換（JSONオブジェクト）—** ［オブジェクトを列に変換］を使用すると、JSONオブジェクトの各キーに新しいJSON操作を設定できます。

### 列に配置操作

列に配置操作は、任意のJSONデータで実行できます。

この操作では、次の項目を指定できます。

- 列名
- 出力のデータ型

列に配置は、次のいずれかに追加できます。

- ソース列に直接、または
- 展開操作の出力

## JSON Expand設定のインターフェース

 JSON Expand操作には、操作の設定時にJSON形式のデータを確認して展開するのに役立つ、切り替え可能な3つのパネルが含まれています。

- サンプルJSON
- JSON操作の設定
- 表のプレビュー

### ソース列を選択する

ソース列は、毎回のDataFlowの実行中にJSONデータが取得される場所を決定します。

1. JSON Expand操作の設定ペインで、右上隅にある**［ソース列の選択］**ドロップダウンメニューを選択します。
2. JSONデータが格納されている列を選択します。  

   <Frame>![コンピューターのスクリーンショット。AIで生成されたコンテンツは、実際とは異なる可能性があります。](/images/kb/0EMVu00000TbRAD.jpg)</Frame>

     
   JSONデータが格納されている列を選択すると、ソース列のJSONデータのプレビューが［サンプルJSON］パネルに自動的に読み込まれます。
3. いつでも**［プレビューから再入力］**を選択してサンプルを更新できます。  
   プレビューにすべての必須のフィールドや構造が含まれていない場合は、［サンプルJSON］パネルでJSONを直接編集することもできます。

［サンプルJSON］パネルの右下隅では、次の操作を実行できます。

- JSONを整えて読みやすくする
- ダークモードとライトモードを切り替える

## ［JSON操作の設定］ツリーをナビゲートする

［JSON操作の設定］ツリーを使用して、ネストされた操作の作成と管理を行えます。

1. ルート列名の横にある下キャレットを選択します。
2. 適用する操作を選択します。  
   各操作によって、ツリーに新しいレベルが追加されます。
3. 各レベルで下キャレットを選択して、JSON構造の展開を続けます。

ツリーの各レベルは、JSON構造をさらに深く展開したことを表しています。

## 追加のツール

ネストされたJSON操作を設定していると、複雑になる可能性があります。特に、DataFlowの実行中に受け取ったJSONデータの明確な例がないと、複雑になりがちです。設定ウィンドウには、セットアップや検証を簡素化するためのツールがいくつか用意されています。

### サンプルJSONエディター

サンプルJSONエディターを使用すると、DataFlowの実行中に想定されるJSONデータのダミーを使用することができます。

- JSONをエディターに直接ペーストするか、エディターで直接編集する
- 組み込みの書式設定ツールを使用して、JSONの検査とクリーンアップを行う
- 有効なJSONが存在する場合に、操作グラフがそのJSONを使用して、設定ツリー内の利用可能なブランチにデータを入力する

JSONを手動で入力する代わりに、**［プレビューから再入力］**を選択することで、DataFlowのプレビューを実行し、自動的にサンプルJSONを読み込むことができます。

### 自動展開

**［自動展開］**を選択すると、サンプルJSONに基づいてJSON操作ツリーが自動的に生成されます。Domoでは、事前定義されたJSON解析アルゴリズムを使用して、データを表形式に変換します。

各ブランチをできるだけ深く展開するには、次の手順を実行します。

1. **［自動展開］**の横にある下キャレットを選択します。
2. **［自動展開（深い）］**を選択します。

<Frame>![コンピューターのスクリーンショット。AIで生成されたコンテンツは、実際とは異なる可能性があります。](/images/kb/0EMVu00000TbRrl.jpg)</Frame>

自動展開は、強力な開始点となります。個々の操作を改善したり調整したりして、求めていたとおりの出力を生成できます。

<Frame>![スクリーンショット](/images/kb/0EMVu00000TbMAZ.jpg)</Frame>

### JSONを表形式でプレビュー

［表］パネルには、JSON操作によって生成された出力のライブプレビューが表示されます。

［表］パネルを切り替えると、列と行が設定されているとおりに表示されます。

操作が追加または変更されると、プレビューがリアルタイムで更新されます。

サンプルJSONエディターと一緒に使用すると、表のプレビューでは、設定の変更が最終的な出力にどのように影響するかに関するフィードバックを即座に確認できます。
