## はじめに

世界中の何万もの企業がAWSを利用して、クラウド計算プラットフォームを稼働させています。これはクラウドコンピューティングの力を活用し、会社の技術力をスケールアップするための信頼性が高く効率的な方法ですが、一方で決定的な重要性を持っています。使用状況を監視できる機能があるので、請求額に驚かされることもなく、クラウドを使用するための予算を簡単に立てることができます。  
AWS Cost and Usageコネクターは、AWSの使用状況を可視化し、AWSの使用状況を最適化してくれます。必要なクリティカルメトリクスをすべてひと目で確認でき、必要に応じて詳細な情報を取得できます。

AWS Cost and Usageレポートには、AWSサービス、価格、予約（例：Amazon EC2 Reserved Instances（RI））に関する追加メタデータを含む、最も包括的なAWSのコストと使用状況のデータが含まれています。このコネクターを使用すると、最新のAWS Cost and Usageレポートデータを取得できます。コネクターの最初の実行は、現在の年のデータを取得します。以降の実行は履歴データを取得します。以降の実行では、コネクターはファイル上の修正された日付を確認し、修正されたデータがあれば、再度データを取得します。AWS APIについて詳しくは、Amazonのウェブサイト（[https://docs.aws.amazon.com/AmazonS3/latest/dev/auth-request-sig-v2.html](https://docs.aws.amazon.com/AmazonS3/latest/dev/auth-request-sig-v2.html)）を参照してください。

AWS Cost and UsageアカウントにはData Centerから接続します。このトピックでは、AWS Cost and Usageコネクターのユーザーインターフェースに固有のフィールドとメニューについて説明します。DataSetの追加や更新スケジュールの設定、DataSet情報の編集に関する一般的な情報は、「[コネクターを使用してDataSetを追加する](/s/article/360042926274)」を参照してください

## この機能を取得する

<Note>**注記：** この機能の使用を希望される場合は、カスタマーサクセスマネージャー（CSM）にお問い合わせください。</Note>

この機能の有効化をリクエストするには、次の手順を実行します。

1. Domoのカスタマーサクセスマネージャー（CSM）、テクニカルコンサルタント（TC）、AEのいずれかにお問い合わせください。
2. 担当のCSM、TC、AEの連絡先が不明な場合は、[Domoテクニカルサポート](https://www.domo.com/client-services/domo-support)にお問い合わせください。

## 必要条件

このコネクターを設定するには、以下の情報が必要です。

- CURレポートがあるAmazon S3バケットの名前
- AWS BillingでCURレポートを設定する際に使用したレポート名
- AWSアクセスキーとシークレットキー
- S3バケットがあるAWSリージョン

### AWSでCost and Usageレポートを作成するには：

1. [https://console.aws.amazon.com/billing/home#/reports](https://console.aws.amazon.com/billing/home#/reports)にアクセスします。
2. **［Create Report］**ボタンをクリックします。
3. レポート名を入力し、必要なオプションを選択して**［Next］**ボタンをクリックします。

<Frame>![clipboard_ef23d883232801bd10f779e789eabe244.png](/images/kb/0EM5w000005vO07.png)</Frame>

4. レポートの配信オプションを設定します。

5. AWS Cost and Usageレポートを受け取るには、Amazon S3バケットを作成し、適切なアクセス権限を設定する必要があります。既存のバケットを追加することも、新規に作成することもできます。

<Frame>![clipboard_ed5b0b3a131be1d0db16b602c6b691a47.png](/images/kb/0EM5w000005vNzw.png)</Frame>

<Warning>**重要：** Cost and Usageレポートを作成する際には、**レポートパスのプレフィックス**と**レポート名**を確認します。これらの情報は、コネクターのUIの［認証情報］セクションに入力する必要があります。</Warning>

6. **［Next］**ボタンをクリックしてレポートの設定を確認し、レポートを作成します。

## AWS Cost and Usageアカウントに接続する

このセクションでは、AWS Cost and Usageコネクターページの**［認証情報］**ペインおよび**［詳細］**ペインのオプションについて説明します。このページのほかのペインの項目である**［スケジュール設定］**や**［DataSetに名前を付け、説明を入力］**に関しては、ほとんどのタイプのコネクターで共通しています。詳細については、「[コネクターを使用してDataSetを追加する](/s/article/360042926274)」を参照してください。

### ［認証情報］ペイン

このペインには、AWS Cost and Usageアカウントに接続する認証情報の入力フィールドがあります。以下の表では、各フィールドに必要な内容を説明しています。  

| フィールド          | 説明                                                         |
| ------------------- | ------------------------------------------------------------ |
| Bucket              | CURレポートがあるAmazon S3バケットの名前を入力します。       |
| Region              | Amazon S3のリージョンを選択します。                          |
| Report Path Prefix  | CURレポートがあるパスを入力します。                          |
| Report Name         | AWS BillingでCURレポートを設定したときと同じ値を入力します。 |
| Authentication Type | 認証方式を選択します。                                       |
| Key-Access          | AWSアクセスキーを入力します。                                |
| Key-Secret          | AWSシークレットキーを入力します。                            |

有効なAWS Cost and Usageの認証情報を一度入力しておくと、いつでもコネクターを実行してCost and Usageレポートデータを取得することができます。 

<Note>**注記：** 認証タイプを選択する際は、認証パラメーターがすべてのデータを格納しているS3フォルダーへの読み取りアクセス権を持つことを確認してください。</Note>

### ［詳細］ペイン

#### AWS Cost and Usageの実行手順

コネクターの最初の実行は、現在の月のデータを取得します。以降の実行は、今月が更新されたかどうかをチェックし、月ごとに遡ってデータの取得を開始します。

コネクターはファイル上の修正された日付を確認し、修正されたデータがあれば、再度データを取得します。
