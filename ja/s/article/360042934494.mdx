---
title: "アクセストークンを管理する"
excerpt: "Domo へのデータインポートやエクスポートに使用するアクセストークンを生成、ユーザーに割り当て、必要に応じて取り消します。"
---

アクセストークンはDomoにデータをインポートする、またはDomoからデータをエクスポートするのに使用します。「管理者」のデフォルトセキュリティ権限またはカスタム権限で、「全てのカンパニー設定を管理」または「全てのアクセストークンを管理」が有効になっている場合、アクセストークンを生成することができます。そうでない場合は、Domoの管理者にアクセストークンをリクエストする必要があります。デフォルトのセキュリティ権限の詳細については、「[カスタム権限を管理する](/s/article/360043438973)」を参照してください。

<Warning>**重要：**アクセストークンは特定のユーザーアカウントに関連付けられており、そのユーザーと同じアクセス権を持ちます。ユーザーの権限が変更されると、アクセストークンにも反映されます。ユーザーは、ほかのユーザーとアクセストークンを共有することはできません。</Warning>

<Frame>![Screenshot](/images/kb/ja/0EM5w000005wL3B.jpg)</Frame>

**アクセストークンを生成するには：**

1. **［その他］****>［管理者］**の順にクリックします。
2. **［認証］** **>** **［アクセストークン］**を選択します。
3. **［アクセストークンを管理］**ペインで**［アクセストークンを生成］**をクリックします。
4. トークン情報を指定します：

   1. **［アクセストークンの説明］**フィールドにトークン名を入力します。
   2. **［ユーザーを検索］**フィールドでトークンを与えるユーザー名を選択します。

<Warning>      **重要：**アクセストークンは特定のユーザーアカウントと関連しています。ユーザーは、ほかのユーザーとアクセストークンを共有することは*できません*。
   3. **［有効期限］**メニューから、トークンの有効期限が切れるまでの日数を選択します。
   4. **［生成する］**をクリックします。
5. アクセストークンをコピーし、後で使用できる場所に貼り付けます。  
   **［アクセストークン］**画面を閉じた後は、トークンを見ることは*できません*。</Warning>

**アクセストークンを取り消すには：**

1. **［その他］****>****［管理者］**の順にクリックします。  
   管理者設定が表示されます。
2. **［認証］** **>** **［アクセストークン］**を選択します。
3. **［アクセストークンを管理］**ペインで、その名前やユーザーでアクセストークンを検索し、**［取り消す］**リンクをクリックします。

## よくある質問

<AccordionGroup>
  <Accordion title="API コネクタ用のクライアント ID とシークレットの作成には、「全てのアクセストークンと API クライアントを管理」権限と「全てのアカウントを管理」権限のどちらが必要ですか？">
    クライアント ID とシークレットの作成は、いずれの権限にも紐付いていません。この記事で説明しているアクセストークンは、Domo の管理者セクションで生成するアクセストークンであり、[developer.domo.com](https://developer.domo.com) で作成するクライアント ID とクライアントシークレットから生成されるアクセストークンとは異なります。クライアント ID とシークレットを使用する際にアクセスできるデータは、そのユーザーの Domo でのロールと、Domo で共有されているコンテンツ（パーソナライズドデータパーミッション（PDP）によってさらに制限される場合があります）によって決まります。
  </Accordion>
  <Accordion title="API アカウントの使用には、「データセットアカウントを作成」権限と「データセットを編集」権限のどちらが必要ですか？">
    これらの権限の役割は異なります。**「データセットを編集」**権限がないと、Domo 上部の**［データ］**ナビゲーションボタンが表示されません。このボタンは、共有されたデータセットを編集するために必要です。**「データセットアカウントを作成」**権限を使用すると、Salesforce などの別のプラットフォームの認証情報を追加し、それをデータセットの基盤として利用できます。**「データセットを編集」**権限はあるが**「データセットアカウントを作成」**権限がない場合、データセットアカウントを作成しようとするとエラーが発生します。
  </Accordion>
  <Accordion title="「全てのアカウントを管理」権限と「データセットアカウントを作成」権限の違いは何ですか？">
    **「全てのアカウントを管理」**権限を使用すると、Domo 内の既存のアカウントの認証情報を編集したり、それらのアカウントを削除したりできます。これは、それらのアカウントを基盤とするデータセットの実行に影響します。これは非常に強力な権限であり、限られた一部のユーザーにのみ付与してください。**「データセットアカウントを作成」**権限を使用すると、ユーザーは自分が明示的にアクセス権を与えられたアカウント（自分自身が作成したものなど）のみを作成および管理できます。
  </Accordion>
</AccordionGroup>
