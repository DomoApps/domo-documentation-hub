## はじめに

この記事では、OAuth（推奨）または手動設定を使用してClaude Desktop、Claude Code、またはVS CodeをDomoのMCPサーバーに接続し、接続を検証する方法について説明します。

接続後、AIツールを使用して次のことができます。

- Domo DataSetのデータをクエリする
- Domoに保存されているドキュメントをクエリする
- Domoインスタンス全体を検索する
- カードとページを要約する（まもなく利用可能）

<Frame>![](/images/kb/DOMO-MCP-Server-Screenshot.png)</Frame>

## 必要な許可

次の許可があれば、AIライブラリ機能を使用できます。
* **AIサービスを利用する —** AIサービスレイヤーを使用して構築された機能やアプリにアクセスできます。
* **AIチャットを利用する —** Domo AIアシスタントにアクセスできます。

許可やカスタマイズされた権限については、[こちら](https://domo-support.domo.com/s/article/360043438973)を参照してください。

## 必要条件

<Note>
  **注記：** OAuthコネクターを使用する場合は、最初に有効にしておく必要があります。カスタマーサクセスマネージャー（CSM）に連絡して、有効化をリクエストしてください。
</Note>

**AIライブラリ**にアクセスして、**Domo Basic MCP**ツールキットからMCPサーバーURLを取得します。

```
https://<DOMO_DOMAIN>/api/ai/v1/assistant/mcp/toolkits/domo_basic_mcp
```

## カスタムコネクターを追加する

Claude CoworkまたはChatでは、Claude Desktopアプリの左側のサイドバーにある**［Customize］**メニューを使用して、AIエージェントをカスタマイズできます。

<Frame><img alt="claude_3" src="/images/kb/claude_3.png" /></Frame>

リモートMCPなどのサードパーティーアプリケーションをリンクするには、**［Customize］**>**［Connectors］**を選択して、Claudeにデータへのアクセス権を付与します。

<Frame><img alt="claude_2" src="/images/kb/claude_2.png" /></Frame>

MCPサーバーに名前を付け、**Domo Basic MCP** URLを**［Remote MCP server URL］**フィールドに貼り付け、**［Add］**を選択します。

```
https://<DOMO_DOMAIN>/api/ai/v1/assistant/mcp/toolkits/domo_basic_mcp
```

<Note>**注記：** `<DOMO_DOMAIN>`は実際のDomoインスタンスドメインで置き換えます（例：`mycompany.domo.com`）。</Note>

<Frame><img alt="claude_1" src="/images/kb/claude_1.png" /></Frame>

## OAuthに関するよくある質問

<AccordionGroup>

<Accordion title="Domoドメインが不明な場合はどうすればよいですか？">
  Domoドメインは、Domoへのログインに使用するURLのサブドメインです。例えば、Domo（`mycompany.domo.com`）にアクセスする場合、ドメインは`mycompany.domo.com`です。Domoドメインが不明な場合は、Domo管理者にお問い合わせください。
</Accordion>

<Accordion title="複数のDomoインスタンスを接続できますか？">
  はい。各インスタンスについて、固有のコネクター名とMCPサーバーURL内の対応するドメインを使用して、この記事の手順を繰り返します。
</Accordion>

<Accordion title="接続した後、Claudeはどのようなデータにアクセスできますか？">
  Claudeは、Domo Basic MCPツールキットが提供するデータとツールにアクセスできます。このツールキットには、DataSetのクエリやMCP APIで利用可能なDomo機能の操作などが含まれています。アクセスできるのは、Domoユーザーアカウントで閲覧が許可されている範囲です。
</Accordion>

## 手動で接続する

## 必要条件

接続する前に、次の条件が満たされていることを確認してください。

- **Node.js**バージョン21以降がインストールされている。[nvm](https://github.com/nvm-sh/nvm)を使用して、Node.jsバージョンを管理する。
- 適切な権限を持つDomo**アクセストークン**。これは**［管理者］**>**［認証］**>**［アクセストークン］**でプロビジョニングするか、MajorDomoにリクエストしてください。手順については、「[アクセストークンを管理する](/s/article/360042934494#manage-access-tokens)」を参照してください。
- サポートされているAIコードエディター（Claude Desktop、Claude Code、VS Code、Cursor、またはその他のMCP互換クライアント）。

## Claude Desktopを接続する

Claude DesktopはリモートMCPサーバーをネイティブではサポートしていないため、`mcp-remote`（デスクトップAIクライアントをリモートMCPサーバーにブリッジするNPMツール）を使用して接続します。

### ステップ1：アクセストークンをプロビジョニングする

Domoインスタンスで、**［管理者］**>**［認証］**>**［アクセストークン］**に進み、トークンを生成します。手順については、「[アクセストークンを管理する](/s/article/360042934494#manage-access-tokens)」を参照してください。

<Frame>![](/images/kb/DOMO-MCP-Server-Screenshot-2.png)</Frame>

### ステップ2：MCPリモートをインストールする

ターミナルを開き、次のコマンドを実行します。

```
npm install mcp-remote
```

### ステップ3：Claude Desktopをインストールする

[Claude Desktop](https://claude.com/ja/download)をダウンロードしてインストールします。

<Frame>![](/images/kb/DOMO-MCP-Server-Screenshot-3.png)</Frame>

### ステップ4：Claude Desktopの設定を編集する

Claude Desktopで**［Settings］**>**［Developer］**に進み、**［Edit Config］**を選択します。

<Frame>![](/images/kb/DOMO-MCP-Server-Screenshot-4.png)</Frame>

次の場所にある設定ファイルが開きます。

```
/Users/<username>/Library/Application Support/Claude/claude_desktop_config.json
```

<Frame>![](/images/kb/DOMO-MCP-Server-Screenshot-5.png)</Frame>

### ステップ5：Domo MCPサーバー設定を追加する

次のコンテンツをコンフィギュレーションファイルに貼り付けます。`<DOMO_DOMAIN>`はDomoインスタンスドメインに、`<DOMO_ACCESS_TOKEN>`はアクセストークンに置き換えます。

<Note>
  **注記：** これが最初の手動接続の場合は、最初の開き括弧`{`の直後に次のコンテンツを貼り付けます。ほかの手動接続がある場合は、`mcpServers`プロパティのコンテンツ（2番目のブロックの例）を貼り付けます。
</Note>


```json
  "mcpServers": {
    "domo-mcp-npx": {
      "command": "npx",
      "args": [
        "mcp-remote",
        "https://<DOMO_DOMAIN>/api/ai/v1/assistant/mcp/toolkits/DOMO_BASIC_MCP",
        "--header",
        "X-DOMO-DEVELOPER-TOKEN:<DOMO_ACCESS_TOKEN>"
      ]
    }
  }
```

```json
    "domo-mcp-npx": {
      "command": "npx",
      "args": [
        "mcp-remote",
        "https://<DOMO_DOMAIN>/api/ai/v1/assistant/mcp/toolkits/DOMO_BASIC_MCP",
        "--header",
        "X-DOMO-DEVELOPER-TOKEN:<DOMO_ACCESS_TOKEN>"
      ]
    }
```

### ステップ6：Claude Desktopを再起動する

Claude Desktopを終了して再起動し、設定を有効にします。

<Frame>![](/images/kb/DOMO-MCP-Server-Screenshot-6.png)</Frame>

### ステップ7：接続を確認する

**［Settings］**>**［Connectors］**に進み、Domo MCPサーバーがリストに表示され、接続されていることを確認します。

<Note>
  **注記：** コネクターは**［Customize］**に移動しました。ここでコネクターの閲覧、接続、管理を行うことができます。
</Note>

<Frame>![](/images/kb/DOMO-MCP-Server-Screenshot-7.png)</Frame>

サーバーのツールの権限を表示するには、サーバーを選択します。次のツールがリスト表示されます。

- `DomoSqlQueryTool`
- `ExtendedThinkingTool`
- `FileSetQueryTool`
- `SearchTool`

<Frame>![](/images/kb/DOMO-MCP-Server-Screenshot-8.png)</Frame>

接続をテストするには、「How many datasets do I have access to?」（アクセスできるDataSetはいくつですか？）などのプロンプトを試してください。

<Frame>![](/images/kb/DOMO-MCP-Server-Screenshot-9.png)</Frame>

## Claude Codeを接続する

Claude Codeで、プロジェクトのルートから次のコマンドを実行します。`<DOMO_DOMAIN>`はDomoインスタンスドメインで、`<DOMO_ACCESS_TOKEN>`はアクセストークンで置き換えます。

```bash
claude mcp add --transport http domo-mcp \
  https://<DOMO_DOMAIN>/api/ai/v1/assistant/mcp/toolkits/DOMO_BASIC_MCP \
  --header "X-DOMO-DEVELOPER-TOKEN: <DOMO_ACCESS_TOKEN>"
```

これにより、設定がプロジェクトのルートにある`.mcp`ファイルに追加されます。

```json
{
  "mcpServers": {
    "domo-mcp": {
      "type": "http",
      "url": "https://<DOMO_DOMAIN>/api/ai/v1/assistant/mcp/toolkits/DOMO_BASIC_MCP",
      "headers": {
        "X-DOMO-DEVELOPER-TOKEN": "<DOMO_ACCESS_TOKEN>"
      }
    }
  }
}
```

## 接続とコード

1. **Cmd+Shift+P**（Mac）または**Ctrl+Shift+P**（Windows/Linux）でコマンドパレットを開きます。

2. 設定範囲を選択します。
   - すべてのワークスペースで使用できる**グローバル（ユーザー）設定**（推奨）にする場合は、「**MCP: Open User Configuration**」を検索して選択します。
   - **ワークスペース固有の設定**（認証情報が漏洩する可能性があるため、セキュリティ上の理由で推奨されません）にする場合は、「**MCP: Open Workspace Folder MCP Configuration**」を検索して選択します。これにより、`.vscode/mcp.json`が作成されるか開きます。
   - **WSL設定**にする場合は、「**MCP: Open Remote User MCP Configuration**」を検索して選択します。これにより、`~/.vscode-server/data/User/mcp.json`が作成されるか開きます。

3. 設定ファイル内の`servers`オブジェクトに次の`domo-mcp`のエントリを、`inputs`配列に`domo-access-token`を追加します。`<DOMO_DOMAIN>`はDomoインスタンスドメインで置き換えます。サーバーを起動すると、アクセストークンの入力を求められます。

   ```json
   {
     "servers": {
       "domo-mcp": {
         "url": "https://<DOMO_DOMAIN>/api/ai/v1/assistant/mcp/toolkits/DOMO_BASIC_MCP",
         "type": "http",
         "headers": {
           "X-DOMO-DEVELOPER-TOKEN": "${input:domo-access-token}"
         }
       }
     },
     "inputs": [
       {
         "id": "domo-access-token",
         "type": "promptString",
         "description": "Domo Access Token",
         "password": true
       }
     ]
   }
   ```

## トラブルシューティング

環境によっては、Claude Desktopの設定をさらに変更する必要がある場合があります。

**Mac**

`npx`が見つからない場合は、設定内の`domo-mcp-npx`サーバーエントリーに`env`プロパティを追加し、`<USER_PATH>`をホームディレクトリのパスに置き換えます。

```json
"env": {
  "PATH": "<USER_PATH>/.nvm/versions/node/v22.21.1/bin:/usr/local/bin:/usr/bin:/bin"
}
```

**Windows**

`npx`が見つからない場合は、設定内の`"command"`の値を`npx`実行ファイルへのフルパスに置き換えます。例：

```json
"command": "C:\\Program Files\\nodejs\\npx.cmd"
```
