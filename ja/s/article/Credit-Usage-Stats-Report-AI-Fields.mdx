## はじめに 

Credit Usage Statsレポートには、`skuGroup`、`skuId`、`entityType`などのフィールド内に複数のAI関連の識別子が含まれています。この記事では、AI固有の各フィールドの概要とレポートでの役割について説明します。

---

## skuGroup

`skuGroup`フィールドでは、使用量が製品エリア別に分類されます。次の値がAI関連です。

| 値 | 意味 |
| --- | --- |
| `jupyter` | Jupyterワークスペースの作成と使用に関連する使用量。 |
| `ai-agent` | AIチャットおよびAIコンテンツビルダーでのすべての使用量が含まれます。これらの製品におけるすべてのアクティビティは、このskuGroupにグループ化されます。 |
| `ai-pro` | プレイグラウンドとAIモデルのいずれであっても、顧客が用意したモデルとDomoが提供したモデルの両方を含め、あらゆるAIモデルの使用量をカバーします。 |

## skuId

`skuId`フィールドでは、特定の製品やモデルが生成した使用量が識別されます。AI関連のSKUが、以下にカテゴリー別にグループ化されています。

**AIエージェントのSKU**

| 値 | 意味 |
| --- | --- |
| `ai-agent-chat` | AIチャットとのやり取りおよびリクエストでの使用量。 |
| `ai-agent-content-builder` | ダッシュボードやAppのコンテンツの生成など、AIコンテンツビルダーでの使用量。 |

**AI Proモデルの処理のSKU**

| 値 | 意味 |
| --- | --- |
| `ai-pro-model-processing-customer-provided` | 顧客が用意したAIモデルのための処理の使用量。 |
| `ai-pro-model-processing-llm-domo-embed-text-cohere-v1-input` | Domoが提供するCohereテキスト埋め込みモデルのための処理の使用量。 |
| `ai-pro-model-processing-llm-domogpt-anthropic-medium-v1-input` | Domoが提供するDomoGPT Mediumモデルのための処理の使用量。 |
| `ai-pro-model-processing-llm-openai-gpt-4-input` | Domoが提供するOpenAI GPT-4モデルのための処理の使用量。 |

<Note> **注記：**利用可能な具体的なSKUは、インスタンス構成とモデルの可用性によって異なる場合があります。上記の値は代表例です。</Note>

**AI ProオペレーションのSKU**

| 値 | 意味 |
| --- | --- |
| `ai-pro-operation` | AIモデルの実行や管理など、AIのオペレーションに関する使用量を追跡します。 |

**データサイエンス/AutoML SKU**

| 値 | 意味 |
| --- | --- |
| `executions-datascience-automl-training` | AutoMLトレーニングの実施またはデータサイエンスモデルのトレーニングでの使用量。 |

## entityType

`entityType`フィールドは、AIの使用量を生成したDomoのオブジェクトまたはサーフェスを示します。

| 値 | 意味 |
| --- | --- |
| `AI Agent` | AIチャットまたはAIコンテンツビルダーでの使用量を示します。 |
| `DATAFLOW` | AIモデル（テキスト生成、分類、センチメント分析など）を含む、または実行するDataFlowを表します。 |
| `DATA_SCIENCE_NOTEBOOK` | Jupyterワークスペース。 |
| `DATA_SOURCE` | AIのオペレーションに使用されるデータソース（`ai-pro` skuGroupに関連付けられたソースなど）。 |
| `DataSet` | AIの使用量に関連付けられたデータセット。 |
| `ODYSSEY_WORKFLOW_MODEL` | ワークフローがAIモデル（予測や自動化など）を使用したことを示します。 |
| `RYUU_APP` | Pro Code App（カスタム構築のDomoアプリケーション）内での使用量を指します。 |
| `USER` | AIチャット、コンテンツエージェント、またはAI APIに直接送信されたコールなど、ユーザーが直接開始した使用量。 |
