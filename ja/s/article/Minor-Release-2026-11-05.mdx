## 2026年11月5日リリース

### AI Labs

- AI機能の使用状況とパフォーマンスのメトリクスを含む、新しいDomoStatsレポート"AI Operations"を追加します。
- 管理者は、AI ServicesでDomo SQLツールキットを有効または無効にできます。
- AI Labsの非構造化データ処理ジョブが、エラー情報を表示せずに失敗することがありました。
- Domo Everywhereを通じて、またはパブリケーションで埋め込まれたときに、AI Libraryカードがアイコンの代わりに空白の灰色のスペースを表示していました。
- AI LabsでAutomated Insightsとメトリクスを個別に制御できます。
- AI Labsのカスタムエージェントとツールキットが、AIチャットとは独立して機能するようになりました。
- 消費レポートの改善とProバッジ表示の更新を含むAIチャットV2を導入します。
- IDでFileSetsを検索できます。
- AI LibraryのReport Builder Toolkitカードにアイコンがありませんでした。

### AI Services

- 分析での機能識別を改善するために、AI Servicesの使用状況トラッキングに表示名を追加します。
- ワークフロー内のAI Agentタイルが、ナレッジソースとしてDocument Collectionsから特定のファイルタイプにアクセスできませんでした。
- AI Agent設定のアクティビティログが、変更された特定のツール名の代わりに、TypeおよびEvent列に"Ai chat tool"を表示していました。
- ワークフロー内のAgentタイルが、構造化出力を使用するときに失敗することがありました。
- Automated Insights機能が、インターフェイスの一部で誤って非表示またはアクセス不能になっていました。

### アラート

- Personalized Data Permissionsが有効なDataSetのアラートが、アラートのしきい値を超えたときにサブスクライバーに通知を送信しませんでした。
- 共有コンテキストでPersonalized Data Permissions（PDP）が構成されたDataSetアラートがWebhookを送信せず、キャンペーンが期待どおりにトリガーされませんでした。
- 200人を超えるユーザーがPDPポリシーを通じてアクセス権を持っている場合、特定の列アラートの共有ダイアログが"Searching"で停止し、Personalized Data PermissionsがあるDataSetで新しいユーザーやグループの追加を妨げていました。
- "Use Alerts"許可を持つユーザーは、基になるDataSetへのアクセス権がない場合、共有されたアラートを表示または受信できませんでした。

### App Platform

- Asset Libraryからカードを作成すると、ワークフローマッピング、コードエンジンマッピング、またはコードエディターのbrick構成を必要とするデザインの配線画面がスキップされ、不完全なカードが生成されていました。これらの要素のセットアップが必要な場合に配線画面が表示されるようになりました。
- 既存のChange Data Capture（CDC）DataSetsが、更新された解析デフォルトを使用するようになりました。
- 所有者以外によって作成された低遅延DataSetsが、DataSetの所有者には表示されず、Adminユーザーにのみ表示されていました。
- カスタムアプリからのDataSetsへのクエリがエラーで失敗することがありました。
- Pro-Code Editorが、DataSetの列名の元の大文字小文字を保持する代わりに、すべて小文字で列エイリアスを生成していました。

### App Studio

- フィルターを適用した後、App Studioの箱ひげ図が棒グラフとして表示され、完全な箱ひげ図の分布ではなく最大値と最小値のみが表示されていました。
- DataSetスキーマの列名の大文字小文字が変更されたときに、App Studioの編集可能なテーブルが入力を受け付けないことがありました。
- App Studioで、DataSetがすでに接続されている場合でも、GridおよびListコンポーネントが"Power from data to configure search"メッセージを表示し、ユーザーが検索列とソート列を構成できませんでした。
- App Studioのスケジュールレポートのテーブルカードが、交互の行の色などのテーマの書式を失い、予期しない罫線を表示していました。
- "Edit Data in Editable Table Cells"許可を持つユーザーは、リンクされたDataSetsを使用するApp Studioの編集可能なテーブルのセルを編集できず、以前は回避策として"Edit Cards"許可を必要としていました。

### Buzz

- Buzzのプライベートトピックとグループチャットの"Remove user from conversation"ダイアログのボタンが応答せず、会話からユーザーを削除できませんでした。

### カード

- ダッシュボードが最初に読み込まれたときに、カードが"Loading"または"Filtering"状態で停止し、データを表示できませんでした。
- 月でグループ化されたカードが、英語以外の閲覧者に対してローカライズされたラベル（"2026年1月"など）ではなく英語の月ラベル（"2026-Jan"など）を表示し、"Data Not Available"と表示されることがありました。
- 日付変数とDATETIME比較が会社のタイムゾーンを正しく適用していませんでした。日付は最初の読み込み時に正しいタイムゾーンで計算されるようになり、タイムゾーン情報を含むSnowflake TIMESTAMP列が2回シフトされることはなくなりました。
- カードの展開された日付セレクターのプリセットボタンが応答しなくなり、複数回クリックすると縦線に圧縮されることがありました。
- テーブルカードが、高精度の小数列に対して構成された数値形式ではなく生の小数値を表示していました。構成に従って、小数の精度、パーセンテージの書式、桁区切りの設定を適用するようになりました。
- 編集ユーザー権限を持つユーザーは、編集アクセス権があっても、自分が所有していないDocument Cardsの新しいバージョンをアップロードできませんでした。アップロードの試行がサイレントに失敗するか、許可エラーを返していました。
- App Studioアプリで適用された変数コントロールフィルターが、カードをメールとしてエクスポートするときに適用されず、エクスポートで値がゼロとして表示されていました。

### コネクター

- TikTokの表示名に絵文字が含まれている場合、TikTok Businessコネクターアカウントの作成に失敗することがありました。
- JSON No Codeコネクターで、前のステップに戻ると、AIアシスタントで行った構成の変更が失われていました。
- File Uploadコネクターで複数のファイルを連続してアップロードすると、インターフェイスがフリーズし、プレビュー画面に進まなくなることがありました。

### Data Center

- フェデレーテッドDataSetsから作成されたDataSet Viewsを編集できず、"Something went wrong while trying to edit this view"エラーが表示されていました。
- 以前に共有されたグループが削除されていた場合、アカウント共有ダイアログが開きませんでした。すべての共有ユーザーとグループを表示し、削除されたグループへの共有を削除できるようになりました。

### データ処理

- 複数のSnowflake DataSetsが同時に更新された場合など、多くのDataFlowsが一度にトリガーされると、Magic ETLのDataFlowsが最大24時間PREPARINGまたはEXPORTING状態で停止することがありました。影響を受けるDataFlowsは、停止する代わりに明確なステータスで完了または失敗するようになりました。

### データクエリ

- CASE WHEN句内でFIXED関数を使用するBeast Mode計算が"invalid column"エラーを生成し、カードのレンダリングを妨げることがありました。
- 場合によっては、Change Data Capture（CDC）がDataSetsを生成しませんでした。

### Embed

- 埋め込みダッシュボードが下部で切れており、ユーザーがカードの下部、テーブルのスクロールバー、軸ラベルを表示できませんでした。
- 埋め込まれたApp Studioアプリのスライサーと変数の選択が、依存するカードをフィルタリングしませんでした。選択は、プライベートとパブリックの両方の埋め込みで正しく適用されるようになりました。
- フィルタリングが有効になっている場合でも、プライベートな埋め込みの展開されたカードにフィルターアイコンが表示されませんでした。埋め込まれたApp Studioアプリのカードに直接フィルターを追加できるようになりました。

### フェデレーテッドデータ

- 列名にスラッシュ、括弧、カンマなどの特殊文字が含まれている場合、BigQuery DataSetsを使用するカードとスケジュールレポートが"Invalid field name"エラーで読み込まれず、フェデレーテッドBigQuery DataSetsとCloud Amplifier BigQuery統合の両方に影響していました。

### Personalized Data Permissions

- DataSet内の一部のPDP行ポリシーが、DataSetを実行した後でも、DomoStats Row Assignmentテーブルに表示されませんでした。

### Publish

- DataSetsがDomo Everywhereインスタンスに公開できず、再試行を求める汎用エラーメッセージが表示されることがありました。
- Publishサブスクライバーインスタンスの変数オプションが、ページレベルのコントロールパネルでは正しく表示されるにもかかわらず、展開されたカードに正しく表示されませんでした。構成されたすべてのオプションが、両方のビューで一貫して公開および表示されるようになりました。

### Sandbox

- Sandboxで、同じインスタンスでリポジトリを昇格してリンクすると、予期しないエラーで失敗することがありました。

### スケジュールレポート

- スケジュールレポートのメール件名の二重角括弧（[[]]）により、スケジュールボタンが有効にならず、ユーザーがレポートを保存できませんでした。

### ワークフロー

- WorkflowsのQuery DataSetブロックが、出力列タイプを（TextやDate-Timeなどの）実際のデータタイプではなく"Object"として表示し、ユーザーが下流のアクションを構成できませんでした。

### ワークスペース

- ユーザーが非表示または非アクティブなグループにのみ属している場合、ページを更新した後にワークスペースが消えることがありました。
