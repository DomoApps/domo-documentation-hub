## はじめに

この記事では、DomoのPostgreSQL SSH Writebackコネクターを使用して、Data CenterでデータをSSHトンネル経由でPostgreSQLデータベースにエクスポートする方法や、接続認証情報を設定する方法、対象のテーブルへのデータの書き込み方法を定義する方法について説明します。

---

## 必要条件

PostgreSQLデータベースにSSHトンネル経由で接続しDataSetを作成するには、以下が必要です。

- PostgreSQLデータベースのログインに使用するユーザー名とパスワード
- PostgreSQLデータベースの名前
- PostgreSQLデータベースのポート番号
- PostgreSQLデータベースサーバーのホスト名またはIPアドレス
- SSHトンネルの接続先であるUNIXサーバー
- UNIXアカウントのユーザー名
- SSHポート番号
- SSH秘密鍵（DESまたはRSAのいずれか）

PostgreSQLデータベースに接続する前に、データベースサーバーの接続ポートでIPアドレスを許可リストに登録する必要があります。IPアドレスの詳細なリストは、「[コネクターのIPアドレスを許可リストに登録する](/s/article/360043630093)」を参照してください。

<Note>
  **注記：**Writeback DataSetの所有者は、入力DataSetの所有者または共同所有者である必要があります。
</Note>

PostgreSQLについての詳細は、PostgreSQLのウェブサイト（[https://www.postgresql.org/](https://www.postgresql.org/)）を参照してください。

<Note>
  **注記：** 
  
      - Domoは、ssh-keygenを使用して生成されるSSHキーをサポートしていません。SSHキーは、OpenSSLが生成するDESまたはRSAキーである必要があります。
      - Writeback DataSetの所有者は、入力DataSetの所有者または共同所有者である必要があります。

  </Note>

<Warning>
  **重要：**PostgreSQLの以下の権限が必要です。
     - CONNECT
     - SELECT
     - CREATE
     - INSERT

</Warning>

この記事では、PostgreSQL SSH Writebackコネクターのユーザーインターフェースに固有のフィールドとメニューについて説明します。DataSetの追加、更新スケジュールの設定およびDataSet情報の編集に関する一般的な情報は、「[コネクターを使用してDataSetを追加する](/s/article/360042926274)」を参照してください。

## 接続を設定する

このセクションでは、 PostgreSQL SSH Writebackコネクターページの**［認証情報］**ペインおよび**［詳細］**ペインのオプションについて説明します。**［スケジュール設定］**ペインや**［DataSetに名前を付け、説明を入力］**ペインの項目に関しては、ほとんどのタイプのコネクターで共通しています。詳細については、「[コネクターを使用してDataSetを追加する](/s/article/360042926274)」を参照してください。

### 認証情報を入力する

**［認証情報］**ペインには、データベースとSSHサーバーに接続する認証情報の入力フィールドが含まれています。下表では、各フィールドに必要な内容を説明しています。

| フィールド               | 説明                                                                                          |
| ------------------- | ---------------------------------------------------------------------------------------------------- |
| SSH Server Hostname | SSHトンネルの接続先であるUNIXサーバーのホスト名を入力します。                                         |
| SSH Username        | UNIXアカウントのSSHユーザー名を入力します。                                                        |
| SSH Port            | UNIXアカウントのポート番号を入力します。このフィールドを空白のままにすると、デフォルトのポートは22になります。 |
| SSH Private Key     | SSH秘密鍵（DESまたはRSAのいずれか）を入力します。                                                       |
| Database Name       | PostgreSQLデータベース名を入力します。                                                                  |
| Database Hostname   | PostgreSQLデータベースのホスト名を入力します。入力例：`db.company.com`                       |
| Database Port       | PostgreSQLデータベースのポート番号を入力します。                                                                   |
| Database Username   | PostgreSQLユーザー名を入力します。                                                                      |
| Database Password   | PostgreSQLのパスワードを入力します。                                                                      |

有効な認証情報を一度入力しておくと、いつでも同じアカウントを使用して新しいDomo-PostgreSQL SSH接続を設定できます。コネクターアカウントは、Data Centerの**［アカウント］**タブで管理することができます。このタブの詳細については、「[コネクターのユーザーアカウントを管理する](/s/article/360042926054)」を参照してください。

**［詳細］**ペインでは、SQLクエリを作成して、データベースからデータを取得します。

| メニュー                                                | 説明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| --------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| DataSet ID                                          | データの取得先となるDataSet IDを入力します。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Select the Schema Name                              | データベーススキーマの名前を選択します。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Table Name Source                                   | SQLテーブルの名前を選択します。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Custom Table Name                                   | SQLテーブル名を入力します。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Operation Type                                      | <table border="1"><tbody><tr><td>Create a New Table</td><td>指定した名前で新しいテーブルを作成します。この名前のテーブルがPostgreSQLデータベースにすでに存在している場合、この操作は失敗します。既存のテーブルを変更するには、**［Update an Existing Table］**を選択します。</td></tr><tr><td>Update an Existing Table</td><td>PostgreSQLデータベースにテーブルが存在する場合は、そのテーブルを更新します。テーブルが存在しない場合、この操作は最初の実行時にテーブルを作成し、その後の実行では選択した更新方法にもとづいてテーブルが更新されます。</td></tr></tbody></table>                                                                                                  |
| Table Update Method                                 | <table border="1"><tbody><tr><td>Append Data</td><td>取得したデータを既存のテーブルに追加します。</td></tr><tr><td>Overwrite With New Data (Drop and Create Table)</td><td>テーブルをドロップして再作成してから、新しく取得したデータをテーブルに書き込みます。 </td></tr><tr><td>Overwrite With New Data (Truncate Table)</td><td>既存のテーブルのデータをトランケートによって上書きしてから、新しく取得したデータをテーブルに書き込みます。 </td></tr></tbody></table><Note>**注記：**テーブルが存在しない場合は、最初の実行によってテーブルが作成されます。その後の実行では、選択したオプションにもとづいてテーブルが更新されます。</Note> |
| Map Domo DataSet Columns with PostgreSQL Data Types | DomoのDataSet列をPostgreSQLデータ型でマッピングします。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
