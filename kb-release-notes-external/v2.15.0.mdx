Hello everyone!

We're excited to announce that version 2.15.0 of the Domo Documentation Hub is now available! This is a big connector-and-developer release — two brand-new connectors, a top-to-bottom rebuild of the DomoStats reference, a modernized App Framework data-handling guide, and fresh MCP and video content. You can view these changes in our knowledge base at [www.domo.com/docs](https://www.domo.com/docs).

## 🌟 What's New

### 🔌 Two New Connectors

Two new connector articles joined the knowledge base this release: the [OpenAI Ads Manager Connector](https://www.domo.com/docs/s/article/OpenAI-Ads-Manager-Connector) for pulling advertising data from OpenAI's Ads platform, and the [Personio v2 Connector](https://www.domo.com/docs/s/article/Personio_v2-Connector) for HR data. Both include configuration steps and role-grant requirements.

### 📊 DomoStats Connector, Fully Overhauled

The [DomoStats Connector](https://www.domo.com/docs/s/article/360043433813) article was rebuilt from the ground up — it now documents every available report and its description, provides field-by-field schema details for each report's DataSet, and audits the Role Grants descriptions verbatim against the connector source. New coverage includes the Dataset Share Modal report, clearly labeled legacy reports, and reworked feature-switch notes. The standalone "DataSet Fields" article was folded into this reference so everything lives in one place.

### 🚀 Amazon Selling Partner, Rebuilt

The [Amazon Selling Partner](https://www.domo.com/docs/s/article/7964629384087) connector article received a major rewrite, trimming outdated content and adding a new "Products - Get Catalog Item by ASIN" report along with refreshed details throughout.

### 🛠️ App Framework: Handling Data Updates Guide

The [handling data updates guide](https://www.domo.com/docs/portal/Apps/App-Framework/Guides/handling-data-updates) got a thorough modernization for app developers. Highlights include:

- Modernized `app.js` examples (no more IIFE — now using `let`/`const`, arrow functions, and template literals)
- An inline, copy-friendly sample data table and a downloadable 300×300 sample thumbnail
- New animated GIFs illustrating card reloading and data-handling behavior
- A clearer, harder-to-miss publish section and a deprecation warning for the old `onDataUpdate` v4 method name

The [Data API reference](https://www.domo.com/docs/portal/API-Reference/app-framework-apis/Data-API) was also clarified to explain the different response formats, noting that array-of-objects is the default.

### 🤝 MCP Documentation Refresh

The [Connect AI Tools to Domo Using MCP](https://www.domo.com/docs/s/article/Connect-AI-Tools-to-Domo-Using-MCP) and MCP Standard OAuth articles were updated to keep the setup guidance current for connecting AI tools to Domo.

### 🔑 Writeback Connector Credential Instructions

Credential instructions across a wide set of writeback connectors were updated to reference the Admin Console rather than the legacy developer account, keeping the Domo Client ID and Secret guidance consistent and current.

### 🎬 New Microlearning Videos

The [Domo Video Library](https://www.domo.com/docs/s/article/Domo-Video-Library) added two new microlearning sessions: building an AI agent for PO verification using Domo Workflows and the AI Library, and building custom MCP agents for Claude Desktop workflows (from Domo BUILD 2026).

## 🙏 Thank You

A heartfelt thank you to everyone who helped make this release possible. Your work makes our documentation clearer, more complete, and more helpful every month.

If you have questions or feedback, please reach out — we're always happy to help!
