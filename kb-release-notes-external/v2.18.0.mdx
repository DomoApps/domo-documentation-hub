title: "Domo Documentation Hub v2.18.0 Release Notes"

Hello everyone!

We're excited to announce that version 2.18.0 of the Domo Documentation Hub is now available! This release adds several brand-new articles across MCP connections, Jupyter workspaces, and Code Engine, and refreshes connector documentation. You can view these changes in our knowledge base at [www.domo.com/docs](https://www.domo.com/docs).

## 🌟 What's New

### 🤖 Connect Amazon Quick Suite to Domo MCP

A new step-by-step guide walks admins through connecting Amazon Quick Suite to Domo's MCP server, including OAuth consent and custom OAuth field configuration. We also tightened up the surrounding MCP setup docs — the manual-connect and standard OAuth flows are clearer and easier to follow. Learn more about how to [connect Amazon Quick Suite to Domo MCP](https://www.domo.com/docs/s/article/Connect-Amazon-Quick-Suite-To-Domo-MCP).

### 📓 Understanding Jupyter Workspace Consumption

A new article explains how consumption works for Jupyter Workspaces, so customers can understand what drives usage and plan accordingly. Read the full guide on [understanding Jupyter Workspace consumption](https://www.domo.com/docs/s/article/Understand-Jupyter-Workspace-Consumption).

### ✉️ Use Email Code Engine Functions

A new article covers how to use email Code Engine functions, with a clarification that no special grants are required to use them. See the new guide on [using email Code Engine functions](https://www.domo.com/docs/s/article/Use-Email-Code-Engine-Functions).

### 🔌 Connector Updates

We added and refreshed several connector articles this release:

- A brand-new article for the Bureau of Economic Analysis (BEA) Connector. See the new [Bureau of Economic Analysis (BEA) Connector](https://www.domo.com/docs/s/article/360043432753) article.
- The Apollo.io Connector docs were reworked to reflect the updated OAuth authentication method and revised prerequisites. Read the updated [Apollo.io Connector](https://www.domo.com/docs/s/article/Apollo.io-Connector) article.
- Google BigQuery now documents the BigQuery Job User requirement for read-only role setups. See the updated guidance on [connecting Domo to Google BigQuery](https://www.domo.com/docs/s/article/000005237).
- The Totango Connector article was updated to use API Key in place of App Token.

### 🎥 New Microlearning Videos

The Domo Video Library picked up a fresh batch of microlearning videos this release, covering AI governance, consumption across data integration and Domo Apps, distribution methods, lineage, certification, and ownership.

## 🙏 Thank You

A heartfelt thank you to everyone who helped make this release possible. Your work makes the Domo documentation better for every reader.

If you have questions or feedback, please reach out — we're always happy to help!
