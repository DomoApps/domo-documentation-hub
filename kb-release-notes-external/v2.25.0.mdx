Hello everyone!

We're excited to announce that version 2.25.0 of the Domo Documentation Hub is now available! This release brings new authentication options for Cloud Integrations, expanded Model Context Protocol (MCP) guidance, a refreshed Jupyter Workspaces guide, five new connector articles, and clearer App Studio repository steps. You can view these changes in our knowledge base at [www.domo.com/docs](https://www.domo.com/docs).

## 🌟 What's New

### ☁️ New Authentication Options for Cloud Integrations

Cloud Integrations gained two authentication enhancements this cycle. Domo on Azure SQL now supports service principal authentication, giving admins a credential-free, app-registration-based way to connect. Read the updated [Domo on Azure SQL](https://www.domo.com/docs/s/article/000005471) article for setup steps. Alongside it, user-to-machine (U2M) OAuth now supports read-only integrations across Snowflake, BigQuery, and Databricks — documented in [Domo on Snowflake](https://www.domo.com/docs/s/article/4402322966807), [Connect Domo to Google BigQuery](https://www.domo.com/docs/s/article/000005237), and [Domo on Databricks](https://www.domo.com/docs/s/article/000005289).

### 🤖 Expanded MCP (Model Context Protocol) Guidance

Our MCP documentation got a thorough refresh. Every Domo instance now exposes its AI Library toolkits as MCP servers, so any MCP-capable tool can sign in and use them — see the updated [Connect AI Tools to Domo Using MCP](https://www.domo.com/docs/s/article/Connect-AI-Tools-to-Domo-Using-MCP) and [Domo MCP](https://www.domo.com/docs/s/article/Domo-MCP) articles. We also clarified the standard OAuth and manual connection flows in [MCP Standard OAuth](https://www.domo.com/docs/s/article/MCP-Standard-OAuth), [Connect Manually](https://www.domo.com/docs/s/article/MCP-Manually-Connect), and [Connect Amazon Quick Suite to Domo MCP](https://www.domo.com/docs/s/article/Connect-Amazon-Quick-Suite-To-Domo-MCP).

### 📓 Refreshed Jupyter Workspaces Guide

The [Jupyter Workspaces User Guide](https://www.domo.com/docs/s/article/36004740075) received a significant refresh, with clearer guidance on how account aliases are referenced and a full set of updated screenshots and icons throughout the walkthrough.

### 🔌 Five New Connector Articles

We published dedicated articles for five connectors so each is now easy to find and reference directly: [Airtable Connector](https://www.domo.com/docs/s/article/360043436333), [Zuora Connector](https://www.domo.com/docs/s/article/360042928514), [Aloha POS Connector](https://www.domo.com/docs/s/article/360043435593), [Yelp Connector](https://www.domo.com/docs/s/article/360042930114), and the [Anaplan Connector (Deprecated)](https://www.domo.com/docs/s/article/360043432713).

### 🧱 Clearer App Studio Repository Steps

The [Domo Sandbox](https://www.domo.com/docs/s/article/4403367344023) article now spells out the previously empty "Configure the repository by…" step with a complete list of what to do, and corrects the explanation of what a linked repository actually is.

## 🙏 Thank You

A heartfelt thank you to everyone who helped make this release possible. Your attention to detail keeps our documentation accurate, helpful, and a pleasure to use.

If you have questions or feedback, please reach out — we're always happy to help!
