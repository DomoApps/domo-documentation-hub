title: "Domo Documentation Hub v2.27.0 Release Notes"
---

Hello everyone!

We're excited to announce that version 2.27.0 of the Domo Documentation Hub is now available! This release brings new Cloud Integrations calendar guidance, SDK examples across the Governance guides, expanded workflow and connector documentation, and a brand-new weekly Minor Release Notes page. You can view these changes in our knowledge base at [www.domo.com/docs](https://www.domo.com/docs).

## 🌟 What's New

### 📅 Fiscal and Localized Calendars for Snowflake and Databricks

Cloud Integrations calendar guidance now has its own dedicated, substantially expanded home covering fiscal and localized calendar configuration for Snowflake and Databricks. The article walks through enabling and configuring calendars so admins can align their integrations to the right fiscal and regional settings. Learn more about [configuring fiscal and localized calendars for Snowflake and Databricks integrations](https://www.domo.com/docs/s/article/Configure-Fiscal-and-Localized-Calendars-for-Snowflake-and-Databricks-Integrations).

### 🛡️ Governance Guides with SDK Examples

The Governance guides — content management, data management, PDP, security, and user management — now include hands-on SDK code examples to help developers automate governance tasks. Access-token links throughout now point to the API Authentication quickstart, and the App Framework Tools page has moved to Getting Started so it's easier to find. See the refreshed [Governance overview](https://www.domo.com/docs/portal/Governance/overview).

### ⚙️ Workflow Documentation Updates

Workflow documentation got two useful additions: the alerts article now explains how to trigger a workflow from a DataSet alert, and the Manage Workflows article now documents how to delete a workflow version. Read the updated [Create an Alert for a DataSet](https://www.domo.com/docs/s/article/360042925994) and [Manage Workflows](https://www.domo.com/docs/s/article/000005179) articles.

### 🔌 Connector Updates

Several connector articles were expanded with new reports, fields, and clearer setup guidance:

- Weather Source gained new report options and field descriptions. See the updated [Weather Source Connector](https://www.domo.com/docs/s/article/360042931054) article.
- The Google Ads article refreshed its deprecation guidance and now points customers to the current Google Ads API connector for recreating their DataSets. Read the updated [Google Ads](https://www.domo.com/docs/s/article/000005507) article.
- Pendo documentation was updated with the latest configuration details. See the [Pendo Connector](https://www.domo.com/docs/s/article/360043434093) article.
- Additional report and field updates landed for Mixpanel, HubSpot, Shopify, and Amazon S3 Advanced, and the DemandMetrics connector was renamed to DemandSphere.

### 🗞️ Weekly Minor Release Notes

A new [Minor Release Notes](https://www.domo.com/docs/s/article/Current-Minor-Release-Notes) page now publishes weekly, documenting incremental updates and resolved issues across Domo features so customers can keep up with the smaller changes between major releases.

### 🧰 Workbench 5 & 5.1 UI Article Refresh

The Workbench 5 and 5.1 user interface articles were refreshed with corrected icon rendering and restored screenshots, alongside cleanup passes on several connector setup articles. Explore the updated [Understanding the Workbench 5.1 User Interface](https://www.domo.com/docs/s/article/4407032210199) and [Understanding the Workbench 5 User Interface](https://www.domo.com/docs/s/article/360042932654) articles.

## 🙏 Thank You

A heartfelt thank you to everyone who helped make this release possible. We're committed to keeping the knowledge base accurate, accessible, and genuinely helpful.

If you have questions or feedback, please reach out — we're always happy to help!
