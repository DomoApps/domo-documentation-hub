title: "Domo Documentation Hub v2.29.0 Release Notes"
---

Hello everyone!

We're excited to announce that version 2.29.0 of the Domo Documentation Hub is now available! This release brings a brand-new connector guide, deeper authentication and troubleshooting guidance for several cloud connectors, fresh Beast Mode training content, and a smarter experience for readers who land on localized pages. You can view these changes in our knowledge base at [www.domo.com/docs](https://www.domo.com/docs).

## 🌟 What's New

### 🔌 New Amazon Redshift Connector Guide

A dedicated article now walks you through connecting Domo to an Amazon Redshift data warehouse, including prerequisites, authentication, and building custom reports with SQL queries against your Redshift database. Read the full guide on getting [the most out of your Amazon Redshift data](https://www.domo.com/docs/s/article/Get-the-most-out-of-your-Amazon-Redshift-data).

### 🔐 BigQuery Workload Identity Federation, Clarified

The Google BigQuery connector article now explains exactly where the Service Account Token Creator grant belongs when using Workload Identity Federation (WIF), how to generate the configuration file with IMDSv2 enabled, and adds a new troubleshooting section for the common Magic ETL `signBlob` permission error — so admins can get WIF working without guesswork. See the updated guide on how to [connect Domo to Google BigQuery](https://www.domo.com/docs/s/article/000005237).

### 🪟 SharePoint Online OAuth Now Runs Through Microsoft Entra

The SharePoint Online REST OAuth configuration article has been substantially rewritten around Microsoft Entra, with step-by-step app-registration instructions, the required multi-tenant account-type setting, and new screenshots of the Entra portal. Read the refreshed article on how to [add a Microsoft SharePoint Online REST OAuth config](https://www.domo.com/docs/s/article/000005610).

### 🧱 Databricks OAuth M2M: Scopes and Troubleshooting

The Databricks OAuth M2M connector article now documents the optional **Scope** field for service-principal OAuth secrets that are restricted to specific scopes (such as `sql`), explains the default `all-apis` behavior, and adds a Troubleshoot section. Learn more in the [Databricks OAuth M2M authentication connector](https://www.domo.com/docs/s/article/Databricks-Using-OAuth-M2M-Authentication-Connector) article.

### 🎓 New Beast Mode Microlearning in the Video Library

The Domo Video Library picked up a set of short Beast Mode microlearning videos covering the Beast Mode interface, editing existing Beast Modes, using Beast Mode Manager, saving a Beast Mode to the DataSet, and working with variables. Browse them in the [Domo Video Library](https://www.domo.com/docs/s/article/Domo-Video-Library).

### 🌐 Smarter Language Routing for Localized Pages

Readers who land on a localized (`/de`, `/es`, `/fr`, `/ja`) URL for an article that hasn't been translated yet are now sent to the English version at the same path instead of hitting a 404, and `?language=` links resolve to the localized article when one exists. The result is a smoother experience for international readers following localized links.
