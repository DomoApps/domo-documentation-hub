Hello everyone!

We're excited to announce that version 2.30.0 of the Domo Documentation Hub is now available! This release brings new AI guidance, refreshed App Framework developer tooling, and a wave of readability and navigation improvements across the knowledge base. You can view these changes in our knowledge base at [www.domo.com/docs](https://www.domo.com/docs).

## 🌟 What's New

### 🤖 New AI Chat and Agent Guidance

Two brand-new articles help you get more out of Domo's AI features. The first explains exactly which Markdown and HTML formats AI Chat turns into live, interactive elements — rendered charts, Mermaid diagrams, Vega-Lite visualizations, copy-enabled code blocks, and more — along with the precise syntax that triggers each one. See the new guide to [response formatting and inline renders in AI Chat](https://www.domo.com/docs/s/article/Response-Formatting-and-Inline-Renders).

The second demystifies token usage in LLM agents: what actually consumes tokens during an agent run, why some runs fail while similar ones succeed, and the fixes to apply in priority order to keep runs under the context limit. Learn more about [token consumption in LLM agents](https://www.domo.com/docs/s/article/Token-Consumption-in-LLM-Agents). Several existing AI articles — including AI Admin Agent Settings and AI Chat — were also refreshed with clarifications like how chat consumption is charged.

### 🛠️ App Framework Developer Tooling Refresh

The App Framework tooling docs are now in sync with the latest releases. The Domo Apps Generator (`da` CLI) page documents the current `da new` flags — `--pm`, `--skip-git`, and `--skip-install` — and updated template behavior. Read the refreshed [Domo Apps Generator](https://www.domo.com/docs/portal/Apps/App-Framework/Tools/da-cli) guide.

The Domo Publish Action page now points at the new `domoinc/domoapps-publish-action@v3` home, with a clear note that existing workflows keep working through GitHub's redirect but should be updated. See [Domo Publish Action](https://www.domo.com/docs/portal/Apps/App-Framework/Tools/domo-publish-CICD). The Toolkit Library page was also repointed at the canonical domoinc toolkit docs — see [Toolkit Library](https://www.domo.com/docs/portal/Apps/App-Framework/Tools/toolkit).

### ⚡ Code Engine Rescan Functions Clarification

The Code Engine docs now spell out how the Rescan Functions detection rule handles JavaScript helper functions, so package authors know what will and won't be picked up. See the updated [Code Engine limitations and troubleshooting](https://www.domo.com/docs/portal/Automate-Actions/Code-Engine/limitations-and-troubleshooting) guidance.

### ✨ KB-Wide Readability and Navigation Polish

We made a broad pass to make the knowledge base easier to scan and navigate. Single-procedure articles now use the Steps component for cleaner, numbered walkthroughs; gerund-style article titles were converted to imperative form for consistency; and long-titled articles received shorter sidebar labels so the navigation reads cleanly without truncation.

### 🔗 Embed Documentation Link Fixes

Several broken `developer.domo.com` links in the embed and instance-template articles have been repaired so readers land on the right pages, including corrected dataset-switching and filter-options references.

## 🙏 Thank You

A heartfelt thank you to everyone who helped make this release possible. Your work makes the Domo knowledge base clearer, more current, and more helpful every week.

If you have questions or feedback, please reach out — we're always happy to help!
