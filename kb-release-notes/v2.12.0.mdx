Hello everyone!

We're excited to announce that version 2.12.0 of the Domo Documentation Hub is now available! This release features substantial new developer documentation for App Broadcasting, a batch of connector additions and improvements, expanded Documents FAQs, and a handful of helpful clarifications across the knowledge base. You can view these changes in our knowledge base at [www.domo.com/docs](https://www.domo.com/docs).

## 🌟 What's New

### 🏗️ App Broadcasting Developer Documentation

App Broadcasting is a new App Framework capability that lets Custom Apps on the same Domo page communicate with each other in real time using a host-mediated pub/sub message bus. Two new documents cover it end to end:

- The [App Broadcasting guide](https://www.domo.com/docs/portal/Apps/App-Framework/Guides/broadcasting) explains the architecture, channel declaration, message publishing, and subscriptions — everything needed to understand how the system works.
- The [Cross-App Broadcasting tutorial](https://www.domo.com/docs/portal/Apps/App-Framework/Tutorials/React/Cross-App-Broadcasting) walks through building two coordinated React apps — a data table that publishes row selections and a detail panel that subscribes and reacts to them.

The `manifest.json` reference was also updated with the new `channels` property, and both the Domo.js reference and the App Framework overview were expanded to surface the new API.

Thanks to the App Framework team for this significant documentation effort.

### 🔌 Connector Additions and Updates

A new article for the [Cisco Webex Connector](https://www.domo.com/docs/s/article/360052381713) is now live, covering connection setup and available report types for pulling conferencing and collaboration data into Domo. The Knack Connector article has also been moved to its canonical location in the knowledge base.

The [SEMRush Connector](https://www.domo.com/docs/s/article/360042929454) article received meaningful new content: a **Traffic Analytics** report type and a detailed **Domains** comparison field that lets you compare keyword data across up to five domains using set-operator syntax (`+`, `-`, `*`, `/`). Several Sage Intacct connector articles were reformatted for improved rendering, and a **Batch Size (rows per page)** field was documented for the Sage Intacct Connector to help users tune performance when hitting API limits.

The [HubSpot Writeback Connector](https://www.domo.com/docs/s/article/1500001012441) article gained a new FAQ covering CSV import requirements — including how to handle quotation marks, single-line value constraints, and what happens when a blank cell is imported into a property that already has a value.

Thanks to Arun Raj and Jared Peterson for these connector improvements.

### 📂 Documents Article Expanded

The [Documents](https://www.domo.com/docs/s/article/Documents) article received several FAQ updates that clarify capabilities customers ask about frequently:

- **New:** Is there a file size upload limit? (No — multi-gigabyte uploads are supported.)
- **Expanded:** The Agent Knowledge file size limit entry now includes a full table of supported file types, sizes, and extensions.
- **Added:** SharePoint is now listed as a supported cloud connector for automatic uploads.
- **Clarified:** Agents & Tools can fully use Documents as Knowledge; Magic ETL Text Generation tile support is on the roadmap and coming soon.

Thanks to Ken Boyer and Jared Peterson for driving these FAQ improvements.

### 🌐 Language Settings: CLDR Locale Note

The [Configure Language Settings](https://www.domo.com/docs/s/article/360043439133) article now includes a note explaining that Domo formats dates and numbers according to the CLDR international standard, with a link so users can look up the expected format for their specific locale.

Thanks to Jared Peterson for this addition.
