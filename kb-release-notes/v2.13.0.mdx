Hello everyone!

We're excited to announce that version 2.13.0 of the Domo Documentation Hub is now available! This release adds three new connector articles, expands the embedded content documentation with PVariables support, delivers accuracy improvements to the Cloud Integrations coverage, and grows the Japanese knowledge base with ten new translated articles. You can view these changes in our knowledge base at [www.domo.com/docs](https://www.domo.com/docs).

## 🌟 What's New

### 🔌 Three New Connector Articles

Documentation is now available for three connectors that previously lacked dedicated articles. The new [Apollo.io Connector](https://www.domo.com/docs/s/article/Apollo.io-Connector) article covers importing account, contact, engagement, call, task, and campaign data from Apollo.io for analyzing sales activity and campaign performance. The [Vanilla Forums Connector](https://www.domo.com/docs/s/article/Vanilla-Forums-Connector) helps community teams import discussions, comments, users, categories, groups, and knowledge articles from Vanilla Forums to analyze engagement and content. And the new [Jira OnPrem OAuth Connector](https://www.domo.com/docs/s/article/000005552) article walks through connecting an on-premises Jira instance to Domo via OAuth to pull in issue tracking, project management, and sprint data.

Thanks to Arun Raj and Jared Peterson for authoring these connector articles.

### 📐 PVariables Support for Embedded Dashboards

The URL Parameters in Embedded Content article has been substantially expanded with a full new section on `pvariables` — a URL parameter that lets developers pre-set the starting values of variable controls on embedded dashboards. The new section covers the JSON format, `exprType` data types (numeric and string), single and multiple variable examples, how to find a variable control ID in browser developer tools, and how to combine `pvariables` with `pfilters` in the same embed URL. Alongside the new content, the existing Pfilters section gains four previously undocumented operands (`NOT_IN`, `NOT_CONTAINS`, `STARTS_WITH`, `ENDS_WITH`) and a spelling correction (`GREATER_THAN_EQUALS_TO`). Read the updated article on [URL parameters in embedded content](https://www.domo.com/docs/portal/embed/embed-in-sites-and-apps/url-parameters-in-embedded-content) to learn more.

Thanks to Mamta Bolaki for this thorough documentation update.

### ☁️ Cloud Integrations and HubSpot Updates

The [Cloud Integrations Overview](https://www.domo.com/docs/s/article/4412849158167) provider support table has been updated to accurately reflect current capabilities: the OAuth M2M entries for Databricks, Google BigQuery, and Snowflake have been removed to match the actual feature set. The [HubSpot Writeback Connector](https://www.domo.com/docs/s/article/1500001012441) article received two improvements — prerequisites now link directly to the Client ID and Secret article rather than repeating the setup steps inline, and a new FAQ entry walks through how to view and review import errors in HubSpot's Data Management interface.

Thanks to Felipe Suarez for the Cloud Integrations accuracy update and Arun Raj for the HubSpot Writeback improvements.

### 🌐 Japanese Content Expansion

Ten articles were translated and added to the Japanese knowledge base, covering AI Admin Settings, AI Chat DataSet Restrictions, Access Tokens, Analyzer, Cloud Integrations data freshness and caching, Documents, DomoStats, Magic ETL AI, the Left Navigation migration guide, and the PostgreSQL SSH Writeback Connector.

Thanks to Masaaki for this localization work.
