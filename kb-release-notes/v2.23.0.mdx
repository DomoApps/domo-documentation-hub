Hello everyone!

We're excited to announce that version 2.23.0 of the Domo Documentation Hub is now available! This is a big one — it bundles the full **September 2026 GA** documentation set alongside a wave of new AI and MCP content that landed since v2.22.0. The September 2026 KB articles are now live in sync with the September 23, 2026 product GA. You can view all of these changes in our knowledge base at [www.domo.com/docs](https://www.domo.com/docs).

## 🚀 September 2026 GA Features

The headline of this release is the batch of KB articles supporting features that go GA with the September 2026 product release. These all shipped from the `release-ga/sept-23-2026` branch and are now live.

### 🤖 AI Chat Enhancements

The [AI Chat](https://www.domo.com/docs/s/article/AI-Chat-v2) article was updated for the September release: chatting across multiple DataSets, working with Documents, generating visualizations directly in chat, and grounding answers in knowledge base content.

Thanks to Ken Boyer for the AI Chat updates.

### 🔗 Card Embed V2

The [Embed Content Outside of Domo](https://www.domo.com/docs/s/article/360043437993) article now documents the new Card Embed experience, including color customization and the upgraded embed URL. A brand-new companion guide walks admins through moving existing embeds over. Learn more in the new [Migrate Embedded Cards to the New Card Embed URL](https://www.domo.com/docs/s/article/Migrate-Embedded-Cards-to-the-New-URL) article.

Thanks to Mamta Bolaki for the embed enhancements and the migration guide.

### 🧱 Magic ETL: Documents Tiles, plus Classification & Sentiment Analysis GA

A new [Magic ETL Tiles: Documents](https://www.domo.com/docs/s/article/Magic-ETL-Tiles-Documents) article documents using Documents inside Magic ETL. Alongside it, the [Magic ETL Tiles: AI Services](https://www.domo.com/docs/s/article/000005741) article was updated to reflect that the Classification and Sentiment Analysis tiles are now generally available (beta badges removed).

Thanks to Ken Boyer for the new Documents tiles article and to Andrea Henderson for shepherding the AI Services tiles to GA.

### ⚙️ Workflows: MCP Trigger

The [Manage Workflows](https://www.domo.com/docs/s/article/000005179) article picked up a new section covering the MCP trigger, so builders can kick off workflows from an MCP client.

Thanks to Ryan Despain for the MCP trigger documentation.

### 📝 Activity Log Webhooks

The [Activity Log](https://www.domo.com/docs/s/article/360042934574) article now documents webhook configuration, letting admins stream activity events to an external endpoint.

Thanks to Dan Brinton for the webhook configuration content.

### 📅 Fiscal & Standard Calendars for Cloud Integrations

A new [Fiscal and Standard Calendar Configuration for Cloud Integrations](https://www.domo.com/docs/s/article/Fiscal-and-Standard-Calendar-Configuration-for-Cloud-Integrations) article covers global and fiscal calendar setup, and the [Cloud Integrations Overview](https://www.domo.com/docs/s/article/4412849158167) was updated to point to it.

Thanks to Felipe Suarez for the new calendar article.

### 📰 September 2026 Release Notes

The [Current Release Notes](https://www.domo.com/docs/s/article/Current-Release-Notes) were rewritten for the September release — covering every new feature, enhancement, beta, and resolved issue — and the prior notes were archived to a dedicated May 2026 Release page.

## 🌟 What's New

Beyond the GA set, several standalone updates merged this cycle.

### 🔌 Domo MCP & MCP Toolkits

A new [Domo MCP](https://www.domo.com/docs/s/article/Domo-MCP) hub introduces Domo's Model Context Protocol integration, backed by a full set of per-area toolkit references: [Alerts](https://www.domo.com/docs/s/article/MCP-Toolkits-Alerts), [Cards](https://www.domo.com/docs/s/article/MCP-Toolkits-Cards), [Code Engine](https://www.domo.com/docs/s/article/MCP-Toolkits-Code-Engine), [Sandbox Repository](https://www.domo.com/docs/s/article/MCP-Toolkits-Sandbox-Repository), [Task Center Queue](https://www.domo.com/docs/s/article/MCP-Toolkits-Task-Center-Queue), [User Administration](https://www.domo.com/docs/s/article/MCP-Toolkits-User-Administration), [Workflow](https://www.domo.com/docs/s/article/MCP-Toolkits-Workflow), and [Workspaces](https://www.domo.com/docs/s/article/MCP-Toolkits-Workspaces), plus a [Coming Soon](https://www.domo.com/docs/s/article/MCP-Toolkits-Coming-Soon) page.

Thanks to Ken Boyer for the entire MCP Toolkits library.

### ✨ Connect Gemini Enterprise to Domo MCP

A new [Connect Gemini Enterprise to Domo MCP](https://www.domo.com/docs/s/article/Connect-Gemini-Enterprise-to-Domo-MCP) article walks through wiring Google's Gemini Enterprise up to Domo's MCP server.

Thanks to Ken Boyer for the Gemini Enterprise integration guide.

### ❄️ Snowflake Semantic Views

A new [About Snowflake Semantic Views](https://www.domo.com/docs/s/article/About-Snowflake-Semantic-Views) article explains how Snowflake semantic views work with Domo, and the [Create and Use Data Models](https://www.domo.com/docs/s/article/Create-and-Use-Data-Models) article was updated to reference them.

Thanks to Felipe Suarez for the semantic views documentation.

### 🔒 AI FAQ: Third-Party Retention

The [Domo AI FAQ](https://www.domo.com/docs/s/article/Domo-AI-FAQ) was refined to clarify third-party (Anthropic) conversation-retention behavior.

Thanks to Jared Peterson for the clarification.

### 🔌 Connector & API Refresh

Arun Raj refreshed connector coverage this cycle — including the custom-connector [IDE limitations](https://www.domo.com/docs/portal/Connectors/Custom-Connectors/ide-limitations) reference — and the Scheduled Reports API spec was enhanced with a new resource-info schema.

Thanks to Arun Raj for the connector and API updates.

### 🛠️ Documentation Presentation & Tooling

Behind the scenes we polished how articles read and how we produce them: standardized support links and feedback icons across the knowledge base, improved article table layouts, a new feature-gated badge convention, and new authoring skills for drafting and reconciling product release notes and tracking GA documentation coverage. A broken image was also restored.

Thanks to Bryce Cindrich for the presentation improvements, to Jared Peterson for the release-notes and coverage tooling, and to Bradley Turek for the image fix.

## 🙏 Thank You

A heartfelt thank you to everyone who contributed to this release. Your work keeps our documentation clear, accurate, and genuinely helpful for our readers.
