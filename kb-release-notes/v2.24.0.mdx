Hello everyone!

We're excited to announce that version 2.24.0 of the Domo Documentation Hub is now available! This release expands caching control for Cloud Integrations, documents several important connector authentication changes, and adds a fresh batch of microlearning videos. You can view these changes in our knowledge base at [www.domo.com/docs](https://www.domo.com/docs).

## 🌟 What's New

### ⚡ Per-DataSet Caching for Cloud Integrations

The Cloud Integrations freshness and caching guide now covers dataset-level cache control, so admins can set a default cache duration for an integration and then override it for an individual DataSet or for several DataSets at once. Fresh step-by-step instructions and new screenshots walk through each path, making it easier to keep data current while limiting warehouse load. Learn more in [configure data freshness and caching in Cloud Integrations](https://www.domo.com/docs/s/article/Configure-Data-Freshness-and-Caching-in-Cloud-Integrations).

Thanks to Felipe Suarez for the overhaul and the supporting updates to the Cloud Integrations overview and connector articles.

### 🔌 Connector Authentication & Report Updates

Several connector articles were updated with time-sensitive authentication guidance and new reporting options:

- The [Microsoft SharePoint Online REST connector](https://www.domo.com/docs/s/article/360043436773) article now documents Microsoft's retirement of IDCRL authentication for the legacy SharePoint connector on May 1, 2026, with a key-dates table and migration guidance for recreating affected datasets.
- The [Shopify connector](https://www.domo.com/docs/s/article/360042927994) article adds a note on Shopify's move to expiring offline access tokens beginning January 1, 2027, and what to do if authentication issues appear afterward.
- The [Anthropic Admin connector](https://www.domo.com/docs/s/article/Anthropic-Admin-Connector) gains a new Usage Partition Report for loading Messages API token usage into monthly partitions.
- The Accellion connector was renamed to **Accellion Kiteworks** to match the current product name.

Thanks to Arun Raj for keeping the connector library accurate and ahead of these authentication deadlines.

### 🎥 New Microlearning Videos

The [Domo Video Library](https://www.domo.com/docs/s/article/Domo-Video-Library) picked up a set of September 2026 microlearning videos covering the AI chat multi-dataset upgrade, safely deleting unused Code Engine packages, the latest card embed enhancements, and new MCP toolkits and triggers for Workflows, Code Engine, and task queues.
