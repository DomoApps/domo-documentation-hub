title: "Domo Documentation Hub v2.26.0 Release Notes"

Hello everyone!

We're excited to announce that version 2.26.0 of the Domo Documentation Hub is now available! This release centers on Domo's new left navigation experience, a big refresh of our Magic ETL and Code Engine developer references, several new and updated connectors, and clearer guidance for data safeguards, color rules, and DataSet archiving. You can view these changes in our knowledge base at [www.domo.com/docs](https://www.domo.com/docs).

## 🌟 What's New

### 🧭 The New Left Navigation Experience

Domo's redesigned left navigation gets a full documentation treatment this release. A brand-new article walks admins through building and assigning Navigation Configs — curated sets of pinned content that control what shows up in the left nav and whether users can personalize their own pins. The core navigation article was substantially rewritten to cover the new main menu, folders, and smart folders, and the Workspaces article now explains how a workspace can serve as a navigation surface. Learn more in the new [Create and Assign Navigation Configs](https://www.domo.com/docs/s/article/Create-and-Assign-Navigation-Configs) article, the refreshed guide to [accessing and creating content through Domo's navigation and main menu](https://www.domo.com/docs/s/article/000005900), and the expanded [Create and Share Workspaces](https://www.domo.com/docs/s/article/Create-and-Share-Workspaces) article.

Thanks to Dany Salas for the deep documentation of the new navigation, folders, smart folders, and workspaces-as-navigation, complete with a full set of fresh screenshots.

### 🔧 Magic ETL & Code Engine Developer References

Our developer references got a major expansion this release. The Magic ETL SQL expression reference and the Supported Functions reference guide were both substantially rewritten for accuracy and completeness, and the Code Engine JavaScript libraries guide grew significantly with expanded coverage of available libraries. Explore the updated [SQL expressions in Magic ETL reference](https://www.domo.com/docs/s/article/000005809), the refreshed [supported functions in Magic ETL reference guide](https://www.domo.com/docs/s/article/360044289573), and the expanded [Code Engine JavaScript libraries reference](https://www.domo.com/docs/portal/Automate-Actions/Code-Engine/javascript-libraries).

Thanks to Bryce Cindrich for the thorough overhaul of these reference docs.

### 🔌 New & Updated Connectors

This release adds a new EncompassV3 Connector for securely retrieving Encompass loan, audit history, field metadata, and user data, and significantly expands our Google BigQuery guidance with step-by-step Workload Identity Federation (WIF) setup for both AWS and OIDC provider types. A batch of connector articles — Amazon S3 AssumeRole Advanced V2, Palace, Apache Kafka, HubSpot Webhook, SAP Fieldglass, Zendesk Guide, LinkedIn, and Vanilla Forums — also received field, report, and credential updates. Read the new [EncompassV3 Connector](https://www.domo.com/docs/s/article/EncompassV3-Connector) article and the updated [Connect Domo to Google BigQuery](https://www.domo.com/docs/s/article/000005237) guide.

Thanks to Arun Raj for the connector additions and updates, and to James Anderson for the detailed BigQuery Workload Identity Federation walkthrough.

### 🛡️ Protect Connector DataSets with Data Safeguards (Beta)

The Adding a DataSet Using a Connector article now includes a new Data Safeguards section explaining how Domo can protect connector DataSets when a schema change would otherwise drop or alter data, including the grants required, which schema changes trigger a safeguard, the available options, and how to configure them. Learn more about [protecting connector DataSets with data safeguards](https://www.domo.com/docs/s/article/360042926274).

Thanks to Jared Peterson for documenting the new data safeguards beta.

### ✨ Clearer Guidance for Color Rules & DataSet Archiving

Two articles got meaningfully clearer this release. The color-rules guide was rewritten with corrected behavior descriptions and new screenshots so analysts can set chart color rules with confidence, and the non-queryable DataSets article gained a new section and FAQ explaining exactly when and why Domo archives inactive DataSets — including how Adrenaline DataFlows factor in. See the updated [Setting Color Rules for a Chart](https://www.domo.com/docs/s/article/360043428813) article and the expanded [Non-queryable DataSets](https://www.domo.com/docs/s/article/360056727214) guide.

Thanks to Dany Salas for the color-rules clarifications and to Felipe Suarez for the DataSet archiving guidance.
