Hello everyone!

We're excited to announce that version 2.28.0 of the Domo Documentation Hub is now available! This release strengthens our security-and-compliance guidance, adds a new connector with a cleaner, easier-to-browse connector catalog, and makes embedding content outside of Domo clearer than ever. You can view these changes in our knowledge base at [www.domo.com/docs](https://www.domo.com/docs).

## 🌟 What's New

### 🔒 Security & Compliance Controls for Vendor Reviews

Customers and their security teams now have a single place to understand how Domo protects data and to gather the evidence they need for third-party vendor assessments. A brand-new article walks through how Domo encrypts data in transit, manages vulnerabilities, and retains security logs — and how to request Domo's SOC reports. We also tied in both the Domo AI FAQ and the public AI Security and Privacy FAQ so AI-related questions are easy to find. Learn more in [Review Domo Security and Compliance Controls](https://www.domo.com/docs/s/article/Review-Domo-Security-and-Compliance-Controls).

Thanks to Jared Peterson for building out this guidance and applying the security review redlines.

### 🔌 New Connector and a Cleaner Connector Catalog

We added a new [Instagram Business Partition Connector](https://www.domo.com/docs/s/article/000005592) article covering setup and configuration. Alongside it, the entire Data Providers catalog was reorganized alphabetically, and a batch of duplicate connector pages was collapsed into single sources of truth with Salesforce slug redirects so older links keep working. We also expanded the [Azure Data Lake Storage Gen2 Using AAD WriteBack Connector](https://www.domo.com/docs/s/article/Azure-Data-Lake-Storage-Gen2-Using-AAD-WriteBack-Connector) article with step-by-step instructions for configuring your Azure app to obtain the client ID and secret. Finally, the Workday, SAP Ariba, and Adaptive Insights connector pages picked up newly supported fields and reports.

Thanks to Jared Peterson for the connector cleanup and new article, and to Arun Raj for keeping the connector field and report coverage current.

### 🖼️ Embedding Enhancements

Managing embedded content is now much clearer. The [Embed Content Outside of Domo](https://www.domo.com/docs/s/article/360043437993) article gained a dedicated Embed Manager section explaining how to update an embed's type, change its owner, and delete an embed. We also simplified the pVariables syntax to a readable, name-based format and documented it in both [URL Parameters in Embedded Content](https://www.domo.com/docs/portal/embed/embed-in-sites-and-apps/url-parameters-in-embedded-content) and [Filter Options for the Embedded View Experience](https://www.domo.com/docs/s/article/4418999855639), with broken links cleaned up along the way.

Thanks to Mamta Bolaki for the embedding improvements.

### 🧰 Developer Docs Link Cleanup

Several App Framework and developer pages stopped linking to code repositories that are moving to internal-only access, so developers no longer hit links that are about to break. This touched the Domo.js tool pages, App Framework Tools, and Sample Projects.

Thanks to Jason Hansen for proactively cleaning up these references.

### ⚙️ Documentation Tooling

Behind the scenes, we simplified the Minor Release Notes format by removing the Updates/Issues Resolved split, refreshed PM ownership and review routing, and kept the automated Minor Release Notes and Video Library syncs running smoothly.

Thanks to Jared Peterson and our automation pipelines for keeping the docs operation humming.

## 🙏 Thank You

A heartfelt thank you to everyone who contributed to this release — your work makes the Domo knowledge base more accurate, more findable, and more helpful every week.

If you have questions or feedback, please reach out — we're always happy to help!
