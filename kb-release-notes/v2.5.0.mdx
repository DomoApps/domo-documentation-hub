Hello everyone!

We're excited to announce that version 2.5.0 of the Domo Documentation Hub is now available! This is a big one — it bundles several smaller releases that landed since v2.4.0 alongside the full May 2026 GA documentation set. The May 2026 KB articles publish today, May 26, 2026, to align with the product feature release date being pushed back from May 20 to May 26. You can view all of these changes in our knowledge base at [www.domo.com/docs](https://www.domo.com/docs).

## 🚀 May 2026 GA Features

The headline of this release is a fresh batch of KB articles supporting features that go GA with the May 2026 product release. These all shipped from the `release-ga/may-20-2026` branch and are now live as of today's publish.

### 📄 FileSets → Documents Rebrand

FileSets has been rebranded to Documents, with a fully reworked KB article that walks through accessing Documents in the new and traditional navigations, creating Document Collections from uploads or DataSet sources, enabling Agent Knowledge for AI Search, searching across Documents, and using Documents from Agents in Workflows, the AI Library, and Magic ETL. Learn more about the new [Documents](https://www.domo.com/docs/s/article/Documents) article.

Thanks to Ken Boyer for the rebrand and the substantial new content.

### 🤖 AI Library, Model Version Differences, and Credit Usage Fields

Three brand-new articles support the expanded AI surface area in May 2026:

- The [AI Library](https://www.domo.com/docs/s/article/AI-Library) article introduces the centralized hub for curating and managing AI agents, AI Agent Builder, AI Toolkits, and the Domo MCP Server integration with Gemini and Claude.
- The [AI Model Version Differences](https://www.domo.com/docs/s/article/AI-Model-Version-Differences) article gives customers a side-by-side reference for Anthropic Claude Sonnet (3.7 / 4 / 4.6), DomoGPT, GPT, Gemini, and Llama — capabilities, version history, and which model to pick for which use case.
- The [Credit Usage Stats Report — AI Fields](https://www.domo.com/docs/s/article/Credit-Usage-Stats-Report-AI-Fields) article documents the AI-related identifiers (`skuGroup`, `skuId`, `entityType`) so admins can interpret AI usage in their credit reports.

Thanks to Ken Boyer for all three new articles.

### 🔑 Self-Serve Access Token Creation (Beta)

A new beta-tagged [Access Tokens](https://www.domo.com/docs/s/article/Access-Tokens) article documents the self-serve access token creation flow, including the new **Create Access Tokens** grant (generate/list/revoke your own tokens) versus the existing **Manage all access tokens and API clients** grant (full admin control). The old access tokens article links forward to the new beta doc.

Thanks to Dan Brinton for authoring the new article and updating the existing one.

### 📋 Task Center — Admin Notification Setting & Queue Archiving

The [Monitor Queues in Task Center](https://www.domo.com/docs/s/article/000005172) article picked up a new Admin Notification Setting section (with three new screenshots showing enabled, disabled, and the setting menu) plus new queue-archiving guidance.

Thanks to Ryan Despain for the Admin Notification Setting work and to Jared Peterson for the queue-archiving section.

### 🏞️ Domo on Lakebase — M2M OAuth

The [Domo on Lakebase](https://www.domo.com/docs/s/article/Domo-on-Lakebase) integration article was substantially expanded to cover machine-to-machine OAuth setup, with a clearer end-to-end flow.

Thanks to Felipe Suarez for the new M2M OAuth content and to Jared Peterson for the clarity refactor.

### 📋 Flex Table & Text Generation Tile

The Current Release Notes were updated with the Flex Table Card Type enhancements (new sorting options and individual column settings) and the new Text Generation Tile, both with refreshed screenshots.

Thanks to McKenna Payne for both write-ups.

## 🌟 What Else Is New

Beyond the May 2026 GA bundle, several smaller releases (v2.4.1, v2.4.2, and ongoing mainline work) shipped between v2.4.0 and v2.5.0. Highlights below.

### 🧩 Data Models — Brand-New KB Article

A net-new [Create and Use Data Models](https://www.domo.com/docs/s/article/Create-and-Use-Data-Models) article walks customers through Domo's new semantic-layer feature: creating a Data Model, adding DataSets to the canvas, defining relationships, configuring schema metadata, and using a model as a data source in Analyzer.

Thanks to Dany Salas for authoring.

### 🎨 Theme-Adaptive Icon System

Inline SVG icon images were migrated to icon fonts repo-wide — Phosphor for general UI icons and the Domo icon font for Domo-specific glyphs — so icons now adapt cleanly to light/dark themes. The legacy `InlineImage` snippet was removed and replaced with native `<img>` tags where icon fonts aren't a fit, and a new `legacy-icon` font was added with an `sm` size class for translated icon strings. The [Alerts Overview](https://www.domo.com/docs/s/article/360043430373) article was the first major article updated to use the new icons (and now correctly references the left nav instead of the header nav).

Thanks to Bryce Cindrich for the multi-week icon overhaul.

### 🛠️ MDX Tooling & Linting Infrastructure

Contributor experience got a major lift this cycle:

- Yarn 4 + remark for MDX linting and format-on-save, with a wrapper script so the formatter picks up Node correctly.
- Mintlify CLI added to `package.json` for local previews.
- New `.editorconfig`, `.gitattributes`, `.prettierignore`, and `.vscode/` settings to standardize editor behavior across the team.
- A new GitHub Actions workflow that flags case-colliding filenames before they land on `main`, plus a one-time rename pass that fixed 40 case-colliding image pairs in `images/kb/` that had been silently breaking on case-insensitive filesystems.
- A `post-merge` git hook (opt-in via `git config core.hooksPath .githooks`) that warns when a `git pull` leaves tracked files missing from your working tree — a known failure mode on macOS APFS / Windows NTFS after case-rename merges.

Thanks to Bryce Cindrich for the Yarn/remark/Prettier setup, the icon-font migration, and the Mintlify CLI integration, and to Jared Peterson for the case-collision check workflow and the phantom-deletion git hook.

### 📊 Chart Types & Tables Refactor

The [Table Charts](https://www.domo.com/docs/s/article/360043429573) and [Period-over-Period Charts](https://www.domo.com/docs/s/article/360042924834) articles were substantially restructured — tables moved into their own dedicated section under Chart Types for Visualization Cards, a stale tree-chart screenshot was fixed, and the old `360042924314.mdx` redirect-only page was retired.

Thanks to Bryce Cindrich.

### ❄️ Snowflake Article Refresh

The [Domo on Snowflake](https://www.domo.com/docs/s/article/4402322966807) article picked up a refreshed Data Transformation section and clearer accordion titles in the FAQ.

Thanks to Jared Peterson.

The navbar, footer, and global anchors were fully localized for Japanese, French, German, and Spanish, with each language block isolated to stop duplicate-render bugs that previously showed all four locales' anchors at once. The Japanese nav was also restructured to move Developer Topics into the Knowledge Base, with a new JP Developer Portal redirect for legacy links.

Thanks to Jared Peterson for the localization pass and to Masaaki Hori for the JP Magic ETL doc updates.
