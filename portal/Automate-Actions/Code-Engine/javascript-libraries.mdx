The Code Engine JavaScript runtime is Node-based. A curated set of libraries is available to functions via `require()`.

## The `codeengine` module

Code Engine provides a built-in helper module for authenticated internal Domo API calls, secure Account credential access, and external HTTP requests:

```javascript
const codeengine = require('codeengine');
```

See [The `codeengine` Runtime Library](./concepts/the-codeengine-library) for the full reference, including `sendRequest`, `getAccount`, `axios`, `getPersonDetails`, and `getExecutionDetails`.

## Third-party libraries via `require()`

The following third-party libraries are available to JavaScript Code Engine functions. The list is **as of 2026-04-23** — if you need a library not listed here, contact Domo Support.

| Library | Purpose | Upstream docs |
|---|---|---|
| `axios` | Promise-based HTTP client. | [axios-http.com](https://axios-http.com) |
| `google-auth-library` | Google OAuth / authentication flows. | [github.com/googleapis/google-auth-library-nodejs](https://github.com/googleapis/google-auth-library-nodejs) |

<Note>
**Note:** `codeengine.axios` (in the `codeengine` module) and the standalone `require('axios')` expose the same underlying library. Use `codeengine.axios` when you want the Code Engine helper conventions; use `require('axios')` when you want a direct handle for advanced configuration.
</Note>

## Requesting a new library

Adding a library to the runtime allowlist is not a user-configurable action. If your function needs a library that is not available, contact Domo Support with your use case.
