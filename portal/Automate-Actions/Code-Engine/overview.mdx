Domo Code Engine is Domo's managed serverless runtime for JavaScript and Python functions. You write functions in the Code Engine UI, version and release them, and call them from Workflows, Custom Apps, Bricks, or external systems.

A Code Engine function is a self-contained unit of server-side code with typed inputs and a typed output. Because Code Engine runs the code inside Domo, functions inherit the caller's Domo session for internal API calls and have controlled access to stored Accounts for external integrations. This makes Code Engine well-suited for automation that needs to act on Domo data, orchestrate external systems, or bridge the two.

## Key concepts at a glance

- [**Packages and versions**](./concepts/packages-and-versions) — Code is grouped into packages; each package has a working version and any number of released versions. Only released versions are callable externally.
- [**Functions and types**](./concepts/functions-and-types) — Functions declare typed inputs and outputs. Types cover primitives plus native Domo entities (`person`, `dataset`, `group`, `account`).
- [**Permissions and sharing**](./concepts/permissions-and-sharing) — Two-layer model: instance grants + per-package ACLs. Workflows and Custom Apps execute under a virtual user, which must have `EXECUTE` on the package.
- [**The `codeengine` runtime library**](./concepts/the-codeengine-library) — Built-in module (`require('codeengine')` in JavaScript) for authenticated internal API calls, stored-account access, and external HTTP.

## Required Grants

To use Code Engine, users need specific grants:

- **Manage Code Engine Packages**: Perform any action on any Code Engine package (for admins/managers).
- **Create Code Engine Packages**: Create new Code Engine packages (for developers).

<Note>**Note:** Contact your Domo account team to enable these grants. Users must also have permission to specific packages to interact with them. See [Permissions and Sharing](./concepts/permissions-and-sharing) for the full model.</Note>

## Accessing Code Engine

1. In the navigation header, select **More > Workflows** to open the Workflows landing page.
2. In the left navigation, select **Code Engine**.

The Code Engine home page displays a list of all available packages based on your permissions.

## Home page

The home page features a repository list of all Code Engine packages you can access. Each row represents a package with columns for:

- **Package Name/Description**
- **Owned By**
- **Runtime** (JavaScript or Python)
- **Last Saved**
- **Created**

Click a row to open the package in the code editor.
