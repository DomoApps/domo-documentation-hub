The Code Engine Python runtime is CPython 3.x. The full Python standard library is available to functions; a curated set of third-party packages is also provided.

## The `codeengine` module

A Python-side `codeengine` helper module may be available, mirroring some or all of the JavaScript helpers (`sendRequest`, `getAccount`, `axios` / `requests`-equivalent, etc.). At the time of writing, the Python surface for `codeengine` helpers is **unverified against runtime source** — use the standard library and the third-party packages listed below until the Python module surface has been confirmed. See [The `codeengine` Runtime Library](./concepts/the-codeengine-library#python-equivalents) for the current status.

## Python standard library

The full Python 3 standard library is available in Code Engine functions. Refer to the [Python Standard Library Documentation](https://docs.python.org/3/library/) for module-by-module reference.

Common stdlib modules that Code Engine users often reach for:

- `json` — parse and serialize JSON.
- `datetime` — date and time manipulation.
- `os`, `sys` — environment and interpreter access.
- `re` — regular expressions.
- `hashlib` — secure hashes.
- `urllib` — URL handling (prefer the third-party `requests` library for HTTP calls).
- `uuid` — generate unique identifiers.
- `sqlite3` — SQLite database access.

## Third-party packages

The following third-party packages are pre-installed in the Python runtime. The list is **as of 2026-04-23** — if you need a package not listed here, contact Domo Support.

| Package | Purpose | Upstream docs |
|---|---|---|
| `boto3` | AWS SDK for Python. | [boto3.amazonaws.com](https://boto3.amazonaws.com/v1/documentation/api/latest/index.html) |
| `botocore` | Low-level core for the AWS SDK. | [botocore.amazonaws.com](https://botocore.amazonaws.com/) |
| `certifi` | Mozilla CA root certificate bundle. | [pypi.org/project/certifi](https://pypi.org/project/certifi/) |
| `numpy` | Numerical arrays and linear algebra. | [numpy.org](https://numpy.org) |
| `pandas` | Data analysis and data frames. | [pandas.pydata.org](https://pandas.pydata.org) |
| `requests` | HTTP client for external APIs. | [requests.readthedocs.io](https://requests.readthedocs.io) |

## Requesting a new package

Adding a package to the runtime is not a user-configurable action. If your function needs a package that is not available, contact Domo Support with your use case.
