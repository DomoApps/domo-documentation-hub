## Intro

Developer Topics collects Knowledge Base articles that are most useful to developers who extend Domo. They cover using the Domo APIs to automate work in Domo, and using the Connector IDE to build connectors for data sources and destinations that Domo doesn't already support. This article describes each topic and links to the full article.

---

## Use the Domo APIs

- [Domo APIs](/s/article/360043439793) — Use Domo APIs to securely automate user and group management, manage data imports and exports, and extend Domo functionality.

For endpoint-level reference documentation, see the [API Reference](/portal/API-Reference/overview).

## Build Connectors

- [Building Custom Connectors in Domo](/s/article/360043439773) — Use the Domo Connector IDE to build custom connectors that integrate APIs not already available in the Appstore with Domo.
- [Build Your Own Writeback Connector](/s/article/1500003318001) — Build a custom Writeback Connector using the Connector IDE to send Domo data to external systems not yet covered by Domo's connector library.

For developer guides on building connectors, see [Connect Data](/portal/Connectors/overview).

## FAQ

<AccordionGroup>

<Accordion title="What is the difference between a custom connector and a writeback connector?">
  A custom connector brings data into Domo from a source that Domo doesn't already connect to. A writeback connector sends Domo data out to an external system. You build both with the Connector IDE.
</Accordion>

<Accordion title="Where do I find the details for a specific API endpoint?">
  See the [API Reference](/portal/API-Reference/overview), which documents the Platform (OAuth) APIs and Product APIs endpoint by endpoint.
</Accordion>

</AccordionGroup>
