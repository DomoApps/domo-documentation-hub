## Intro

A software development kit (SDK) is a collection of tools for building software on a specific platform. Domo's Python and R SDKs wrap the Domo APIs in language-native clients, so you can pull DataSets out of Domo for analysis and push results back. This article describes each SDK and links to its setup article.

---

## Use the Python SDK

- [Python SDKs](/s/article/360042936554) — Use Domo's Python SDK to pull DataSets out of Domo for external data analysis, library-based processing, and cross-system data comparisons.

## Use the R SDK

- [Installing the R SDK](/s/article/360042923734) — Install and initialize the Domo R SDK to transfer DataSets between Domo and R for statistical analysis and data science workflows.

## Find Other SDKs

Domo also supports a Java SDK. For installation details for the Java and Python SDKs, see [Domo SDKs](/portal/Getting-Started/sdks).

## FAQ

<AccordionGroup>

<Accordion title="Do I need an access token to use the SDKs?">
  Yes. The SDKs call the Domo APIs, so they need credentials to reach your instance. For example, the R SDK uses a Domo access token that an admin generates in **Admin** > **Security** > **Access Tokens**. See each SDK's article for its setup steps, and [API Authentication](/portal/1845fc11bbe5d-api-authentication) for how the APIs authenticate.
</Accordion>

<Accordion title="Should I use an SDK or call the APIs directly?">
  Use an SDK when you work in Python or R and want a language-native client for moving DataSets. Call the APIs directly when you work in another language or need an endpoint the SDK doesn't cover. See the [API Reference](/portal/API-Reference/overview).
</Accordion>

</AccordionGroup>
