## Overview

The Activity Log API provides programmatic access to users' actions in Domo. For example, programs can discover the most active users or show trending cards based on page views. The information provided through this API is the same data as provided in the Activity Log in the Admin Settings page of Domo. For the full list of endpoints, parameters, and response objects, see the [Activity Log API reference](/portal/i19jain6fvwjj-activity-log-api).

<Frame>
  ![](/images/dev/s3.amazonaws.com/development.domo.com/wp-content/uploads/2018/01/08164723/ActivityLog1.png)
</Frame>

Note that the API currently supports lookups for activity by specified users.

### Use cases

Using the Activity Log API, your program can:

- Create a list of most active users in the instance
- Discover trends in your Domo instance, such as the most popular cards of the week based on card views
- Surface suspicious activities, such as logins from unexpected locations or at unusual times
- Identify certain problems in your Domo instance, such as failed login attempts and user lockouts

## Quickstart

Accessing your Activity Log entry data is simple and can be done in just one request.

<Note>
  **Note:** In order to follow this Quickstart you will need to obtain an
  [access token](/portal/uc9ls4li6ny8s-embed-token-api#quickstart) or you can
  use the [Rust SDK](/portal/Getting-Started/sdks#rust), which will also handle
  authentication. The Rust SDK is currently the only Domo SDK that supports the
  Activity Log API.
</Note>

### Retrieving Activity Log Entries

This code retrieves a list of Activity Log entries via the Audit API. The `start` parameter is required and takes a time in milliseconds since the Unix epoch. This example retrieves the entries for December 13, 2017 (UTC):

#### Sample Request

<CodeGroup>
```http HTTP icon="globe"
GET /v1/audit?start=1513123200000&end=1513209600000&limit=50 HTTP/1.1
Accept: application/json
Host: api.domo.com
Authorization: bearer <your-valid-oauth-access-token>
```

```rust Rust icon="rust"
// https://github.com/domoinc/domo-rust-sdk/blob/master/src/public/activity/mod.rs#L73
let start = 1513123200000;
let end = Some(1513209600000);
let limit = Some(50);

// Retrieve Activity Log entries (user_id and offset are optional)
let entries = domo.get_entries(None, start, end, limit, None).await?;
println!("Retrieved {} Activity Log entries", entries.len());
```

</CodeGroup>

#### Returns

Returns a list of Activity Log entries. You can provide query parameters to narrow your results based on time and user ID. For the available parameters, see the [Activity Log API reference](/portal/i19jain6fvwjj-activity-log-api).
