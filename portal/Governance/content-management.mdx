## Overview

A page in Domo is a screen where you can view a "collection" of data, which is typically displayed in cards. You use a page to organize, manage, and share content to other users in Domo. For the full list of endpoints, parameters, and response objects, see the [Page API reference](/portal/gcl6cvkh1x5nk-page-api).

<Frame>
  ![](/images/dev/s3.amazonaws.com/development.domo.com/wp-content/uploads/2017/08/09100910/PageVisuals.png)
</Frame>

Pages allow you to send external reports, create holistic filters across all metrics within the page, or have conversations in Domo's Buzz tool about the data associated to the entire page. The Page API allows you to create, delete, retrieve a page or a list of pages, and update page information and content within a page.

### Page use cases

The Page API allows you to extend Domo's platform to support multiple use cases:

- Automate external processes to administer and manage content within Domo
- Easily copy pages, page collections, or cards within an instance
- Grant access to groups or users to a page
- Lock or unlock the capability to edit a page's information or content

For additional help refer to the following guides and articles:

- [Control Access to Cards and Dashboards](/s/article/360042934254)
- [Specify Default Overview Content for Users](/s/article/360043439153)
- [Page Filters and Filter Views on Dashboards](/s/article/360042923914)

## Quickstart

In this guide we will show you how to:

- Create a page
- Create page collections
- Share a page with users or groups

Once a page is created, you can continue to programmatically update its content and access.

<Note>
  **Note:** In order to follow this Quickstart you will need to obtain an
  [access token](/portal/1845fc11bbe5d-api-authentication#quickstart) or you can
  leverage any of [Domo's SDKs](/portal/Getting-Started/sdks) which will also
  handle authentication.
</Note>

### Step 1: Create a page

The first step to managing content in Domo is to create a page. When initially creating a new page, you can automatically add existing cards and grant access to users and groups within the initial request.

#### Sample Request

<CodeGroup>
```http HTTP icon="globe"
POST /v1/pages HTTP/1.1
Content-Type: application/json
Accept: application/json
Host: api.domo.com
Authorization: bearer <your-valid-oauth-access-token>

{
  "name": "Supply Chain",
  "parentId": 23,
  "locked": true,
  "cardIds": [12, 2535, 233, 694],
  "visibility": {
    "userIds": [793, 20, 993, 19234],
    "groupIds": [32, 25, 17, 74]
  }
}
```

```python Python icon="python"
# https://github.com/domoinc/domo-python-sdk/blob/master/examples/page.py#L8
# Create a page
page = domo.pages.create(
    'Supply Chain',
    parentId=23,
    locked=True,
    cardIds=[12, 2535, 233, 694],
    visibility={
        'userIds': [793, 20, 993, 19234],
        'groupIds': [32, 25, 17, 74]
    }
)
domo.logger.info("Created Page {}".format(page['id']))
```

```rust Rust icon="rust"
// https://github.com/domoinc/domo-rust-sdk/blob/master/src/public/page/mod.rs#L149
use domo::public::page::{Page, Visibility};

// Build a Page
let mut page_request = Page::new();
page_request.name = Some(String::from("Supply Chain"));
page_request.parent_id = Some(23);
page_request.locked = Some(true);
page_request.card_ids = Some(vec![12, 2535, 233, 694]);
page_request.visibility = Some(Visibility {
    user_ids: Some(vec![793, 20, 993, 19234]),
    group_ids: Some(vec![32, 25, 17, 74]),
});

// Create a Page
let page = domo.post_page(page_request).await?;
println!("Created Page {}", page.id.unwrap_or_default());
```

```java Java icon="java"
// https://github.com/domoinc/domo-java-sdk/tree/master/domo-java-sdk-all/src/test/java/com/domo/sdk/pages/CreateExample.java
package com.domo.sdk.pages;

import com.domo.sdk.ExampleBase;
import com.domo.sdk.pages.model.Page;
import com.domo.sdk.pages.model.PageVisibility;
import org.junit.Test;

import java.io.IOException;
import java.util.Arrays;

public class CreateExample extends ExampleBase {

  @Test
  public void pageClient_smokeTest() throws IOException {
    PageClient pageClient = client.pageClient();

    create(pageClient);
  }

  public static Page create(PageClient pageClient) {
    // Build a Page
    Page page = new Page.Builder("Supply Chain")
        .setParentId(23)
        .setLocked(true)
        .setCardIds(Arrays.asList(12L, 2535L, 233L, 694L))
        .setPageVisibility(new PageVisibility(
            Arrays.asList(793L, 20L, 993L, 19234L),
            Arrays.asList(32L, 25L, 17L, 74L)))
        .build();

    //Create a page
    return pageClient.create(page);
  }
}
```

```r R icon="r-project"
# https://github.com/domoinc/rdomo/blob/main/R/rdomo.R#L517
page_def <- list(
  name = 'Supply Chain',
  parentId = 23,

    userIds = list(793, 20, 993, 19234),
    groupIds = list(32, 25, 17, 74)
  )

page <- domo$page_create(page_def)

```

</CodeGroup>

Once you create the page, store the `page_id` value with the page name in your own database to use when creating page collections or making updates to the page's content.

### Step 2: Create a page collection

Now that you've created a page and added cards, you can organize the page's content into page collections.

<Note>
  **Note:** In order to add cards to a page collection, the cards must already
  exist on the page. To add a card to the page, add it when you create or update
  the page via the API.
</Note>

#### Sample Request

<CodeGroup>
```http HTTP icon="globe"
POST /v1/pages/3242/collections HTTP/1.1
Content-Type: application/json
Accept: application/json
Host: api.domo.com
Authorization: bearer <your-valid-oauth-access-token>

{
  "title": "East Sales",
  "description": "East Region team includes all Eastern states.",
  "cardIds": [2535, 233, 694]
}
```

```python Python icon="python"
# https://github.com/domoinc/domo-python-sdk/blob/master/examples/page.py#L33
collection = domo.pages.create_collection(
    page['id'],
    'East Sales',
    description='East Region team includes all Eastern states.',
    cardIds=[2535, 233, 694]
)
```

```rust Rust icon="rust"
// https://github.com/domoinc/domo-rust-sdk/blob/master/src/public/page/mod.rs#L233
use domo::public::page::Collection;

let page_id = page.id.unwrap();

let mut collection_request = Collection::new();
collection_request.title = Some(String::from("East Sales"));
collection_request.description = Some(String::from("East Region team includes all Eastern states."));
collection_request.card_ids = Some(vec![2535, 233, 694]);
let collection = domo.post_page_collection(page_id, collection_request).await?;
```

```java Java icon="java"
// https://github.com/domoinc/domo-java-sdk/tree/master/domo-java-sdk-all/src/test/java/com/domo/sdk/pages/CollectionActionsExample.java
package com.domo.sdk.pages;

import com.domo.sdk.ExampleBase;
import com.domo.sdk.pages.model.Page;
import com.domo.sdk.pages.model.PageCollection;
import org.junit.Test;

import java.io.IOException;
import java.util.Arrays;

public class CollectionActionsExample extends ExampleBase {

  @Test
  public void pageClient_smokeTest() throws IOException {
    PageClient pageClient = client.pageClient();

    //Create a page
    Page page = CreateExample.create(pageClient);

    //Build a collection
    PageCollection collection = new PageCollection();
    collection.setTitle("East Sales");
    collection.setDescription("East Region team includes all Eastern states.");

    pageClient.createCollection(page.getId(), collection);
  }
}
```

### Step 3: Share page with users or groups

When you share a page with a user, the page itself is added to the page tab row in the user's personalized Domo view, and the name of the page is added to the user's Pages listing in the People tab.

When you share a page with a group, the page is added to the Domo view of every member of that group, and the name of the page is added to the group's Content Accessible by this Group listing in the Groups tab. Users you've shared with have access to the page and all the cards in it (unless you restrict access to specific cards in the page using the Share dialog).

In order to share a page with either a group or user, the `visibility` object needs to be added as a parameter with either an array of `groupIds` or `userIds` you wish to grant access.

#### Sample Request

<CodeGroup>
```http HTTP icon="globe"
PUT /v1/pages/3242 HTTP/1.1
Content-Type: application/json
Accept: application/json
Host: api.domo.com
Authorization: bearer <your-valid-oauth-access-token>

{
  "name": "Supply Chain Management",
  "parentId": 84,
  "locked": false,
  "collectionIds": [2, 4, 3, 1],
  "cardIds": [2535, 233, 12, 9932, 694],
  "visibility": {
    "userIds": [993, 19234],
    "groupIds": [2, 28, 17, 24]
  }
}
```

```python Python icon="python"
# https://github.com/domoinc/domo-python-sdk/blob/master/examples/page.py#L16
domo.pages.update(

```
