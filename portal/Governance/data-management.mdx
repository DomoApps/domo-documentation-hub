## Overview

DataSets enable visualizations, alerts, and user collaboration that ultimately allow businesses to make data-driven decisions and then take action. Since data is a foundation of the Domo platform, it is important to maintain the accuracy and ownership of DataSets. The DataSet API enables you to automate processes to ensure DataSets have the correct information, access, and ownership. For the full list of endpoints, parameters, and response objects, see the [DataSet API reference](/portal/3b1e3a7d5f420-data-set-api).

For additional help refer to the following guides and articles:

- [Change the Owner of a DataSet](/s/article/360042926074)
- [Schema Management](/s/article/6814561223959)
- [Best Practices for Managing DataSets](/s/article/360042926154)

<Note>
  **Note:** Only DataSets created with the API can be updated via APIs.
</Note>

### Changing DataSet owner

Often there may be a case where an owner of a DataSet has changed companies and has had their access removed or simply changed roles in a company and is no longer responsible for the maintenance of a DataSet. In these cases, the DataSet API allows you to programmatically make updates by first querying for all DataSets owned by a user and then updating each with the new owner's user ID.

#### Sample Request

<CodeGroup>
```http HTTP icon="globe"
PUT /v1/datasets/317970a1-6a6e-4f70-8e09-44cf5f34cf44 HTTP/1.1
Content-Type: application/json
Accept: application/json
Host: api.domo.com
Authorization: bearer <your-valid-oauth-access-token>

{
"name": "Leonhard Euler Birthday Bash",
"description": "VIP Guest List",
"owner": {
"id": 28,
"name": "Carl Friedrich Gauss"
}
}

````

```javascript Node icon="node-js"
// https://github.com/domoinc/domo-node-sdk/blob/master/src/datasets/DatasetClient.ts#L37
const datasetUpdate = {
  name: 'Leonhard Euler Birthday Bash',
  description: 'VIP Guest List',
  owner: {
    id: 28,
    name: 'Carl Friedrich Gauss'
  }
};

domo.datasets.update(datasetId, datasetUpdate)
  .then(res => { console.log(`Updated DataSet '${res.name}'`); })
  .catch(console.error);
````

```python Python icon="python"
# https://github.com/domoinc/domo-python-sdk/blob/master/examples/dataset.py#L32
from pydomo.datasets import DataSetRequest

update = DataSetRequest()
update.name = 'Leonhard Euler Birthday Bash'
update.description = 'VIP Guest List'
update.owner = {
    "id": 28,
    "name": "Carl Friedrich Gauss"
}
updated_dataset = domo.datasets.update(dataset_id, update)
```

```rust Rust icon="rust"
// https://github.com/domoinc/domo-rust-sdk/blob/master/src/public/dataset/mod.rs#L318
use domo::public::dataset::{DataSet, Owner};

let mut ds_update = DataSet::new();
ds_update.name = Some(String::from("Leonhard Euler Birthday Bash"));
ds_update.description = Some(String::from("VIP Guest List"));
ds_update.owner = Some(Owner {
    id: 28,
    name: Some(String::from("Carl Friedrich Gauss")),
});
let dataset = domo.put_dataset(&dataset_id, ds_update).await?;
```

```java Java icon="java"
// https://github.com/domoinc/domo-java-sdk/tree/master/domo-java-sdk-all/src/test/java/com/domo/sdk/datasets/UpdateExample.java
package com.domo.sdk.datasets;

import com.domo.sdk.ExampleBase;
import com.domo.sdk.datasets.model.DataSet;
import com.domo.sdk.datasets.model.Owner;
import org.junit.Test;

import java.io.IOException;

public class UpdateExample extends ExampleBase {

  @Test
  public void dataSetClient_smokeTest() throws IOException {
    DataSetClient dsClient = client.dataSetClient();

    //Create DS
    DataSet ds = CreateExample.create(dsClient);

    //Change the DS owner
    Owner newOwner = new Owner();
    newOwner.setName("Carl Friedrich Gauss");
    newOwner.setId(28);
    ds.setOwner(newOwner);
    dsClient.update(ds);
  }
}
```

```r R icon="r-project"
# https://github.com/domoinc/rdomo/blob/main/R/rdomo.R#L271

  name = 'Leonhard Euler Birthday Bash',
  description = 'VIP Guest List',
  owner = list(
    id = 28,
    name = 'Carl Friedrich Gauss'
  )
)
domo$update_dataset(dataset_id, rjson::toJSON(ds_update))
```

</CodeGroup>

### Updating a DataSet schema

At times, it is necessary to update the DataSet's schema, for example to add a new column as your source data changes.

#### Sample Request

<CodeGroup>
```http HTTP icon="globe"
PUT /v1/datasets/317970a1-6a6e-4f70-8e09-44cf5f34cf44 HTTP/1.1
Content-Type: application/json
Accept: application/json
Host: api.domo.com
Authorization: bearer <your-valid-oauth-access-token>

{
"name": "Leonhard Euler Birthday Bash",
"description": "VIP Guest List",
"pdpEnabled": true,
"schema": {
"columns": [
{
"type": "STRING",
"name": "Friend"
},
{
"type": "STRING",
"name": "Address"
},
{
"type": "STRING",
"name": "Attending"
}
]
}
}

````

```javascript Node icon="node-js"
// https://github.com/domoinc/domo-node-sdk/blob/master/src/datasets/DatasetClient.ts#L37
const datasetUpdate = {
  name: 'Leonhard Euler Birthday Bash',
  description: 'VIP Guest List',
  schema: {
    columns: [
      { type: 'STRING', name: 'Friend' },
      { type: 'STRING', name: 'Address' },
      { type: 'STRING', name: 'Attending' }
    ]
  }
};

domo.datasets.update(datasetId, datasetUpdate)
  .then(res => { console.log(`Updated DataSet '${res.name}'`); })
  .catch(console.error);
````

```python Python icon="python"
# https://github.com/domoinc/domo-python-sdk/blob/master/examples/dataset.py#L32
from pydomo.datasets import DataSetRequest, Schema, Column, ColumnType

update = DataSetRequest()
update.name = 'Leonhard Euler Birthday Bash'
update.description = 'VIP Guest List'
update.schema = Schema([Column(ColumnType.STRING, 'Friend'),
                        Column(ColumnType.STRING, 'Address'),
                        Column(ColumnType.STRING, 'Attending')])
updated_dataset = domo.datasets.update(dataset_id, update)
```

```rust Rust icon="rust"
// https://github.com/domoinc/domo-rust-sdk/blob/master/src/public/dataset/mod.rs#L318
use domo::public::dataset::{Column, DataSet, Schema};

let column = |name: &str| Column {
    name: Some(String::from(name)),
    column_type: Some(String::from("STRING")),
};

let mut ds_update = DataSet::new();
ds_update.name = Some(String::from("Leonhard Euler Birthday Bash"));
ds_update.description = Some(String::from("VIP Guest List"));
ds_update.pdp_enabled = Some(true);
ds_update.schema = Some(Schema {
    columns: Some(vec![column("Friend"), column("Address"), column("Attending")]),
});
let dataset = domo.put_dataset(&dataset_id, ds_update).await?;
```

```java Java icon="java"
// https://github.com/domoinc/domo-java-sdk/tree/master/domo-java-sdk-all/src/test/java/com/domo/sdk/datasets/UpdateExample.java
package com.domo.sdk.datasets;

import com.domo.sdk.ExampleBase;
import com.domo.sdk.datasets.model.Column;
import com.domo.sdk.datasets.model.DataSet;
import org.assertj.core.util.Lists;
import org.junit.Test;

import java.io.IOException;

import static com.domo.sdk.datasets.model.ColumnType.STRING;

public class UpdateExample extends ExampleBase {

  @Test
  public void dataSetClient_smokeTest() throws IOException {
    DataSetClient dsClient = client.dataSetClient();

    //Create DS
    DataSet ds = CreateExample.create(dsClient);

    //Update the DS schema
    ds.getSchema().setColumns(Lists.newArrayList(new Column(STRING, "Friend"), new Column(STRING, "Address"), new Column(STRING, "Attending")));
    dsClient.update(ds);
  }
}
```

```r R icon="r-project"

    )
  )
)
```
