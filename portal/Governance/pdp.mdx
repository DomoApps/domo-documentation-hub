## Overview

Personalized Data Permissions (PDP) allow you to create a customized experience for each Domo user through the definition of Entitlement Policies. Using Entitlement Policies, you can filter data in a DataSet for specified users and/or groups. In other words, the same DataSet can have a card displayed to three different users and display a filtered visual of information based on the user viewing the cards. PDP policies are managed through the DataSet API. For the full list of endpoints, parameters, and response objects, see the [DataSet API reference](/portal/3b1e3a7d5f420-data-set-api).

![PDP Example](/images/dev/s3.amazonaws.com/development.domo.com/wp-content/uploads/2017/08/15093608/PDP2.png)

PDP policies are applied almost anywhere in Domo that data from this DataSet is used, including the following:

- **Cards:** When a KPI or Sumo card is powered by a DataSet with PDP policies in place, impacted users and groups can only view data on the card that is relevant to them.
- **Alerts:** PDP policies in an alert serve to filter the data and regulate which users can subscribe.
- **DataFlows:** While you cannot add input DataSets to a DataFlow if you are limited by PDP policies, it is possible to apply policies to the output DataSets generated by the DataFlow.

Sharing cards affected by PDP policies with users who are not part of the PDP policy will result in them being unable to view the content. However, they can click a button on the card to request to be included in the policy.

For additional help refer to the following guides and articles:

- [Personalized Data Permissions (PDP)](/s/article/360042934614)
- [PDP Automation](/s/article/4415800746391)
- [PDP and Alerts](/s/article/360042934634)

### Creating a Personalized Data Permission (PDP) policy

In order to create a personalized data permission policy you will need to have both the `dataset_id` of the DataSet that you would like to apply a filter to, as well as the `user_ids` or `group_ids` that will have access applied.

Once you have a `dataset_id` and either a `user_id` or `group_id`, choose the columns within the DataSet to apply filters to. Each filter needs a `column`, its `values`, and an `operator`, as seen in the example below.

#### Sample Request

<CodeGroup>
```http HTTP icon="globe"
POST /v1/datasets/4405ff58-1957-45f0-82bd-914d989a3ea3/policies HTTP/1.1
Content-Type: application/json
Accept: application/json
Host: api.domo.com
Authorization: bearer <your-valid-oauth-access-token>

{
  "name": "Only Show Attendees",
  "filters": [
    {
      "column": "Attending",
      "values": ["TRUE"],
      "operator": "EQUALS"
    }
  ],
  "users": [27]
}
```

```javascript Node icon="node-js"
// https://github.com/domoinc/domo-node-sdk/blob/master/src/datasets/PDPClient.ts#L15
// Build a PDP
const policy = {
  name: 'Only Show Attendees',
  filters: [{
    column: 'Attending',
    values: ['TRUE'],
    operator: 'EQUALS',
    not: false
  }],
  users: [27]
};

// Create a PDP
domo.policies.create(datasetId, policy)
  .then(res => { console.log(`Created PDP '${res.name}': ${res.id}`); })
  .catch(console.error);
```

```python Python icon="python"
# https://github.com/domoinc/domo-python-sdk/blob/master/examples/dataset.py#L76
from pydomo.datasets import Policy, PolicyFilter, FilterOperator, PolicyType

# Build a Policy Filter
pdp_filter = PolicyFilter()
pdp_filter.column = 'Attending'
pdp_filter.operator = FilterOperator.EQUALS
pdp_filter.values = ['TRUE']

# Build the PDP
pdp_request = Policy()
pdp_request.name = 'Only Show Attendees'
pdp_request.filters = [pdp_filter]
pdp_request.type = PolicyType.USER
pdp_request.users = [27]

# Create the PDP
pdp = domo.datasets.create_pdp(dataset_id, pdp_request)
domo.logger.info("Created PDP '{}': {}".format(pdp['name'], pdp['id']))
```

```rust Rust icon="rust"
// https://github.com/domoinc/domo-rust-sdk/blob/master/src/public/dataset/mod.rs#L454
use domo::public::dataset::{Filter, Policy};

// Build a PDP
let mut policy_request = Policy::new();
policy_request.name = Some(String::from("Only Show Attendees"));
policy_request.filters = Some(vec![Filter {
    column: Some(String::from("Attending")),
    not: Some(false),
    operator: Some(String::from("EQUALS")),
    values: vec![String::from("TRUE")],
}]);
policy_request.users = Some(vec![27]);

// Create a PDP
let policy = domo.post_dataset_policy(&dataset_id, policy_request).await?;
```

```java Java icon="java"
// https://github.com/domoinc/domo-java-sdk/blob/master/domo-java-sdk-all/src/main/java/com/domo/sdk/datasets/PDPClient.java#L21
import com.domo.sdk.datasets.PDPClient;
import com.domo.sdk.datasets.model.FilterOperator;
import com.domo.sdk.datasets.model.Policy;
import com.domo.sdk.datasets.model.PolicyFilter;

import java.util.Arrays;

PDPClient pdpClient = client.pdpClient();

//Build a policy filter
PolicyFilter filter = new PolicyFilter();
filter.setColumn("Attending");
filter.setValues(Arrays.asList("TRUE"));
filter.setOperator(FilterOperator.EQUALS);

//Build a policy
Policy policy = new Policy();
policy.setName("Only Show Attendees");
policy.setFilters(Arrays.asList(filter));
policy.setUsers(Arrays.asList(27L));

//Create a policy
policy = pdpClient.create(dataSetId, policy);
```

```r R icon="r-project"
# https://github.com/domoinc/rdomo/blob/main/R/rdomo.R#L565
policy_def <- list(
  name = 'Only Show Attendees',
  filters = list(
    list(column = 'Attending', values = list('TRUE'), operator = 'EQUALS')
  ),
  users = list(27)
)

# Create a PDP
pdp <- domo$pdp_create(dataset_id, policy_def)
message(sprintf("Created PDP '%s': %s", pdp$name, pdp$id))
```

</CodeGroup>

Domo will return a subset of the DataSet object specific to the data permission policy.

#### Sample Response

```http
HTTP/1.1 201 Created
Content-Type: application/json

{
  "id": 8,
  "type": "user",
  "name": "Only Show Attendees",
  "filters": [
    {
      "column": "Attending",
      "values": ["TRUE"],
      "operator": "EQUALS",
      "not": false
    }
  ],
  "users": [27],
  "groups": []
}
```

### Listing all PDP policies applied to a DataSet

It is useful to see what existing permission policies have already been applied to the DataSet. This information can be used as a reference to mirror similar group or user access when creating new policies with other DataSets.

The `dataset_id` is required to retrieve all of a DataSet's policies as seen below.

#### Sample Request

<CodeGroup>
```http HTTP icon="globe"
GET /v1/datasets/4405ff58-1957-45f0-82bd-914d989a3ea3/policies HTTP/1.1
Accept: application/json
Host: api.domo.com
Authorization: bearer <your-valid-oauth-access-token>
```

```javascript Node icon="node-js"
// https://github.com/domoinc/domo-node-sdk/blob/master/src/datasets/PDPClient.ts#L30
domo.policies.list(datasetId)
  .then(res => { console.log(`Retrieved ${res.length} PDP(s)`); })
  .catch(console.error);
```

```python Python icon="python"
# https://github.com/domoinc/domo-python-sdk/blob/master/examples/dataset.py#L103
pdp_list = domo.datasets.list_pdps(dataset_id)
domo.logger.info("Retrieved {} PDP(s)".format(len(pdp_list)))
```

```rust Rust icon="rust"
// https://github.com/domoinc/domo-rust-sdk/blob/master/src/public/dataset/mod.rs#L434
let policies = domo.get_dataset_policies(&dataset_id).await?;
println!("Retrieved {} PDP(s)", policies.len());
```

```java Java icon="java"
// https://github.com/domoinc/domo-java-sdk/blob/master/domo-java-sdk-all/src/main/java/com/domo/sdk/datasets/PDPClient.java#L40
int limit = 50;
int offset = 0;
List<Policy> policies = pdpClient.list(dataSetId, limit, offset);
```

```r R icon="r-project"
# https://github.com/domoinc/rdomo/blob/main/R/rdomo.R#L585
policies <- domo$pdp_list(dataset_id)
message(sprintf("Retrieved %d PDP(s)", length(policies)))
```

</CodeGroup>

Domo will return all PDP policies that are applied to the DataSet specified in the request.

#### Sample Response

```http

Content-Type: application/json

[
  {

    "name": "Only Show Attendees",
```

### Updating a PDP policy

Because users and groups change so frequently in addition to data, programmatically updating a DataSet policy can ensure better accuracy and timeliness when managing access rights to sensitive data.

In order to update a DataSet Personalized Data Permission (PDP), you will need both the `dataset_id` and the `policy_id`.

#### Sample Request

<CodeGroup>
```http HTTP icon="globe"
PUT /v1/datasets/4405ff58-1957-45f0-82bd-914d989a3ea3/policies/8 HTTP/1.1
Content-Type: application/json
Accept: application/json
Host: api.domo.com
Authorization: bearer <your-valid-oauth-access-token>

{
  "name": "Not Attending",
  "filters": [
    {
      "column": "Attending",
      "values": ["TRUE"],
      "operator": "EQUALS",
      "not": true
    }
  ]
}
```

```javascript Node icon="node-js"
// https://github.com/domoinc/domo-node-sdk/blob/master/src/datasets/PDPClient.ts#L36
const policyUpdate = {
  name: 'Not Attending',
  filters: [{
    column: 'Attending',
    values: ['TRUE'],
    operator: 'EQUALS',
    not: true
  }]
};

domo.policies.update(datasetId, policyId, policyUpdate)
  .then(res => { console.log(`Updated PDP '${res.name}'`); })
  .catch(console.error);
```

```python Python icon="python"
# https://github.com/domoinc/domo-python-sdk/blob/master/examples/dataset.py#L108
# `not` is a Python keyword, so set it as a dictionary key
pdp_filter['not'] = True

pdp_update = Policy()
pdp_update.name = 'Not Attending'
pdp_update.filters = [pdp_filter]
pdp = domo.datasets.update_pdp(dataset_id, pdp['id'], pdp_update)
```

```rust Rust icon="rust"
// https://github.com/domoinc/domo-rust-sdk/blob/master/src/public/dataset/mod.rs#L496
use domo::public::dataset::{Filter, Policy};

let policy_id = policy.id.unwrap();

let mut policy_update = Policy::new();
policy_update.name = Some(String::from("Not Attending"));
policy_update.filters = Some(vec![Filter {
    column: Some(String::from("Attending")),
    not: Some(true),
    operator: Some(String::from("EQUALS")),
    values: vec![String::from("TRUE")],
}]);
let policy = domo.put_dataset_policy(&dataset_id, policy_id, policy_update).await?;
```

```java Java icon="java"
// https://github.com/domoinc/domo-java-sdk/blob/master/domo-java-sdk-all/src/main/java/com/domo/sdk/datasets/PDPClient.java#L52
filter.setNot(true);
policy.setName("Not Attending");
policy.setFilters(Arrays.asList(filter));
policy = pdpClient.update(dataSetId, policy.getId(), policy);
```

```r R icon="r-project"
# https://github.com/domoinc/rdomo/blob/main/R/rdomo.R#L591
policy_update <- list(
  name = 'Not Attending',
  filters = list(
    list(column = 'Attending', values = list('TRUE'), operator = 'EQUALS', not = TRUE)
  )
)
pdp <- domo$pdp_update(dataset_id, pdp$id, policy_update)
```
