## Intro

Other Resources collects developer resources that live outside the main Developer Portal documentation. Use them to check the health of Domo APIs, ask questions of other Domo developers, and learn from working code. This article describes each resource and links to it.

---

## Check API Status

- [API Status](/portal/Other-Resources/api-status) — Check the latest status of the Domo platform, including API uptime and performance history.

## Connect With the Community

- [Community Forums](/portal/Other-Resources/Developer-Forum) — Connect with other Domo customers to ask questions, find answers, and share best practices.

## Learn From Sample Code

- [Sample Projects](/portal/Other-Resources/sample-projects) — Example projects, visualization samples, and community libraries built by Domo and the developer community.

## FAQ

<AccordionGroup>

<Accordion title="Where can I see whether a Domo API is having an outage?">
  The [API Status](/portal/Other-Resources/api-status) page links to the current status of the Domo platform, along with uptime and performance history.
</Accordion>

<Accordion title="Are the community sample projects supported by Domo?">
  Some sample projects are built by Domo and others by members of the developer community. Each project on the [Sample Projects](/portal/Other-Resources/sample-projects) page names its author.
</Accordion>

</AccordionGroup>
