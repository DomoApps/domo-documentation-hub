Hello everyone!

We're excited to announce that version 2.19.0 of the Domo Documentation Hub is now available! This release adds a brand-new Workspaces guide, expands our AI model documentation with DomoGPT—Large, and keeps several connectors current with new reports and an important Greenhouse API deprecation notice. You can view these changes in our knowledge base at [www.domo.com/docs](https://www.domo.com/docs).

## 🌟 What's New

### 🗂️ Create and Share Workspaces

A brand-new article walks users through creating, configuring, and sharing Workspaces from start to finish, with step-by-step screenshots throughout. Learn more in [Create and Share Workspaces](https://www.domo.com/docs/s/article/Create-and-Share-Workspaces).

Thanks to Dany Salas for authoring the article and its screenshots, and to Jared Peterson for tidying up the header formatting.

### 🤖 DomoGPT—Large Now Documented

The AI Model Version Differences article now includes a dedicated section for DomoGPT—Large (powered by Anthropic Claude), complete with a compare-versions table covering context window, max response length, image/doc support, and recommended use cases. Read the updated [AI Model Version Differences](https://www.domo.com/docs/s/article/AI-Model-Version-Differences).

Thanks to Ken Boyer for keeping our AI model documentation current.

### 🔌 Connector Updates

Several connectors received updates this release:

- **Greenhouse** — Added an important notice that Greenhouse is deprecating its Harvest API V1 and V2 endpoints effective August 31, 2026. The connector now authenticates with a Client ID and Client Secret, and a new Job Interviews report is available. See the [Greenhouse Connector](https://www.domo.com/docs/s/article/360042928174).
- **Qualtrics and Qualtrics Upsert** — Refreshed report and credential details.
- **TikTok Ads** — Added a Smart Plus Ads report.
- **EDGE by Ascential, LiveChat, and Apollo.io** — Report and detail cleanups.

Thanks to Arun Raj for keeping our connector documentation accurate and up to date.

### 🎥 Video Library Refresh

Our automated Domo Video Library sync added new microlearning videos covering Magic ETL settings and utility actions, and managing dataflow versions.

## 🙏 Thank You

A heartfelt thank you to everyone who contributed to this release. Your work keeps our documentation clear, current, and genuinely helpful for the people who rely on it every day.

If you have questions or feedback, please reach out — we're always happy to help!
