Hello everyone!

We're excited to announce that version 2.2.0 of the Domo Documentation Hub is now available! This release brings substantial content overhauls for key integration articles, a wave of new and updated connector docs, a standardized beta-feature convention across the repo, and a broad infrastructure cleanup that makes the codebase easier to maintain. You can view these changes in our knowledge base at www.domo.com/docs.


**🌟 What's New**

**🗄️ Domo on BigQuery & Cloud Integrations — Major Overhaul**
The Domo on BigQuery article has been completely rebuilt from the ground up: new UI screenshots (29 fresh images), a reorganized structure, coverage of Workload Identity Federation (WIF) authentication, updated prerequisites and permissions, a new "BQ Query Metadata" section, and a FAQ. As part of this work, all references to "Cloud Amplifier" have been updated to "Cloud Integrations" throughout the article to align with the current product name.
Thanks to Felipe Suarez and Jared Peterson for the full review and overhaul.

**🔷 Databricks — Fully Refactored Article**
The Databricks connector article has been rewritten to match the updated UI, with a new callout block, revised prerequisites, and step-by-step coverage of the new Machine-to-Machine (M2M) authentication method.
Thanks to Felipe Suarez for the complete refactor.

**🔌 New & Updated Connector Articles**
  • Wasabi Connector: brand-new KB article and screenshots added to the connector library, now listed in the Data Providers T–X and # navigation group.
  • ZiftOne Connector: title and section heading corrected to "ZiftOne Connector."
  • HubSpot Upsert Connector: fixed a missing table and formatting issues, including a typo in bold syntax.
  • Cvent Connector: added a new "Cvent API Scopes" section, Goals Report descriptions, Top Campaign Content report, and Event Dates field documentation.
  • Microsoft SharePoint Online Single-Tenant Writeback Connector: revised for clarity and completeness.
Thanks to ArunRaj, Jared Peterson, and the connector team for these additions and fixes.

**🔑 Access Token Documentation — Clarified Requirements**
The access token management article has been substantially revised: it now clearly explains what roles and grants are required to generate access tokens, with improved formatting and step-by-step requirements breakdown. Updated allowlisting coverage also adds the us-east-1 exile range, OCI, and AWS London IP ranges to the network allowlisting article.
Thanks to Bradley Turek and John Nielsen for these improvements.

**🚀 Domo Publish Action v3 — New Reference Documentation**
The domo-publish CI/CD documentation has been completely rewritten for the v3 release. The new article covers the updated chdir-based publish workflow, a full v3 inputs/outputs reference, multi-environment and path-filter examples (including pnpm/yarn), a v2→v3 migration diff, and a troubleshooting table. The CI/CD pipeline itself has also been updated to Node.js 24.
Thanks to Bradley Turek for the v3 documentation rewrite.

**🏷️ Beta Feature Convention — Standardized Repo-Wide**
A single, consistent convention for marking beta content is now documented in the Style Guide and applied across all relevant articles and portal pages. Beta articles use frontmatter `tag: "Beta"` plus a standard Note block; section-level betas use a `<Badge>` component on the heading. Legacy ad-hoc beta markers have been cleaned up, and several features that shipped GA have had their beta markers removed. The new-kb-article, update-kb-article, and csv-to-mdx skills have all been updated to apply this convention automatically.
Thanks to Bryce Cindrich for the convention design and repo-wide rollout.

**🛠️ Inline Image Infrastructure Cleanup**
The deprecated `<InlineImage>` component has been replaced with native `<img>` tags across the entire repository, and unused InlineImage imports were removed from 22 KB articles. Several malformed image tags in the Cloud Integrations, caching, and Cloud Amplifier permissions tables were also corrected.
Thanks to Jared Peterson for this maintenance sweep.

**✍️ Authoring Tooling — Mintlify Design Skill & Style Guide Updates**
A new `mintlify-design` Claude Code skill is now available for choosing Mintlify components, composing custom layouts, and authoring reusable snippets. The Style Guide has been updated with a `<Tooltip>` component style entry and the full Beta Features convention section. The New Article Template has also been updated to include a JSX-comment scaffolding block describing the beta convention.
Thanks to Jonathan Tiritilli and Jared Peterson for these authoring improvements.


**🙏 Thank You**

A heartfelt thank you to everyone who contributed to this release — your careful documentation work makes Domo easier to use for developers, admins, and customers everywhere. We especially appreciate the contributors who took on large-scale rewrites and infrastructure cleanup this cycle.

If you have questions or feedback, please reach out — we're always happy to help!
