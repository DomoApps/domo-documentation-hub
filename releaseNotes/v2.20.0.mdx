title: "Domo Documentation Hub v2.20.0 Release Notes"

Hello everyone!

We're excited to announce that version 2.20.0 of the Domo Documentation Hub is now available! This release sharpens our DataSet sharing guidance, keeps connector documentation current with upstream API changes, and adds a fresh batch of microlearning videos. You can view these changes in our knowledge base at [www.domo.com/docs](https://www.domo.com/docs).

## 🌟 What's New

### 📊 Clearer DataSet Sharing and Access Rights

The **Share a DataSet** article got a significant accuracy pass. The Access Rights table now correctly reflects that Editors can change dataset configurations, and that Can Share users can view all data in the dataset (subject to PDP policy). The article was also reformatted with corrected icons, links, and note styling so it's easier to scan. See the updated guidance on [sharing a DataSet](https://www.domo.com/docs/s/article/360043430713).

Thanks to Landon Woollard for the Access Rights corrections and to Jared Peterson for the formatting cleanup.

### 🔌 Connector Documentation Updates

- The **Facebook Advanced Connector** article now includes an important notice about Facebook metrics being deprecated on June 30, 2026, with a table mapping each deprecated metric to its replacement so customers can update datasets and reports ahead of the change. Read the full details in the [Facebook Advanced Connector](https://www.domo.com/docs/s/article/360043434413) article.
- The **Commission Junction Connector** prerequisites were updated to reflect CJ's move from an API key to a Personal Access Token. See the current setup steps in the [Commission Junction Connector](https://www.domo.com/docs/s/article/360043431033) article.
- The Neurio connector was repositioned alphabetically in the navigation between NetSuite and New Relic.

Thanks to Arun Raj for keeping our connector docs in step with upstream provider changes.

### 🎓 New Microlearning Videos

The Domo Video Library picked up a new set of microlearning videos this release, including a Managing DataFlows series (dataflow details, history, naming and tagging, scheduling and triggering, and sharing), SQL-based DataFlows using the SQL DataFlow interface, and consumption and distribution topics. Browse them all in the [Domo Video Library](https://www.domo.com/docs/s/article/Domo-Video-Library).

### 🔗 API Reference Correction

The User API reference was updated to use the correct endpoint path, `/api/identity/v1/users`, in both the spec and the navigation.

Thanks to Dallin for catching and correcting the endpoint path.

### 🛠️ Documentation Tooling

We added a local Mintlify preview script and a matching `generate-mint-preview-link` skill so contributors can spin up a preview deploy for any branch on demand.

Thanks to Jared Peterson for building the preview workflow.

## 🙏 Thank You

A heartfelt thank you to everyone who contributed to this release — your accuracy fixes, connector updates, and new training content keep the knowledge base trustworthy and genuinely useful.

If you have questions or feedback, please reach out — we're always happy to help!
