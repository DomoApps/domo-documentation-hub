Hello everyone!

We're excited to announce that version 2.3.0 of the Domo Documentation Hub is now available! This release delivers a major site-wide cleanup of headings and anchor links, several brand-new connector articles, important deprecation notices for Adobe Analytics customers, and a smoother onboarding flow in our Getting Started navigation. You can view these changes in our knowledge base at www.domo.com/docs.


🌟 What's New

🧭 Site-Wide Heading & Anchor Cleanup
We completed a sweeping repository-wide normalization that touched well over a thousand KB articles across English, German, Spanish, French, and Japanese locales. This work:
  • Normalized heading hierarchy across ~600 KB articles so every page begins with a single H1 and descends in proper order, fixing accessibility and Mintlify TOC rendering.
  • Migrated legacy Salesforce-style underscore anchors (#some_anchor) to Mintlify's kebab-case format across ~400 articles, and patched edge cases by hand.
  • Removed obsolete table-of-contents blocks and "back-to-top" anchor links carried over from the old Salesforce site, along with their localized counterparts in DE/ES/FR/JA.
  • Stripped leading "> " prefixes from 16 article titles and cleaned up stray `/minasan/` path segments left over in legacy domo-support URLs.
Thanks to Jared Peterson for the multi-pass migration scripts and the careful hand-fixes that kept this from breaking real links.

🆕 New Connector Articles
Three brand-new connector KB articles landed this cycle:
  • Databricks Using OAuth M2M Authentication Connector — full draft and walkthrough for the new Machine-to-Machine OAuth flow.
  • Databricks AWS Writeback Connector — a new writeback connector article covering AWS-targeted Databricks setups.
  • Microsoft SharePoint Online Rest P&G Domo Connector — a new connector reference added to the SharePoint family of articles.
Thanks to ArunRaj and Jared Peterson for authoring and shepherding these through review.

⚠️ Adobe Analytics Connector Deprecations
Three Adobe Analytics connectors now carry clear, customer-facing deprecation notices ahead of Adobe's August 2026 retirement of the v1.4 API (and the resulting Domo connector retirement on July 8, 2026):
  • Adobe Analytics Advanced Legacy Connector
  • Adobe Analytics Real Time API Connector
  • Adobe Analytics 1.4 Server to Server OAuth Connector
Each article now has "(Deprecated)" in the title and a prominent Warning block pointing customers to the recommended v2 OAuth Partition Connector replacement where applicable.
Thanks to ArunRaj for the consistent deprecation rollout across all three articles.

🤖 MCP Server — Updated Beta Note & Grants Section
The Connect AI Tools to Domo Using MCP article now reflects MCP's move to public open beta, clarifies that DOMO AI is available only to customers on a consumption agreement (with a Customer Success Manager trial path for others), and adds a dedicated Required Grants section so admins can see exactly which grants (Use AI Services, Use AI Chat) unlock the feature.
Thanks to Ken Boyer for the beta-status update and Jared Peterson for tightening the grants formatting.

🔌 Connector Article Polish
A round of targeted improvements to existing connector and writeback articles:
  • PostgreSQL SSH Writeback Connector — title normalized, content revised, and note/warning formatting corrected.
  • Azure Data Lake Storage Gen2 Using AAD Writeback Connector — five new sections added (Get an Azure App Client ID, Get the Azure App Client Secret, Get the Microsoft Entra Tenant ID, and more), plus a tenant-ID typo fix.
  • Microsoft SharePoint Online Single-Tenant Writeback Connector — corrected Redirect URI in the Create an Azure App section to use the singletenant-specific endpoint.
  • Microsoft SharePoint Online Rest Single Tenant Connector — title corrected from "Rest Tenant" to "Rest Single Tenant."
  • HubSpot connector — fixed a malformed table row in the Reports section.
  • Databricks OAuth M2M article — title, intro, and grant-description formatting tightened up.
Thanks to ArunRaj, Jared Peterson, and Bradley Turek for these fixes.

🧑‍💼 Getting Started — Reordered for Better Onboarding
The Getting Started group in the left-hand nav has been re-sequenced to put the most important first-time articles earlier in the list, smoothing the path new users take through the documentation.
Thanks to Jared Peterson for the navigation reorder.
