Hello everyone!

We're excited to announce that version 2.17.0 of the Domo Documentation Hub is now available! This release brings a top-to-bottom overhaul of our AppDB developer documentation, a new workflow trigger, and two brand-new connector articles. You can view these changes in our knowledge base at [www.domo.com/docs](https://www.domo.com/docs).

## 🌟 What's New

### 🗄️ AppDB Documentation Overhaul

Our AppDB documentation received a comprehensive rewrite this release. The App Framework and Product API references were rebuilt around the current v2 document endpoints — with accurate request/response examples verified against live API behavior, domo.js v6 code samples on every operation, aggregation and partial-update guidance, and clearer permissions and collection-management docs. See the refreshed [AppDB App Framework API reference](https://www.domo.com/docs/portal/API-Reference/app-framework-apis/AppDB-API) and [AppDB Product API reference](https://www.domo.com/docs/portal/API-Reference/Product-APIs/App-DB).

New app builders also get a hands-on starting point: a step-by-step guide that walks through building a working [inventory tracker with AppDB](https://www.domo.com/docs/portal/Apps/App-Framework/Guides/appdb-inventory-tracker), demonstrating collections, documents, and queries end to end.

### 🔄 Modernized AppDB Custom Sync Guide

The AppDB custom sync schedule guide was modernized with retry logic, clearer pass/fail handling, tightened setup instructions, and reference links so developers can wire up dependable scheduled syncs. Read the updated [AppDB custom sync schedule guide](https://www.domo.com/docs/portal/Apps/App-Framework/Guides/workflow-appdb-sync).

### ⚙️ New Workflow Trigger: Access Request

Workflows can now be kicked off automatically whenever someone requests access to a Card, Page, or App. The new Access Request trigger captures the requestor and entity IDs and can map them into your workflow's starting parameters — great for automating approvals and access reviews. Learn more in the [Manage Workflows](https://www.domo.com/docs/s/article/000005179) article.

### 🔌 New Connectors

Two new connector articles joined the knowledge base this release: the [Snowflake OAuth Unload Connector](https://www.domo.com/docs/s/article/1500010166282), which uses OAuth to unload data from Snowflake, and the [Brivo Connector](https://www.domo.com/docs/s/article/Brivo-Connector) for pulling in Brivo access-control data. We also refreshed several existing connector articles, including Facebook/Meta Ads Advanced, Cvent, Salesforce, Workiva, and Workday Adaptive Planning writeback connectors, with updated fields, reports, and setup details.

## 🙏 Thank You

A heartfelt thank you to everyone who helped make this release possible. We hope these updates make your Domo experience even better.

If you have questions or feedback, please reach out — we're always happy to help!
