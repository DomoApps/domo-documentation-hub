Hello everyone!

We're excited to announce that version 2.22.0 of the Domo Documentation Hub is now available! This release expands our App Studio component guidance, adds AI Agents to Workspaces, and brings a new AWS cost connector online. You can view these changes in our knowledge base at [www.domo.com/docs](https://www.domo.com/docs).

## 🌟 What's New

### 🧩 New App Studio Component Guides

Three brand-new articles walk you through building and styling app components in App Studio. Learn how to [group and aggregate data in an app component](https://www.domo.com/docs/s/article/Group-and-Aggregate-Data-in-App-Components) with a Number widget and component header, how to [create a KPI component](https://www.domo.com/docs/s/article/Create-a-KPI-Component-in-App-Studio) and configure each metric with a column, aggregation, filter, and formatting, and how to [apply conditional formatting and conditional rendering](https://www.domo.com/docs/s/article/Apply-Conditional-Formatting-and-Conditional-Rendering-in-App-Components) to change a widget's appearance or visibility based on DataSet values. Each guide is fully illustrated with step-by-step screenshots.

### 🤖 AI Agents in Workspaces

AI agents are now a supported content type in Workspaces. The [Create and Share Workspaces](https://www.domo.com/docs/s/article/Create-and-Share-Workspaces) article now documents how to add custom AI agents, what members can access (including the DataSets, Documents, Tools, Toolkits, and Skills the agent depends on), and the fact that agents can only be added from inside the Workspace.

### ☁️ AWS FOCUS Cost and Usage Connector

A new connector article covers the [AWS Focus Cost And Usage Connector](https://www.domo.com/docs/s/article/AWS-Focus-Cost-And-Usage-Connector), which retrieves FOCUS-formatted cost and usage data from AWS for reporting and analysis in Domo. We also refreshed the Facebook Ads Advanced and Ivinex connector articles with small field and report updates.

## 🙏 Thank You

A heartfelt thank you to everyone who helped make this release possible. Your work keeps our documentation clear, accurate, and genuinely helpful for our readers.

If you have questions or feedback, please reach out — we're always happy to help!
