## Intro

You can apply CSS styling to cards embedded in the email body of your campaigns. This article describes the process.

To learn more about creating a campaign, see our article on the [Domo Campaigns App](http://domo-support.domo.com/s/article/360042933494).

### Known Limitations

The following are known limitations of this feature.

* Supported components include:
    
  * cards
* You can only add one CSS class per component
* Adding the class tag to the following card fields makes no change to the card's styling:
    
  * Title
    
  * Summary Number
    
  * Description
    
  * Alert
    
  * Comment
    
  * Unsubscribe
* Adding the CSS tag to the fields listed above does not generate an error, but the tag is not added in the HTML node.

## Adding CSS to a Card

<Steps titleSize="h3">
<Step title="Open a Campaign">
In the Campaigns app, select a campaign to open it.
</Step>
<Step title="Locate the Email Body Editor">
In the **Email Body** tab, locate the **Email Body Editor**.
</Step>
<Step title="Switch to HTML Mode">
Switch to HTML mode by selecting <img src="/images/kb/ka05w00000125Kw-00N5w00000Ri7BU-0EM5w000005wZOL.jpg" style={{width: 20, height: 20, display: 'inline', verticalAlign: 'start', margin: '0'}}/> **Change mode** in the toolbar.

<Frame><img alt="change mode.png" src="/images/kb/ka05w00000125Kw-00N5w00000Ri7BU-0EM5w000005wZOa.jpg"/></Frame>
</Step>
<Step title="Add a Style Tag">
Add an HTML style tag at the top of the editor: \<style>
</Step>
<Step title="Write Your CSS Class">
Inside the style tag, write your custom CSS class. Make sure to close the style tag: \</style>
</Step>
<Step title="Add a Card">
Select **Add Card** to add a card to the email.
</Step>
<Step title="Apply the Class to the Card">
Edit the card tag and add a class tag followed by the name of your custom class.

<Frame><img alt="applying css examples.png" src="/images/kb/ka05w00000125Kw-00N5w00000Ri7BU-0EM5w000005wZNc.jpg"/></Frame>
</Step>
<Step title="Save Your Changes">
Select **Save** to save your changes.
</Step>
</Steps>

When the card is rendered, the CSS class is applied to the component.
