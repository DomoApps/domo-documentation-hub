## Intro

MySQL users can connect their data to Domo through Cloud Integrations native integration. Provide connection parameters and select the tables you want to see as Domo DataSets.

Follow the steps in this article to configure your read-only MySQL-Domo connection with Cloud Integrations.

## Configure Read-only Connection to MySQL

<Steps titleSize="h3">
<Step title="Navigate to the Data Center">
Navigate to the Domo Data Center.
</Step>
<Step title="Open the Data Warehouse">
(Conditional) If you're not already there, use the sidebar to go to the <img src="/images/kb/ka0Vq000000BCNd-00N5w00000Ri7BU-0EMVq000000uR3y.jpg" style={{width: 20, height: 20, display: 'inline', verticalAlign: 'start', margin: '0'}}/> **Data Warehouse**.
</Step>
<Step title="Add a New Cloud Account">
Select <img src="/images/kb/ka0Vq000000BCNd-00N5w00000Ri7BU-0EMVq000000uSeO.jpg" style={{width: 20, height: 20, display: 'inline', verticalAlign: 'start', margin: '0'}}/> **Add New Cloud Account**.

<Frame><img alt="add new cloud account.jpg" src="/images/kb/ka0Vq000000BCNd-00N5w00000Ri7BU-0EMVq000000uRaE.jpg"/></Frame>

The **Amplify existing cloud warehouses** modal displays.
</Step>
<Step title="Expand the Native Integration Options">
In the **Native integration** section, choose **See More** to see the rest of the options.

<Frame><img alt="see more.jpg" src="/images/kb/ka0Vq000000BCNd-00N5w00000Ri7BU-0EMVq000000uTIf.jpg"/></Frame>
</Step>
<Step title="Select MySQL">
Select **MySQL**.

<Frame><img alt="mysql.jpg" src="/images/kb/ka0Vq000000CwrR-00N5w00000Ri7BU-0EMVq000000uRYc.jpg"/></Frame>
</Step>
<Step title="Add a New Integration">
Select **+ Add New Integration**.

<img src="/images/kb/ka0Vq000000CwrR-00N5w00000Ri7BU-0EMVq000000uSL0.jpg" style={{width: 20, height: 20, display: 'inline', verticalAlign: 'start', margin: '0'}}/> <img src="/images/kb/ka0Vq000000CwrR-00N5w00000Ri7BU-0EMVq000000uTgr.jpg" style={{width: 20, height: 20, display: 'inline', verticalAlign: 'start', margin: '0'}}/>
</Step>
<Step title="Enter Connection Parameters">
Enter the following connection parameters in the appropriate fields:

* **Integration name —** If you need to update your integration in the future, this is the name to search for in the list of integrations.
* **Integration description (optional) —** Enter any additional information about the integration.
* **MySQL connection URL —** Enter the host and port that represents the MySQL instance you are connecting to. Ex. *[myhost.com](http://myhost.com):3306*
* **MySQL username —** The MySQL instance username that has access to the data you are connecting to.
* **MySQL password —** The password for the MySQL user.

<Frame><img alt="Screenshot 2024-05-07 at 3.21.47 PM.png" src="/images/kb/ka0Vq000000CwrR-00N5w00000Ri7BU-0EMVq000000uWej.jpg"/></Frame>
</Step>
<Step title="Configure Caching Options">
Configure caching options. You can choose whether to automatically check for data updates and at what interval. Learn about Cloud Integrations [caching rules](/s/article/4412849158167#caching-rules).

<Frame><img alt="Screenshot 2024-05-07 at 3.24.52 PM.png" src="/images/kb/ka0Vq000000BCNd-00N5w00000Ri7BU-0EMVq000000uWur.jpg"/></Frame>
</Step>
<Step title="Select Next">
Select **Next**.

A success message displays.
</Step>
<Step title="Choose Tables to Connect">
Select **Choose Tables to Connect** to open the table picker.

<Frame><img alt="choose tables to connect.jpg" src="/images/kb/ka0Vq000000CwrR-00N5w00000Ri7BU-0EMVq000000uXCb.jpg"/></Frame>
</Step>
<Step title="Create DataSets">
Select from schemas and tables and when you're ready, select **Create DataSets**.

<Frame><img alt="create datasets.jpg" src="/images/kb/ka0Vq000000CwrR-00N5w00000Ri7BU-0EMVq000000uXFp.jpg"/></Frame>
</Step>
<Step title="Share Your DataSets">
(Optional) In the confirmation modal, you can share your DataSets with other Domo users.

<Frame><img alt="share modal.jpg" src="/images/kb/ka0Vq000000BCNd-00N5w00000Ri7BU-0EMVq000000uXZB.jpg"/></Frame>
</Step>
</Steps>

You can now interact with your MySQL DataSets in Domo.

<Frame><img alt="mysql data.jpg" src="/images/kb/ka0Vq000000CwrR-00N5w00000Ri7BU-0EMVq000000uXcP.jpg"/></Frame>
