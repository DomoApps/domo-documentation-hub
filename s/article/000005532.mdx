## Intro

Freee is a cloud service for streamlining back-office operations for small businesses, corporations, and sole proprietors.

The freee Enterprise Connector enables you to import accounting information registered in your freee account, such as income and expense lists, balance sheets, profit and loss statements, journal entries, and so on, into Domo.

You can connect to your freee account in the Data Center. This topic discusses the fields and menus specific to the freee Enterprise Connector user interface. To add DataSets, set update schedules, and edit DataSet information, see [Adding a DataSet Using a Connector](https://domohelp.domo.com/hc/en-us/articles/360042926274-Adding-a-DataSet-Using-a-Data-Connector).

## Prerequisites

To connect to your freee account and create a DataSet, you must have the following:

- freee account
- Creating an application in freee
- The Client ID and Client Secret of the created freee application.

For step-by-step instructions on creating a freee application and obtaining the Client ID and Client Secret, see [freee APIthe  Start Guide](https://developer.freee.co.jp/startguide/starting-api).

<Note>
**Note:** To create a freee application, you will be asked to enter the following callback URL:

[https://oauth.domo.com/api/data/v2/oauth/providers/freee-enterprise-0123953e-2537-4f98-9725-45f34d5a9f4c/exchange](https://oauth.domo.com/api/data/v2/oauth/providers/freee-enterprise-0123953e-2537-4f98-9725-45f34d5a9f4c/exchange)

## Connecting to your freee Enterprise account

This section enumerates the options in the **Credentials** and **Details** panes on the freee Enterprise Connector page. The components of the other panes on this page, **Scheduling**, and **Name & Describe Your DataSet**, are universal across most Connector types and are discussed in great detail in [Adding a DataSet Using a Connector](/s/article/360042926274).

## Credentials pane

This pane contains fields for entering credentials to connect to your freee Enterprise account. For information about obtaining these credentials, see "Prerequisites," above. The following table describes what is needed for each field:

|  Field | Description  |
| --- | --- |
| Client ID | The Client ID of the created application in freee. |
| Client Secret | The Client Secret of the created application in freee. |

After you have entered valid credentials, you are taken to freee's OAuth page where you are prompted to enter your freee login email address and password. Once you have successfully authenticated, you can use the same account any time you go to create a new freee Enterprise DataSet. You can manage Connector accounts in the **Accounts**tab in the Data Center. For more information about this tab, see [Manage Connector Accounts](/s/article/360042926054).

<Note>**Note:** When you connect to freee account from Domo, if you are already logged in to freee, you will be automatically authenticated when you click **Add Account**. To connect to a freee account other than the one you are already logged in to, you must first log out of freee.</Note>
