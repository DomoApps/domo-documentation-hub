---
title: "Copying a DataFlow"
excerpt: "Create a copy of a DataFlow that can be renamed, edited, and run independently of the original without preserving version history."
---

You can create a copy of a DataFlow. This is similar to doing a "Save As," in that copied DataFlows can be renamed, edited, saved, and run independently of their original DataFlow. This is an excellent way to make minor changes to a complicated DataFlow without having to rebuild it from scratch.

When you choose to create a copy of a DataFlow, the **Edit DataFlow** view opens. You can make any changes you want to the copy of the DataFlow, including giving it a new name, before saving/running it.

When you copy a DataFlow, the version history of the DataFlow is *not* preserved. For more information about DataFlow versioning, see [Viewing the Version History for a DataFlow](/s/article/360042923074 "Viewing the Version History for a DataFlow").

**To make a copy of a DataFlow,**

1. In Domo, click **Data** in the toolbar at the top of the screen.
2. Click
   <i className="icon-dataflow sm" aria-hidden="true" /> in the left-hand navigation pane.
3. The **DataFlows** tab opens.
4. Locate the DataFlow you want to copy.
     
   You can use the filter options to narrow down the DataFlows that appear in the list.
5. Mouse over the desired DataFlow then click
   <img src="/images/kb/ka05w00000123hh-00N5w00000Ri7BU-0EM5w000005vOsh.png" style={{width: 20, height: 20, display: 'inline', verticalAlign: 'start', margin: '0'}}/> to display a list of options.
6. Click **Create Copy**.
     
   The **Edit DataFlow** view opens.
     
   When you copy a DataFlow, the title of the copied DataFlow is prefixed with "Copy of " before the title, which you can edit.

From this point, you can rename the DataFlow, edit the input and output data sets and transforms, save it with or without running it, etc.
  
You can also copy a DataFlow from its Details view, by selecting **Create Copy** in the <img src="/images/kb/ka05w00000123RE-00N5w00000Ri7BU-0EM5w000005vOCa.png" style={{width: 20, height: 20, display: 'inline', verticalAlign: 'start', margin: '0'}}/> menu.

## Replicate a DataFlow Lineage for Development and Production

Copying a DataFlow duplicates its transforms, but the copy still reads the same input DataSets as the original. To build a development or test version that runs against different sources, copy the DataFlow and then swap its inputs:

1. Create a copy of the DataFlow using the steps above.
2. In the **Edit DataFlow** view, replace each input DataSet with the corresponding development or test DataSet.
3. Rename the output DataSet so the copy writes to its own DataSet instead of overwriting the original output.
4. Save the copy.

This repoints a single DataFlow at a new set of sources. Replicating a longer lineage—several chained DataFlows and DataSets—means repeating this for each DataFlow in the chain, or scripting the extract-and-reload against the Domo CLI or APIs.
