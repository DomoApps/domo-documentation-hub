---
title: "Remove White Space from Text Strings"
excerpt: "Strip whitespace from text columns by adding a Replace Text tile in Magic ETL with the RegEx pattern for whitespace characters."
---

You can use Magic ETL to remove spaces from text strings.

<Steps titleSize="h2">
<Step title="Open Magic ETL">
Open Magic ETL.
</Step>
<Step title="Select the Input DataSet">
For your input DataSet, select the DataSet you want to remove spaces from.

<Frame><img alt="df_removewhitespace_1.png" src="/images/kb/ka05w00000123is-00N5w00000Ri7BU-0EM5w000005vOv4.png"/></Frame>
</Step>
<Step title="Add a Replace Text Tile">
Add a "Replace Text" tile.
</Step>
<Step title="Select the Column to Search">
Under **Select a column to search**, select the column you want to remove spaces from.
</Step>
<Step title="Enter the Search Term">
Under **Enter a term to search for**, enter \s.

<Note>
  **Note:** In RegEx \s is the expression for whitespace.

</Note>
</Step>
<Step title="Enable RegEx">
Check the box reading **Use RegEx**.

<Frame><img alt="df_removewhitespace_2.png" src="/images/kb/ka05w00000123is-00N5w00000Ri7BU-0EM5w000005vOvD.png"/></Frame>
</Step>
<Step title="Repeat for Other Columns">
Repeat steps 4-6 for all columns that need to be corrected.
</Step>
<Step title="Select Done">
Select **Done**.
</Step>
<Step title="Add and Name the Output DataSet">
Add an output DataSet and name it.

<Frame><img alt="df_removewhitespace_3.png" src="/images/kb/ka05w00000123is-00N5w00000Ri7BU-0EM5w000005vOtm.png"/></Frame>
</Step>
</Steps>

Your output DataSet should incorporate the changes.
