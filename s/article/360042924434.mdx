## Intro

A Comparative gauge is a simplified version of a [Comparative Fill gauge](/s/article/360042924414). Like a Comparative Fill gauge, a Comparative gauge shows the degree of change between a previous value and a current value. However, Comparative gauges lack graphical elements and consist solely of a percentage value. They do not require minimum, maximum, or target values.

The degree of change may be shown as a percentage or as a straight value. Alternatively, you may choose to show only the current value. You can change this setting in the chart properties.

Learn more about [other gauges](/s/article/360042924334) in Domo.

---

## Power a Comparative Gauge

A Comparative gauge requires only two columns or rows of data from your DataSet. One of these contains the current value for the gauge, and the other contains the previous value.

If multiple rows are present in your DataSet, only the *first* row is used. No aggregations occur.

In Analyzer, you choose the columns containing the data for your Comparative gauge. For more information about choosing data columns, see [Applying DataSet Columns to Your Chart](/s/article/360043428713 "Applying DataSet Columns to Your Chart").

## FAQ

<AccordionGroup>
  <Accordion title="How Does a Comparative Gauge Calculate the Percentage Change?">
    When **General** > **Value displayed** is set to **Percentage Change**, the gauge divides the difference between the two values by the previous value:

    `(Current Value − Previous Value) / Previous Value`

    For example, if the previous value is 30 and the current value is 55, the gauge shows `(55 − 30) / 30 = 83.3%`. For the value to render as a percentage rather than a raw number, also set **General** > **Value Format** to **Percentage**. See [Properties for Gauges](/s/article/360042925354 "Chart Properties").
  </Accordion>
  <Accordion title="What Happens When the Previous Value Is 0?">
    Percentage change divides by the previous value, so when the previous value is 0 the calculation divides by zero and a meaningful percentage cannot be produced. If your previous value can be 0, set **General** > **Value displayed** to **Value Change** (and **General** > **Value Format** to **Number**) so the gauge shows the absolute difference instead of an undefined percentage.
  </Accordion>
  <Accordion title="Why Is My Comparative Gauge Blank?">
    A Comparative gauge uses only the *first* row of your DataSet, and it performs no aggregation. If that first row is missing either the current value or the previous value, or if the columns applied to the gauge do not both contain data, the gauge has nothing to compare and appears blank. Confirm that the two columns you applied each hold a value in the first row, and pre-aggregate your data in a DataFlow first if the gauge needs a single summarized current and previous value rather than raw rows.
  </Accordion>
</AccordionGroup>
