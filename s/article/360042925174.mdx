---
title: "Adding Scale Labels to Your Charts"
excerpt: "Add titles to value and category scales in Chart Properties to clarify what each axis measures, especially in charts with multiple value scales."
---

By default, value and category scales in charts do not have titles indi
cating what is being measured. Often, scale titles are not necessary because the data or chart title indicates what is being measured. In some charts, scale titles may be necessary to clarify what is being measured, especially in charts with multiple value scales. The following example shows a chart with scale titles:

<Frame><img alt="scale_labels.png" src="/images/kb/ka05w000001243P-00N5w00000Ri7BU-0EM5w000005vZ8E.png"/></Frame>
You add scale titles to charts in the **Chart Properties** for that chart.

**To add scale titles to a chart,**

<Steps titleSize="h2">
<Step title="Open Chart Properties">
Edit the chart you want, then select **Chart Properties**.
</Step>
<Step title="Open the Category Scale">
(Optional) If you want to add titles to the category scale, select **Category Scale**.
</Step>
<Step title="Open the Value Scale">
(Optional) If you want to add titles to the value scale, select **Value Scale**. If the chart contains more than one value scale, choose the value scale that corresponds to the element you want to clarify using titles (for example, **Value Scale (Bar)** in a grouped bar with line chart).
</Step>
<Step title="Enter the Title">
Enter the desired title in the **Title** field.
</Step>
<Step title="Apply the Changes">
Select **Apply**.
</Step>
</Steps>

For more information about how values and categories are displayed in a chart, see [Understanding Chart Data](/s/article/360043428693 "Understanding Chart Data").
