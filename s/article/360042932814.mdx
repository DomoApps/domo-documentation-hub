---
title: "Filtering Columns in Workbench 5"
excerpt: "Apply Filter transforms in Workbench 5 to include or exclude matching rows, optionally using regular expressions and null handling."
---

You can use the **Filter** transform to apply filters to a selected column. You can choose to have Workbench return matches or non-matches for the specified filter query. You can also include or exclude blank cells in your filtered data.

<Frame><img alt="wb5_transforms_filter.png" src="/images/kb/ka05w00000123sy-00N5w00000Ri7BU-0EM5w000005vPP6.png"/></Frame>

You can use regular expressions in building filter queries, just as you can when using the **Search & Replace** filter. Currently no Regular Expression Builder is available for helping you build filters as it is with **Search & Replace**; however, you can use all of the same constructions when building filter queries. For more information about the **Search & Replace** Regular Expression Builder, see [Replacing a Column Value in Workbench 5.](/s/article/360043437433)

<Steps titleSize="h2">
<Step title="Open the Database View">
In Workbench, select <i className="legacy-icon-database sm" aria-hidden="true" /> in the left-hand icon bar.
</Step>
<Step title="Open the DataSet Job">
In the Jobs listing, double-click the DataSet job with columns you want to filter.
</Step>
<Step title="Expand the Transforms Section">
Select **Transforms** to expand that section of the pane.
</Step>
<Step title="Add a Filter Transform">
In the **Add a transform** menu, select **Filter Transform**.
</Step>
<Step title="Open the Transform Editor">
Select the <img src="/images/kb/ka05w00000123sv-00N5w00000Ri7BU-0EM5w000005vPOn.png" style={{width: 20, height: 20, display: 'inline', verticalAlign: 'start', margin: '0'}}/> button.

The **Filter Transform Editor** appears.
</Step>
<Step title="Select the Column to Filter">
In the **Search Column** menu, select the column you want to filter.
</Step>
<Step title="Enter Your Filter Query">
In the **Include Filter** field, enter your filter query.
</Step>
<Step title="Set Exclude Null">
(Conditional) If you want to prevent blank cells from appearing in your filtered column, set **Exclude Null** to **On**. Otherwise leave this off.
</Step>
<Step title="Set Exclude Matches">
(Conditional) If you want your filter to return non-matches for your query, set **Exclude Matches** to **On**. Otherwise leave this off.
</Step>
<Step title="Apply the Transform">
Select **Apply**.
</Step>
<Step title="Save the Transform">
Select the save icon <i className="icon-save sm" aria-hidden="true" /> at the top of the pane to save your transform.
</Step>
</Steps>
