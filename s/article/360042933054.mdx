## Intro

This article explains how to print a Domo Visualization card from the page or Details view, apply filters to the printed output, and include optional metadata such as the data update time or card owner.

---

You can print a Visualization card from either the page or the Details view. If you print a card from the Details view when filters are applied, those filters are applied in the printed version of the card. For more information about applying filters, see [Chart](/s/article/360042924074 "Adding Filters to Your Chart"). Only Visualization cards can be printed—you cannot print notebook, Sumo, or Document cards. However, all chart types are supported, including tables.

If data in a card is filtered due to PDP policies, those filters are applied in the printed version.

**To print a Visualization card,**

1. Do either of the following:

   * (Conditional) If you are in the card page, mouse over the card that you want to print, click
     <img src="/images/kb/ka05w00000123Qn-00N5w00000Ri7BU-0EM5w000005vOAb.png" style={{width: 20, height: 20, display: 'inline', verticalAlign: 'start', margin: '0'}}/> > **Send / Export**.
       
     The **Export** dialog opens.
   * (Conditional) If you are in the Details view, click
     <i className="icon-wrench sm" aria-hidden="true" /> > **Send / Export**.
       
     The **Export** dialog opens.
2. Select **Print**.
3. Select the desired size.
4. (Optional) Select options for additional information you want to print, such as last data update time or the card owner.
5. Click **Print**.

## Printing Wide Mega Tables

A Mega Table that has many columns can be wider than a single printed page. When you print or export a wide Mega Table, columns that do not fit are pushed onto additional pages rather than scaled down to fit one page—Domo's print options do not include a setting to define a print area or force all columns onto a single sheet.

To reduce how far a wide table overflows before you print, adjust the table's **Chart Properties**:

* **Allow text to wrap** wraps long cell text instead of letting it run off the side of the column, which narrows wide columns.
* **Set column widths** lets you assign narrower widths to individual columns.
* **Hide columns** removes columns you do not need in the printout.

For details on these properties, see [Properties for Tables](/s/article/360042925374 "Properties for Tables").

If you need every column together in one wide document—for example, to work with the data outside of Domo—consider exporting the DataSet through the [Google Sheets Add-On](/s/article/360043437913 "Google Sheets Add-On") as an alternative to an Excel export or a printout.
