## Intro

The Activity log allows Domo administrators to see how their users are using Domo. They can see a near real-time record of activities such as user logins, dashboard views, groups created, and more.

Admins can view Activity Log entries in the Domo UI and export them to a CSV file or send them to a webhook. Activity Log data is also available in the [DomoStats](/s/article/360043433813) Activity Log report.

---

## Using the Log

The Activity log is updated in near real-time and includes activities logged within the rolling one-year period. You can explore the log with filters on the date range and the person who took the action. In addition, filters on type, event, and object can be applied to find specific activities. When you first load the Activity log, the data is filtered to a rolling 24-hour window.

<Note>
  **Refresh the log:** Selecting <img src="/images/kb/ka0Vq0000008Oht-00N5w00000Ri7BU-0EMVq000005bfFq.jpg" style={{width: 20, height: 20, display: 'inline', verticalAlign: 'start', margin: '0'}}/> **Refresh** reloads the log, displaying events logged since the page was last loaded.

</Note>

## DomoStats Report Available

<Frame>
  <img
    alt=""
    src="/images/kb/ka0Vq0000000Rcv-00N5w00000Ri7BU-0EM5w000006vKuy.jpg"
  />
</Frame>
For more extensive analysis of user activity, we recommend installing the
DomoStats Activity Log report. This report loads a rolling 30-day window of
activities the first time it executes; each subsequent execution of the report
loads and appends only the activities logged since the last time the report was
executed (up to the last 30 days' worth of activities).

The DomoStats Activity Log report allows building a long-running history of user activity in Domo. Learn more about the [DomoStats connector](/s/article/360043433813) and the [Activity Log report](/s/article/360043433813) in the Knowledge Base.

## Export to CSV

You can export the Activity log for your instance to a CSV file by selecting **Export CSV**.

<Frame>
  <img
    alt=""
    src="/images/kb/ka0Vq0000008Oht-00N5w00000Ri7BU-0EMVq000005d0bZ.jpg"
  />
</Frame>
The download process may take from a few seconds to several minutes, depending
on the number of logs in your instance. When the download is successful, an
**Export successful** message displays.

Then, select <img src="/images/kb/ka0Vq0000008Oht-00N5w00000Ri7BU-0EM5w000006uzIS.jpg" style={{width: 20, height: 20, display: 'inline', verticalAlign: 'start', margin: '0'}}/> **Download** to download the CSV file to your machine.

<Frame><img alt="" src="/images/kb/ka0Vq0000008Oht-00N5w00000Ri7BU-0EMVq000005bst0.jpg"/></Frame>
<Warning>
  **Important:** The exported data reflect the filters you have in place at the time of export.

For example, if your **Time** filter is set to **Past 24 hours**, the export file only contains data from the past 24 hours. If your export file does not contain all the data you expected, check your filter configuration and re-export if necessary.

</Warning>

## Send Events to a Webhook <Badge className="text-primary bg-primary/10 font-bold">Beta</Badge>

<BetaNote />

You can send log events to a webhook, sharing events with a third-party system and consolidating auditing across your enterprise.

You need the following items to configure this feature:

- The **Payload URL** of your webhook that accepts an HTTP POST request containing a JSON body with the event details.
- A **Secret** key if required by your webhook.
- (Optional) An authorization header, if required by your webhook. For example, "Bearer ABC123DEF356."
- (Optional) An OAuth client ID/secret, if required by your webhook.

After obtaining these items, follow the configuration steps below.

1. [Access](#access-activity-log) the Activity log.
2. Select <img src="/images/kb/ka0Vq0000008Oht-00N5w00000Ri7BU-0EMVq000001RI3V.jpg" style={{ width: 20, height: 20, display: "inline", verticalAlign: "start", margin: "0", }} /> **Activity Log Webhook Configuration**.

   <Frame>

3. In the modal, fill in the following fields:
   - **Payload URL —** This is the destination webhook URL where the Activity log events should be sent.
   - **Secret —** The secret allows the webhook to verify that the data being sent to the payload URL came from this instance of Domo. You can select <img src="/images/kb/ka0Vq0000008Oht-00N5w00000Ri7BU-0EMVq000001HDd0.jpg" style={{width: 20, height: 20, display: 'inline', verticalAlign: 'start', margin: '0'}}/> **Show secret/Hide secret**.

To stop sending activity log events to the webhook, select <img src="/images/kb/ka0Vq0000008Oht-00N5w00000Ri7BU-0EMVq000001RI3V.jpg" style={{width: 20, height: 20, display: 'inline', verticalAlign: 'start', margin: '0'}}/> **Activity Log Webhook Configuration** to open the webhook configuration modal.

In the modal above the payload URL, select <img src="/images/kb/ka0Vq0000007KoP-00N5w00000Ri7BU-0EMVq000000SmMf.jpg" style={{width: 20, height: 20, display: 'inline', verticalAlign: 'start', margin: '0'}}/> **Delete**.
