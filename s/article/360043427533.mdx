---
title: "Creating a New List in the Customer Portal"
excerpt: "Create a custom list view in the Domo Customer Portal to filter cases by criteria such as the user who submitted them."
---

In the Domo Customer Portal, you can create lists of cases based on different criteria. This is especially useful for Admin-level users who want to be able to view just their own cases instead of the entire list of cases in their Domo instance. This walkthrough shows you how to do this.

**To create a list in the Customer Portal,**

<Steps titleSize="h2">
<Step title="Access the Customer Portal">
Access the Customer Portal through support.domo.com.
</Step>
<Step title="Open the Gear Menu">
In the Portal, select the gear icon in the button bar in the top right corner.

<Frame><img alt="customer_portal_list_1.png" src="/images/kb/ka05w00000123bR-00N5w00000Ri7BU-0EM5w000005vOdl.png"/></Frame>
</Step>
<Step title="Create a New List">
Select **New** in the gear menu.

<Frame><img alt="customer_portal_list_2.png" src="/images/kb/ka05w00000123bR-00N5w00000Ri7BU-0EM5w000005vOdi.png"/></Frame>
</Step>
<Step title="Name the List">
Enter a name for the new list.
</Step>
<Step title="Set the Visibility">
Leave the default setting of **Only I can see this list view**.
</Step>
<Step title="Save the List View">
Select **Save**.

<Frame><img alt="customer_portal_list_3.png" src="/images/kb/ka05w00000123bR-00N5w00000Ri7BU-0EM5w000005vOdp.png"/></Frame>
</Step>
<Step title="Add Filters">
Add the desired filters.

In this example, an Admin sets a filter allowing them to see only the cases they created as a specific user.

<Frame><img alt="customer_portal_list_4.png" src="/images/kb/ka05w00000123bR-00N5w00000Ri7BU-0EM5w000005vOdn.png"/></Frame>
</Step>
<Step title="Apply the Filters">
Select **Done**.

<Frame><img alt="customer_portal_list_5.png" src="/images/kb/ka05w00000123bR-00N5w00000Ri7BU-0EM5w000005vOdr.png"/></Frame>
</Step>
<Step title="Save Your Changes">
Select **Save**.

<Frame><img alt="customer_portal_list_6.png" src="/images/kb/ka05w00000123bR-00N5w00000Ri7BU-0EM5w000005vOdg.png"/></Frame>
</Step>
</Steps>

Your new list is now created.

For more information about the Support Portal, see [Getting Help](/s/article/360042922874 "Getting Help").
