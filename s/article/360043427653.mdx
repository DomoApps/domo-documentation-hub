You can edit a Magic ETL DataFlow by opening it in the Data Center and making the desired changes.

**To edit a Magic ETL DataFlow,**

1. Click **Data** in the toolbar at the top of the screen.
2. Click
   <i className="icon-dataflow sm" aria-hidden="true" /> in the left-hand navigation pane.
3. Locate and click the Magic ETL DataFlow you want to edit.
4. Make any changes you want, then click **Save**, enter a version description if desired, then click **Save** to confirm.

When you save a DataFlow, an entry for this version is added to the **Versions** tab in the Details view for the DataFlow. If you entered a description when saving, that description is shown in the entry for the DataFlow. For more information about versions, see [Viewing the Version History for a DataFlow](/s/article/360042923074).

## Larger Grid and Canvas Display Options

Magic ETL offers a Larger Grid canvas that gives tiles more room and increases the spacing between them.

* DataFlows created after April 8, 2025 use the Larger Grid by default.
* For DataFlows created before that date, the DataFlow owner sees a one-time recommendation to switch to the Larger Grid when editing the flow.
* In the recommendation, selecting **Ignore** dismisses it permanently, so it does not appear again for that DataFlow. Closing it with the **X** dismisses it only for the current session, so it reappears the next time the DataFlow is opened.

You can also adjust other canvas display options, such as grid lines and the mini-map, from the editor's canvas settings.
