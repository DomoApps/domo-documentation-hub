---
title: "Join DataSets by Adding a Unique Key Column"
excerpt: "Use the Rank & Window tile in Magic ETL to generate a Row Number column so you can join DataSets that lack a natural unique key."
---

## Intro

Sometimes you want to join DataSets together but there is no unique key column to join on. In this case, you can create a unique key column.

## Create a Unique Key Column

<Steps titleSize="h3">
<Step title="Open or Create a DataFlow">
Open an existing DataFlow in Magic ETL or begin creating a new DataFlow.
</Step>
<Step title="Add the Rank and Window Tile">
Add the [Rank and Window](/s/article/360042922814 "ETL Actions: Rank and Window") tile to the canvas and connect it to your Input DataSet.

<Frame><img alt="" src="/images/kb/ka0Vq0000000l8b-00N5w00000Ri7BU-0EM5w000005vOxE.png"/></Frame>
</Step>
<Step title="Select the Rank & Window Tile">
Select the **Rank & Window** tile.
</Step>
<Step title="Add a Function">
In the configuration pane below the canvas, select **Add Function**.

<Frame><img alt="add function.jpg" src="/images/kb/ka0Vq0000000l8b-00N5w00000Ri7BU-0EMVq000000nTda.jpg"/></Frame>
</Step>
<Step title="Name the New Column">
In step 1, name the new column.

<Frame><img alt="Screenshot 2024-04-22 at 11.58.45 AM.png" src="/images/kb/ka0Vq0000000l8b-00N5w00000Ri7BU-0EMVq000000nUHt.jpg"/></Frame>
</Step>
<Step title="Select the Row Number Function">
In step 2, expand the **Select the function to apply** dropdown and select **Row Number**.

<Frame><img alt="Screenshot 2024-04-22 at 11.58.57 AM.png" src="/images/kb/ka0Vq0000000l8b-00N5w00000Ri7BU-0EMVq000000nUJW.jpg"/></Frame>
</Step>
<Step title="Apply the Function">
Select **Apply**.

<Frame><img alt="apply function.jpg" src="/images/kb/ka0Vq0000000l8b-00N5w00000Ri7BU-0EMVq000000nUUn.jpg"/></Frame>
</Step>
<Step title="Choose a Column to Order On">
In step 2, choose a column to order the functions on to determine how to apply the row numbers.
</Step>
<Step title="Set the Sort Order">
In step 3, choose to order your column by either ascending or descending values.

<Frame><img alt="Screenshot 2024-04-22 at 12.03.20 PM.png" src="/images/kb/ka0Vq0000000l8b-00N5w00000Ri7BU-0EMVq000000nUjJ.jpg"/></Frame>
</Step>
<Step title="Leave the Partition Option Blank">
To have a unique key value for every row of your data, leave the optional **What columns make up the partition** option blank.
</Step>
<Step title="Complete and Run the DataFlow">
Complete your DataFlow and run it.
</Step>
</Steps>

After running your DataFlow, the output DataSet has a new column with a unique value for each row.

<Frame><img alt="unique key column.jpg" src="/images/kb/ka0Vq0000000l8b-00N5w00000Ri7BU-0EMVq000000nRLe.jpg"/></Frame>
