---
title: "Create a Project"
excerpt: "Create a project in Projects and Tasks, set its team members, privacy level, and due date, and start adding tasks and assignments."
---

You can add a new project in the Projects & Tasks page. Once you have specified the basic information for the project, including the name, team members, privacy level (either public or private), and the optional description and due date, you can begin populating the project with tasks and giving assignments to team members.

**To create a new project,**

<Steps titleSize="h2">
<Step title="Open Projects and Tasks">
Open the Projects & Tasks page by selecting **Projects and Tasks** in the **More** menu at the top of the screen.
</Step>
<Step title="Add a Project">
Select **Add Project**.

A **Create New Project** dialog opens.

<Tip>
  **Tip:** You can also open this dialog from anywhere in Domo by selecting <i className="icon-plus-circle sm" aria-hidden="true" /> in the app toolbar and selecting **Tasks > Project**.
</Tip>
</Step>
<Step title="Enter the Project Name">
Enter the project name.
</Step>
<Step title="Add Team Members">
Enter the team members for the project. As you enter letters, user names containing matching letters appear in a pop-up list. When you select a name, it is added to the field. You can add as many names to the field as you want.
</Step>
<Step title="Set the Privacy Level">
Select a privacy setting. If you select "Public," anyone in your company can view, access, and edit this project. If you select "Private," only the team members you selected for the project in the previous step can view and access the project.
</Step>
<Step title="Enter a Description">
(Optional) Enter a project description.
</Step>
<Step title="Enter a Due Date">
(Optional) Enter a due date for the project.
</Step>
<Step title="Finish the Project">
Select **Done**.
</Step>
</Steps>
