## Intro

The Bureau of Economic Analysis (BEA) is a U.S. government agency that provides official macroeconomic and industry statistics, including the gross domestic product (GDP) of the United States. This article explains how to use Domo's BEA Connector to import BEA reports into Domo. To learn more about the BEA API, see the [BEA API signup page](https://www.bea.gov/API/signup/index.cfm).

You connect to your BEA account in the Data Center. This article covers the fields and menus specific to the BEA Connector user interface. For general information about adding DataSets, setting update schedules, and editing DataSet information, see [Add a DataSet Using a Data Connector](/s/article/360042926274).

---

## Prerequisites

To connect to your BEA account and create a DataSet, you must have a BEA API key. This API key is provided to you by email after you register at the [BEA API signup page](https://www.bea.gov/API/signup/index.cfm).

## Connect to Your BEA Account

This section describes the options in the **Credentials** and **Details** panes on the BEA Connector page. The components of the **Scheduling** and **Name & Describe Your DataSet** panes are universal across most connector types and are discussed in [Add a DataSet Using a Data Connector](/s/article/360042926274).

### Enter Your Credentials

The **Credentials** pane contains the field for entering credentials to connect to your BEA account. The following table describes what is needed for each field.

| Field   | Description                                                                                                                                          |
| ------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| API Key | Enter your BEA API key. This API key is provided to you by email after you register at the [BEA API signup page](https://www.bea.gov/API/signup/index.cfm). |

Once you have entered valid BEA credentials, you can use the same account any time you create a new BEA DataSet. You can manage connector accounts in the **Accounts** tab in the Data Center. For more information about this tab, see [Manage User Accounts for Connectors](/s/article/360042926054).

## FAQ

<AccordionGroup>

<Accordion title="How often can the data be updated?">
  DataSets can be updated as often as once an hour. Decrease the update frequency if you encounter rate-limit errors.
</Accordion>

<Accordion title="Are there any API limits that I need to be aware of?">
  BEA limits users to 1,000 API calls per minute.
</Accordion>
