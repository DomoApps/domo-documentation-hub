## Intro

The DomoStats Connector allows you to explore how your team is using Domo. Learn about your team's activities, Projects and Tasks, DataSets, Buzz conversations, and more to find insights and shape your company's Domo experience.

You must have an Admin security role to access the DomoStats Connector or to connect to the DomoStats apps. However, after the DataSets have been created or the app has been deployed, they can be shared with anyone in your organization.

You import DomoStats DataSets into the Data Center. This topic discusses the fields and menus that are specific to the DomoStats Connector user interface. General information for adding DataSets, setting update schedules, and editing DataSet information is discussed in [Adding a DataSet Using a Data Connector](/s/article/360042926274).

---

## Prerequisites

To pull in DomoStats DataSets using this Connector, you must have the Admin default security role.

## Locating DomoStats DataSets

After a DataSet is created, you can locate the DataSet through filters. This helps keep DataSets organized and accessible.

1. In the navigation header, select **Data**.

2. Select **DataSets** from the <img src="/images/kb/0EM5w000005vO0y.png" style={{width: 20, height: 20, display: 'inline', verticalAlign: 'start', margin: '0'}}/> navigation rail.

3. In the **Search** bar, type the name of your DataSet. You can also locate DataSets using filters.

4. In the **Search** bar, select **Add Filter**.

5. Choose **Type** and enter **DomoStats**.

A list of DomoStats DataSets will generate. Choose your DataSet from the list.
