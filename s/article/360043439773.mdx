---
title: "Building Custom Connectors in Domo"
---

At Domo, our engineering team has developed hundreds of connectors but we understand the difficulties of developing for a new API platform. That's why we've created the Connector Dev Studio, an intuitive environment for managing and creating connections between Domo and the web's most powerful APIs. If there isn't a connector built for an API you use in the AppStore, you now have the ability to build it.

Domo offers several ways to bring data in:

- [Custom Connectors (Connector Dev Studio)](/portal/Connectors/Custom-Connectors/connector-dev-studio) — build your own connector to a cloud API.
- [Data API](/portal/API-Reference/app-framework-apis/Data-API) — create and upload data using Domo APIs.
- [On-Premises Data](/portal/Connectors/on-premises-data) — use Workbench to bring on-premise data into Domo.
