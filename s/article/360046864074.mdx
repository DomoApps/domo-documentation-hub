title: "Filter Columns in Workbench 4"

---

You can use the **Filter** transform to apply filters to a selected column. You can choose to have Workbench return matches or non-matches for the specified filter query. You can also include or exclude blank cells in your filtered data.

<Frame><img alt="wb4_transform_filter.png" src="/images/kb/ka05w00000123qZ-00N5w00000Ri7BU-0EM5w000005vPKK.png"/></Frame>

You can use regular expressions in building filter queries, just as you can when using the **Search & Replace** filter. Currently no Regular Expression Builder is available for helping you build filters as it is with **Search & Replace**; however, you can use all of the same constructions when building filter queries. For more information about the **Search & Replace** Regular Expression Builder, see [Replacing a Column Value in Workbench 4](/s/article/360046864274 "Replacing a Column Value in Workbench 4").

<Steps titleSize="h2">
<Step title="Select the DataSet Job">
In the **Accounts** pane, select the DataSet job in which you want to set filters.
</Step>
<Step title="Add a New Transform">
In the **Transforms** grouping in the Buttons toolbar at the top of the Workbench window, select **Add New**.
</Step>
<Step title="Choose the Filter Transform Type">
In the **Transform Type** menu, select **Filter** then select **Next**.
</Step>
<Step title="Finish Adding the Transform">
Select **Finish**.

A **Filter** item is added under **Transforms** for this DataSet job.
</Step>
<Step title="Open the Filter Transform">
Select the new **Filter** item under **Transforms**.

A set of **Filter Data Transform** options appear in the Dynamic Options panel.
</Step>
<Step title="Select the Column to Filter">
In the **Search Column** menu, select the column you want to filter.
</Step>
<Step title="Enter Your Filter Query">
In the **Include Filter** field, enter your filter query.
</Step>
<Step title="Set Exclude Null">
(Conditional) If you want to prevent blank cells from appearing in your filtered column, set **Exclude Null** to **On**. Otherwise leave this off.
</Step>
<Step title="Set Exclude Matches">
(Conditional) If you want your filter to return non-matches for your query, set **Exclude Matches** to **On**. Otherwise leave this off.
</Step>
<Step title="Save the Transform">
Select **Save** in the **DataSet Jobs** grouping in the **Buttons** toolbar at the top of the Workbench window.
</Step>
</Steps>
