You can set the time zone for a DataSet Job in Workbench. When the job is sent to Domo, all of the date-time data is based on the time zone you selected.

American Daylight Savings is taken into account for time zones in Workbench.

You apply a time zone to a DataSet using the **Shift Date Timezone** Transform.

<Frame><img alt="wb4_transform_timezone.png" src="/images/kb/ka05w00000123qL-00N5w00000Ri7BU-0EM5w000005vPJu.png"/></Frame>

<Steps titleSize="h2">
<Step title="Select the DataSet Job">
In the **Accounts** pane, select the DataSet job in which you want to set the time zone.
</Step>
<Step title="Add a New Transform">
In the **Transforms** grouping in the Buttons toolbar at the top of the Workbench window, select **Add New**.
</Step>
<Step title="Choose the Shift Date Timezone Transform Type">
In the **Transform Type** menu, select **Shift Date Timezone** then select **Next**.
</Step>
<Step title="Finish Adding the Transform">
Select **Finish**.

A **Shift Date Timezone** item is added under **Transforms** for this DataSet job.
</Step>
<Step title="Open the Shift Date Timezone Transform">
Select the new **Shift Date Timezone** item under **Transforms**.
</Step>
<Step title="Select the Time Zone">
In the **Data Timezone** menu, select the desired time zone.
</Step>
<Step title="Save the Transform">
Select **Save** in the **DataSet Jobs** grouping in the Buttons toolbar at the top of the Workbench window.
</Step>
</Steps>
