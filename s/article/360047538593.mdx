---
title: "Setting Up Direct Upload in Workbench"
excerpt: "Configure direct upload for CSV DataSet jobs in Workbench using the External Process File Provider transport to increase upload speeds."
---

Direct upload is designed to limit load and increase upload speeds for Workbench users. It is available only when using the "External Process File Provider" transport method for CSV data. Follow the steps in this section to set up direct upload of data in Workbench. Remember to save the job and validate the data types throughout the process to not lose your work.

The CSV file must be in the correct format and the steps outlined below must be followed in the correct order for direct upload to work.

<Warning>
  **Important:**

  Following the direct upload setup process as shown below. is essential for successful uploads. Be sure not to turn on direct upload until the end of the process.

</Warning>

**To set up direct upload in Workbench,**

<Steps titleSize="h2">
<Step title="Add a New CSV DataSet Job">
Add a new CSV DataSet job to Workbench, making sure to do the following:

1. Set the **Transport Method** to **External process provider**.
2. In the **Data Source** menu, select CSV. For more information about configuring CSV jobs in Workbench, see [Connecting to CSV Data in Workbench 4](/s/article/360047496473 "Connecting to CSV Data in Workbench 4").
</Step>
<Step title="Configure the Transport Method">
In the **Source** tab, under **Transport Method**, do the following:

1. Configure the **Program executable** field with the connection needed.
2. In the **Arguments** field, set arguments as needed.
3. In **Output File Path**, select the file path for the CSV file. The file type can be CSV or GZIP. GZIP files will have the fastest upload times.
4. Select **Validate Configuration**.

   *Do not enable Direct Upload yet!*
</Step>
<Step title="Deselect the Column Headers Option">
At the bottom of the Source tab, deselect the box for **First row contains column headers**.
</Step>
<Step title="Preview the Job">
Select **Preview** in the task bar at the top of the screen.
</Step>
<Step title="Open the Schema">
After the preview has appeared, select **Schema** for this job in the **Accounts** pane.
</Step>
<Step title="Set Column Names and Validate Data Types">
Set/rename **Destination Column** names (as column names do not appear for CSV files by default) and validate the data types for the columns.
</Step>
<Step title="Return to the Source Tab">
Return to the **Source** tab.
</Step>
<Step title="Turn On Direct Upload">
Under **Settings**, set **Direct Upload** to **On**.
</Step>
<Step title="Run the Job">
Run the job.
</Step>
</Steps>
