## Intro

Not all DataSets are created equal. For example, some DataSets may be used strictly as DataFlow inputs or have not been accessed for a while and therefore are not being actively queried (i.e. used and viewed regularly in Cards or Dashboards). These DataSets will continue to run as scheduled, perform normally as expected, and are optimized for their current use, but must be brought into an actively queried state to use in visualizations.

## Understand DataSet Archiving

Domo archives a DataSet automatically when it meets the criteria for inactivity. A DataSet typically qualifies when all of the following are true:

- It hasn't been used recently, with no queries and no user activity.
- It isn't an input to any Adrenaline DataFlow.
- It doesn't meet other conditions that keep DataSets active, such as recent updates or frequent access.

An archived DataSet becomes inactive and moves from the Adrenaline engine to long-term storage. This is the same non-queryable state described in the following section. The DataSet remains available, but you can't use it in Cards, Analyzer, or DataFusions, or as an input to Adrenaline DataFlows, until you [bring it back to an actively queried state](#bringing-datasets-to-an-actively-queried-state).

### Bringing DataSets to an actively queried state

To optimize a DataSet for querying to be used in Cards, Dashboards, and more, click the **Start** button in the Details View Overview tab. You may begin using that DataSet as soon as it is done preparing.

<Frame><img alt="Cold_Storage_Start.jpg" src="/images/kb/ka05w000001233P-00N5w00000Ri7BU-0EM5w000005vNuJ.jpg"/></Frame>
#### From the Data Center

1. Navigate to the
   [Data Center](https://domohelp.domo.com/Welcome/Domo_User_Interface/Data_Center_Layout "Data Center Layout") and search for the DataSet you want to actively query.
2. Click on the DataSet to view the Overview tab in the DataSet Details.
3. Click
   **Start**.

#### In Analyzer

1. In Analyzer, you will be presented with the following message if a DataSet is not actively queried.
     
   <Frame><img alt="Cold_Storage_Analyzer.png" src="/images/kb/ka05w000001233P-00N5w00000Ri7BU-0EM5w000005vNuH.png"/></Frame>
2. Click
   **Get Details** to be taken directly to the DataSet Details view.
3. Click
   **Start**.

#### From Card Details

1. In the Card Details view, you will be presented with the following message if a DataSet is not actively queried.
     
   <Frame><img alt="Cold_Storage_Cards.png" src="/images/kb/ka05w000001233P-00N5w00000Ri7BU-0EM5w000005vNuQ.png"/></Frame>
2. Click
   **Get Details** to be taken directly to the DataSet Details view.
3. Click
   **Start**.

#### In DataFusions

1. In DataFusions, you will be presented with the following message if a DataSet you are attempting to use as an input is not actively queried.
     
   <Frame><img alt="Cold_Storage_DataFusion.png" src="/images/kb/ka05w000001233P-00N5w00000Ri7BU-0EM5w000005vNuT.png"/></Frame>
2. Navigate to the Data Center. Find and select the DataSet to access the DataSet Details view.
3. Click
   **Start**.

## FAQ

<AccordionGroup>
<Accordion title="If my DataSet is used in a DataFlow, why was it archived?">

Only Adrenaline DataFlows require their input DataSets to stay on the Adrenaline engine, so Domo doesn't archive a DataSet while it's an input to an Adrenaline DataFlow. Your DataSet may have been archived for one of these reasons:

- It's used only in DataFlows that don't run on Adrenaline, which don't require it to stay active.
- It was archived before you added it to an Adrenaline DataFlow. To use it, [bring it back to an actively queried state](#bringing-datasets-to-an-actively-queried-state).

</Accordion>
