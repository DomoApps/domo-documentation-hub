## Intro

You can add Smart Text to a card title or description while working in Analyzer or from a dashboard. Smart Text references certain data elements and updates in place whenever the underlying data changes. You can use more than one piece of Smart Text at a time, if needed.

Anyone with permission to edit a card or dashboard can add/modify associated Smart Text.

Personalized Data Permissions (PDP) do apply when adding Smart Text to a card title or description. For more information about PDP, see [Personalized Data Permissions (PDP)](/s/article/360042934614).

The Smart Text options are described below:

* **Date range —**
  Shows dates in text. Ex: this quarter, graphed by week
* **Filters —**
  Displays the filters applied. Ex: order status.
* **Variables —**
  When a variable is present, the selected value of the variable is listed.
* **Segments used —**
  Names the visible segments.
* **DataSet info —**
  Displays information about the DataSet such as the date last updated or owner.

  <Note>
    **Note:**
    You can also add Smart Text to Notebook Cards. See
    [Adding a Notebook Card](/s/article/360043430233)
    to learn more.

  </Note>

<Note>
  **Note:** Date range Smart Text displays the *named* range label applied to the card — for example, "This Week," "This Quarter," or "All Time" — rather than the literal start and end dates of that range. When a card is not directly filtered by a date range, the Smart Text reflects the card's own configured date range rather than a value shown to the viewer.

## Where Smart Text Appears

Smart Text renders only in the live card, dashboard, and app views where it is configured, showing its current value when the content is viewed in Domo.

Smart Text is not designed to carry its rendered value into exported or scheduled output. It does not appear in Excel or CSV exports, PowerPoint exports, or scheduled reports, and the value stored in Smart Text is not used for exported filenames, email subject lines, or email attachments. For related export limitations, see [Export Visualization Cards](/s/article/360043437813).

To make a value available outside the live view — for example, in an export or a scheduled report — surface it in the data itself rather than in Smart Text:

- Add the value as a Beast Mode or calculated column so it exports as part of the DataSet.
- Display it as a summary number on the card.
- To combine multiple filter values into a single field, use the `LISTAGG` function in a Beast Mode to concatenate them.
