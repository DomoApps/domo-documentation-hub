## Intro

This article explains how to use AI Chat v2 for data analysis, document context, visualizations, and global chat settings.

---

## Required Grants

To access AI Chat v2, all the following grants must be enabled for your role:

- **Use AI Services —** Allows you to access AI services in Domo apps, Domo Bricks, Jupyter Workspaces, and Workflows. This grant should be given to anyone who needs to use AI services but does not need to manage them.
- **Use AI Chat —** Allows you to access and use the Domo AI Chat v2 feature throughout Domo. Those with Privileged- and Participant-level roles have this grant enabled by default.

Learn more about [grants](/s/article/360043438973).

## AI Chat v2 Security

Domo AI Chat v2 uses DomoGPT to ensure that your data is secure and maintains the same security settings seen throughout Domo.

Learn more about [Domo AI Security and DomoGPT <i className="icon-arrow-square-out sm" aria-hidden="true" />](https://web-assets.domo.com/blog/wp-content/uploads/2024/09/Domo.AI-and-DomoGPT-Security-and-Privacy-FAQ-Sept2024.pdf).

## Use Context and Knowledge

AI Chat v2 handles complex, multi-part questions and questions that span multiple DataSets, synthesizing the results into a single, comprehensive answer.

<Note>**Note:** Cross-DataSet joins and unions aren't supported. AI Chat v2 queries each DataSet independently, then synthesizes the results.</Note>

AI Chat v2 supports longer conversations, allowing you to continue an analysis in depth without losing context. AI Chat v2 also supports unstructured data in the form of Documents.

## Create a Visualization

AI Chat v2 supports visualizations of your data. Ask AI Chat v2 to show you a card, or create a card on your current dashboard or app.

<Note>**Note:** If you ask AI Chat v2 to "create" a card, it's created on the dashboard or app you're currently on. If you aren't on a dashboard or app, the card is created on your Overview page.</Note>

## Admin Settings

Global Chat Settings control how AI Chat v2 behaves for your instance:

- Control which prompt-based agent is invoked when you choose AI Chat v2 — Domo AI Chat v2 or a custom agent from the AI Library.
- Auto-discovery of new tools and which types of knowledge they can access.
- Allow the agent to query DataSets using SQL.
- Allow the agent to search and list Documents.
- Allow the agent to search for DataSets and content that aren't included in the chat context.
