## Intro

App Studio lets you add charts and tables directly on the canvas and configure them without leaving the editor. This article covers adding a chart, formatting and organizing table columns, sorting and filtering table data, applying Beast Mode functions, setting date ranges, and working with editable and linked tables.

To add a chart or table, open your app in the [app editor](/s/article/Build-an-App-Studio-App#app-editor) and use the [left navigation toolbar](/s/article/Build-an-App-Studio-App#use-the-left-navigation-toolbar).

## Add a Chart

App Studio lets you add charts to your app and configure chart properties and styles without leaving the canvas.

To add a chart, follow these steps:

1. Select the **Charts** icon from the left toolbar. A pop-up menu appears.

2. Search for your desired chart using the search field, or select the drop-down menu to browse the list of available chart types.

<Frame>![](/images/kb/app-studio-enhancements-screenshot-21.png)</Frame>

<Frame>![](/images/kb/app-studio-enhancements-screenshot-22.png)</Frame>

3. Select your desired chart, then drag it onto the canvas.

<Frame>![](/images/kb/app-studio-enhancements-screenshot-23.png)</Frame>

4. Configure your chart settings and styles by selecting the chart. A right panel appears where you can edit, configure, sort, filter, and add styles to your charts.

<Frame>![](/images/kb/app-studio-enhancements-screenshot-24.png)</Frame>

### Right-Panel Configurations for Charts and Tables

The right panel is your command center for any selected object on the canvas.

1. Select a table or chart to activate the panel.
2. Use the **Settings** tab to change chart settings, set date ranges, set filters, set sorting criteria, limit rows, and apply other chart-specific configuration.

<Frame>![](/images/kb/app-studio-enhancements-screenshot-25.png)</Frame>

3. Use the **Styles** tab to change or set colors, font types, font family, conditional formatting, general table or chart formatting, sorting settings, and additional chart-specific configuration.

<Frame>![](/images/kb/app-studio-enhancements-screenshot-26.png)</Frame>

4. Use the **Actions** tab to configure interactive filters, edit Drill Paths, and select filter exceptions.

<Frame>![](/images/kb/app-studio-enhancements-screenshot-27.png)</Frame>

### Format Table Columns

Apply specific formatting to table columns to ensure your data is readable.

Select a table on the canvas to begin, then follow one of the options below to format.

**Right Panel — Column Formatting**

1. In the right panel, select a column under the **Select Columns** list.
2. Select the more options menu and select **Formatting**.
3. Set the **Data Label** and choose a display type in the **Set display type** option.

**Reorder Columns**

- Drag and drop columns by hovering over the icon and moving columns up or down to arrange them in the desired order.

<Frame>![](/images/kb/app-studio-enhancements-screenshot-28.png)</Frame>

**Show/Hide Columns**

- Select the **show/hide** <i className="icon-eye sm" aria-hidden="true" /> icon on the column name to hide or unhide a column.

<Frame>![](/images/kb/app-studio-enhancements-screenshot-29.png)</Frame>

- Select **Show/Hide All** to show or hide all columns.

<Frame>![](/images/kb/app-studio-enhancements-screenshot-30.png)</Frame>

**Fit Columns to Card Width**

Drag the edge of a column header to resize a column; App Studio saves the adjustment. To keep a table readable as the card resizes, set the app page to a responsive [page width](/s/article/Build-an-App-Studio-App#format-page) and size the columns so the table fills the card rather than overflowing it.

## Add Date Ranges

The **Date Range** feature lets you define time-based data sets precisely within a component. This configuration is useful for performing historical comparisons, aligning data with specific fiscal periods, and controlling the visual display of time metadata.

The following settings are available within the Date Range panel:

- **Range:** Defines the primary time interval for the data set (such as Current Month, Last 7 Days, or Year to Date).
- **Graph By:** Sets the granularity of the time axis on the visualization. Options include **Daily**, **Weekly**, **Monthly**, **Quarterly**, and **Yearly** intervals.
- **Compare To:** Enables comparative analysis by overlaying the current range against a previous period, such as **Previous Period** (sequential) or **Previous Year** (same period, one year prior).
- **Date Range Field:** Specifies the exact column from the underlying DataSet that contains the timestamps used to drive the range logic.
- **Date Filter:** Provides an additional layer of refinement to include or exclude specific dates within the broader selected range.
- **Use Fiscal Calendar:** When enabled, the range logic aligns with your organization's defined fiscal year start and end dates rather than the standard Gregorian calendar.
- **Hide Date on Card Details:** When selected, removes the date range text from the header or footer of the visualization, creating a cleaner interface for dashboards where the time context is already established.

## Filter Your Data

Apply filters to your data to narrow your focus.

<Frame>![](/images/kb/worksheets-screenshot-23.png)</Frame>

1. Select the **Filter** <i className="icon-funnel sm" aria-hidden="true" /> icon.

## Edit Data in Editable and Linked Tables (Beta)

App Studio supports two spreadsheet-style table elements, available from the **Tables** menu in the [left navigation toolbar](/s/article/Build-an-App-Studio-App#use-the-left-navigation-toolbar):

- **Editable Table —** A spreadsheet-like table where you can enter data directly, add columns and rows, create calculated columns, copy and paste, and filter.
- **Linked Tables —** Combine existing Domo data with new columns you add for use cases such as financial forecasting and budgeting.

<Note>
  **Note:** Calculated columns in an Editable Table can be edited only from the formula editor bar. This prevents unintended changes from actions like double-clicking, copy-pasting, or dragging to fill.
</Note>

Editing data in an Editable or Linked Table cell writes to the underlying content, so an app viewer needs edit access to that content in addition to access to the app.
