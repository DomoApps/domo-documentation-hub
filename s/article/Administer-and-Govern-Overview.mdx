## Intro

Managing a Domo instance means more than building dashboards—it means maintaining users and roles, securing data access, governing content quality, and keeping instance settings aligned with your organization's policies. Domo's Administer & Govern capability area covers all of these admin and governance responsibilities. This article explains what it covers and points to the key articles for each area.

---

## Required Grants

Most administration tasks require Admin-level grants:

- **Manage All Roles —** Create and assign roles and grants.
- **Manage All Company Settings —** Configure instance settings, SSO, and security policies.
- **Manage All DataSets —** View and govern DataSets across the instance.

Learn more about [grants](/s/article/360043438973).

## FAQ

<AccordionGroup>

<Accordion title="What is the minimum role required to access Admin settings?">
  You need the Admin system role or a custom role with the Manage All Company Settings grant. Most governance features require this Admin-level grant.
</Accordion>

<Accordion title="How do I audit which users have access to a specific DataSet?">
  From the Data Center, open the DataSet and select the **Sharing** tab to see which users and groups have access. Admins with the Manage All DataSets grant can see sharing settings for any DataSet in the instance.
</Accordion>

<Accordion title="What is the difference between Sandbox and Production in Domo?">
  Domo Sandbox is a separate, isolated environment for testing changes—new DataFlows, app configurations, or instance settings—before applying them to your production instance. See [Domo Sandbox Overview](/s/article/Domo-Sandbox-Overview) for details.
</Accordion>
