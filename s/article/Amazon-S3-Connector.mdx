This article will walk you through setting up a connection to an AWS S3 Bucket.

To get an AWS Access Key ID and Secret Access Key for programmatic access to Amazon S3, you must generate them through the AWS Identity and Access Management (IAM) service. Note that AWS access keys belong to an IAM user identity, not directly to the S3 bucket itself.

## Create an IAM User and Grant S3 Permissions

1. Sign in to your [AWS Management Console](https://aws.amazon.com/console/).
2. Search for and select IAM (Identity and Access Management) from the services menu.
3. Click **Users** in the left sidebar menu, then click **Create user**.
4. Enter a name (e.g., `s3-application-user`) and click **Next**.
5. On the permissions page, choose **Attach policies directly**.
6. In the search box, type `S3` and select the appropriate policy:
7. Select **AmazonS3FullAccess** for complete access to all your buckets.
   - **Security Recommendation:** To enforce least-privilege, create a custom inline JSON policy that restricts permissions to your specific bucket name.
8. Click **Next**, review the user configurations, and click **Create user**.

## Generate the Access Key and Secret Key

1. Click on your newly created user from the IAM user list.
2. Select the **Security credentials** tab.
3. Scroll down to the **Access keys** section and click **Create access key**.
4. Choose **Application running outside AWS** (or **Other**) as your use case, then click **Next**.
5. Set an optional tag value description and click **Create access key**.
6. Copy both the **Access key ID** and the **Secret access key** immediately.

<Warning>**Critical Security Warning:** The Secret Access Key is only displayed once. Click **Download .csv file** to save a copy locally. If you navigate away or lose the secret key, you cannot retrieve it later; you will have to delete the key and generate a new pair. Never upload these keys to public repositories like GitHub.</Warning>
