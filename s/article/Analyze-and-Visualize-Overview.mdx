## Intro

Domo turns prepared DataSets into interactive visualizations through Analyzer (the chart-building tool), over 150 chart types, Beast Mode calculated fields, and dashboards that combine cards into shared views. This article explains the Analyze & Visualize capability area and points to the key articles for each component.

---

## Required Grants

To create cards and dashboards, the following grants must be enabled for your role:

- **Edit Cards —** Build and edit visualization cards in Analyzer.
- **Create Pages and Apps —** Create dashboards.
- **Edit Pages —** Modify existing dashboards.

Learn more about [grants](/s/article/360043438973).

## FAQ

<AccordionGroup>

<Accordion title="Can I use Domo without writing any code or formulas?">
  Yes. The core analysis workflow—connecting a DataSet, choosing a chart type, and placing the card on a dashboard—requires no code. Beast Mode formulas are optional and can be written in plain-English style with help from the Beast Mode AI Assistant.
</Accordion>

<Accordion title="How do I make a chart responsive across devices?">
  Use Domo Stories to create a layout-locked dashboard. Stories maintain card positions and sizes across web, mobile, tablet, and print. See [Creating Domo Stories](/s/article/360043428433).
</Accordion>

<Accordion title="What is the difference between a Dashboard Filter and a card-level filter?">
  A card-level filter applies only to the individual card it is set on. A Dashboard Filter applies to every card on the dashboard whose DataSet includes the filtered column—it is cross-card and visible to all viewers. See [Page Filters and Filter Views on Dashboards](/s/article/360042923914).
</Accordion>

</AccordionGroup>
