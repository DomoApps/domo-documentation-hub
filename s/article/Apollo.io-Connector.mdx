## Intro

This article explains how to use Domo's Apollo.io Connector to import account, contact, email engagement, call activity, task, and campaign performance data from your Apollo.io workspace into Domo. Combine this data with your first-party data to analyze sales performance, measure engagement, and gain deeper insights into prospect and campaign activity.

---

## Prerequisites

To connect to the Apollo.io account and create a DataSet, you need the Access Token associated with your Apollo.io account. For more information, see [Apollo.io API Documentation](https://docs.apollo.io/reference/authentication).

To generate an Apollo.io API key:

1. Sign in to your Apollo.io account.
2. Go to **Settings**.
3. Select **Integrations**.
4. Select **API Keys**.
5. Select **Create New Key**.
6. Copy and securely store the generated API key for use when configuring the connector.

This article covers the fields and menus specific to the Apollo.io Connector user interface. For general information about adding DataSets, setting update schedules, and editing DataSet information, see [Add a DataSet Using a Data Connector](/s/article/360042926274).

## Configure the Connection

This section describes the options in the **Credentials** and **Details** panes on the Apollo.io Connector page. The components of the **Scheduling** and **Name & Describe Your DataSet** panes are universal across most connector types and are discussed in [Add a DataSet Using a Data Connector](/s/article/360042926274).

### Enter Your Credentials

The **Credentials** pane contains the field for entering credentials to connect to the Apollo.io API. The following table describes what is needed for each field.

| Field         | Description                     |
| ------------- | ------------------------------- |
| Access Token  | Enter the Access Token.         |

Once you have entered valid Apollo.io Connector credentials, you can use the same account to create a new Apollo.io Connector DataSet. You can manage connector accounts in the **Accounts** tab in the Data Center. For more information about this tab, see [Manage User Accounts for Connectors](/s/article/360042926054).
