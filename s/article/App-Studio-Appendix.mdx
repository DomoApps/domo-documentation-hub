## Intro

This appendix defines the terms and concepts used throughout the App Studio articles. Some of these terms—like *appendix*, *drill view*, and *pro-code component*—have a specific meaning in App Studio or are used differently elsewhere in Domo, so they are worth knowing before you build.

## App Studio Terms

- **App —** A low-code application you build in App Studio. An app can contain multiple pages, custom navigation, cards, tables, charts, forms, and other elements. See [Build an App Studio App](/s/article/Build-an-App-Studio-App).

- **Appendix —** Within an app, the holding area where cards are kept when they are removed from a layout rather than deleted. Deleting a tab moves its cards and pro-code components to the appendix, and a card's **Remove Card** menu includes a **Move to appendix** option. Cards in the appendix still exist in the app but are not placed on a page.

- **App editor —** The build environment for an app, made up of the main navigation, the left navigation and side panel, the canvas, and the right configuration panel. See [App Editor](/s/article/Build-an-App-Studio-App#app-editor).

- **Apps Home —** The landing page that lists the apps you can access, organized into the **All apps**, **Favorited**, **Shared**, and **Owned** tabs. See [Apps Home](/s/article/Build-an-App-Studio-App#apps-home).

- **App theme —** A reusable set of visual styles—fonts, colors, cards, tables, and more—applied to an app. See [Add Themes to an App Studio App](/s/article/000005543).

- **Canvas —** The area of the app editor where your app displays as you build it and where you drag layouts and elements. See [Canvas](/s/article/Build-an-App-Studio-App#canvas).

- **Controls —** The app-viewer menu for creating and applying Filter Views and date ranges. See [View an App](/s/article/Build-an-App-Studio-App#view-an-app).

- **Doc Card —** A card that embeds a document, presentation, image, video, or other file. When presentation mode is enabled, app users can download the embedded file. See [Download Content from a Doc Card](/s/article/Distribute-an-App-Studio-App#download-content-from-a-doc-card).

- **Domo Everywhere —** Domo's embedding and publishing capability, used to embed an app or publish it to a subscriber instance. See [Embed an App](/s/article/Distribute-an-App-Studio-App#embed-an-app) and [Publish Content to a Subscriber Instance](/s/article/360045120554).

- **Drill view —** A page that is hidden from the app's main navigation and reached only through a Page Drill. See [Page Drill](/s/article/Build-an-App-Studio-App#page-drill).

- **Elements and actions —** The items you drag from the left navigation toolbar onto the canvas. *Elements* include cards, tables, charts, text, images, layout containers, tabs, and more; *actions* include buttons and controls. See [Add Actions and Elements](/s/article/Build-an-App-Studio-App#add-actions-and-elements).

- **Filter View —** A saved set of filters created from the **Controls** menu that can be applied by app viewers and optionally set as the default for every viewer.

- **Interaction filter —** A filter applied when an app user interacts with a chart or card element, such as selecting a chart segment. See [Add Interactivity: Popups, Filters, and Actions to an App Studio App](/s/article/Add-Interactivity-to-an-App-Studio-App).

- **Main navigation —** The app's navigation bar, which can be oriented along the top, left, or bottom of the app. See [Main Navigation](/s/article/Build-an-App-Studio-App#main-navigation).

- **Notebook Card —** A text element that opens as a notebook, used to add titles, descriptions, and formatted text (including Smart Text) to a page.

- **Page density —** The amount of space around objects on a page: Default (4 px), Comfortable (8 px), Compact (2 px), Nil (0 px), or custom. See [Format Page](/s/article/Build-an-App-Studio-App#format-page).

- **Page Drill —** A navigation feature in which selecting a card opens another app page and carries the card's filters forward. See [Page Drill](/s/article/Build-an-App-Studio-App#page-drill).

- **Persistent filter —** A filter that, once applied, takes effect across all app pages rather than a single page. See [Configure Persistent Filters](/s/article/Add-Interactivity-to-an-App-Studio-App#configure-persistent-filters).

- **Pro-code component (Domo Brick) —** A custom object built from HTML, CSS, and JavaScript that extends an app beyond the standard elements. Called a *pro-code component* in App Studio and a *Domo Brick* (formerly DDX Brick) elsewhere in Domo. See [Use Advanced Customization in App Studio with Forms and Pro-Code Components](/s/article/Use-Advanced-Customization-in-App-Studio) and [Domo Bricks | Overview](/s/article/4423762260375).

- **Queue —** A Task Center queue added to an app as an element, giving app users access to the tasks in that queue.

- **Report / Report Builder —** A personalized, scheduled email report generated from an app. See [Deliver Customized Reports with App Studio Report Builder](/s/article/000005829).

- **Sandbox —** Domo Sandbox, used as the version-control and promotion path for apps—commit an app to a repository, promote it between instances, and roll back to an earlier version. See [Version and Roll Back an App with Sandbox](/s/article/Manage-an-App-Studio-App#version-and-roll-back-an-app-with-sandbox) and [Domo Sandbox](/s/article/4403367344023).

- **Spacer —** A layout element that adds blank space between other elements, often used to balance the height of tabs.

- **Tabs —** A layout element that organizes content into multiple tabs on a single page. See [Add Tabs](/s/article/Build-an-App-Studio-App#add-tabs).

- **Variable control —** A control that exposes a Variable to app users. See [Variables | Overview](/s/article/7903767835031).

- **Workflow —** A Domo Workflow added to an app as an element. When an app user fills out and submits the workflow's start form, the workflow executes.

- **Writeback —** Pushing data from an app to a third-party application, typically with a writeback connector triggered by a button.
