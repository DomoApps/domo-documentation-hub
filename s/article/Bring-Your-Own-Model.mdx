---
title: "Bring Your Own Model"
excerpt: "Bring Your Own Model (BYOM) lets you connect your own AI model, like a custom language model, to Domo instead of using a Domo-provided model."
---

## Intro

This article explains how to set up Bring Your Own Model (BYOM).

---

## Import Your Model

1. Select **AI Models** from the main menu.

<Frame>
  <img src="/images/kb/byom_1.png" alt="AI Models option in the Domo main menu" />
</Frame>

2. Select **Add Model**.

<Frame>
  <img src="/images/kb/byom_2.png" alt="Add Model button on the AI Models page" />
</Frame>

### Select an Adapter

3. For this example, select **Meta (Amazon Bedrock)**, then select **Next**.

<Frame>
  <img src="/images/kb/byom_4.png" alt="Adapter selection screen with Meta (Amazon Bedrock) selected" />
</Frame>

### Select an Account

4. Choose a corresponding account, or create a new one. For this example, select an Amazon Bedrock account.

<Frame>
  <img src="/images/kb/byom_5.png" alt="Account selection screen for the model import" />
</Frame>

### Import a Model

5. Select the model to import. For this example, import the Llama 3 70B Instruct model.

<Frame>
  <img src="/images/kb/byom_6.png" alt="Model selection screen showing Llama 3 70B Instruct" />
</Frame>

### Configure Tasks

6. Define the **Task** the model performs, including the input and output schemas.

<Frame>
  <img src="/images/kb/byom_7.png" alt="Task configuration screen with input and output schema fields" />
</Frame>

### Configuration

7. Fine-tune the setup, then select **Import Model**.

<Frame>
  <img src="/images/kb/byom_8.png" alt="Final configuration screen before importing the model" />
</Frame>

<Frame>
  <img src="/images/kb/byom_9.png" alt="Model import confirmation screen" />
</Frame>

## Configure Your Model

1. Select the **Text Generation** service from the **AI Service Models** page in Admin Settings.

<Frame>
  <img src="/images/kb/byom_10.png" alt="Text Generation service option in AI Service Models" />
</Frame>

2. Select **Add Model**.

<Frame>
  <img src="/images/kb/byom_11.png" alt="Add Model button on the Text Generation service page" />
</Frame>

3. Select your newly imported model — in this case, Llama 3 70B Instruct.

<Frame>
  <img src="/images/kb/byom_12.png" alt="Llama 3 70B Instruct model selected in the Text Generation service" />
</Frame>

4. The new model is now listed and available for use. Set it as the **default** model for this service, or leave it available for programmatic use only.

<Frame>
  <img src="/images/kb/byom_13.png" alt="Newly added model listed with default option" />
</Frame>

## Use Your Model

1. Select **AI Playground** from the main menu.

<Frame>
  <img src="/images/kb/byom_14.png" alt="AI Playground option in the Domo main menu" />
</Frame>

Use the **Text Generation** service with the default Domo model, **DomoGPT - Medium v2.2**.

2. Ask the model "Who is your creator?" to confirm which vendor it belongs to.

<Frame>
  <img src="/images/kb/byom_15.png" alt="DomoGPT model response to the creator question" />
</Frame>

3. Select **Llama 3 70B Instruct** from the **Model** dropdown.

<Frame>
  <img src="/images/kb/byom_16.png" alt="Model dropdown with Llama 3 70B Instruct selected" />
</Frame>

4. Ask this model "Who is your creator?"

<Frame>
  <img src="/images/kb/byom_17.png" alt="Llama 3 70B Instruct response to the creator question" />
</Frame>
