## Intro

This article explains how to use Domo's Brivo Connector to import data from Brivo, including access events, users, credentials, schedules, and other physical security management information.

---

## Prerequisites

To connect to the Brivo API account and create a DataSet, you must have the following:

- Client ID and Client Secret for your Brivo account
- API Key
- Username and Password for your Brivo account
- You need to select the Auth Base URL

This article covers the fields and menus specific to the Brivo Connector user interface. For general information about adding DataSets, setting update schedules, and editing DataSet information, see [Add a DataSet Using a Data Connector](/s/article/360042926274).

## Configure the Connection

This section describes the options in the **Credentials** and **Details** panes on the Brivo Connector page. The components of the **Scheduling** and **Name & Describe Your DataSet** panes are universal across most connector types and are discussed in [Add a DataSet Using a Data Connector](/s/article/360042926274).

### Enter Your Credentials

The **Credentials** pane contains the field for entering credentials to connect to the Brivo API. The following table describes what is needed for each field.

| Field   | Description                                               |
| ------- | --------------------------------------------------------- |
| Client ID | Enter the Client ID. |
| Client Secret | Enter the Client Secret. |
| API Key | Enter the api key obtained from developer.brivo.com |
| Auth Base URL | select the Auth base url. |
| Username | Select the username for your Brivo account. |
| Password | Select the password for your Brivo account. |

After you have entered valid credentials, you can use the same account any time you set up a new Domo-Brivo connection. You can manage connector accounts in the **Accounts** tab in the Data Center. For more information about this tab, see [Manage User Accounts for Connectors](/s/article/360042926054).
