## Intro

Domo goes beyond visualization into application building and process automation. App Studio lets you build custom data apps with a drag-and-drop editor. Workflows automates multi-step business processes by triggering actions based on data events or schedules. Code Engine provides a serverless function environment for custom logic. The Appstore lets you install pre-built apps and publish your own. This article explains the Build Apps & Automate capability area and points to the key articles for each component.

## Required Grants

Required grants vary by feature. Common grants:

- **Create Pages and Apps —** Build apps in App Studio.
- **Manage Workflows —** Create, edit, and deploy Workflows.
- **Manage All Company Settings —** Configure Code Engine packages (Admin grant).

## FAQ

<AccordionGroup>

<Accordion title="What is the difference between Workflows and Code Engine?">
  Workflows models an entire business process as a visual flow: steps, conditions, loops, and triggers. Code Engine provides the individual functions that Workflow steps can call when you need custom logic. Think of Workflows as the orchestrator and Code Engine as the function library it draws from.
</Accordion>

<Accordion title="Do I need to be a developer to use App Studio or Workflows?">
  No. Both are designed for non-developers. App Studio uses drag-and-drop components; Workflows uses a visual flow builder. Code Engine is the extension point for developers who need custom logic, but it is optional.
</Accordion>

<Accordion title="Can I trigger a Workflow from a Domo Alert?">
  Yes. Workflows can be triggered by a Domo Alert, a DataSet update, a form submission, or a schedule. See [Workflows | Overview](/s/article/000005108) for the full list of trigger types.
</Accordion>
