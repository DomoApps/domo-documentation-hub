This article will walk you through setting up a connection to Confluence.

## How to Create an API Token

1. Go to the [Atlassian Account API Tokens Page](https://developer.atlassian.com/cloud/confluence/basic-auth-for-rest-apis/).
2. Click **Create API token** (or select **Create API token with scopes** for restricted app-specific permissions).
3. Enter a descriptive label for your token (e.g., "Domo Documents Integration").
4. Set an expiration date if prompted.
5. Click **Create**.
6. Click **Copy to clipboard** and save the token securely. **You will not be able to view it again.**
