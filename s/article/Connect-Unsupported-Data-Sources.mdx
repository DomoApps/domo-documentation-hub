## Intro

This article explains how to bring data into Domo when no prebuilt connector matches your source: using a flexible file or API connector, pulling data with Workbench, ingesting with code, building a custom connector, and requesting a new one.

---

## Check for an Existing Connector First

Domo has hundreds of prebuilt connectors and is always adding more, so start by searching the connector library—your source may already be covered, or an adjacent connector (for example, a generic database or cloud-storage connector) may fit. See [What Is a Connector?](/s/article/What-is-a-Connector) for how connectors work.

If nothing matches, choose one of the options below based on where your data lives and how you prefer to work.

## Use a Flexible File or API Connector

When your source exposes an API or a structured file, a general-purpose connector often works without any custom code:

- **JSON No Code and JSON No Code OAuth connectors** connect to REST APIs that return JSON, including APIs that require OAuth. See [Connecting with the JSON No Code and JSON No Code OAuth Connectors](/s/article/000005360).
- File-based sources can be delivered over SFTP. Domo does not permit uploading data over FTP for security reasons—use SFTP instead.

## Pull On-Premise or Local Data with Workbench

When data lives behind your firewall—in an on-premise database, a local file share, or a system with no public API—use Workbench to extract it and push it to Domo on a schedule. See [What Is Workbench?](/s/article/What-is-Workbench).

## Ingest with Code in Jupyter Workspaces

When ingestion requires custom logic—calling an unusual API, transforming a response, or combining several sources—use a Jupyter Workspace to write the ingestion in Python or R and land the result as a DataSet. See [Jupyter Workspaces | User Guide](/s/article/36004740075).

## Build a Custom Connector

For a reusable, configurable connector to a source Domo does not yet support, more technical users can build one with the Connector IDE. Start at the [Developer Portal](https://developer.domo.com/connect-to-domo), and see [Building Custom Connectors in Domo](/s/article/360043439773).

## Request a New Connector

If none of the above fits, contact your account executive or customer success manager to discuss creating a new connector or updating an existing one.

## FAQ

<AccordionGroup>

<Accordion title="Can I write data back out of Domo to a system with no connector?">
  Writeback also depends on an available connector. If none exists for your destination, contact your account executive or customer success manager to discuss building one, or use a custom connector.
</Accordion>

<Accordion title="My API returns JSON but needs authentication. Which option should I use?">
  Use the JSON No Code OAuth connector for APIs that require OAuth, or the JSON No Code connector for simpler authentication. See [Connecting with the JSON No Code and JSON No Code OAuth Connectors](/s/article/000005360).
</Accordion>
