## Intro

Before you can analyze or visualize data in Domo, you bring it in from where it lives. Domo supports multiple ingestion methods: cloud connectors for SaaS and web services, Cloud Integrations for cloud data warehouses, Workbench for on-premises and local files, and direct file uploads for one-time or ad hoc imports. This article explains the Connect & Bring In Data capability area and points to the key articles for each method.

## Required Grants

To add DataSets to Domo, the following grants must be enabled for your role:

- **Can Create DataSets —** Add new DataSets using any ingestion method.

## Workbench

Workbench is a Windows agent that runs on-premises and pushes data from local files, databases, or systems not accessible from the public internet.

- [What Is Workbench?](/s/article/What-is-Workbench) — Overview of Workbench and when to use it instead of a cloud connector.

## File Upload

Use the File Upload Connector to bring CSV, XLS, and XLSX spreadsheets into Domo directly from your computer—no authentication required.

- [File Upload Connector](/s/article/360043436573) — Upload a spreadsheet as a DataSet using the guided wizard.

## Writeback Connectors

Writeback connectors push data from a Domo DataSet back to an external system—such as writing a transformed DataSet back to Snowflake or a CRM. They are found in the Connector Library under the Writeback category.

## FAQ

<AccordionGroup>

<Accordion title="When should I use a cloud connector versus Cloud Integrations?">
  Use a cloud connector when you want Domo to store a copy of the data and keep it updated on a schedule—the connector pulls the data and writes it to Domo storage. Use Cloud Integrations when your data is already in Snowflake, BigQuery, Redshift, or Azure SQL Database and you want to query it in place without duplicating it. See [Cloud Integrations Overview](/s/article/4412849158167) for a full comparison.
</Accordion>

<Accordion title="When should I use Workbench instead of a cloud connector?">
  Use Workbench when your data lives behind a firewall, on a private network, or on-premises—where Domo's cloud servers cannot reach it. Workbench runs on a Windows machine inside your network and pushes data to Domo. See [What Is Workbench?](/s/article/What-is-Workbench).
</Accordion>

<Accordion title="How do I update an existing DataSet's credentials?">
  Go to **Data > Data Center**, find the DataSet, open its options menu, and select **Edit Connection**. Update the credentials on the connector account. All DataSets using that account are updated simultaneously. See [Manage Connector/Adapter Accounts](/s/article/360042926054).
</Accordion>

</AccordionGroup>
