## Intro

This article explains how to create a navigation config, assign it to people and groups, control personalization, and edit, duplicate, or delete it.

---

## Required Grants

To access Navigation Configs, the following grant must be enabled for your role:

- **Manage All Company Settings —** Manage company metadata, security rules and SSO, publishing, and licenses.

Learn more about [grants](/s/article/360043438973).

## Understand Navigation Configs

Navigation Configs let you customize the Domo experience by assigning tailored navigation configs to different people and groups, with each person seeing only what's relevant to them.

Individual users can personalize their own navigation. With Navigation Configs, admins can also create a global, customized navigation experience. You can pin any Domo object, such as apps, Workspace homes, folders, or dashboards, to the section below the global navigation for all users, or customize it for specific departments or groups.

For example, you can make sure your CFO sees financial dashboards immediately, while your marketing team gets instant access to campaign metrics.

### Understand Configured Items and Personal Pins

The navigation items in a config appear in the navigation of every assigned user. When personalization is enabled for the config, users can also personalize their navigation by pinning new items below the configured navigation. When personalization is off, users' own pins are hidden.

### Understand Permission-Aware Content Pins <Badge>Beta</Badge>

<BetaNote />

Turn on permission awareness for a navigation config to make sure users only see content pins they can open. When **Permission-aware content pins** is on, users assigned to the config only see a content pin if they have access to that content.

Permission awareness applies only to content pins. It doesn't extend to other types of pins, such as folders, subfolders, smart folders, feature pins, or action pins, which are always shown.

### Understand How Configs Are Assigned

Each user has one navigation config at a time. When a user receives configs from more than one source, Domo applies these rules:

- A config assigned directly to a user takes priority over a config assigned through a group.
- If a group has more than one config, the most recently assigned config applies.
- Users keep a config as long as they have access to it through any source, such as a direct assignment or another group.
- When you assign a config with **Override everyone's config** selected, it overrides any navigation config assigned to the people and groups in that config.
- When you assign a config from the **People** page or from a user's profile, it overrides any navigation config that's already been assigned to the selected people.

## Access Navigation Configs

To open Navigation Configs, follow these steps:

1. In the left navigation, select **Admin** (the wrench icon <i className="icon-wrench" aria-hidden="true" />).
2. Under **Company settings**, select **Navigation** > **Navigation Configs**.

<Frame>![Navigation option under Company settings in the Admin menu](/images/kb/nav_configs_01.png)</Frame>

The **Navigation Configs** page lists your instance's configs, with the name, description, creator, assignees, and last saved date of each one.

<Frame>![Navigation Configs page listing the configs in an instance](/images/kb/nav_configs_landing_page.png)</Frame>

## Create a Navigation Config

A navigation config has three tabs: **Config Settings**, **Navigation**, and **Assignees**. As you work, a preview of the navigation bar shows what assigned users see.

To create a navigation config, follow these steps:

1. Open Navigation Configs. Learn how to [access Navigation Configs](#access-navigation-configs).
2. Select **Create**.  
   The **New Config** editor opens to the **Config Settings** tab.

   <Frame>![Create button on the Navigation Configs page](/images/kb/nav_configs_02.png)</Frame>

   <Frame>![Config Settings tab with Name and Description fields](/images/kb/nav_configs_03.png)</Frame>

3. Enter a **Name** for the config.
4. (Optional) Enter a **Description**.
5. Select **Next**.  
   The **Navigation** tab opens with a **Permissions** section and the config's navigation items. The config starts with a few default items, such as **Home**, **Apps**, **Dashboards**, **Alerts**, **DataSets**, and **Dataflows**, which you can keep, edit, or remove.

   <Frame>![Navigation tab with the Permissions section, navigation items, and Add Navigation Item](/images/kb/nav_configs_navigation_section.png)</Frame>

6. (Optional) Under **Permissions**, turn on **Permission-aware content pins**.  
   When this option is on, users only see content pins they have access to. Feature, folder, and other pin types are always shown. Learn more about [permission-aware content pins](#understand-permission-aware-content-pins-beta).
7. Select **Add Navigation Item** to add the pins you want users to see.  
   You can't add the same pin to a config twice.
8. (Optional) Drag the navigation items by their handles to reorder them.
9. Select **Next**.  
   The **Assignees** tab opens.
10. Assign the config to people and groups, and choose whether users can personalize their navigation. Learn how to [assign a config to people and groups](#assign-a-config-to-people-and-groups).
11. Select **Save** in the top-right corner.

## Assign a Navigation Config

You can assign a navigation config from the config itself, from the **Navigation Configs** page, from the **People** page, or from a user's profile.

### Assign a Config to People and Groups

To assign a navigation config, follow these steps:

1. Open the navigation config, and go to the **Assignees** tab.
2. In the **Enter people or groups** field, type the name of a user or group, and select **Add**.  
   Repeat for each user or group who should use the config. The assignees you add appear in the list below the field.
3. (Optional) Select **Override everyone's config** to override any navigation config assigned to the people and groups in this navigation config.

   <Frame>![Assignees tab with the people and groups field, assignee list, and Override everyone's config option](/images/kb/nav_configs_assignees_section.png)</Frame>

4. (Optional) Under **Personalization**, turn on **Enable personalization** to allow users to personalize their navigation by pinning new items below the configured navigation.  
   When personalization is off, users' own pins are hidden.

   <Frame>![Enable personalization toggle in the Personalization section](/images/kb/nav_configs_personalization_toggle.png)</Frame>

5. Select **Save** in the top-right corner.  
   The config's navigation items are added to each assignee's navigation.

### Assign a Config from the Navigation Configs Page

To add people and groups to a config without opening it, follow these steps:

1. Open Navigation Configs.
2. Select the more options menu (the three-dot icon) for the config.
3. Select **Manage Access**.
4. Add the people and groups who should use the config.  
   **Manage Access** works the same way as the **Assignees** tab. Learn how to [assign a config to people and groups](#assign-a-config-to-people-and-groups).

### Assign a Config from the People Page

To assign a navigation config to several people at once, follow these steps:

1. Go to **Admin** > **Governance** > **People**.
2. In the grid, select the people you want to assign.  
   A toolbar appears at the top of the page.
3. In the toolbar, select the **Assign navigation config** icon.  
   The **Assign navigation config** modal opens.

   <Frame>![Assign navigation config icon in the People page toolbar](/images/kb/nav_configs_people_menu.png)</Frame>

4. In the **Navigation Config** field, select the config you want to assign.
5. Select **Assign**.  
   The selected people are assigned the config. This overrides any navigation config that's already been assigned to them.

   <Frame>![Assign navigation config modal with the Navigation Config field](/images/kb/nav_configs_people_menu_modal.png)</Frame>

### Assign a Config from a User's Profile

To view or change the navigation config assigned to one user, follow these steps:

1. Go to **Admin** > **Governance** > **People**, and select the user's name.  
   The user's profile opens. The **Navigation Config** field in **Personal details** shows the user's current config. **Default** means no config is assigned.

   <Frame>![Navigation Config field and Edit button in the Personal details of a user profile](/images/kb/nav_configs_user_profile_menu.png)</Frame>

2. In **Personal details**, select **Edit**.
3. Next to the **Navigation Config** field, select the pencil icon <i className="icon-pencil-simple" aria-hidden="true" />.  
   The **Assign navigation config** modal opens.

   <Frame>![Pencil icon next to the Navigation Config field](/images/kb/nav_configs_profile_menu_edit.png)</Frame>

4. In the **Navigation Config** field, select the config you want to assign.
5. Select **Assign**.  
   This overrides any navigation config that's already been assigned to the user.

   <Frame>![Assign navigation config modal for a single user](/images/kb/nav_configs_profile_menu_modal.png)</Frame>

6. In **Personal details**, select **Save** to save the configuration and exit edit mode.

## Edit a Navigation Config

To edit a navigation config, follow these steps:

1. Open Navigation Configs.
2. Select the more options menu (the three-dot icon) for the config you want to edit.

   <Frame>![More options menu for a navigation config with Edit, Duplicate, Delete, and Manage Access](/images/kb/nav_configs_more_options_menu.png)</Frame>

3. Select **Edit**.  
   The **Edit Config** editor opens to the **Config Settings** tab.

   <Frame>![Edit Config editor open to the Config Settings tab](/images/kb/nav_configs_config_settings_section.png)</Frame>

4. Edit the name, description, navigation items, assignees, permission-aware content pins, or personalization.
5. Select **Save** in the top-right corner.

### Edit or Remove Navigation Items

To edit or remove an item in a navigation config, follow these steps:

1. Open the navigation config, and go to the **Navigation** tab.
2. Select the gear icon <i className="icon-gear" aria-hidden="true" /> on the navigation item.
3. Select **Edit** to change the item, or select **Remove** to remove it from the config.
4. Select **Save** in the top-right corner.

## Duplicate a Navigation Config

To make a copy of a navigation config, follow these steps:

1. Open Navigation Configs.
2. Select the more options menu (the three-dot icon) for the config you want to copy.
3. Select **Duplicate**.  
   A copy of the navigation config is created.

## Delete a Navigation Config

To delete a navigation config, follow these steps:

1. Open Navigation Configs.
2. Select the more options menu (the three-dot icon) for the config you want to delete.
3. Select **Delete**.  
   A confirmation modal opens.
4. Confirm the deletion.

## FAQ

<AccordionGroup>

<Accordion title="Can a user be assigned more than one navigation config?">
  No. Each user has one navigation config at a time. When a user receives
  configs from more than one source, Domo decides which one applies. Learn more
  about [how configs are assigned](#understand-how-configs-are-assigned).
</Accordion>

<Accordion title="What happens to a user's own pins when I turn off personalization?">
  When personalization is off, the user's own pins are hidden, and the user sees
  only the pins in their navigation config.
</Accordion>

<Accordion title="What happens when a user is removed from a group?">
  The user loses the group's config only if they don't have access to it through
  another source, such as a direct assignment or another group.
</Accordion>

<Accordion title="Can I customize the top section of the left navigation?">
  No. The top section, which contains **Features**, **Search**, **Create**,
  **Recent**, and **Admin**, stays global and reflects each user's grants and access.
</Accordion>

</AccordionGroup>
