## November 12, 2026 Release

### AI Labs

- AI Library cards displayed blank gray space instead of icons when embedded or published through Domo Everywhere.
- FileSets would skip processing a file if its updated content matched another file already in the set.
- Introduces AI Chat V2 with improved consumption reporting and an updated Pro badge display.
- Magic ETL DataFlows using the AI Text Generation tile would intermittently fail with an "unknown error occurred" message.
- OAuth sign-in for the Domo MCP Server returned errors, preventing users from connecting MCP sessions through Claude, Snowflake, Cursor, and other AI tools.
- Search for FileSets by their ID.

### AI Readiness

- Tool display names and descriptions are now correctly included when retrieving Domo-provided and skill-derived toolkits through the API.

### AI Services

- Adds display names to AI Services usage tracking for clearer reporting and analytics.
- AI Agent tiles in Workflows could not access certain file types from Documents and Document Collections as knowledge sources.

### Alerts

- Users with the "Use Alerts" grant could not see or receive alerts shared with them unless they also had access to the underlying DataSet.
- Webhook alerts with Personalized Data Permissions applied in a shared context failed to trigger, preventing campaigns from starting as expected.

### App Platform

- An unintended blank space appeared at the top of the Pro-Code Apps editor.

### App Studio

- In App Studio, users could not reorder navigation tabs when AI chat was disabled.

### Cards

- Beast Mode calculations on cards using Data Models failed validation with "A column in this calculation did not exist" when a variable was referenced after a column; variables now populate and validate correctly.
- Card filters and controls failed to display values on cards built from data models that used aggregate filters combined with variable-driven groupings.
- Cards grouped by month displayed English month labels (such as "2026-Jan") instead of localized labels (such as "2026年1月") for non-English viewers, sometimes showing "Data Not Available."
- Date variables and DATETIME comparisons did not correctly apply the company timezone; dates now calculate in the correct timezone on first load, and Snowflake TIMESTAMP columns are no longer shifted twice.
- Exporting a card with a semicolon or non-ASCII characters in its title could produce a file with no extension or a corrupted filename.
- Preset buttons in the expanded date selector on cards could become unresponsive and compress into a vertical line after multiple clicks.
- Shared pages from inactive or deleted users could appear in the admin page list.
- Table cards displayed raw decimal values instead of the configured number format; cards set to show percentages, currency, or abbreviated numbers now display correctly, including high-precision decimal columns from sources like Snowflake.

### Dashboards

- Notebook cards and table cards exported to PDF or PowerPoint could have text or content cut off by extra margins.

### Data Center

- The account sharing dialog would fail to open if the account had previously been shared with a group that no longer exists; it now displays all shared users and groups and lets you remove leftover shares to deleted groups.

### Data Processing

- In Magic ETL, Document tiles are now marked beta, and AI tiles reflect whether AI features are enabled for your instance.

### Embed

- Embedded dashboards were cut off at the bottom, preventing users from seeing the full content of cards, including table scroll bars and axis labels.
- Slicer and variable selections in embedded App Studio apps did not filter dependent cards; selections now apply correctly in both private and public embeds.

### Navigation

- Add Buzz Chat to custom navigation so it appears in the navigation menu and links to the Buzz Chat interface.
- The notification badge on a user's profile avatar overlapped the full-screen Buzz view for users who had disabled the new left navigation.

### Publish

- Notebook cards in Domo Everywhere publications could lose their DataSet connections when using summary numbers and dynamic text with multiple DataSets, causing pages to fail to render in the subscriber instance.
- Variable options in Publish did not appear correctly on expanded cards in subscriber instances; all configured options now display as expected, matching the parent instance.

### Sandbox

- In Sandbox, promoting and linking a repository in the same promotion operation could fail with an unexpected error.

### Workspaces

- Workspaces could disappear after a page refresh for users who belonged only to hidden or inactive groups.
