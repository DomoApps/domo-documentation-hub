## November 20, 2026 Release

### AI Labs

- AI Chat was unavailable in certain instances due to regional configuration settings.
- AI Library toolkit cards displayed blank grey space instead of icons in Domo Everywhere Embed and Publications.
- Enables form respondents to upload file attachments to Document Collections when submitting forms in App Studio.
- OAuth sign-in for the Domo MCP Server returned HTTP 500 errors, preventing users from connecting MCP sessions from Claude, Snowflake, and other AI tools across multiple instances.

### AI Readiness

- Ensures that tool display names and descriptions are now included when retrieving Domo-provided and skill-derived toolkits through the API.

### Alerts

- Users could not be added to certain alerts. The share dialog would get stuck on "Searching" when trying to add users or groups to column alerts on DataSets with Personalized Data Permissions (PDP) and more than 200 users with access.

### App Platform

- AppDB DataSets could fail to reflect recent changes, with updates visible in the History tab but not appearing in the DataSet itself.
- Creating a card from the Asset Library would skip the wiring screen for designs requiring setup, such as those with workflow mappings or Code Engine components. Cards now properly route to the wiring screen when configuration is needed.
- Custom apps using page variables could fail to load on App Studio pages and dashboards following the October 6th release.
- Installing Bricks from the Appstore failed with an "Install Failed" error in App Studio.

### App Studio

- Non-admin users received a PAGE_ACCESS_DENIED error when attempting to move or copy cards to App Studio pages, even when those pages were offered as valid destinations in the dialog.
- Users with the "Edit Data in Editable Table Cells" permission were unable to edit cells in App Studio editable tables that use linked DataSets. These users can now edit table cells without requiring the "Edit Cards" permission.

### Authentication

- Mobile users with Single Sign-On configured could not complete authentication, as the login screen remained in the browser window instead of returning to the Domo mobile app.

### Buzz

- Clicking "Add to Page" on a card attached to a Buzz conversation caused an error and prevented the card from being added to a page.
- Emoji category icons in the emoji picker appeared blank in Buzz messages.

### Cards

- Card filters and controls could fail to display values on cards built from data models that use aggregate filters and variable-driven groupings.
- Card filters and controls could fail to display values on cards built from data models when the card used both an aggregate filter and a variable-driven grouping. A related fix addresses duplicate table aliases in nested data model queries with date ranges.
- Issues where date variables and DATETIME comparisons did not correctly apply the company timezone. Date variables now calculate to the correct date for the company's timezone, and filters using those variables apply properly on dashboard load.
- Table cards with multiple columns and a total row could fail to render with a "Bad Request" error when adding dimensions.

### Cloud Integrations

- DataSets displayed a false authentication warning even after valid credentials were re-entered, particularly affecting Snowflake Cloud Amplifier connections. DataSets continued to sync correctly despite the warning message.
- Magic ETL dataflows writing large datasets to Snowflake through Cloud Amplifier could intermittently fail with a "Connection is closed" error when the write operation took longer than 30 minutes.
- MySQL Cloud Integrations failed to list or preview tables when the connecting user lacked privileges on the mysql system schema.

### Connectors

- The Facebook connector settings page would fail to load, preventing users from updating account selections or modifying connector configurations.
- Uploading multiple files consecutively in the File Upload connector could cause the interface to freeze and fail to advance to the preview screen. Users previously had to reload the page between uploads to avoid this behavior.

### Data Center

- DataSet Views created from federated DataSets could not be edited, returning a "403 Forbidden" error.

### Data Processing

- Improves diagnostic logging for partitioned DataSets in Magic ETL. When a partition delete operation completes but removes no rows, the system now logs that condition, making it easier to detect and investigate issues where DataSets grow unexpectedly large due to failed partition removal.
- Magic ETL DataFlows could become stuck in PREPARING or EXPORTING status for up to 24 hours when multiple DataFlows were triggered simultaneously, such as when several Snowflake DataSets updated at once. Affected DataFlows would eventually time out or require manual cancellation, though they typically succeeded when run individually.
- The timeframe dropdown was missing from the "DataFlow has not run within the last" trigger condition in DataFlow settings.

### Data Query

- Schema changes to DataSets used in Apps with low-latency sync enabled were not applied after the initial sync was configured.

### Embed

- App Component cards in embedded App Studio apps failed to load and displayed "This content is no longer available.".
- Embedded dashboards were cut off at the bottom, preventing users from viewing the lower portions of cards, including table scroll bars and chart axis labels.
- Introduces a beta feature that allows embedded Domo content to appear live within AI clients, including Domo agent chat, VS Code, ChatGPT, and Claude.
- Slicer and variable selections in embedded App Studio apps did not filter dependent cards. The selections would appear to register visually in the control but would not update the connected content. Both private and public embeds were affected. Interactive filtering now works correctly in embedded apps.
- Slicer and variable selections in embedded App Studio apps did not filter dependent cards. The selections would appear to register visually in the control but would not update the connected content. This affected both private and public embeds, while the same interactions worked correctly when the app was viewed directly in Domo.

### Federated Data

- Cards and Scheduled Reports using BigQuery DataSets failed to load with "Invalid field name" errors when column names contained special characters such as forward slashes, parentheses, or commas. Column aliases are now properly sanitized before queries are sent to BigQuery, and the 300-character alias limit is enforced. This affects both federated BigQuery DataSets and Cloud Amplifier BigQuery integrations.

### Personalized Data Permissions

- Some Personalized Data Permissions (PDP) row policies present in a DataSet did not appear in the DOMO Stats Row Assignment table.

### Publish

- CSV exports failed on cards built from views that join multiple Publish DataSets. Other export formats were unaffected.
- Notebook cards in published Domo Everywhere apps could lose their DataSet connections when using summary numbers and dynamic text with multiple DataSets, causing pages to fail to render in the subscriber instance.

### Sandbox

- Improves the handling of shared content when promoting changes within the same Sandbox instance.
- In Sandbox where omitting a commit description could cause an error instead of proceeding without one.

### Vertica Cust. Performance

- A rare issue where viewing DataSet details could trigger excessive updates to multiple users simultaneously, causing intermittent slowdowns across the instance.

### Workflows

- Adds the ability to redeploy Code Engine functions by runtime version from the Admin Console, allowing administrators to selectively migrate functions to newer runtimes.
- Output column types in the Query Dataset block of Workflows could not be updated and would incorrectly display as Object type instead of the correct data type such as Text or Date-Time.

### Workspaces

- Workspaces could disappear after a page refresh for Admin users who were only members of hidden or inactive groups.
