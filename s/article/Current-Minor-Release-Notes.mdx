## November 12, 2026 Release

### AI Labs

- Adds the ability to search for FileSets by their ID.
- AI Library cards displayed blank grey space instead of icons when embedded or published through Domo Everywhere.
- FileSets would skip processing a file if its updated content matched another existing file in the set.
- Introduces AI Chat V2 with improved consumption reporting and updated Pro badge display.
- Magic ETL DataFlows using the AI Text Generation tile would intermittently fail with an "unknown error occurred" message.
- OAuth sign-in for the Domo MCP Server returned HTTP 500 errors, preventing users from connecting MCP sessions through Claude, Snowflake, Cursor, and other AI tools across multiple instances.

### AI Readiness

- Ensures that tool display names and descriptions are correctly included when retrieving Domo-provided toolkits and skill-derived toolkits through the API.

### AI Services

- Adds display names to AI Services usage tracking for improved reporting and analytics.
- AI Agent tiles in Workflows could not access certain file types from Documents and Document Collections as knowledge sources.

### Alerts

- Users with the "Use Alerts" grant could not see or receive alerts shared with them unless they also had access to the underlying DataSet.
- Webhook alerts with Personalized Data Permissions applied in a shared context failed to trigger, preventing campaigns from starting as expected.

### App Platform

- Removes an unintended blank space that appeared at the top of the Pro-Code Apps editor.

### App Studio

- In App Studio where users could not reorder navigation tabs when AI chat was disabled in their instance.

### Authentication

- This update implements SCIM deprovisioning for users, resolving an issue where user deprovisioning requests sent via SCIM were not being applied in Domo.

### Cards

- Beast Mode calculations on cards using Data Models failed validation with "A column in this calculation did not exist" when a variable was referenced after a column reference. Variables now populate and validate correctly in Beast Mode calculations.
- Card filters and controls failed to display values on cards built from data models that used aggregate filters combined with variable-driven groupings. A related fix addresses duplicate table aliases in nested data model queries with date ranges that also caused filter failures.
- Cards grouped by month displayed English month labels (such as "2026-Jan") instead of localized labels (such as "2026年1月") for non-English viewers, sometimes showing "Data Not Available.".
- Exporting a card with a semicolon or non-ASCII characters in its title would result in a file without an extension or with a corrupted filename.
- Issues where date variables and DATETIME comparisons did not correctly apply the company timezone. Variables now calculate dates in the correct timezone on first load, and Snowflake TIMESTAMP columns are no longer shifted twice.
- Preset buttons in the expanded date selector on cards could become unresponsive and visually compressed into a vertical line after multiple click attempts.
- Shared pages from inactive or deleted users could appear in the admin page list.
- Table cards displayed raw decimal values instead of the configured number format. Cards set to show percentages, currency, or abbreviated numbers with specific decimal precision now display correctly, particularly for high-precision decimal columns from sources like Snowflake.

### Dashboards

- Notebook cards and table cards exported to PDF or PowerPoint could have text or content cut off due to extra margins.

### Data Center

- The account sharing dialog would fail to open if the account had previously been shared with a group that no longer exists. The dialog now displays all shared users and groups, and leftover shares to deleted groups can be removed.

### Data Processing

- Adjusts the appearance of AI and Document tiles in Magic ETL, marking Document tiles as beta and ensuring AI tiles respect feature settings.
- Improves diagnostic logging for partitioned DataSets in Magic ETL. When a partition delete operation reports success but removes no rows, the system now logs that condition, making it easier to detect and investigate issues where DataSets grow unexpectedly large due to failed partition removal.

### Data Query

- A data cleanup issue in Change Data Capture (CDC) DataSets to prevent accumulation of unused internal records when DataSets are deleted.

### Embed

- Embedded dashboards were cut off at the bottom, preventing users from viewing the full content of cards, including table scroll bars and axis labels.
- Slicer and variable selections in embedded App Studio apps did not filter dependent cards. Filters now propagate correctly in both private and public embeds.
- Slicer and variable selections in embedded App Studio apps did not filter dependent cards. Selections now propagate correctly in both private and public embeds.

### Navigation

- Adds Buzz Chat to the list of features available when configuring custom navigation, allowing it to be added to the navigation menu and correctly link to the Buzz Chat interface.
- The notification badge on a user's profile avatar overlapped the full-screen Buzz view for users who had disabled the new left navigation.

### Publish

- Notebook cards in Domo Everywhere publications could lose their DataSet connections when using summary numbers and dynamic text with multiple DataSets, causing pages to fail to render in the subscriber instance.
- Variable options in Publish did not appear correctly on expanded cards in subscriber instances. All configured variable options now display as expected when cards are expanded, matching the behavior in the parent instance.

### Sandbox

- In Sandbox where promoting and linking a repository in the same promotion operation could fail with an unexpected error.

### Workspaces

- Workspaces could disappear after a page refresh for users who belonged only to hidden or inactive groups.
