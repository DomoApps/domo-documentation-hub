## New Features and Enhancements

### Data Models

With Data Modeling, you can now easily relate tables in your data environment for fast querying and insight, and create calculated fields that contain the logic needed for querying data tables.

You can also incorporate logic into your data models, and more easily group and aggregate data by category or timeframe.

<Frame>![](/images/kb/data_models)</Frame>

### Domo Documents

The Domo Documents tool extracts and gathers structured information from images, documents, transcriptions, customer reviews, and other unstructured data to power visualizations and data products in Domo. Documents also help you automate document-driven business processes to streamline your business.

<Frame>![](/images/kb/domo_documents)</Frame>


### Domo Schema

Domo Schema lets you format fields, change their order, and include field descriptions and tags for downstream users.

You can also access and turn on AI fields and add context and synonyms in the Schema tab.

<Frame>![](/images/kb/domo_schema)</Frame>

### Enhancements to Databricks Authorization

With OAuth 2.0 M2M support, Domo uses the OAuth client credentials flow to authenticate Databricks and Lakebase connections on the service's behalf. Domo handles the short-lived token generation automatically, meaning no static credentials are stored or passed. Set up the connection once using a client ID, client secret, and workspace hostname, and ensure your Databricks connections are connected smoothly. 

Benefits from this enhancement include:

- Stronger security posture
- Reduced credential exposure
- Simplified credential management

<Frame>![](/images/kb/databricks_lakebase_oauth)</Frame>


### New Mobile UI Updates

With App Studio apps on mobile, you can now access both the app pages and mobile tabs simultaneously. The filter dropdown has also been improved and appears in place, making it easier to select items.

Domo Mobile also supports app components —enabling you to elevate your app into a true native-like mobile experience.

<Frame>![](/images/kb/mobile_ui_updates)</Frame>


### Text Generation DataFlow Tile in Magic ETL

The AI Text Generation Magic ETL tile leverages the power of Domo AI to process text fields in your data. The tile allows you to analyze and gain further value from previously inaccessible information in your DataSets.

<Frame>![](/text_generation_tile)</Frame>


### Workflows Updates

#### Queue Notification Controls 

The new Admin Queue Notification Setting on the Manage Queues page in Task Center allows admins to enable or disable notifications for a specific queue. When this setting is enabled, you can customize your personal notification preferences for task events within that queue. When disabled, all queue notifications are turned off. 

<Frame>![](/images/kb/queue_notification_controls)</Frame>


#### Workflow Event Triggering - Access Request

The new Access Request event-based trigger option in Workflows allows you to configure your workflows to initiate when someone requests access to a Card, Page, or App. 

This feature improves visibility into access requests and related workflows, better enabling you to create customizable workflows tailored to your organization's needs.

<Frame>![](/images/kb/access_request_config_modal)</Frame>


### Workspaces (Mobile & Web)

Workspaces, now available on the web and mobile, provide a centralized location for organizing Domo objects, such as Cards, Dashboards, Apps, DataSets, DataFlows, Workflows, and Worksheets.

Workspaces enable you to find relevant content more efficiently, support team and department-specific organization using folders and subfolders, and enhance the navigation experience on both web and mobile platforms. Additionally, Workspaces make it easy to control sharing the right content with the right people and also revoking access when needed.

<Frame>![](/images/kb/workspaces)</Frame>

#### Advanced Feature Management for Instances

Admins can now configure connectors, Toolkits, and other features directly from their instance with Advanced Feature Management in Instances using the New Instance Template modal. Use this to enable or disable features available to your organization and maintain consistency across all managed instances.

<Frame>![](/images/kb/advanced_feature_management)</Frame>

### Column PDP - Alerts Compatibility

Alerts now function on DataSets where Column PDP is enabled, allowing masking to be enforced according to the Alert recipient's policies. 

Usage of PDP-controlled columns in the Alert evaluation criteria applies restrictions to which users can subscribe to or receive an Alert by design to protect sensitive data. 


### Connector Execution Details in History Tab

The Connector Execution Details modal provides more insight about a connector's execution, so you can better self-serve on some of the more common questions that occur when a DataSet fails or runs long.

The modal provides simple information on whether the connector version has changed, how many rows were processed, and how long each phase of the import took. This update reduces the amount of time it takes to resolve data pipeline issues and enables you to troubleshoot the problem yourself before reaching out to Support.

<Frame>![](/images/kb/connector_execution_failed)</Frame>
<Frame>![](/images/kb/connector_execution_pass)</Frame>


### Domo's AI Library: Conversational Agents

Domo's AI Library allows you to curate and manage AI solutions and provides a centralized environment for building and managing AI agents operating with your trusted, governed data. 

Within the AI Library, you can leverage Domo's AI Agent Builder to create custom agents or agentic workflows tailored to specific use cases. 

<Frame>![](/images/kb/conversational_agents)</Frame>


### Domo Essentials MCP

Domo Essentials MCP is our hosted server that gives AI tools secure access to your Domo platform for actions like Query DataSet, Query Documents, and Search Domo. 

Now with Domo Essentials MCP, you can quickly trigger powerful actions all powered by the security and context of your live Domo instance. 

<Frame>![](/images/kb/domo_mcp)</Frame>


### Magic ETL Enhancements

#### Classification Tile

The new AI Classification Tile in Magic ETL allows you to categorize your data, including text, images, and files, into pre-defined classes. 

The AI Classification tile lets you focus more on your classification entities and less on the actual configuration details.

<Frame>![](/images/kb/classification_tile)</Frame>


#### Multi-Statement SQL Tile

The new Multi-Statement SQL tile lets you write multiple SQL statements in a single tile and create multiple outputs.

This functionality provides a higher-code feel and enables you to create interstitial tables that might not have any outputs associated with them as part of the total SQL Script. 

<Frame>![](/images/kb/multi_statement_sql_tile)</Frame>


#### Sentiment Analysis tile

Panels in the new Magic ETL canvas interface have been converted into tools that can be moved to different parts of the screen. You can set layouts depending on how you like to work on different screens and in different scenarios; and save and persist your layouts across DataFlows. You can also choose your panel placement and select whether panels are pinned open or closed by default.  

<Frame>![](/images/kb/customizable-window-layout.png)</Frame>
