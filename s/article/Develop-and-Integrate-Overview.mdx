## Intro

Beyond the Domo web interface, every major platform capability is also accessible programmatically. The Develop & Integrate capability area covers the Domo APIs, Python and R SDKs, command-line interface, ODBC driver, the Connector IDE for building custom data integrations, and the Domo MCP Toolkit for connecting AI tools to Domo. Whether you're pushing data in from a proprietary system, automating user management, or building a brand-new connector, this article explains the available tools and points to the relevant documentation.

---

## Required Grants

To use developer tools and integrations, one of the following grants must be enabled for your role in the area you want to control:

- **Manage All grants —** Admin grants, such as **Manage All DataSets** or **Manage All Users**, that give full control of everything in that area.
- **Edit grants —** Grants, such as **Edit DataSet**, that let you change the content in that area to which you have access.

Learn more about [grants](/s/article/360043438973).

## Domo APIs

Domo's REST APIs give you programmatic access to DataSets, users, groups, cards, dashboards, and more. Use the APIs to automate data imports, manage users at scale, or extend Domo from an external system.

- [Domo APIs](/s/article/360043439793) — Overview of the available API endpoints and how to authenticate.

For API reference documentation, see the [API Reference](/portal/API-Reference/overview) section of the Developer Portal.

## Python and R SDKs

The Python and R SDKs wrap the Domo APIs with language-native clients so you can work with Domo DataSets in your data science workflows.

- [Python SDKs](/s/article/360042936554) — Pull and push DataSets between Domo and Python.
- [Installing the R SDK](/s/article/360042923734) — Transfer DataSets between Domo and R for statistical analysis.

## Domo CLI

The Domo CLI is a terminal-based tool for uploading large DataSets, managing users and groups, and running data management commands in bulk—without writing API code.

- [Domo CLI (Command Line Interface) Tool](/s/article/360043437733) — Install and use the Domo CLI.

## ODBC

The Domo ODBC driver exposes your Domo DataSets as a SQL-queryable ODBC data source—letting external BI tools, reporting systems, or spreadsheet applications query Domo data directly.

- [Domo ODBC Data Driver](/s/article/360043437693) — Install and configure the ODBC driver.

## Custom Connectors

If the Domo Connector Library doesn't have a connector for your data source, you can build one using the Connector IDE.

- [Building Custom Connectors in Domo](/s/article/360043439773) — Build and publish a custom connector using the Connector Dev Studio.
- [Build Your Own Writeback Connector](/s/article/1500003318001) — Build a writeback connector to push Domo DataSets to an external system.

## Domo MCP

The Domo MCP Toolkit connects AI tools to your Domo instance through the Model Context Protocol (MCP). Use it to query and search your data in plain language, and to build Cards, App Studio apps, Workflows, Workspaces, and ETL pipelines from a conversation.

- [Domo MCP](/s/article/Domo-MCP) — Overview of the Domo MCP Toolkit and the tools it includes.
- [Connect AI Tools to Domo Using MCP](/s/article/Connect-AI-Tools-to-Domo-Using-MCP) — Connect Claude Desktop, Claude Code, VS Code, or other AI tools to Domo's MCP Server.

## FAQ

<AccordionGroup>

<Accordion title="Do I need an API key or access token to use the Domo APIs?">
  Yes. The method depends on which APIs you use:

  - **App Framework APIs** use an access token. See [Manage Access Tokens](/s/article/360042934494).
  - **Platform APIs** use OAuth 2.0. Create a client ID and client secret on the **API Clients** page in Admin Settings, then use them to request an access token. See [Manage API Clients](/s/article/000005240).

  See [Domo APIs](/s/article/360043439793) for authentication details.
</Accordion>

<Accordion title="What is the difference between the Domo CLI and the Python SDK?">
  The Domo CLI is a terminal-based tool designed for bulk operations—uploading large files, managing users—without writing code. The Python SDK is a library for developers who want to integrate Domo into Python scripts and data pipelines. Both wrap the underlying Domo APIs.
</Accordion>

<Accordion title="Can I query Domo DataSets using standard SQL tools?">
  Yes, via the ODBC driver. Install the Domo ODBC driver and configure a data source, then connect any ODBC-compatible tool (Excel, Tableau, Power BI, SQL clients) to query your DataSets using SQL. See [Domo ODBC Data Driver](/s/article/360043437693).
</Accordion>

</AccordionGroup>
