## Intro

After you build an app, you can get it in front of the people who need it. This article covers sharing an app with Domo users and groups, embedding it with Domo Everywhere, allowing export, and letting viewers download files from Doc Cards.

## Share an App

To share an app, open it and select <i className="icon-arrow-square-out sm" aria-hidden="true" /> **Distribute** in the app's [main navigation](/s/article/Build-an-App-Studio-App#view-an-app). You can share the app with users and groups in your Domo instance, or enter an email address to invite a new user, and you can send an email notification of the shared app. To control which rows of data each viewer sees, apply [Personalized Data Permissions (PDP)](/s/article/360042934614) to the underlying DataSets.

### App Sharing Is App-Level Only

Sharing in App Studio applies to the entire app. There is currently no way to share or hide individual pages with different users or groups, and personalized data permissions cannot be scoped to a single app page. Every user who has access to an app can open all of its visible pages.

When different audiences need different pages, the supported approach is to build a separate app for each audience and share each app with the appropriate users or groups. You can [duplicate an app](/s/article/Build-an-App-Studio-App#duplicate-an-app) to reuse a common structure as a starting point.

## Embed an App

<Warning>
  **Important:** The following items are not currently supported for embedded apps.

  - Button pop-ups
  - Workflows widget
  - Queues widget

  The following field data types are not supported for public embed:

  - Account
  - Person
  - Groups
  - DataSet
</Warning>

Follow these steps to embed an app you have access to:

1. From the
   [app viewer](/s/article/Build-an-App-Studio-App#view-an-app), select <i className="icon-arrow-square-out sm" aria-hidden="true" /> **Distribute** > **Embed app** to display the embed modal.

2. (Optional) Check the boxes to allow interactions and filtering and allow export.

3. (Optional) In the **Width (px)** and **Height (px)** fields, adjust the dimensions for the embedded app.

## Download Content from a Doc Card

App users can *only* download the file (document, presentation, photo, video, or other) embedded in an App Studio Doc Card if presentation mode is enabled when the card is added to the app.

This process is described in two parts: first, the app creator enables presentation mode for a Doc Card; second, an app user downloads the applicable file.

### Enable Presentation Mode for Doc Card

Presentation mode is off by default. Enable it by following the steps below.

Open your App Studio app in edit mode and select the Doc Card where the file you want users to download is located.

1. In the **Settings** tab of the right configuration panel, select **Content Display Options** > **Presentation mode**.

   A checkmark displays by **Presentation mode**, meaning it is enabled for the card.

   <Frame>![](/images/kb/ka0Vq000000C3gT-00N5w00000Ri7BU-0EMVq000005Gbjt.jpg)</Frame>

2. Save the changes to your app and close edit mode.

### Download a Doc Card File

While viewing an app, if presentation mode is enabled for a Doc Card, an app user can download the file locally by following the steps below.

Open an app in view mode and locate the Doc Card containing the file you want to download.

1. Hover over the card and select <i className="icon-expand sm" aria-hidden="true" /> **Expand** to open presentation mode.

   <Frame>![](/images/kb/ka0Vq000000C3gT-00N5w00000Ri7BU-0EMVq000005GZ8c.jpg)</Frame>

2. Select **Download** at the top of the screen.

   The file is downloaded locally.

   <Frame>![](/images/kb/ka0Vq000000C3gT-00N5w00000Ri7BU-0EMVq000005Ge6f.jpg)</Frame>
