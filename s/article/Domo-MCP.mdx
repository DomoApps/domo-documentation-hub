## Intro

Ask Domo anything, or tell it what to build. The Domo MCP Toolkit gets you answers across your entire data platform in plain language, and it builds Cards, App Studio apps, Workflows, Workspaces, and ETL pipelines from a conversation — the shift from AI that helps you understand your data to AI that helps you run your business on it.

---

<Note>**Note:** A Toolkit's tools only return data and perform actions that the connected Domo account already has permission to access.</Note>

<Note>**Note:** This Toolkit is also referred to as **Domo Basic MCP** or the **Domo Essentials MCP Server** in some interfaces and articles. See [Connect AI Tools to Domo Using MCP](/s/article/Connect-AI-Tools-to-Domo-Using-MCP) to connect an external AI client to it.</Note>

## Tools Included

 - List Document Collection Files
   - List the files and their metadata in a document collection (FileSet).
 - Read File
   - Read the full contents of a specific document in a document collection.
 - Query Document Collection
   - Query unstructured documents and knowledge bases.
 - SQL Query
   - Query Domo datasets using natural language.
 - Domo Documentation Query
   - Search the global Domo documentation index to answer questions about Domo products and features.
 - Search
   - Search for Domo entities by name or description.
