<Note>**Note:** This Toolkit used to be called the **Domo Basic MCP** or the **Domo Essentials MCP Server** and may still be referred to as such in some interfaces and articles.</Note>

## Required Grants

To use the Domo MCP Toolkit, the following grants must be enabled for your role:

- **Use AI Services —** Access to features and Apps built using the AI Services Layer.
- **Use AI Chat —** Access to the Domo AI Assistant.
- **Use MCP —** Access to connect external AI tools to Domo's MCP Server.

Learn more about [grants](/s/article/360043438973).

## Tools Included

- List Document Collection Files
  - List the files and their metadata in a document collection (FileSet).
- Read File
  - Read the full contents of a specific document in a document collection.
- Query Document Collection
  - Query unstructured documents and knowledge bases.
- SQL Query
  - Query Domo datasets using natural language.
- Domo Documentation Query
  - Search the global Domo documentation index to answer questions about Domo products and features.
- Search
  - Search for Domo entities by name or description.

## Consumption Considerations for MCP

MCP tool calls don't incur AI operation charges. However, if the tool that gets called uses any of the Domo-provided models, input and output token charges can apply.
