## Intro

Access in Domo is governed by roles and grants. Every user is assigned a role, and every role is a collection of grants—permissions that unlock specific capabilities such as editing cards, creating DataSets, or managing users. Domo ships with five system roles that cover the most common access patterns, and Admins can create custom roles to match any combination of grants their organization needs. This article explains how roles and grants work and points to the key articles for managing them.

---

## Required Grants

To manage user roles and grants, the following grants must be enabled for your role:

- **Manage Roles —** Create, edit, and delete custom roles and assign roles to users (Admin grant).

Learn more about [grants](/s/article/360043438973).

## System Roles

Domo ships with five default system roles:

| Role | Description |
|------|-------------|
| **Admin** | Full access to all Domo features, settings, and user management. |
| **Privileged** | Can create and edit all content; cannot manage users or instance settings. |
| **Editor** | Can create cards and dashboards; cannot manage users or instance settings. |
| **Participant** | Read-only access to shared content; can interact with but not modify cards or dashboards. |
| **Social** | Can post in Buzz and view shared content; most data features disabled. |

See [System Roles | Reference](/s/article/360043438953) for the full grant list assigned to each system role.

## Custom Roles

Admins can create custom roles by selecting any combination of grants. Custom roles let you define access precisely—for example, a "DataSet Admin" role with full DataSet management but no ability to modify cards, or a read-only "External Partner" role.

- [Manage User Roles and Grants](/s/article/360043438973) — Create and edit custom roles; assign grants.
- [System Roles | Reference](/s/article/360043438953) — Full reference of every grant and which system roles include it.
- [Role Settings: Default Role and Roles Allowlist](/s/article/000005839) — Set the default role for new users and restrict which roles can be assigned.
- [Data Refresh Permissions](/s/article/000005492) — Control which roles can run DataSet updates on demand.

## FAQ

<AccordionGroup>

<Accordion title="Can I change a user's role after they have been added?">
  Yes. Admins can change any user's role at any time from **Admin > Governance > Users**. See [Change User Information](/s/article/360043438933).
</Accordion>

<Accordion title="What is the difference between a role and a grant?">
  A role is a named collection of grants. A grant is an individual permission (for example, "Edit Cards" or "Manage DataFlows"). Every user is assigned one role, and the role's grants determine what they can do. Custom roles let you pick exactly which grants to include.
</Accordion>

<Accordion title="Can I assign the same user two roles to combine their permissions?">
  No. Each user is assigned exactly one role. If you need a user to have permissions from two roles, create a custom role that includes all the grants from both.
</Accordion>

</AccordionGroup>
