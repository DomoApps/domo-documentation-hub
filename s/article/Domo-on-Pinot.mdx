## Intro

With Cloud Integrations, you can query and visualize [Apache Pinot](https://docs.pinot.apache.org/) data directly in Domo without copying or duplicating data. Apache Pinot is a real-time, distributed OLAP datastore that ingests and queries data from streaming or batch sources.

To request access to the Pinot integration, contact your Domo AE or CSM.

---

## Before You Begin

- Confirm you have an account with access to your Pinot cluster, including the controller host and port.
- Have your Pinot username and password ready. Domo connects to Pinot over JDBC.
- (Recommended) Create a dedicated Domo service account for this integration. Your account's custom role must include the **Manage Cloud Accounts** and **Manage DataSet** grants. For more information about roles and grants, see [Manage User Roles and Grants](/s/article/360043438973).

## Access the Pinot Integrations Page

1. In the navigation menu, select **Data** > **Data Warehouse**.
2. Select **Manage Cloud Connections**.
3. In the **Native integration** section, select **See More**.
4. Select the **Pinot** tile.
   The Domo on Pinot page appears.

## Create a Pinot Integration

1. From the Pinot integrations list, select **+ Add New Integration**.
2. Enter an **Integration Name** — the label that identifies the integration within Domo. This name is local to Domo and does not need to match any name in Pinot.
3. (Optional) Enter an **Integration Description** to explain the purpose of the integration and who created it.
4. Enter the **Pinot connection URL** — the JDBC connection string for your Pinot controller.
   Do not include `jdbc:pinot://` in the URL — Domo prepends it for you.
   Example: `myControllerHost.net:9000?scheme=http`
5. Enter your Pinot **Username**.
6. Enter your Pinot **Password**.
7. Select **Save** (or the equivalent confirm button) to create the integration.

   {/* TODO[screenshot]: Add New Integration form — Pinot fields for Integration Name, Description, connection URL, Username, and Password — see scripts/reports/screenshot_tracker.md */}

<Note>**Note:** Pinot integrations expose Tables only. Pinot's data model does not include Schemas or Catalogs, so those layers are not available when browsing Pinot data in Domo.</Note>

After the integration is saved, it appears in the Pinot integrations list alongside any others in your instance. From the list, you can connect the Pinot tables you want to use in Domo — either by browsing available tables or by adding them manually. For details, see [Connect Tables in Cloud Integrations](/s/article/Connect-Tables-in-Cloud-Integrations).

## Manage Existing Integrations

You can manage any Pinot integration you own or that has been shared with you from the Pinot integrations list. Select the integration to view its details, edit its name and description, change the service account or connection settings, share the integration with other users, connect or disconnect tables, and configure data freshness. For details on data freshness and account sharing, see [Cloud Integrations Overview](/s/article/4412849158167).

<Note>**Note:** Pinot integrations do not currently support real-time card updates. To approximate real-time refresh, contact your Domo representative or use [Domo Bricks](/s/article/000005295) to build a custom refresh pattern.</Note>
