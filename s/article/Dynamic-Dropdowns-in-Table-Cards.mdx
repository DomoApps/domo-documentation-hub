## Intro

This article explains what a standard Analyzer table card supports for in-cell interactivity, and the supported approaches when you need interactive controls—such as dropdowns—or the ability to write data back from a table.

---

## What a Standard Table Card Supports

A standard Analyzer table card is built for display and navigation, not data entry. It supports:

- **Drill Paths** — drilling works the same in tables as in other chart types, so a click can open a more detailed view. See [Add a Drill Path to Your Chart](/s/article/360042924094).
- **Action links** — set a column's display option to **Link** to convert its values into links. Use the **Prefix/Suffix** fields to build a URL that is dynamic per row, or the **Label** field to give the link static text.
- **Links and images** — the Mega Table supports functional links and images for large, scannable lists.

## Add Interactive Table Controls with App Studio

When you need users to interact with rows—filter, select, or explore within the table itself—use App Studio table elements rather than an Analyzer table card. See [Explore Data with Table Elements in App Studio](/s/article/000005681).

## Build Custom In-Cell Controls with Bricks or an App

For custom in-cell controls such as dropdowns, build a custom visual with Domo Bricks or the App Framework, where you control the rendering and behavior of each cell. See [Domo Bricks | Overview](/s/article/4423762260375) and [What Is App Studio?](/s/article/What-is-App-Studio).

## Write Data Back

To capture input and write it back to Domo, use one of the supported write-back paths rather than the table card itself:

- **Writeback connectors** push data from Domo to an external system. See [DOMO's List of Writeback Connectors](/s/article/000005353).
- **Workflows** can write rows to a DataSet or AppDB. See [Write Data Back to a DataSet with Workflows](/s/article/Workflows-Write-Data-Back).
- **Pro-code apps** can write to AppDB collections directly. See [Write Data from Pro-Code Apps to AppDB](/s/article/Write-Data-from-Pro-Code-Apps-to-AppDB).

## FAQ

<AccordionGroup>

<Accordion title="Can I make a cell in a table card a dropdown that updates the data?">
  Not in a standard Analyzer table card. Table cards display and link to data; they do not accept in-cell input. Build the interactive control in App Studio, a Brick, or a custom app, and use a write-back path to persist the value.
</Accordion>

<Accordion title="What is the lowest-effort option?">
  If you only need users to navigate or filter, App Studio table elements require no code. Custom in-cell controls with Bricks or an app require development effort and, for external write-back, a connector—factor that cost in before choosing an approach.
</Accordion>

</AccordionGroup>
