## Intro

This article explains how to use Domo's EncompassV3 Connector to securely retrieve loan pipeline, loan population, audit history, field metadata, and user information from ICE Mortgage Technology through the Encompass V3 APIs. Use this connector to access Encompass data for reporting, analytics, operational monitoring, data warehousing, and historical analysis in Domo. The connector supports configurable field selection, incremental loan updates, historical field backfills, loan population reconciliation, milestone history, custom audit history, canonical field metadata, and Encompass user information.

You can connect to your EncompassV3 account in the Data Center. This topic discusses the fields and menus specific to the EncompassV3 Connector user interface. To add DataSets, set update schedules, and edit DataSet information, see [Adding a DataSet Using a Connector](/s/article/360042926274).

## Prerequisites

To connect to your EncompassV3 account and create a DataSet, you must have the following:

* Account's Smart Client User and Password
* Account's Client Id and Client Secret
* Account's Instance

## Configure the Connection

This section enumerates the options in the **Credentials** and **Details** panes on the EncompassV3 Connector page. The components of the other panes in this page, **Scheduling** and **Name & Describe Your DataSet**, are universal across most connector types and are discussed in great detail in [Adding a DataSet Using a Connector](/s/article/360042926274).

### Enter Your Credentials

This pane contains fields for entering credentials to connect to your EncompassV3 account. The following table describes what is needed for each field:

| Field                 | Description                                                   |
| --------------------- | ------------------------------------------------------------- |
| Smart Client User     | Enter the Smart Client User for your EncompassV3 account.     |
| Smart Client Password | Enter the Smart Client Password for your EncompassV3 account. |
| Client Id             | Enter the Client Id for your EncompassV3 account.             |
| Client Secret         | Enter the Client Secret for your EncompassV3 account.         |
| Instance              | Enter the Instance for your EncompassV3 account.              |

Once you have entered valid EncompassV3 Connector credentials, you can use the same account any time you go to create a new EncompassV3 Connector DataSet. You can manage connector accounts in the **Accounts** tab in the Data Center. For more information about this tab, see [Manage Connector Accounts](/s/article/360042926054).
