## Intro

This article explains how to produce formatted and static reports from Domo data using three approaches: native card and dashboard export, the App Studio Report Builder, and the Google Sheets Add-On.

---

## Export Cards and Dashboards Natively

Native export is the quickest way to get data out of a card:

- A card exports to CSV, Excel (XLSX), or PowerPoint. A full dashboard exports to PowerPoint with one card per slide. Non-visualization cards—Notebook, Document, and Sumo—may not export.
- On CSV and Excel export, only the card's data is pulled; graphical elements appear only in the Excel export. Native export gives limited formatting control.
- Only Pivot Tables and Mega Tables support exporting color rules, so use those chart types to carry color onto an Excel export.

<Warning>**Important:** Native exports have size and content limits. Exported files are capped at 4 MB. An Excel export supports roughly 3 million cells from a Mega Table and 1.5 million from a Pivot Table (default 100,000 rows for a Mega Table, 50,000 for a Pivot Table). Variables and dynamic smart text are not supported in filenames, email subjects, or attachments—a card titled with a variable exports with the variable dropped from the filename.</Warning>

For the full export reference, see [Exporting Cards](/s/article/360043437813).

## Build Scheduled Reports with App Studio Report Builder

The App Studio Report Builder creates and automates personalized email reports from your App Studio apps—the native path for a styled, scheduled report.

- Report Builder output is static: charts and tables are snapshots, similar to scheduled reports.
- You can configure the report's appearance—background color, density, header and footer, the Domo logo—and apply themes.
- Schedule a view to email recipients daily, weekly, or monthly.

Report Builder requires the **Edit Report (Report Builder)** grant, which is enabled for Admins and editors by default. See [App Studio Report Builder](/s/article/000005829).

## Share Data through the Google Sheets Add-On

The Google Sheets Add-On downloads any DataSet into Google Sheets, where you can edit it and use **Refresh** to pull the current version from Domo. It is a good way to share Domo data with colleagues who don't have Domo access, and works well for periodic static reporting. See [Google Sheets Add-On](/s/article/360043437913).

## Choose an Approach

- A quick one-off extract of a card's data: **native export**.
- A recurring, styled report delivered by email: **App Studio Report Builder**.
- Data others can view and refresh in a familiar spreadsheet: **Google Sheets Add-On**.

## FAQ

<AccordionGroup>

<Accordion title="Why did my export drop part of the filename?">
  Variables and dynamic smart text are not supported in export filenames, email subjects, or attachments. A card whose title includes a variable exports with the variable portion dropped. Use a static title if the filename matters.
</Accordion>

<Accordion title="How do I keep color formatting in an Excel export?">
  Only Pivot Tables and Mega Tables support exporting color rules. Build the card as a Pivot Table or Mega Table to carry color formatting into the Excel export.
</Accordion>

</AccordionGroup>
