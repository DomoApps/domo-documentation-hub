## Intro

This article explains how to extract text and structured data from PDFs and images using Domo AI. The core capability is **Image-to-Text**, which you can invoke from Workflows, Domo Bricks, Domo apps, and Jupyter Workspaces, and which pairs with FileSets for document-driven pipelines.

---

## What Image-to-Text Does

Image-to-Text extracts or generates text from an image. It covers OCR (reading text out of an image), caption generation, and visual question answering. Because a PDF page can be processed as an image, this is the capability behind pulling text out of scanned or image-based documents.

Image-to-Text is part of the AI Service Layer and is available in Jupyter Workspaces, Domo apps, Domo Bricks, and Workflows. See [AI Service Layer Settings](/s/article/000005279) for the full list of services and where each can be used.

## Extract Text in a Workflow

For an automated, no-code pipeline, call the AI Service Layer from a Workflow:

1. Confirm the AI Service Layer (standard or advanced) is enabled for your instance and role.
2. In a Workflow, add an AI Service Layer function and select the Image-to-Text service.
3. For large documents, use the function's chunking configuration so the content is processed in segments.

See [Workflows — AI Service Layer Integration](/s/article/000005369) for the exact configuration steps.

## Extract Structured Data from Documents with FileSets

When your goal is to turn a body of documents into structured data—not just read one image—use FileSets. FileSets extract structured information from images, documents, transcripts, and other unstructured data to power visualizations, automate document-driven processes, and ground AI Search. See [Use FileSets to Gather Information from Unstructured Data](/s/article/000005849).

## FAQ

<AccordionGroup>

<Accordion title="Which should I use—Image-to-Text in a Workflow, or FileSets?">
  Use Image-to-Text in a Workflow when you need to read text from an image or a small number of documents as part of an automated process. Use FileSets when you are building a repeatable pipeline that turns many documents into structured data for analysis or AI Search.
</Accordion>

<Accordion title="Can Image-to-Text read a multi-page PDF?">
  Image-to-Text processes image content, and large documents can be split using the chunking configuration in the Workflow function. See the confirmed limitations above regarding scanned/image-only PDFs and complex layouts.
</Accordion>
