## Intro

This article explains how to extract text from PDFs and images using Domo AI. The core capability is **Image-to-Text**, which you can invoke from Workflows, Magic ETL, Domo apps, and Jupyter Workspaces, and which pairs with Documents for document-driven pipelines.

---

## Required Grants

To extract data from PDFs and images with Domo AI, the following grants must be enabled for your role:

- **Use AI Services —** Access to features and Apps built using the AI Services Layer.
- **Manage DataFlows —** Create, edit, and delete DataFlows in your instance.
- **Edit Magic ETL v2 DataFlow —** Create and edit Magic ETL DataFlows to which you have access.
- **Manage Workflows —** Perform any action on any Workflow in your Domo instance.
- **Manage Documents —** View, edit, and delete any Document Collections in this instance.

Learn more about [grants](/s/article/360043438973).

## What Image-to-Text Does

Image-to-Text extracts or generates text from an image. It covers OCR (reading text out of an image), caption generation, and visual question answering. Because a PDF page can be processed as an image, this is the capability behind pulling text out of scanned or image-based documents.

Image-to-Text is part of the AI Service Layer and is available in Jupyter Workspaces, Domo apps, Workflows, and Magic ETL (through the Text Generation tile). See [AI Service Layer Settings](/s/article/000005279) for the full list of services and where each can be used.

## Extract Text in a Workflow

For an automated, no-code pipeline, call the AI Service Layer from a Workflow:

1. Confirm the AI Service Layer (standard or advanced) is enabled for your instance and role.
2. In a Workflow, add an AI Service Layer function and select the Image-to-Text service.
3. For large documents, use the function's chunking configuration so the content is processed in segments.

See [Workflows — AI Service Layer Integration](/s/article/000005369) for the exact configuration steps.

## Work with Unstructured Data Using Documents

When you need to work with a body of documents—not just read one image—use Documents. Store files in Document Collections by uploading them or connecting a data source, enable Agent Knowledge to make them searchable with AI Search, and use them from Workflows, the AI Library, and Magic ETL. See [Documents](/s/article/Documents).

To bring a Document Collection into a DataFlow, use the Collection Input tile. See [Magic ETL Tiles: Documents](/s/article/Magic-ETL-Tiles-Documents).

## Extract Text in Magic ETL

Magic ETL is the recommended way to bulk-process PDFs. To extract text as part of a DataFlow, use the **Text Generation** tile. Learn more about the [Text Generation tile](/s/article/000005741#text-generation-tile).

To bulk-process PDFs stored in Amazon S3 or SFTP:

1. Create a Document Collection that connects to your Amazon S3 or SFTP source. See [Documents](/s/article/Documents#connect-to-a-data-source).
2. In Magic ETL, add a **Collection Input** tile and select the Document Collection. See [Magic ETL Tiles: Documents](/s/article/Magic-ETL-Tiles-Documents).
3. Connect a **Text Generation** tile to extract text from each file.

## FAQ

<AccordionGroup>

<Accordion title="Which should I use—a Workflow or Magic ETL?">
  Use Image-to-Text in a Workflow when you need to read text from an image or a small number of documents as part of an automated process. Use Magic ETL with a Document Collection to bulk-process many PDFs in a repeatable pipeline. See [Extract Text in Magic ETL](#extract-text-in-magic-etl).
</Accordion>

<Accordion title="Can Image-to-Text read a multi-page PDF?">
  Image-to-Text processes image content, and large documents can be split using the chunking configuration in the Workflow function.
</Accordion>

</AccordionGroup>
