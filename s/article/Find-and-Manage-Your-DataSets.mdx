## Intro

The Data Center gives you a searchable list of every DataSet you have access to, along with controls to filter, sort, and act on them. You can run DataSets on demand, change owners, share access, export data, and delete DataSets you no longer need—individually or in bulk using multi-select. This article explains how to find and manage your DataSets from the Data Center.

---

## Required Grants

To manage DataSets, the following grants must be enabled for your role:

- **Can Create DataSets —** Create new DataSets and manage DataSets you own.
- **Manage All DataSets —** Manage DataSets owned by any user in the instance (typically an Admin-only grant).

Learn more about [grants](/s/article/360043438973).

## Find DataSets

<Frame>
  <img alt="The Data Center DataSets tab, showing a searchable list of DataSets with filter and sort controls." src="/images/kb/0EMVq000001PyYH.jpg" />
</Frame>

1. Select **Data** from the top navigation, then select **Data Center**.
2. Use the **Search** bar to search by DataSet name.
3. Use the filter controls to narrow by:
   - **Owner** — filter to DataSets owned by a specific user.
   - **Type** — filter by connector type (e.g., Salesforce, Snowflake, File Upload).
   - **Status** — filter by last-run result: Success, Failed, Running, or Overdue.
   - **Tags** — filter by tag you or another user applied.
4. Select a column header to sort by name, last run, or owner.

## Common DataSet Actions

From the **Options** menu (<i className="icon-ellipsis sm" aria-hidden="true" />) on any DataSet row, you can take the following actions:

- **Run Now —** Manually trigger the DataSet to update immediately. See [Executing DataSets](/s/article/360042926214).
- **Edit —** Modify the connector settings, schedule, or update method.
- **Change Owner —** Transfer the DataSet to another user. See [Change the Owner of a DataSet](/s/article/360042926074).
- **Share —** Grant view or edit access to users or groups. See [Share a DataSet](/s/article/360043430713).
- **Set Update Frequency —** Define how often Domo expects the DataSet to run. See [Setting the Expected Update Frequency for a DataSet](/s/article/360042926114).
- **Export —** Download the DataSet as a CSV. See [Exporting DataSets](/s/article/360042926134).
- **View Impact —** See which cards, DataFlows, and alerts depend on this DataSet before making changes. See [Viewing the Impact of Changes to DataSets](/s/article/360042926234).
- **Delete —** Permanently remove the DataSet. See [Deleting DataSets](/s/article/360042926194).

## Bulk Actions

To perform an action on multiple DataSets at once:

1. Select the checkbox to the left of each DataSet row.
2. Use the bulk-action bar that appears at the top of the list to change owner, add tags, or delete.

Bulk actions are useful for reassigning DataSets from a departing user or tagging DataSets for a project in one pass.

## FAQ

<AccordionGroup>

<Accordion title="I can't see a DataSet I know exists. Why?">
  By default, you see only DataSets you own or that have been shared with you. Ask the DataSet owner or a Domo Admin to share it with you. Admins with the Manage All DataSets grant can see every DataSet in the instance.
</Accordion>

<Accordion title="How do I prevent a card from breaking when I delete a DataSet?">
  Before deleting, check the DataSet's **Cards** or **Lineage** tab to see every card that depends on it. Reconnect those cards to a replacement DataSet using [Connecting Cards to a Different DataSet](/s/article/360043430653), then delete.
</Accordion>

<Accordion title="Can I export only certain columns of a DataSet?">
  The export option downloads the full DataSet as a CSV. To export a subset, create a DataSet View with only the columns you want, then export the view. See [Manage DataSet Views](/s/article/360046074774).
</Accordion>

</AccordionGroup>
