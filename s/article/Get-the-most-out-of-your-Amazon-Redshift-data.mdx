## Intro

This article explains how to use Domo's Amazon Redshift Connector to retrieve data from your Amazon Redshift database and create custom reports by using SQL queries. Amazon Redshift is an AWS-hosted data warehouse designed for analytics workloads on large-scale datasets.

## Prerequisites

To connect to the Amazon Redshift account and create a DataSet, you need the the following:

*  Amazon Resource Name (ARN)
*  Role Session Name
*  External ID
*  Unique identifier of your Amazon Redshift cluster
*  Amazon Redshift database name
*  Database User Name
*  You also need to select the Amazon Redshift region

This article covers the fields and menus specific to the Amazon Redshift Connector user interface. For general information about adding DataSets, setting update schedules, and editing DataSet information, see [Add a DataSet Using a Data Connector](/s/article/360042926274).

## Configure the Connection

This section describes the options in the **Credentials** and **Details** panes on the Amazon Redshift Connector page. The components of the **Scheduling** and **Name & Describe Your DataSet** panes are universal across most connector types and are discussed in [Add a DataSet Using a Data Connector](/s/article/360042926274).

### Enter Your Credentials

The **Credentials** pane contains the field for entering credentials to connect to your Amazon Redshift. The following table describes what is needed for each field.

| Field                   | Description                                                                                                                                              |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Role ARN                | Enter the Amazon Resource Name (ARN) of the role that you want to assume.                                                                                |
| Role Session Name       | Enter the identifier for the role session.                                                                                                               |
| External ID             | Select Generate Code to generate a value.                                                                                                                |
| Region                  | Select the Amazon Redshift region.                                                                                                                       |
| Amazon Redshift Cluster | Enter the unique identifier for your Amazon Redshift cluster. For example, my-redshift-cluster. Don't enter the cluster endpoint or port.                |
| Database Name           | Enter the name of the Amazon Redshift database that you want to connect to. For example, dev.                                                            |
| Database User Name      | Enter the database user name to use for authentication. The user must exist in Amazon Redshift and have the required permissions to access the database. |

After you have entered valid credentials, you can use the same account any time you set up a new Amazon Redshift connection. You can manage connector accounts in the **Accounts** tab in the Data Center. For more information about this tab, see [Manage User Accounts for Connectors](/s/article/360042926054).
