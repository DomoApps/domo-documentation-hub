This article will walk you through setting up a connection to GitHub.

For a personal GitHub connection, follow the OAuth prompts.

For Enterprise:

## How to Generate a Token

Follow these steps on the [GitHub Desktop](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens) website to create a new token:

1. Open **Settings**: Click your profile picture in the top-right corner of any GitHub page and select **Settings**.
2. **Developer Settings**: Scroll to the bottom of the left sidebar and click **Developer settings**.
3. **Choose Token Type**: Expand the **Personal access tokens** menu and click either **Fine-grained tokens** or **Tokens (classic)**.
4. **Initiate Generation**: Click **Generate new token**.
5. **Configure Details**:
   - Enter a descriptive **Token name** or note.
   - Set an **Expiration** period (setting an expiration is strongly recommended for security).
   - Choose the **Resource owner** and specific **Repository access** (for fine-grained tokens).
6. **Set Permissions**: Under **Permissions** or **Scopes**, check the boxes matching your requirements. (Note: For command-line repository management like pushing and pulling, you must select the `repo` scope or read/write repository permissions.)
7. **Create and Save**: Scroll to the bottom and click **Generate token**.

<Warning>**Important:** Copy your token immediately and save it in a password manager. GitHub will never display the token again once you navigate away from the page.</Warning>
