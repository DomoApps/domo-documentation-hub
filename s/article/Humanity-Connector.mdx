## Intro

This article explains how to use Domo's Humanity Connector to retrieve leave and vacation data from your Humanity workforce management account. The connector enables you to import employee time-off records into Domo for reporting, workforce planning, and operational analysis.

---

## Prerequisites

To connect to your Humanity account and create a DataSet, you need the following:
- Client ID
- Client Secret
- Username
- Password

This article covers the fields and menus specific to the Humanity Connector user interface. For general information about adding DataSets, setting update schedules, and editing DataSet information, see [Add a DataSet Using a Data Connector](/s/article/360042926274).

## Configure the Connection

This section describes the options in the **Credentials** and **Details** panes on the Humanity Connector page. The components of the **Scheduling** and **Name & Describe Your DataSet** panes are universal across most connector types and are discussed in [Add a DataSet Using a Data Connector](/s/article/360042926274).

### Enter Your Credentials

The **Credentials** pane contains the field for entering credentials to connect to the Humanity account. The following table describes what is needed for each field.

| Field   | Description                                               |
| ------- | --------------------------------------------------------- |
| Client ID | Enter the App ID of your API v2 application. |
| Client Secret | Enter the App Secret of your API v2 application. |
| Username | Enter your Humanity account username. |
| Password | Enter your Humanity account password. |

After you have entered valid credentials, you can use the same account any time you set up a new Domo-Humanity connection. You can manage connector accounts in the **Accounts** tab in the Data Center. For more information about this tab, see [Manage User Accounts for Connectors](/s/article/360042926054).

### Configure the Details Pane

This pane contains a primary **Reports** menu, along with various other menus for configuring your report.

| Menu                                                | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Report                                              | The Leaves report is selected by default.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Start Date                                          | Specify the start date to filter leave records.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Start Date                                          | Specify the earliest leave start date to include in the report.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Days from today                                     | Specify the number of days before or after today to use as the start date.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| End Date                                            | Select the end date to filter leave records.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| End Date                                            | Select the latest leave end date to include in the results.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Days from today                                     | Specify the number of days before or after today to use when calculating the end date.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
