## Intro

This article explains how to use Domo's Knack Connector to import data from your Knack applications into Domo. The connector retrieves the full contents of a Knack app—including objects (tables), field definitions, and records—and loads them into a single dataset. The data is structured in a long (entity-attribute-value) format that integrates with Magic ETL, enabling you to combine Knack data with other business data, build visualizations, and schedule automatic data refreshes.

---

## Prerequisites

To connect to a Knack account and create a DataSet, you must have the following:

- Your REST API Key associated with your Knack account.
- The Application ID associated with your knack account.

### Locate the Application ID

Follow these steps to find your Application ID in Knack:

1. Sign in to your account and open your application in the [Knack Builder](https://docs.knack.com/v3/docs/search-the-builder).
2. Click the **Settings** (gear) icon in the left navigation pane.
3. Select **API & Code**.
4. Locate your **Application ID** on the API settings page.

For more information about the Knack API, see the [Knack API Documentation](https://docs.knack.com/reference/welcome-to-the-knack-api).

This article covers the fields and menus specific to the Knack Connector user interface. For general information about adding DataSets, setting update schedules, and editing DataSet information, see [Add a DataSet Using a Data Connector](/s/article/360042926274).

## Configure the Connection

This section describes the options in the **Credentials** and **Details** panes on the Knack Connector page. The components of the **Scheduling** and **Name & Describe Your DataSet** panes are universal across most connector types and are discussed in [Add a DataSet Using a Data Connector](/s/article/360042926274).

### Enter Your Credentials

The **Credentials** pane contains fields for entering credentials to connect to your Knack account. The following table describes what is needed for each field.

| Field               | Description                                                                                          |
| ------------------- | ---------------------------------------------------------------------------------------------------- |
| API Key             | Enter the REST API Key associated with your Knack account.                                                |
| Application ID      | Enter the Application ID associated with your Knack account.                                         |                                                                   |

After you have entered valid credentials, you can use the same account any time you set up a new Domo-Knack connection. You can manage connector accounts in the **Accounts** tab in the Data Center. For more information about this tab, see [Manage User Accounts for Connectors](/s/article/360042926054).

### Configure the Details Pane

In the **Details** pane, you have the option to run the App Data report.

| Menu                                                | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| --------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Report                                              | Select the <b>App Data</b> report from the drop-down list.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
