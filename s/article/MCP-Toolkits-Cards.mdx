## Intro

The Cards Toolkit gives AI full card management: create, preview, clone, update, rename, verify, place, and delete Domo cards.

---

<Note>**Note:** A Toolkit's tools only return data and perform actions that the connected Domo account already has permission to access.</Note>

## Tools Included

- Create Card
- Update Card
- Delete Card
- Clone Card
- Preview Card
- Verify Card
- Get Card
- Change Card Title
- Change Card Description
- Add Card to Pages
- Create Page
- Lookup Dataset Schema
