## Intro

The Code Engine Toolkit enables AI to create, manage, version, and execute Code Engine packages. These tools allow AI to create packages, retrieve package metadata and definitions, manage package versions, update unreleased code, release production-ready versions, and execute package functions with user-provided inputs. This enables AI to generate and maintain reusable business logic, extend workflow capabilities with custom code, and securely execute code as part of end-to-end business automation. This Toolkit enters beta on September 23, 2026.

---

<Note>**Note:** A Toolkit's tools only return data and perform actions that the connected Domo account already has permission to access.</Note>

## Tools Included

- Create Code Engine Package
- Edit Code Engine Package
- Get Code Engine Package
- List Code Engine Packages
- Promote Code Engine Version
- Run Code Engine Function
