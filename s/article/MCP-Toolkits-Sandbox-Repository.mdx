## Intro

The Sandbox Repository Toolkit, a Domo MCP Toolkit, lets AI create, list, retrieve, delete, commit versions to, share, and promote Sandbox repositories. 

---

<Note>**Note:** A Toolkit's tools only return data and perform actions that the connected Domo account already has permission to access.</Note>

## Tools Included

- Create Repository
- Get Repository
- List Repositories
- Delete Repository
- Share Repository
- Promote Repository
- Map Repository Content
- List Allowed Instances
- Search
- `domo_repository_access_list`
