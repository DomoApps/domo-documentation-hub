## Intro

The Task Center Queue Toolkit enables AI to create and manage human-in-the-loop work queues. These tools allow AI to create queues, retrieve queue configurations and permissions, manage tasks, search and count queue activity, access task history, and monitor watchlists. This enables generated workflows to incorporate task assignments, approvals, reviews, and other user-driven process steps. This Toolkit enters beta on September 23, 2026.

---

<Note>**Note:** A Toolkit's tools only return data and perform actions that the connected Domo account already has permission to access.</Note>

## Tools Included

- Create Queue
- List Queues
- Get Queue
- Get Queue Permissions
- List Tasks
- Get Task
- Search Tasks
- Count Queue Tasks
- Get Task History
- Get Watchlist
