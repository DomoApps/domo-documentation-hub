## Intro

The User Administration Toolkit lets AI create users, update roles, manage group membership, and list roles and authorities.

---

<Note>**Note:** A Toolkit's tools only return data and perform actions that the connected Domo account already has permission to access.</Note>

<Warning>**Important:** This Toolkit can create users and change their roles. Only assign it to Agents and Toolkits that trusted administrators manage.</Warning>

## Tools Included

- Create User
- Update User Role
- Add User to Group
- Get Group Members
- List Roles
- List Authorities
