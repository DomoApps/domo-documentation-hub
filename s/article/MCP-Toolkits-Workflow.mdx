## Intro

The Workflow Toolkit provides complete workflow lifecycle management capabilities. These tools enable AI to create workflows and versions, retrieve and update workflow definitions, validate workflow configurations, perform test executions, deploy workflows, and monitor execution results. The toolkit also provides access to trigger details and forms, execution metrics, and execution events, giving AI the context and operational insights needed to help you manage your workflows effectively. This Toolkit enters beta on September 23, 2026.

---

<Note>**Note:** A Toolkit's tools only return data and perform actions that the connected Domo account already has permission to access.</Note>

<Note>**Note:** This Toolkit also includes the tools from the [Code Engine](/s/article/MCP-Toolkits-Code-Engine) and [Task Center Queue](/s/article/MCP-Toolkits-Task-Center-Queue) Toolkits, so workflows built with it can create and run Code Engine functions and manage human-in-the-loop task queues directly.</Note>
