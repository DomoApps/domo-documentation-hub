## Intro

The Workspaces Toolkit lets AI create, share, and manage Domo workspaces, their members, folders, and content.

---

<Note>**Note:** A Toolkit's tools only return data and perform actions that the connected Domo account already has permission to access.</Note>

## Tools Included

- Create Workspace
- Get Workspaces
- List Workspaces
- Update Workspace
- Delete Workspace
- Add Workspace Members
- Update Workspace Member
- Remove Workspace Member
- List Workspace Members
- Create Workspace Folder
- Get Workspace Folder
- Update Workspace Folder
- Delete Workspace Folder
- List Workspace Folders
- Add Workspace Content
- Move Workspace Content
- Remove Workspace Content
- List Workspace Contents
- Validate Workspace Content Add
