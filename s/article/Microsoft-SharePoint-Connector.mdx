## Intro

This article explains how to set up a connection to Microsoft SharePoint and create a Document Collection in Domo.

---

## Prerequisites

To connect to your Microsoft SharePoint Online Rest Enterprise OAuth account and create a Document Collection, you must select the OAuth Configuration. See [Microsoft SharePoint Online Rest Enterprise OAuth Connector](/s/article/Microsoft-SharePoint-Online-Rest-Enterprise-OAuth-Connector) for details.

## Create a SharePoint Connection

1. Navigate to **Domo Documents**.

<Frame><img alt="sharepoint_1" src="/images/kb/GoogleDrive1.png" /></Frame>

2. Select **Create Collection**, then select **Connectors**.

<Frame><img alt="sharepoint_12" src="/images/kb/GoogleDrive2.png" /></Frame>

3. Choose **Microsoft SharePoint**.

<Frame><img alt="sharepoint_12" src="/images/kb/sharepoint_12.png" /></Frame>

4. Choose a Microsoft SharePoint account or create a new one.

<Frame><img alt="sharepoint_2" src="/images/kb/sharepoint_2.png" /></Frame>

5. Select the **Microsoft SharePoint Online Rest Enterprise OAuth** account type.

<Frame><img alt="sharepoint_3" src="/images/kb/sharepoint_3.png" /></Frame>

6. Choose a Microsoft SharePoint OAuth connection and select **Connect**.

<Note>**Note:** OAuth Configurations have service credentials stored by your administrator that automatically log you in, so only your personal OAuth login is required. Your administrator can create and edit configurations in the Data Center under the **Accounts** tab.</Note>

<Frame><img alt="sharepoint_4" src="/images/kb/sharepoint_4.png" /></Frame>

7. Follow the OAuth sign-in flow.

<Frame><img alt="sharepoint_5" src="/images/kb/sharepoint_5.png" /></Frame>

<Frame><img alt="sharepoint_6" src="/images/kb/sharepoint_6.png" /></Frame>

8. Specify the **Site URL** and **Library Name**.

<Frame><img alt="sharepoint_7" src="/images/kb/sharepoint_7.png" /></Frame>

9. Configure the update schedule.

<Frame><img alt="sharepoint_8" src="/images/kb/sharepoint_8.png" /></Frame>

10. Specify the **Name** and **Description** of this Document Collection.

<Frame><img alt="sharepoint_10" src="/images/kb/sharepoint_10.png" /></Frame>

Give the Collection some time to load the files. Select the **Files** tab to view a listing of the referenced files. Select the **Overview** tab to enable **Agent Knowledge**.

<Frame><img alt="sharepoint_11" src="/images/kb/sharepoint_11.png" /></Frame>
