## Intro

This article explains how to understand the left navigation migration banner and migrate your users to the new left navigation before Domo disables the top navigation on September 23, 2026.

---


## Required Grants

You must have the Admin role to see the migration banner and migrate users to the new left navigation. The required grant is **Manage all company settings** which is included in the default Admin role.


## Understand the Migration Banner

If you are a Domo Admin, a banner appears in your Domo instance notifying you that Domo will disable the top navigation on September 23, 2026. You should migrate your users before that date for a smoother transition.

<Frame>![Navigation Banner](/images/kb/navigation-migration1.png)</Frame>

## Migrate Users to the New Left Navigation

Follow these steps to migrate your users to the new left navigation:

1. Click on the notification banner to access the **New Navigation** Feature under the **Company Settings** menu.

   <Frame>![Navigation Banner](/images/kb/navigation-migration2.png)</Frame>

   <Note>**Note:** If you dismiss the banner, you can also select **More** > **Admin** in the top navigation, then select **New Navigation** under **Company Settings** to access the enablement tool.</Note>

   <Frame>![Navigation Banner](/images/kb/navigation-migration3.png)</Frame>
   <Frame>![Navigation Banner](/images/kb/navigation-migration4.png)</Frame>

2. The following options are available to help you migrate users to the new navigation:

   - **Not enabled in your instance —** This option disables the new navigation for all users in your instance. It is the default behavior if the new navigation has not been enabled yet.
   - **Enabled for everyone —** Enables the navigation for all users in your instance.
   - **Enabled for admins —** Enables the navigation for all admin users in your instance. This option grants all admins who can view the Company Settings page access to the navigation enablement tool.
   - **Enabled for a specific group —** Enables the navigation for a specific group.
   
   <Frame>![Navigation Banner](/images/kb/navigation-migration5.png)</Frame>

3. To save your changes, select **Save** in the top-right corner. A confirmation message appears. Select **Enable** to confirm. The change takes effect immediately.

   <Frame>![Navigation Banner](/images/kb/navigation-migration6.png)</Frame>
