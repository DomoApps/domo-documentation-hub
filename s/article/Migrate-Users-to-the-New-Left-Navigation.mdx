## Intro

This article explains how to understand the left navigation migration banner and migrate your users to the new left navigation before the top navigation is disabled on September 23, 2026.

---


## Required Grants

You must have the Admin role to see the migration banner and migrate users to the new left navigation.


## Understand the Migration Banner

If you are a Domo Admin, a banner displays in your Domo instance notifying you that Domo plans to disable the top navigation on September 23, 2026. All users in your instance must be migrated to the new left navigation before that date. Use the steps below to complete the migration.

<Frame>![Navigation Banner](/images/kb/navigation-migration1.png)</Frame>

## Migrate Users to the New Left Navigation

Follow these steps to migrate your users to the new left navigation:

1. Select **Start Here** in the notification banner to access the **New Navigation** Feature under the **Company Settings** menu.

   <Frame>![Navigation Banner](/images/kb/navigation-migration2.png)</Frame>

   <Note>**Note:** If you close the banner and it disappears, you can also go to the **More** menu in the top navigation, select **Admin**, and under **Company Settings** select **New Navigation** to access the enablement tool.</Note>

   <Frame>![Navigation Banner](/images/kb/navigation-migration3.png)</Frame>
   <Frame>![Navigation Banner](/images/kb/navigation-migration4.png)</Frame>

2. The following options are available to help you migrate users to the new navigation:

   - **Not enabled in your instance —** This option disables the new navigation for all users in your instance. It is the default behavior if the new navigation is not enabled yet in your instance.
   - **Enabled for everyone —** Enables the navigation to all users in your instance.
   - **Enabled for admins —** Enables the navigation to all admin users in your instance. This option grants access to all admins who can view the Company Settings page to the navigation enablement tool.
   - **Enabled for a specific group —** Enables the navigation to a specific group.
   - **Migration Schedule —** Choose a date and time to migrate all users to the new navigation before Domo's permanent update.

   <Frame>![Navigation Banner](/images/kb/navigation-migration5.png)</Frame>

3. To save your changes, select **Save** in the top-right corner. A confirmation message appears. Select **Enable** to save your changes. The change takes effect immediately.

   <Frame>![Navigation Banner](/images/kb/navigation-migration6.png)</Frame>
