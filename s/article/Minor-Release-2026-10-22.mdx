## October 22, 2026 Release

### AI Labs

- Adds support for new identity permission types in PDP policy targeting for Files, enabling more granular control over user and group access in AI Labs unstructured data features.
- Adds support for OAuth and the default MCP resource identifier in AI Labs.
- Administrators have more control over data access permissions for unstructured data in AI Labs through Personalized Data Permissions (PDP) for FileSet APIs.
- AI Agent tiles in Workflows failed to display output previews when a DataSet was added as a knowledge source.
- Deleting an OAuth 2.1 client ends that client's active sessions and access.
- DomoGPT Medium v2.2 and v3 models were not functioning correctly in Magic ETL AI Labs tiles.
- Resolves connectivity issues with AI services in the AI Library.
- Skills in the AI Library were temporarily unavailable and have been restored.
- The Sandbox Repository Toolkit card in the AI Library displayed blank gray space instead of its icon.

### AI Services

- A new AI provider option is available in AI Services.

### Alerts

- Scheduled DataSet alerts on PDP-enabled DataSets did not notify subscribers when the alert threshold was crossed.

### App Platform

- AppDB DataSets could show row-count discrepancies when the underlying data table was missing; affected DataSets now rebuild it automatically.

### App Studio

- Administrators can control the visibility of scheduling options in Report Builder.
- Boxplot charts were incorrectly displayed as bar charts after applying a filter.
- Custom apps re-applying a filter could clear the page filter they were trying to set, causing cards to display unfiltered data; you can again remove a filter applied by another card on the same page with a single click.
- In App Studio, users could not reorder navigation tabs when AI chat was disabled.
- Some charts displayed blank after loading an App Studio app.

### Authentication

- Organizations using SCIM can now automatically deprovision users through patch requests.

### Buzz

- Buttons in the remove user popup became unresponsive in private Buzz topics and group chats.

### Cards

- Card filters and controls failed to display values when the card used both an aggregate filter and a variable-driven grouping.
- Date selector preset buttons became non-selectable and the layout compressed when expanded in card filters.
- Editing date range filters in Analyzer could shift dates by one day for users in certain timezones, affecting the column filter popup and the Date range panel and compounding with each edit.
- Editor users could not upload a new version of a Doc Card they did not own; users with edit permissions can now upload new versions without needing delete permissions on the file.
- Table cards displayed raw decimal values instead of applying the configured number formatting (such as percentages, currency, or abbreviated numbers) for high-precision decimal columns.

### Connectors

- Connecting very large PostgreSQL tables (100M+ rows) in Cloud Amplifier failed with an "Unable to find a Schema" error; tables now connect immediately, with row counts computed in the background.
- The Snowflake Writeback connector failed with a SQL compilation error when DataSets contained column names that conflicted with reserved column names.

### Consumption

- Adds a new Partner-Reseller portfolio type to Consumption accounts, expanding the available account type options for managing partner and reseller relationships.

### Dashboards

- Notebook and table cards exported to PDF or PowerPoint could be cut off by extra margins.

### Data Center

- Cloud Amplifier Redshift DataSet Views failed with a "column does not exist" error when identifiers contained lowercase or full-width characters.
- The account sharing dialog would fail to display when a previously shared group no longer existed; you can now view all shared users and groups and remove leftover shares to deleted groups.

### Data Processing

- Magic ETL DataFlows could become stuck in PREPARING or EXPORTING status for up to 24 hours instead of completing normally.

### Data Query

- Customers could not create multiple Databricks M2M OAuth accounts; accounts now show a distinguishing name based on workspace host and service principal client ID, allowing separate accounts for different environments.

### Embed

- Admins could not add localhost-based origins to the Authorized Private Embed Domains list because the Add button stayed disabled for URLs without a dot in the domain.

### Mobile

- Sets the minimum supported app version to 4.38 for iOS and 4.38.3 for Android for compatibility with updated certificates.

### Performance

- Certain DataSet detail page events could cause instance slowdowns when pushed to many users at once.

### Publish

- Creating new cards in Publish resulted in an error when app components lacked a data subscription.
- Exporting a view spanning multiple DataSets via Domo Publish would fail.
- Notebook cards in Domo Everywhere publications would incorrectly remove DataSets when using summary numbers and dynamic text with multiple DataSets.

### Scheduled Reports

- Double brackets in a Scheduled Report subject line prevented the report from being saved.

### Tasks & Projects

- Users attempting to access private projects they don't have permission to view now receive a proper access denied message instead of an error.

### Workflows

- In Workflows, HTML characters in Send Email actions were not escaped properly, causing text inputs to retain escaped slashes that could break email formatting.
