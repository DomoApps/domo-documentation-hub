## October 22, 2026 Release

### AI Labs

**Updates:**

- Adds support for new identity permission types in PDP policy targeting for Files, enabling more granular control over user and group access in AI Labs Unstructured Data features.
- Adds support for OAuth and the default MCP resource identifier in AI Labs.
- Enables AI Labs features to function through the Domo Apps proxy, resolving connectivity issues with AI services in the AI Library.
- Ensures that deleting an OAuth 2.1 client immediately revokes all active sessions and access tokens associated with that client.
- Introduces a feature switch for PDP (Personalized Data Permissions) in FileSet APIs, providing administrators with more control over data access permissions for unstructured data in AI Labs.

**Issues Resolved:**

- AI Agent tiles in Workflows failed to display output previews when a DataSet was added as a knowledge source.
- Apps generated by App Catalyst were created without proper data-source mappings, causing Sandbox promotion to fail with a 404 error when attempting to resolve those mappings on the destination instance.
- DomoGPT Medium v2.2 and v3 models were not functioning correctly in Magic ETL AI Labs tiles.
- Skills in the AI Library were failing due to a feature switch configuration problem.
- The Sandbox Repository Toolkit card in the AI Library displayed blank grey space instead of its icon.

### AI Services

**Updates:**

- Adds support for a new AI provider option in AI Services, available through a feature switch.

### Alerts

**Issues Resolved:**

- Scheduled dataset alerts on PDP-enabled datasets did not notify subscribers when the alert threshold was crossed.

### App Platform

**Issues Resolved:**

- AppDB datasets could show row count discrepancies when the underlying physical table went missing. The fix rebuilds the table automatically when enabled for affected datasets.

### App Studio

**Updates:**

- Adds a feature switch to control the visibility of scheduling options in Report Builder.

**Issues Resolved:**

- Boxplot charts were incorrectly displayed as bar charts after applying a filter.
- Custom apps re-applying a filter could clear the page filter they were trying to set, causing cards to display unfiltered data. It also restores the ability to remove a filter applied by another card on the same page with a single click.
- In App Studio where users could not reorder tabs in the navigation when AI chat was disabled.
- Some charts displayed blank after loading an App Studio app.

### Authentication

**Updates:**

- Implements SCIM patch deprovisioning, allowing organizations using SCIM to automatically deprovision users through patch requests.

### Buzz

**Issues Resolved:**

- Buttons in the remove user popup became unresponsive in private Buzz topics and group chats.

### Cards

**Issues Resolved:**

- Card filters and controls failed to display values when the card used both an aggregate filter and a variable-driven grouping.
- Date selector preset buttons became non-selectable and the layout compressed when expanded in card filters.
- Editing date range filters in Analyzer would incorrectly shift dates by one day for users in certain timezones. The issue affected both the column filter popup and the Date range panel, with the shift compounding on each edit. A related fix addresses similar date shifting on card details and page filters.
- Editor users could not upload a new version of a Doc Card they did not own. Users with edit permissions can now upload new versions without requiring delete permissions on the file.
- Table cards displayed raw decimal values instead of applying the configured number formatting (such as percentages, currency, or abbreviated numbers) for high-precision decimal columns.

### Connectors

**Issues Resolved:**

- Connecting very large PostgreSQL tables (100M+ rows) in Cloud Amplifier failed with a "Unable to find a Schema" error. Tables now connect immediately, with row counts computed in the background.
- The Snowflake Writeback connector failed with a SQL compilation error when datasets contained columns with names that conflicted with reserved internal column names.

### Consumption

**Updates:**

- Adds a new Partner-Reseller portfolio type to Consumption accounts, expanding the available account type options for managing partner and reseller relationships.

### Dashboards

**Issues Resolved:**

- Notebook and table cards exported to PDF or PowerPoint were being cut off due to extra margin that caused content truncation.

### Data Center

**Issues Resolved:**

- Cloud Amplifier Redshift DataSet Views failed with a "column does not exist" error when identifiers contained lowercase or full-width characters.
- The account sharing dialog would fail to display when a previously shared group no longer existed. Users can now view all shared users and groups and remove leftover shares to deleted groups.

### Data Processing

**Issues Resolved:**

- Magic ETL DataFlows could become stuck in PREPARING or EXPORTING status for up to 24 hours instead of completing normally.
- This update improves diagnostic logging for partitioned Magic ETL DataSets to help detect when data deletion operations complete without removing rows, preventing undetected table growth.

### Data Query

**Issues Resolved:**

- An internal data cleanup issue in the CDC dataset deletion process, ensuring proper removal of associated allocation records. No change to customer-visible behavior.
- Customers could not create multiple Databricks M2M OAuth accounts. Accounts now display a distinguishing name based on workspace host and service principal client ID, enabling separate accounts for different environments.

### Embed

**Issues Resolved:**

- Admins could not add localhost-based origins to the Authorized Private Embed Domains list for embedded content. The Add button previously remained disabled for localhost URLs because the field required a domain containing a dot.

### Mobile

**Updates:**

- Sets the minimum supported version to 4.38 for iOS and 4.38.3 for Android to ensure compatibility with new security certificates.

### Publish

**Issues Resolved:**

- Creating new cards in Publish resulted in an error when app components lacked a data subscription.
- Exporting a view spanning multiple DataSets via Domo Publish would fail.
- Notebook cards in Domo Everywhere publications would incorrectly remove datasets when using summary numbers and dynamic text with multiple datasets.

### Scheduled Reports

**Issues Resolved:**

- Double brackets in a Scheduled Report subject line prevented the report from being saved.

### Tasks & Projects

**Issues Resolved:**

- Users attempting to access private projects they don't have permission to view now receive a proper access denied message instead of an error.

### Vertica Cust. Performance

**Issues Resolved:**

- A rare issue where certain dataset detail page events could cause instance slowdowns when pushed to many users simultaneously.

### Workflows

**Issues Resolved:**

- In Workflows where HTML characters in Send Email actions were not being escaped properly, causing text inputs to retain escaped slashes that could break email formatting.
