## October 29, 2026 Release

### AI Labs

- Adds support for OAuth authentication and the new default MCP resource identifier in AI Labs.
- Adds support for Personalized Data Permissions (PDP) policies in AI Labs file handling, allowing administrators to control access to unstructured data based on user and group permissions.
- AI Agent tasks in Workflows failed with a deserialization error when a DataSet was specified as a knowledge source.
- AI agents embedded in pages or apps did not load their configured data sources correctly.
- AI Chat was unavailable in certain Domo instances due to regional configuration settings.
- AI Library cards in Domo Everywhere embeds and publications displayed blank gray space instead of their icons.
- AI Skills could fail to run.
- Apps created by App Catalyst could not be promoted from Sandbox to production, failing with an error about missing data sources.
- Custom applications can now access AI Services, improving integration.
- Custom toolkits in AI Labs could not connect using OAuth authentication.
- DomoGPT Medium v2.2 and v3 models were not functioning in Magic ETL.
- Embedded AI agents could not read files from Document Collections.
- FileSets would skip processing a file if its updated content matched another existing file, even when the file itself had changed.
- Form respondents can upload file attachments to Document Collections when submitting App Studio forms.
- Improves the readability of audit log entries for AI Chat agent executions, making it easier to track AI activity in your instance.
- Magic ETL DataFlows using the AI Text Generation tile could fail intermittently with an "unknown error occurred" message.
- Personalized Data Permissions (PDP) rules for FileSets were rejected if the rule value ended with a slash.
- Sorts the model dropdown list in AI Playground alphabetically for easier navigation.
- Steps were no longer visible in AI Chat and Agent responses.
- The "Live help" button now opens AI Chat.
- The Report Builder Toolkit card in the AI Library was missing an icon.
- Two experimental unstructured data tiles in Magic ETL are available only when AI Labs experimental features are enabled.

### AI Readiness

- Tool display names and descriptions are now correctly included when retrieving Domo-provided and skill-derived toolkits through the AI Services API.

### AI Services

- Adds production deployment capabilities for Domo Models in AI Services.
- Adds support for additional AI model types in AI Services, expanding the range of models available for use in Domo's AI features.
- Adds support for Amazon Bedrock's OpenAI models as a provider option in AI Services.
- Adds support for Google Gemini Embedding 2 in AI Services.
- AI Agent tiles in Workflows could not access certain file types from Documents and Document Collections when used as knowledge sources.
- An error occurred when using PDF files with the Image Embedding feature in AI Services.
- Improves the Activity Log for AI Agents so that the Type and Event columns now display the specific tool name instead of the generic label "Ai chat tool".
- Sets new default models for AI Services and AI Agents in production environments.
- The CardGetTool in AI Services did not return filters applied to Cards in Analyzer.
- The DomoStats AI Chat Sessions report could fail with a "Temporary Internal Connector Error" message.

### Advanced Pipeline

- The CLI delete-rows command would fail on upsert DataSets if the key file contained invalid data, such as a header row with a UTF-8 byte-order mark, which could block further deletes until the problematic data version was removed.

### Alerts

- Alert value filtering did not properly handle special characters in the input field.
- Alerts failed to trigger workflows when a numeric column was mapped to a workflow parameter.
- Alerts on DataSets with Personalized Data Permissions enabled would not send notifications to subscribers when the alert threshold was crossed.
- Users with the "Use Alerts" grant could not see or receive alerts shared with them if they did not have access to the underlying DataSet.

### App Components

- App Studio forms with person fields failed to load when embedded; forms now display correctly in both private and public embeds.

### App Platform

- Access AppDB Admin from the Asset Library in the redesigned interface.
- App Studio AppDB sync wrote JSON arrays in an incorrect format, causing them to be unparseable when synced to DataSets.
- AppDB collections could show a different row count than their synced DataSets, with some rows failing to write to the DataSet.
- Bricks from the Appstore failed to install in App Studio, displaying an "Install Failed" error message.
- Creating a card from the Asset Library skipped the wiring screen for designs that require workflow mappings, Code Engine mappings, or code-editor brick configuration, producing incomplete cards; the wiring screen now appears when setup is needed.
- Enabling low-latency sync for AppDB did not create the expected DataSet.
- Low-latency DataSets created by non-owners were not visible to the DataSet owner, making them accessible only to Admin users.
- Low-latency sync can no longer be enabled on App Studio collections that lack a declared schema, matching the existing behavior for batch sync.
- Queries to DataSets in Pro-Code Apps could fail with an error.
- Rebuilds Change Data Capture (CDC) DataSets to use updated default data-parsing settings.

### App Studio

- App Studio tabs could not be reordered when AI chat was disabled.
- Box plot charts in App Studio displayed as bar charts after applying a filter, showing only the maximum and minimum values instead of the full box plot visualization.
- Cards in App Studio dashboards appeared compressed with unexpected scroll bars in desktop view.
- Editable tables in App Studio could fail to accept user input when the DataSet schema's column name casing was changed.
- Grid and List components in App Studio displayed "Power from data to configure search/sort" even when a DataSet was already connected, preventing configuration of search and sort columns.
- In App Studio, a custom app reapplying a filter could inadvertently clear the page filter it was setting, causing cards to display unfiltered data; you can again remove a filter applied by another card on the same page with a single click.
- In App Studio, charts could display data from a variable value set on a previously visited page even when "Persist Variable controls" was disabled, so chart data did not update properly after navigation while smart text showed the correct card-level value.
- In App Studio, filter cards did not stay synchronized across pages when "Persist interaction filters" was enabled: changing a filter on one page updated the data but not the filter card display on other pages, and removing a filter sometimes required two clicks (desktop web only).
- Multiple Workflow Start actions in an App Studio app would all execute the same workflow instead of their individually configured workflows.
- Non-admin users received an access-denied error when attempting to move or copy cards to App Studio pages that appeared as available destinations in the dialog.
- Some charts in App Studio would briefly appear and then go blank after the app loaded.
- Table cards exported from App Studio applications in scheduled reports lost their theme formatting, including alternating row colors and other styling.
- Text boxes in App Studio displayed unnecessary scroll bars regardless of content size or box dimensions.
- Users with the "Edit Data in Editable Table Cells" permission were unable to edit cells in App Studio editable tables that use linked DataSets unless they also had the "Edit Cards" permission.

### Authentication

- Desktop applications could not complete authentication because custom URI schemes (such as cursor://) were not supported when registering OAuth redirect URIs.
- Users could not log in via SAML if their profile contained text fields exceeding 255 characters.

### Buzz

- Buttons in the remove user dialog were unresponsive in private Buzz topics and group chats.
- On macOS, pressing Enter to confirm Japanese text input in Buzz would unexpectedly send the message instead of completing the text entry.

### Cards

- Beast Mode calculations in Data Model cards failed validation with "A column in this calculation did not exist" when a variable was referenced after a column; variables now populate and validate correctly.
- Beast Modes referencing Variables could not be duplicated to another DataSet using Beast Mode Manager; the action was incorrectly blocked with a message reporting the Variable as a nested Beast Mode reference.
- Card filters and controls failed to display values on cards built from data models that used aggregate filters combined with variable-driven groupings.
- Cards became stuck in a "Loading" or "Filtering" state and failed to render on initial dashboard load, though they loaded after changing a filter or when opened in Analyzer.
- Cards grouped by month displayed English month labels (such as "2026-Jan") instead of localized labels (such as "2026年1月") for non-English viewers, causing some cards to show "Data Not Available."
- Cards with Relative Date variables could not be saved on Cloud Amplifier Snowflake instances.
- Custom JavaScript cards built from the DDX-HTML-Blank template could become stuck on "Loading..." and prevent the Pro-Code Editor from opening when editing the app.
- Date range filters in Analyzer could shift by one day when edited, compounding on subsequent edits, for users in timezones behind or ahead of UTC (including card details and page filter date inputs).
- Date variables and DATETIME comparisons did not correctly apply the company timezone; dates now calculate in the correct timezone, and filters using date variables apply properly on dashboard load.
- Duplicate variable controls could appear on cards in Analyzer and card details views.
- Editor users could not upload new versions of Document Cards they did not own even when they had edit access; they can now upload new versions, including PDF and image files.
- Exporting a card with a semicolon or non-ASCII characters in its title would result in a file without an extension or with a garbled filename.
- Preset buttons in the expanded date selector on cards were unresponsive and could compress into a vertical line after multiple clicks.
- Shared pages from inactive or deleted users could incorrectly appear in the admin pages list.
- Table cards displayed raw decimal values instead of the configured number format for high-precision decimal columns; affected cards now apply decimal precision, percentage formatting, and thousands-separator settings.
- Table cards with multiple columns and a total row could fail to render with a "Bad Request" error when adding dimensions, particularly when the card configuration reused certain column references.
- Users who owned a document card through group membership could not see the "Upload Version" button, preventing them from updating the card.
- Variable control filters applied in App Studio apps did not carry over when exporting cards as email attachments, causing filtered values to display as zero in the export.

### Chart Type

- Using a dropdown to sort a Mega Table card could cause errors on other cards in the same dashboard.

### Cloud Integrations

- Azure SQL Cloud Amplifier DataSets did not refresh their row count after each sync; the DataSet Overview now reflects the current row count, including when the source table is empty or smaller than before.
- Cloud Amplifier exports to Snowflake could lose table data when using REPLACE or APPEND modes due to incorrect schema mapping in table comments.
- Cloud Amplifier integrations could not be deleted when hidden system DataSets remained associated with them, even though those DataSets were not visible in Data Center.
- Cloud Amplifier writes to Snowflake that ran longer than 30 minutes could fail intermittently with a "Connection is closed" error.
- Customers using custom calendars in Cloud Amplifier could lose access to the feature or see incorrect date boundaries in their queries.
- Databricks live-query cards that sort on a window-function Beast Mode (such as DENSE_RANK or ROW_NUMBER) returned a query error instead of rendering.
- DataSets displayed a false authentication warning even though the account credentials were valid and data was syncing correctly; re-entering valid credentials now clears the warning.

### Connectors

- Connecting very large PostgreSQL tables (100 million or more rows) through Cloud Amplifier failed with a validation error; tables now connect immediately, with row counts computed in the background.
- Creating a TikTok Business connector account could fail if the TikTok account display name contained an emoji.
- SMALLINT columns from Redshift Cloud Amplifier were imported as Text instead of Integer, preventing their use in aggregations like sum and max.
- The Facebook connector's settings page could fail to load properly.
- Uploading multiple files consecutively in the File Upload connector could cause the interface to freeze and fail to advance to the preview screen.

### Consumption

- Adds support for Partner-Reseller account types in Consumption tracking.

### Dashboards

- Notebook cards and table cards exported to PDF or PowerPoint could have content cut off due to extra margins.

### Data Center

- Adds Activity Log entries when columns are reordered on a DataSet's Schema tab, showing who made the change, when, and each column's previous and new position, and lets you reset a DataSet's column order to its original order.
- Cloud Amplifier Redshift DataSet Views failed with a "column does not exist" error when column names contained lowercase letters or full-width characters.
- DataSet Views created from federated DataSets could not be edited, displaying a "Something went wrong while trying to edit this view" error.
- Federated Postgres DataSets converted time zones in the wrong direction when a company's time zone had a negative UTC offset, adding hours instead of subtracting them and affecting displayed datetime values and date-range filter boundaries.
- The account sharing dialog would fail to open if a previously shared group had been deleted, preventing users from managing account permissions.

### Data Export

- Exporting a DataSet to Excel could produce a corrupt file that Excel could not open when text values contained characters not permitted in XML; such values are now handled properly during export.

### Data Manipulation

- Partitioned DataFlows using Snowflake Cloud Amplifier could time out with an "Unspecified error" when replacing existing partitions in the output DataSet.

### Data Processing

- Improves the appearance and labeling of AI and Document tiles in Magic ETL, marking Document tiles as beta and reflecting whether AI features are enabled for your instance.
- Magic ETL DataFlows could become stuck in PREPARING or EXPORTING status for up to 24 hours when many DataFlows were triggered at once, such as when several Snowflake tables updated simultaneously; affected DataFlows now complete or fail with a clear status instead of hanging.
- Magic ETL DataFlows could run twice in response to a single DataSet update, consuming unnecessary credits.
- Magic ETL SQL tiles using window functions could fail with an error.
- The timeframe selector was missing from the "DataFlow has not run within the last" trigger condition in DataFlow settings.

### Data Query

- Beast Mode calculations using FIXED functions within CASE WHEN clauses could fail with an "invalid column" error, even when all columns existed in the DataSet.
- BigQuery federated connections failed with an "Internal Server Error" when running queries or creating new connections.
- Change Data Capture (CDC) did not produce DataSets in some cases.
- Customers could not create multiple Databricks M2M OAuth accounts; each account now shows a unique name based on its workspace host and service principal client ID.
- DataSets failed to appear after enabling low-latency sync in Data Query.
- Declaring nested-path columns with dot notation in AppDB schemas for Pro-Code Apps would create empty columns; dot notation is now supported.
- Empty objects in AppDB low-latency sync documents could prevent DataSet columns from being created.
- In Cloud Amplifier, the table list would not load when browsing Snowflake schemas if the user lacked admin permissions and the schema contained DataSets they could not access.
- Materialized DataSet Views could stop refreshing and incorrectly report successful runs with zero rows instead of displaying an error.
- MySQL DataFlows and Magic ETL could read stale data from low-latency DataSets that was minutes to hours out of date; they now read current data.
- Saving a DataSet View would reset the column order and remove column descriptions, hidden column settings, and tags from the Schema tab.
- Schema changes to low-latency AppDB DataSets were not applied after the initial sync was enabled.
- Snowflake connectors could fail to sync for some customers.

### Embed

- App Component cards in embedded App Studio dashboards failed to load and displayed "This content is no longer available."
- Drilling into a chart in Card Embed v2 did not trigger the expected drill event to the host page.
- Exporting a card to CSV with the inline export button in a privately embedded App Studio app returned only column headers when a server-side programmatic filter (sqlFilter) was applied via the embed token; the filtered data now exports correctly through both the inline shortcut and the expanded card export.
- Localhost-based origins (such as http://localhost:8000) could not be added to the Authorized Private Embed Domains list, blocking local development workflows that had previously worked.
- Slicer and variable selections in App Studio apps did not filter dependent cards when viewed through private or public embeds, though the same interactions worked correctly in the native app view.
- The export button on private embedded dashboards did not display the format picker when clicked, even when export was enabled.
- The filter icon did not appear on expanded cards in private embeds of App Studio apps, even when filtering was enabled in the embed settings.

### Federated Data

- Cards and Scheduled Reports using BigQuery DataSets failed to load with "Invalid field name" errors when column names contained special characters such as forward slashes, parentheses, or commas, affecting both federated BigQuery DataSets and Cloud Amplifier BigQuery integrations.

### Mobile

- Raises the recommended mobile app version for compatibility with updated certificates.

### Navigation

- Add Buzz Chat to custom navigation so it appears in the navigation menu and links to the Buzz interface.
- Code Engine was incorrectly hidden in the navigation for some users who had permission to access it.
- The notification badge on a user's profile avatar overlapped the full-screen Buzz view for users who had disabled the new left navigation.
- The Recent section in the left navigation could lose history from previous days following a network disruption.

### Performance

- Viewing DataSet details could trigger excessive notifications, causing intermittent slowdowns across the instance.

### Personalized Data Permissions

- Some PDP row policies in a DataSet did not appear in the DomoStats Row Assignment view.

### Publish

- App Studio components without data subscriptions failed to replicate to Publish subscribers, returning an error during card creation.
- Cards with Beast Mode calculations could fail to display on subscriber instances after publishing, showing an error message that processing could not be completed.
- CSV exports failed silently when a card was built on a DataSet View that joined multiple Publish DataSets.
- Notebook cards in published Domo Everywhere apps could lose their DataSet connections when using summary numbers and dynamic text with multiple DataSets, causing content to fail to render in the subscriber instance.
- The last refresh duration displayed incorrectly for certain publications in Publish.
- Variable options in Publish subscriber instances did not appear correctly on expanded cards, even though they displayed properly in the page-level control panel.
- Very large publications could fail or take more than 24 hours to update when adding subscribers or refreshing content.

### Sandbox

- Adds support for content type parameters in Sandbox rename rules.
- Improves how Sandbox promotions handle sharing settings when promoting content within the same instance.
- In Sandbox, commit operations could fail when no commit description was provided.
- Sandbox page mappings were not saved during promotion, causing authorization errors.
- Sandbox promotions consistently failed with a service unavailable error.
- Sumo cards deployed from a Sandbox repository could fail to load if they referenced Beast Mode calculations that no longer existed in the target instance.

### Scheduled Reports

- Double square brackets ([[]]) in Scheduled Report email subject lines were incorrectly flagged as emoji syntax, preventing the report from being saved or sent.

### Tasks & Projects

- Users attempting to access a private project they don't have permission to view did not receive an appropriate access denied message.

### Workflows

- AI toolkits referencing a Code Engine package did not appear in that package's usages tab.
- HTML content in Workflows Send Email actions could display incorrectly due to escaped slashes in text inputs.
- The Query DataSet block in Workflows displayed output column types as "Object" instead of their actual data types, such as Date-Time or Text, preventing users from configuring downstream actions.

### Workspaces

- Workspaces would disappear after refreshing the page if the user belonged only to hidden or inactive groups.
