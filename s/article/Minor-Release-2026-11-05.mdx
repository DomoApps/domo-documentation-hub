## November 5, 2026 Release

### AI Labs

- A missing icon in the Report Builder Toolkit card in the AI Library.
- Adds a feature switch that allows customers to enable or disable the Domo SQL toolkit in AI Services.
- Adds a new DomoStats report called "AI Operations" that provides usage and performance metrics for AI features.
- Adds the ability to search for FileSets by their ID in AI Labs.
- AI Labs unstructured data processing jobs could fail without displaying error information.
- AI Library cards displayed blank grey space instead of icons when embedded using Domo Everywhere or in Publications.
- Allows custom agents and toolkits in AI Labs to function independently of the AI Chat feature toggle.
- Introduces AI Chat V2 with improved consumption reporting and an updated Pro badge display.
- Introduces AI Chat V2 with improvements to consumption reporting and Pro badge display.
- Separates the Automated Insights toggle from the metrics toggle in AI Labs, allowing you to control each feature independently.

### AI Services

- Adds display names to AI Services usage tracking to improve feature identification in analytics.
- AI Agent tiles in Workflows could not access certain file types from Document Collections as knowledge sources due to a mismatch in available tools.
- The Activity Log for AI Agent Settings displayed "Ai chat tool" in the Type and Event columns instead of showing the specific tool name that was toggled.
- The Agent tile in Workflows could fail when using structured outputs.
- The Automated Insights feature was incorrectly hidden or inaccessible in some parts of the interface.

### Alerts

- Alerts on DataSets with Personalized Data Permissions enabled would not send notifications to subscribers when the alert threshold was crossed.
- Dataset alerts with Personalized Data Permissions (PDP) configured in shared context failed to send webhooks, preventing campaigns from triggering as expected.
- The share dialog for certain alerts became stuck on "Searching" and prevented adding new users or groups. This occurred on column alerts for DataSets with Personalized Data Permissions when more than 200 users had access through PDP policies.
- Users with the "Use Alerts" grant could not see or receive alerts that were shared with them if they did not have access to the underlying DataSet.

### App Platform

- Creating a card from the Asset Library would skip the wiring screen for designs requiring workflow mappings, Code Engine mappings, or code-editor brick configuration, resulting in incomplete cards. The wiring screen now appears as expected when these elements need setup.
- Low-latency DataSets created by non-owners were not visible to the DataSet owner, only to Admin users.
- Migrates existing Change Data Capture (CDC) DataSets to use updated parsing defaults.
- Queries to DataSets from custom apps could fail with a 500 error.
- The Pro-Code Editor generated column aliases in all lowercase instead of preserving the original casing from DataSet column names.

### App Studio

- Box plot charts in App Studio displayed as bar charts after applying a filter, showing only the maximum and minimum values instead of the full box plot distribution.
- Editable Tables in App Studio could fail to accept input when the DataSet schema's column name casing was changed.
- In App Studio where Grid and List components displayed a "Power from data to configure search" message even when a DataSet was already connected, preventing users from configuring search and sort columns.
- Table cards in App Studio scheduled reports lost their theme formatting, such as alternating row colors, and displayed unexpected gridlines.
- Users with the "Edit Data in Editable Table Cells" permission were unable to edit cells in App Studio editable tables that use linked DataSets. These users previously required the "Edit Cards" permission as a workaround.

### Buzz

- Buttons in the "Remove user from conversation" dialog in Buzz private topics and group chats were unresponsive, preventing users from being removed from conversations.

### Cards

- A reported issue where cards became stuck in a "Loading" or "Filtering" state and failed to display data when dashboards were initially loaded. The issue affected multiple dashboards and was resolved by reverting a recent change.
- A reported issue where preset buttons in the expanded date selector on Cards became unresponsive and could compress into a vertical line after multiple click attempts.
- Cards grouped by month displayed English month labels (e.g., "2026-Jan") instead of localized labels (e.g., "2026年1月") for non-English viewers, sometimes showing "Data Not Available.".
- Issues where date variables and DATETIME comparisons did not correctly apply the company timezone. Variables now calculate dates in the correct timezone on first load, and Snowflake TIMESTAMP columns with timezone information are no longer shifted twice.
- Table cards displayed raw decimal values instead of the configured number format (percent, currency, or abbreviated) for high-precision decimal columns. Cards now correctly apply decimal precision, percentage formatting, and thousands separator settings as configured.
- Users with Editor permissions could not upload new versions of Document Cards they did not own, even when they had edit access to the card. The issue caused upload attempts to fail silently or display a 403 Forbidden error.
- Variable control filters applied in App Studio apps were not being applied when exporting cards as email, causing values to display as zero in the export.

### Connectors

- Creating a TikTok Business connector account would fail with a 500 error if the TikTok display name contained an emoji.
- In the JSON No Code connector where configuration changes made with the AI assistant were lost when navigating back to a previous step.
- Uploading multiple files consecutively in the File Upload connector could cause the interface to freeze and fail to advance to the preview screen.

### Data Center

- DataSet Views created from federated DataSets could not be edited, displaying the error "Something went wrong while trying to edit this view.".
- The account sharing dialog would fail to open if a previously shared group had been deleted. The dialog now displays all shared users and groups, and allows removal of shares to deleted groups.

### Data Processing

- Magic ETL DataFlows could become stuck in PREPARING or EXPORTING status for up to 24 hours when multiple DataFlows were triggered simultaneously, such as when several Snowflake DataSets updated at once. Affected DataFlows now complete normally or fail with a clear status instead of hanging.

### Data Query

- A database cleanup issue in CDC DataSets to prevent accumulation of unused internal records during deletion. No change to DataSet behavior or functionality.
- Beast Mode calculations using FIXED functions within CASE WHEN clauses could generate an "invalid column" error, preventing the card from rendering.
- Change Data Capture (CDC) did not produce DataSets in certain environments.

### Embed

- Embedded dashboards were cut off at the bottom, preventing users from viewing the lower portions of cards, table scroll bars, and axis labels.
- Slicer and variable selections in embedded App Studio apps did not filter dependent cards. Filters now apply correctly in both private and public embeds.
- The filter icon did not appear on expanded cards in private embeds, even when filtering was enabled. Users can now add filters directly to cards in embedded App Studio apps.

### Federated Data

- Cards and Scheduled Reports using BigQuery DataSets failed to load with "Invalid field name" errors when column names contained special characters such as forward slashes, parentheses, or commas. This affected both federated BigQuery DataSets and Cloud Amplifier BigQuery integrations.

### Personalized Data Permissions

- Some PDP row policies present in a DataSet did not appear in the DOMO Stats Row Assignment table, even after running the DataSet.

### Publish

- DataSets could fail to publish to Domo Everywhere instances, displaying a generic error message asking users to retry.
- Variable options in Publish subscriber instances did not appear correctly on expanded cards, even though they displayed properly in the page-level control panel. All configured variable options now publish and display consistently across both views.

### Sandbox

- In Sandbox where promoting and linking a repository on the same instance could fail with an unexpected error.

### Scheduled Reports

- Double square brackets ([[]]) in Scheduled Report email subject lines prevented the Schedule button from being enabled, blocking users from saving the report.

### Workflows

- The Query Dataset block in Workflows incorrectly displayed output column types as "Object" instead of their actual data types (such as Text or Date-Time), preventing users from properly configuring downstream actions.

### Workspaces

- Workspaces could disappear after refreshing the page when the user belonged only to hidden or inactive groups.
