## Intro

This article explains how to use Domo's OpenAI Ads Manager Connector to import data from OpenAI Ads Manager, including ad accounts, campaigns, ad groups, ads, and insights using an Ads API key.

---

## Prerequisites

To connect to the OpenAI Ads Manager API and create a DataSet, you need the Admin API key associated with your OpenAI Ads Manager account. Learn how to [create an Admin API key](https://platform.openai.com/settings/organization/admin-keys).

This article covers the fields and menus specific to the OpenAI Ads Manager Connector user interface. For general information about adding DataSets, setting update schedules, and editing DataSet information, see [Add a DataSet Using a Data Connector](/s/article/360042926274).

## Configure the Connection

This section describes the options in the **Credentials** and **Details** panes on the OpenAI Ads Manager Connector page. The components of the **Scheduling** and **Name & Describe Your DataSet** panes are universal across most connector types and are discussed in [Add a DataSet Using a Data Connector](/s/article/360042926274).

### Enter Your Credentials

The **Credentials** pane contains the field for entering credentials to connect to the OpenAI Ads Manager API. The following table describes what is needed for each field.

| Field   | Description                                                                                                                                |
| ------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| API Key | Enter your Admin API key. If you do not have one, create an [Admin API key](https://platform.openai.com/settings/organization/admin-keys). |

After you have entered valid credentials, you can use the same account any time you set up a new Domo-OpenAI Ads Manager connection. You can manage connector accounts in the **Accounts** tab in the Data Center. For more information about this tab, see [Manage User Accounts for Connectors](/s/article/360042926054).

### Configure the Details Pane

This pane contains a primary **Reports** menu, along with various other menus for configuring your report.

| Menu              | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Report            | Select the OpenAI Ads Manager report to retrieve. Entity reports (Ad Accounts, Campaigns, Ad Groups, and Ads) return metadata, while Insights reports return aggregated performance data and require a date range. The following reports are available: <table class='zebra-striped bordered'><thead><tr><th>Report</th></tr></thead><tbody><tr><td>Ad Account</td></tr><tr><td>Ad Groups</td></tr><tr><td>Ads</td></tr><tr><td>Campaigns</td></tr><tr><td>Costs</td></tr><tr><td>Insights Ad Account</td></tr><tr><td>Insights Ad Groups</td></tr><tr><td>Insights Ads</td></tr><tr><td>Insights Campaigns</td></tr></tbody></table> |
| Date Range        | Specify the start and end dates for retrieving insights data. This field is required when running the Insights Ad Account, Insights Campaigns, Insights Ad Groups, or Insights Ads reports. Enter dates in YYYY-MM-DD format and select a range between 2000-01-01 and 2100-12-31. The field is available only after you select an account and a supported Insights report.                                                                                                                                                                                                                                                           |
| Time Granularity  | Specify how the report aggregates insights data. Select Daily to return one row per day within the selected date range, or None (Aggregated) to return a single row that summarizes data across the entire date range. This option is available only for Insights Ad Account, Insights Campaigns, Insights Ad Groups, and Insights Ads reports. By default, the report uses Daily granularity.                                                                                                                                                                                                                                        |
| Aggregation Level | Specify how insights data is grouped in the report. Leave the setting as Default to match the aggregation level of the selected Insights report. To view data at a different level, select Ad Account, Campaign, Ad Group, or Ad. This option is available only for Insights Ad Account, Insights Campaigns, Insights Ad Groups, and Insights Ads reports. By default, the report uses the aggregation level that corresponds to the selected report.                                                                                                                                                                                 |
