## Intro

This article explains how to use the Paycom Connector to retrieve employee, labor allocation, position, time and attendance, and other HR and payroll data from Paycom.

## Prerequisites

To connect to the Paycom API and create a DataSet, you need the following:

* Security Identifier (API connection identifier)
* API Authentication Token

This article covers the fields and menus specific to the Paycom Connector user interface. For general information about adding DataSets, setting update schedules, and editing DataSet information, see [Add a DataSet Using a Data Connector](/s/article/360042926274).

## Configure the Connection

This section describes the options in the **Credentials** and **Details** panes on the Paycom Connector page. The components of the **Scheduling** and **Name & Describe Your DataSet** panes are universal across most connector types and are discussed in [Add a DataSet Using a Data Connector](/s/article/360042926274).

### Enter Your Credentials

The **Credentials** pane contains the field for entering credentials to connect to the Paycom API. The following table describes what is needed for each field.

| Field   | Description                                               |
| ------- | --------------------------------------------------------- |
| SID | Enter the security identifier (SID) for your Paycom API connection. |
| Token | Enter the API authentication token for your Paycom API connection. |

After you have entered valid credentials, you can use the same account any time you set up a new Paycom connection. You can manage connector accounts in the **Accounts** tab in the Data Center. For more information about this tab, see [Manage User Accounts for Connectors](/s/article/360042926054).
