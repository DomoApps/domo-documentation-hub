## Intro

This article explains how to use Domo's Personio_v2 Connector to import Personio HR data from Personio API v2 into Domo. You can retrieve custom Report Builder reports and attendance data for a selected date range, then use the imported data to build dashboards, monitor HR KPIs, analyze attendance trends, and combine HR data with other business data sources.

---

## Prerequisites

To connect to the Personio_v2 account and create a DataSet, you need the Client ID and Client Secret for your Personio account. For more information, refer to the [Personio API Documentation](https://developer.personio.de/).

This article covers the fields and menus specific to the Personio_v2 Connector user interface. For general information about adding DataSets, setting update schedules, and editing DataSet information, see [Add a DataSet Using a Data Connector](/s/article/360042926274).

## Configure the Connection

This section describes the options in the **Credentials** and **Details** panes on the Personio_v2 Connector page. The components of the **Scheduling** and **Name & Describe Your DataSet** panes are universal across most connector types and are discussed in [Add a DataSet Using a Data Connector](/s/article/360042926274).

### Enter Your Credentials

The **Credentials** pane contains the field for entering credentials to connect to the Personio_v2 account. The following table describes what is needed for each field.

| Field         | Description                        |
| ------------- | ---------------------------------- |
| Client ID     | Enter your Personio Client ID.     |
| Client Secret | Enter your Personio Client Secret. |

After you have entered valid credentials, you can use the same account any time you set up a new Domo-Personio_v2 connection. You can manage connector accounts in the **Accounts** tab in the Data Center. For more information about this tab, see [Manage User Accounts for Connectors](/s/article/360042926054).
