## Intro

Beyond the standard drag-and-drop elements, App Studio supports two advanced building blocks: **Forms**, which collect input from the people using your app, and **pro-code components**, which let you add custom HTML, CSS, and JavaScript to an app. This article explains how to add and configure a Form, how to work with pro-code components, how to combine the two, and the permissions required to edit pro-code components.

<Note>
  **Pro-code components and Domo Bricks are the same thing.** In App Studio, these custom HTML, CSS, and JavaScript objects are called **pro-code components**. Elsewhere in the Knowledge Base—and historically in the product—they are called **Domo Bricks** (formerly DDX Bricks). The "brick" terminology is being phased out, so when App Studio refers to a pro-code component, it means what was previously called a brick: the two are the same thing. See [Domo Bricks Overview](/s/article/4423762260375) for the full reference.
</Note>

## Required Grants

To build and customize apps in App Studio, the following grant must be enabled for your role:

- Edit App (App Studio)

Working with Forms and pro-code components also depends on the related Forms and Domo Bricks permissions. To learn more about grants, see [Manage User Roles and Grants](/s/article/360043438973).

## Add and Configure a Form

Forms let app users submit data directly from your app. You can add a Form as its own element on the canvas or insert one into a card.

- To add a Form element, drag a **Form** action onto the canvas. The form editor opens so you can build or select the form.
- To insert a Form into a card, select <i className="icon-plus sm" aria-hidden="true" /> **Add Content** > **Insert form** on the card, then choose an existing form or select **Create New Form**.

When a Form is placed inline on a page, it receives the page's current filter context. To open a Form from a button pop-up instead, see [Open a Form in a Pop-Up](/s/article/Add-Interactivity-to-an-App-Studio-App#open-a-form-in-a-pop-up)—note that filter selections on the page are *not* passed into a form opened as a pop-up.

For full instructions on creating, configuring, and editing forms—including configuring form appearance, sections, and questions, and reviewing submissions—see [Forms](/s/article/000005171), especially [Forms in App Studio](/s/article/000005171#forms-in-app-studio).

## Use Pro-Code Components (Domo Bricks)

Pro-code components are pre-built objects that let you create advanced visualizations and apps using HTML, CSS, and JavaScript. You can choose a component from the [Appstore](https://www.domo.com/appstore/) or build your own by pasting in code. The default code editor is Monaco, which powers VS Code.

To add a pro-code component to an app, insert it from the Appstore the same way you add other content, then open its code to customize it.

### Edit Pro-Code Component Code

You can fully customize a pro-code component's HTML, CSS, and JavaScript. Changes render immediately and can be updated within your Domo instance. For implementation details and the developer reference, see [Domo Bricks Overview](/s/article/4423762260375) and the linked Domo developer documentation.

<Warning>
  **Important:** AppDB in a pro-code component (Domo Brick) is blocked in public embed contexts due to security concerns and trust requirements.
</Warning>

### Combine a Pro-Code Component with a Form

You can pair a pro-code component with a Form to build custom input-and-action experiences—for example, a pro-code component that renders a custom interface while a Form captures the user's input and passes it into a Domo Workflow or writes it back to a DataSet. Build the Form as described in [Add and Configure a Form](#add-and-configure-a-form), add the pro-code component from the Appstore, and place both on the same app page so they share the page's data and filter context.

### Permissions for Editing Pro-Code Components

Editing a pro-code component's code requires the appropriate Domo Bricks permissions in addition to the Edit App (App Studio) grant. Admins and most Privileged users have these permissions by default. To learn more about adding grants to custom roles, see [Manage User Roles and Grants](/s/article/360043438973). For the full list of Domo Bricks permissions, see [Domo Bricks Overview](/s/article/4423762260375).
