## Intro

This article explains how to use Domo's Vanilla Forums Connector to import community data into Domo, including discussions, comments, users, categories, groups, and knowledge articles. This data helps you analyze community engagement, monitor user activity, and gain insights into content performance and participation trends.

---

## Prerequisites

To connect to your Vanilla Forums account and create a DataSet, you must have the following:

- Base URL
- Access Token

This article covers the fields and menus specific to the Vanilla Forums Connector user interface. For general information about adding DataSets, setting update schedules, and editing DataSet information, see [Add a DataSet Using a Data Connector](/s/article/360042926274).

#### Find Base URL

To find your Base URL:

1. Sign in to your Vanilla Forums community in a web browser.
2. Copy the protocol and host name from the browser's address bar.

For example:

`https://community-forums.company.com`

#### Generate a Vanilla Forums Access Token

To generate a personal access token:

1. Select the **MeBox**, then select your profile picture.
2. On your profile page, select **Edit Profile**.
3. In the right-hand navigation pane, select **Access Tokens**.
4. Select **Generate New Token**.
5. Copy and securely store the generated access token for use when configuring the connector.

## Configure the Connection

This section describes the options in the **Credentials** and **Details** panes on the Vanilla Forums Connector page. The components of the **Scheduling** and **Name & Describe Your DataSet** panes are universal across most connector types and are discussed in [Add a DataSet Using a Data Connector](/s/article/360042926274).

### Enter Your Credentials

This section contains fields for entering credentials to connect to your Vanilla Forums account. The following table describes what is needed for each field:

| Field               | Description                                                                                          |
| ------------------- | ---------------------------------------------------------------------------------------------------- |
| Base URL            | Enter the base URL of your Vanilla Forums community.                                                 |
| Access Token        | Enter the access token for your Vanilla Forums account.                                              |                                                                

After you have entered valid Vanilla Forums Connector credentials, you can use the same account any time you go to create a new Vanilla Forums Connector DataSet. You can manage connector accounts in the **Accounts** tab in the Data Center. For more information about this tab, see [Manage User Accounts for Connectors](/s/article/360042926054).
