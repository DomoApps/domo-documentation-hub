## Intro

App Studio is Domo's visual app-building environment. You connect DataSets, drag-and-drop components (charts, tables, forms, buttons, navigation menus), and publish a custom application directly inside Domo—without writing front-end code. Apps built in App Studio can include interactive forms, filtered views, drill paths, and custom themes. This article explains what App Studio is, how to access it, and points to the key articles for building and publishing apps.

## Required Grants

To build apps in App Studio, the following grant must be enabled for your role:

- **Edit App (App Studio) —** Create and edit apps in App Studio.

Learn more about [grants](/s/article/360043438973).

## Access App Studio

Select **App Studio** from the top navigation or from the Domo launcher. If App Studio is not visible, ask an Admin to grant you access.

## What You Can Build with App Studio

App Studio supports a range of custom data application types:

- **DataSet-powered dashboards —** Custom layouts with charts, tables, and metrics connected to your Domo DataSets.
- **Forms and workflows —** Collect data from users through forms and pass it into a Domo Workflow.
- **Navigation apps —** Build multi-page apps with a custom navigation menu and branded themes.
- **Report builders —** Configure parameterized reports users can customize and export. See [Deliver Customized Reports with App Studio Report Builder](/s/article/000005829).

## Domo Bricks

Domo Bricks—called **pro-code components** in App Studio—are pre-built objects (HTML, CSS, and JavaScript) available from the Appstore that you can add to App Studio apps or embed directly on a dashboard. Use them for custom visualizations not available in the standard chart library.

- [Domo Bricks | Overview](/s/article/4423762260375) — What Bricks are and how to add them to an app or dashboard.

## FAQ

<AccordionGroup>

<Accordion title="What is the difference between App Studio and a Domo dashboard?">
  A standard Domo dashboard is a layout of cards arranged on a shared screen. App Studio lets you build more structured, multi-page apps with custom navigation, forms, user-input collection, and branded themes—going beyond what a standard dashboard supports.
</Accordion>

<Accordion title="Do I need to know code to use App Studio?">
  No. App Studio is a drag-and-drop, low-code environment. You can build a full custom app without writing any code. For advanced customizations (custom CSS, JavaScript-powered Bricks, or API integrations), code is optional. See [Domo Bricks | Overview](/s/article/4423762260375) for the code-based extension option.
</Accordion>

<Accordion title="Can I publish an app I build in App Studio to the Domo Appstore?">
  Yes. Once an app is complete, you can list it on the Appstore so other Domo users can install it. See [List on the Appstore](/s/article/000005184).
</Accordion>
