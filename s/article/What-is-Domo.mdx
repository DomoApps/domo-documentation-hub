## Intro

Domo is a cloud-based data experience platform. It connects your data from hundreds of sources, gives you tools to prepare and analyze it, and puts the resulting insights in front of the people who need them—without requiring you to leave a single environment. This article explains what Domo is, how to access it, and points to the key articles for each capability area.

---

## What You Can Do in Domo

Domo covers the full data lifecycle, from ingestion to decision. Here are the core capability areas:

- **Connect your data —** Bring in data from 1,000+ sources: databases, cloud data warehouses, spreadsheets, SaaS apps, APIs, and file uploads. See [Connect & Bring In Data Overview](/s/article/Connect-and-Bring-In-Data-Overview).
- **Manage your data —** Find and organize your DataSets in the Data Center. Set update schedules, manage ownership and access, and monitor DataSet health. See [Manage Your Data in Domo](/s/article/Manage-Data-Overview).
- **Prepare and transform your data —** Use Magic ETL, SQL DataFlows, and DataFusion to join, clean, and reshape data for analysis. See [Prepare and Transform Your Data Overview](/s/article/Prepare-and-Transform-Overview).
- **Analyze and visualize —** Build charts, tables, and metric cards in Analyzer, then arrange them on shared dashboards. See [Analyze and Visualize Overview](/s/article/Analyze-and-Visualize-Overview).
- **Share and collaborate —** Send alerts, schedule reports, embed dashboards, and share content with colleagues inside and outside your organization. See [Share and Collaborate Overview](/s/article/Share-and-Collaborate-Overview).
- **Build apps and automate —** Use App Studio to create custom data apps, and Workflows to automate business processes. See [Build Apps and Automate Overview](/s/article/Build-Apps-and-Automate-Overview).
- **Apply AI and data science —** Use Domo AI, AutoML, and Jupyter Workspaces to generate insights, run predictive models, and build ML pipelines. See [AI and Data Science Overview](/s/article/AI-and-Data-Science-Overview).
- **Administer and govern —** Manage users, roles, security settings, and row-level permissions (PDP) for your Domo instance. See [Administer and Govern Overview](/s/article/Administer-and-Govern-Overview).

## Access Domo

Domo runs entirely in the browser—there is no software to install.

1. **Log in at your organization's Domo URL**—typically `yourdomain.domo.com`. See [Sign in to Domo](/s/article/000005875) for sign-in options, including SSO.
2. **Navigate using the left sidebar.** Select any icon to move between your Home dashboard, the Data Center, Apps, and Admin areas. See [Access and Start Creating Content through Domo's Navigation and Main Menu](/s/article/000005900) for a full walkthrough.

## FAQ

<AccordionGroup>

<Accordion title="What kinds of data sources can Domo connect to?">
  Domo includes connectors for databases, cloud data warehouses (Snowflake, BigQuery, Databricks, Redshift), spreadsheets (Google Sheets, Excel), SaaS applications (Salesforce, Marketo, HubSpot), REST APIs, and flat files. See [What Is a Connector?](/s/article/What-is-a-Connector) for a full overview of connector types.
</Accordion>

<Accordion title="Do I need to install any software to use Domo?">
  No. Domo runs in your web browser—navigate to your organization's Domo URL and log in. For on-premises data sources, the Workbench desktop application is available as a local bridge to Domo. See [What Is Workbench?](/s/article/What-is-Workbench) for details.
</Accordion>

<Accordion title="What is the difference between a card and a dashboard?">
  A card is a single visualization—a chart, table, number summary, or custom app—powered by a DataSet. A dashboard is a shared screen that displays a collection of cards. Dashboards can have filters that apply across all cards on the page. See [What Is a Card?](/s/article/What-is-a-Card) and [What Is a Dashboard?](/s/article/What-is-a-Dashboard).
</Accordion>

<Accordion title="How does Domo handle data security and permissions?">
  Domo uses two layers: role-based grants control which features a user can access, and Personalized Data Permissions (PDP) control which rows of a DataSet a user can see. See [Security and Permissions Overview](/s/article/Security-and-Permissions-Overview) for an overview of both systems.
</Accordion>

</AccordionGroup>
