## Intro

Magic ETL is Domo's drag-and-drop data transformation tool. You build a pipeline on a visual canvas by connecting input DataSets and chaining tiles—each tile performs one transformation (join, filter, aggregate, rename, and many others)—to produce a clean, analysis-ready output DataSet. No SQL or coding skills are required for most operations. This article explains what Magic ETL is, how it works, and points to the tiles reference and how-to articles.

---

## Required Grants

To create and edit Magic ETL DataFlows, the following grants must be enabled for your role:

- **Can Create DataSets —** Required to create the output DataSet from a DataFlow.
- **Manage DataFlows —** Create, edit, and delete DataFlows in your instance.

Learn more about [grants](/s/article/360043438973).

## How Magic ETL Works

A Magic ETL DataFlow reads one or more input DataSets, applies a chain of transformation tiles, and writes the result to a new output DataSet. The output DataSet refreshes automatically whenever the input DataSets update (or on a schedule you configure).

The canvas has three layers:

- **Input DataSets —** Drag any DataSet from your Data Center onto the canvas as a starting point.
- **Transformation tiles —** Connect tiles to filter, join, pivot, aggregate, compute columns, or run Python/R scripts. Each tile has a configuration panel.
- **Output DataSet —** A tile at the end of every branch that names and writes the transformed DataSet.

## What You Can Do With Tiles

Tiles are organized by function:

- **Combine Data —** Join two DataSets (inner, left, right, full), union, or append. See [Magic ETL Tiles: Combine Data](/s/article/360044876194).
- **Filter —** Remove rows by condition or formula. See [Magic ETL Tiles: Filter](/s/article/360044876614).
- **Aggregate —** Group rows and compute sums, counts, averages, and more. See [Magic ETL Tiles: Aggregate](/s/article/360044876094).
- **Text —** Trim, split, concatenate, and transform text columns. See [Magic ETL Tiles: Text](/s/article/360045402873).
- **Dates and Numbers —** Parse, format, and calculate with date and numeric columns. See [Magic ETL Tiles: Dates and Numbers](/s/article/360045402313).
- **Pivot —** Reshape from wide to long or long to wide. See [Magic ETL Tiles: Pivot](/s/article/360044951294).
- **DataSets —** Add, remove, rename, or reorder columns; select data. See [Magic ETL Tiles: DataSets](/s/article/360045402273).
- **Scripting —** Run Python or R code in a tile for advanced transforms. See [Magic ETL Tiles: Scripting](/s/article/360045485833).
- **Data Science —** Apply ML models and statistical functions. See [Magic ETL Tiles: Data Science](/s/article/360045259294).
- **Performance —** Tune execution for large DataSets. See [Magic ETL Tiles: Performance](/s/article/4405156517527).
- **Utility —** Add constants, duplicate columns, disable tiles for debugging. See [Magic ETL Tiles: Utility](/s/article/360044876874).

## Build Your First Magic ETL DataFlow

1. Open the Data Center and select **<i className="icon-plus sm" aria-hidden="true" /> New** > **Magic ETL**.
2. Drag one or more input DataSets onto the canvas.
3. Add and connect transformation tiles to shape the data.
4. Connect an **Output DataSet** tile, name it, and save.

See [Create a Magic ETL DataFlow](/s/article/360055259234) for the full step-by-step walkthrough.

## FAQ

<AccordionGroup>

<Accordion title="Do I need to know SQL or Python to use Magic ETL?">
  No. Most Magic ETL operations are configuration-based, not code-based. The formula editor uses a function syntax similar to Excel for calculated columns. The optional Scripting tiles (Python and R) are available for advanced use cases but are not required.
</Accordion>

<Accordion title="What is the difference between Magic ETL and a SQL DataFlow?">
  Magic ETL is visual and no-code; SQL DataFlows require writing MySQL or Redshift SQL queries. Magic ETL is the recommended starting point for most users. SQL DataFlows offer broader SQL expressiveness and can be a better fit for data engineers already fluent in SQL. See [What Is a DataFlow?](/s/article/What-is-a-DataFlow) for a comparison of all DataFlow types.
</Accordion>

<Accordion title="How do Personalized Data Permissions (PDP) work in Magic ETL?">
  Input DataSets in a Magic ETL DataFlow cannot be restricted by PDP—all rows pass through the transformation. Apply PDP policies to the output DataSet, not the inputs. See [Create a Magic ETL DataFlow](/s/article/360055259234) for details on PDP and DataFlows.
</Accordion>

<Accordion title="Can I run Python or R in Magic ETL?">
  Yes. The Scripting tiles let you write Python or R code that runs within the DataFlow pipeline. See [Magic ETL Tiles: Scripting](/s/article/360045485833) for setup and usage, and [Magic ETL v2 Scripting Tile Environments](/s/article/000005117) for available packages and environment details.
</Accordion>

</AccordionGroup>
