## Intro

Workbench is a Windows desktop application that runs inside your network and pushes data to Domo on a schedule. Unlike cloud connectors (which Domo's servers initiate), Workbench initiates the connection outbound from your machine—making it the right choice when your data lives behind a firewall, on a private network, or in an on-premises database that the public internet cannot reach. This article explains what Workbench is, how it works, and points to the installation and configuration articles.

## Required Grants

To create DataSets via Workbench, the following grants must be enabled for your role:

- **Can Create DataSets —** Create DataSets in Domo from Workbench jobs.

Learn more about [grants](/s/article/360043438973).

## How Workbench Works

You install Workbench on a Windows machine inside your network, configure one or more "jobs" (each job defines a data source, a query or file path, and a Domo DataSet to write to), and set a schedule. Workbench runs the jobs on schedule, pulling data from the source and uploading it to Domo over an encrypted HTTPS connection.

Workbench supports the following data source types:

- **Relational databases —** Connect via ODBC or native drivers (SQL Server, MySQL, Oracle, PostgreSQL, and others).
- **Local files —** CSV, Excel, and other flat files.
- **OLAP cubes —** SAP and similar.
- **XML and JSON —** Local or network-accessible feeds.

## FAQ

<AccordionGroup>

<Accordion title="What is the difference between Workbench and a cloud connector?">
  A cloud connector runs in Domo's cloud and pulls data from services accessible on the public internet. Workbench runs on-premises and pushes data from systems inside your network. Use Workbench when your data source is behind a firewall or on a private network that Domo's servers cannot reach. See [What Is a Connector?](/s/article/What-is-a-Connector) for more on cloud connectors.
</Accordion>

<Accordion title="What operating system does Workbench support?">
  Workbench runs only on Windows. If you need to move data from a Linux or macOS system, use the Domo API or a third-party ETL tool to push data programmatically.
</Accordion>

<Accordion title="Does Workbench need an always-on connection to Domo?">
  Workbench only needs an outbound internet connection when a job runs. It authenticates to Domo over HTTPS and pushes the data. Between job runs, no persistent connection is required.
</Accordion>

</AccordionGroup>
