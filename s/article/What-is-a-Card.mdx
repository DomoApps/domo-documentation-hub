## Intro

A card is the building block of every dashboard in Domo. Each card is a self-contained visualization—a bar chart, a table, a single-number metric, a document, or a custom app—that draws its data from one or more DataSets. Cards are built in Analyzer, published to dashboards, and can be shared, filtered, and drilled into. This article explains what cards are, the types available, and points to the key articles for building and managing them.

## Required Grants

To create and edit cards, the following grants must be enabled for your role:

- **Edit Cards —** Build and modify visualization cards in Analyzer.

Learn more about [grants](/s/article/360043438973).

## Card Types

Domo supports several card types:

- **Visualization cards —** Interactive charts and tables powered by a DataSet. Built in Analyzer. This is the most common card type.
- **Sumo cards —** Pivot-style tables that let users drill into summarized data on the fly. See [Adding a Sumo Card](/s/article/360042925674).
- **Document cards —** Attach and display files (PDFs, PowerPoints, images) directly on a dashboard. See [Updating a Doc Card](/s/article/360042925614).
- **Notebook cards —** Freeform text, images, and HTML content. Good for explanations, context, and headings on a dashboard. See [Editing a Notebook Card](/s/article/360042925654).
- **App cards —** Custom Domo apps (from App Studio or the Appstore) embedded as a card on a dashboard.

## Build a Visualization Card

Visualization cards are built in Analyzer—Domo's chart-building tool. You connect a DataSet, assign columns to chart axes, choose a chart type, and apply formatting.

1. **Open Analyzer.** From the navigation, select **+ New** > **Card**, or open an existing card and select **<i className="icon-pencil sm" aria-hidden="true" /> Edit**. See [Opening Analyzer](/s/article/360042924054).
2. **Connect a DataSet.** Select the DataSet that will power the card.
3. **Build the chart.** Drag columns to the X-axis, Y-axis, and series fields. See [Analyzer Layout](/s/article/360042924034) for a reference of every pane and control.
4. **Choose a chart type.** Over 150 chart types are available. See [Chart Types](/s/article/360042935294) for the full reference.
5. **Save the card** and add it to a dashboard.

## What You Can Do With Cards

- **Filter** — Apply row-level filters to a card independently of dashboard filters. See [Filtering Data in a Card Details View](/s/article/360042924014).
- **Drill paths** — Let viewers click a data point to drill into a more granular DataSet or card. See [Drilling into Data](/s/article/360042923994).
- **Beast Mode calculations** — Add computed columns or custom metrics that don't exist in the DataSet. See [What Is Beast Mode?](/s/article/What-is-Beast-Mode).
- **Alerts** — Trigger a notification when a card's data crosses a threshold. See [What Is an Alert?](/s/article/What-is-an-Alert).

## FAQ

<AccordionGroup>

<Accordion title="How many DataSets can power a single card?">
  A standard visualization card is powered by one DataSet. To combine data from multiple DataSets, use a DataFusion or DataFlow to create a combined DataSet, then power the card from that output. Beast Mode calculations can also perform joins in limited contexts.
</Accordion>

<Accordion title="Who can edit a card?">
  By default, users with the Editor role or higher (or the Edit Cards grant) can edit any card they have access to. Card owners can optionally restrict editing to themselves and admins. See [Opening Analyzer](/s/article/360042924054) for the full permission details.
</Accordion>

<Accordion title="What happens to a card if its DataSet is deleted?">
  The card loses its data connection and displays an error. Use [Connecting Cards to a Different DataSet](/s/article/360043430653) to repoint the card to a replacement DataSet.
</Accordion>
