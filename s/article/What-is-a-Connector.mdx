## Intro

A connector is a pre-built data integration that authenticates to an external service or data source and imports data into Domo as a DataSet. Domo ships with thousands of connectors covering SaaS apps, databases, cloud storage, social platforms, advertising networks, and more. Once configured, a connector runs on a schedule you define and keeps the DataSet current automatically. This article explains what connectors are, how they work, and points to the key articles for setting them up.

## Required Grants

To add a DataSet using a connector, the following grants must be enabled for your role:

- **Can Create DataSets —** Add new DataSets to Domo using connectors.

Learn more about [grants](/s/article/360043438973).

## How Connectors Work

When you configure a connector, you:

1. **Authenticate** — provide credentials or OAuth authorization for the external service.
2. **Configure the data pull** — choose the data object, date range, columns, and any filters.
3. **Set an update schedule** — choose how often Domo re-pulls the data (hourly, daily, weekly, or manual).

Domo stores the credentials as a connector account, which can be reused across multiple DataSets from the same service. The connector runs on its schedule, pulls the data, and writes it to the DataSet using the update method you specified (Replace, Append, or Partition).

See [Adding a DataSet Using a Connector](/s/article/360042926274) for the full walkthrough.

## Connector Types

Domo offers several connector categories:

- **Standard connectors —** Pre-built integrations available in the Connector Library. Search and add from **Data > Data Center > <i className="icon-plus sm" aria-hidden="true" /> Add DataSet**.
- **Partition connectors —** Connectors that split large DataSets into date-partitioned segments for efficient updates. See [About Partition Connectors](/s/article/360052122294).
- **Multi-account connectors —** Connectors that pull from multiple accounts of the same service into a single DataSet. See [Powering Up Multi Account Connectors](/s/article/000005825).
- **Writeback connectors —** Push data from a Domo DataSet back to an external system. Available in the [Writeback Connectors](/s/article/Connect-and-Bring-In-Data-Overview) section.
- **Custom connectors —** Connectors built using the Connector Dev Studio for sources not in the library. See [Develop & Integrate Overview](/s/article/Develop-and-Integrate-Overview).

## Manage Connector Accounts

Connector accounts store the authentication credentials that power one or more DataSets. You can view, transfer ownership, and share accounts with other users.

- [Manage Connector/Adapter Accounts](/s/article/360042926054) — View and manage all connector accounts in the Data Center.
- [Connector Permissioning in Domo](/s/article/1500002094122) — Control which users can create DataSets from a shared connector account.
- [Understanding the Connector Options Menu Items](/s/article/360051558694) — Reference for the DataSet Options menu available to owners and admins.

## FAQ

<AccordionGroup>

<Accordion title="How is a connector different from Workbench?">
  A connector runs entirely in Domo's cloud and pulls data from cloud-hosted services over the internet. Workbench is a Windows agent that runs on-premises and pushes data from local files, databases, or systems that are not accessible from the public internet. If your data source is behind a firewall or on a private network, use Workbench. See [What Is Workbench?](/s/article/What-is-Workbench).
</Accordion>

<Accordion title="Can I reuse a connector account for multiple DataSets?">
  Yes. Domo stores connector credentials as a named account. Once an account is configured, you can create as many DataSets as you like from that account without re-entering credentials. See [Manage Connector/Adapter Accounts](/s/article/360042926054).
</Accordion>

<Accordion title="What update methods are available for connector DataSets?">
  Connectors support Replace (overwrite the DataSet on each run), Append (add new rows without deleting existing ones), and Partition (update only the date-partitioned segments that changed). See [DataSet Update Methods](/s/article/360043430733).
</Accordion>

<Accordion title="What do I do if a connector I need is not in the library?">
  You can build a custom connector using the Connector Dev Studio, use the Domo API to push data programmatically, or use Workbench if the data lives on-premises. See [Develop & Integrate Overview](/s/article/Develop-and-Integrate-Overview).
</Accordion>

</AccordionGroup>
