## Intro

A dashboard is a shared screen in Domo that holds a collection of cards—charts, tables, metrics, documents, and apps—arranged in a layout you control. Dashboards are the primary way most Domo users experience and interact with data. They support cross-card filtering, sub-dashboards, scheduled reports, and interactive exploration. This article explains what dashboards are, how to create and manage them, and points to the key articles for advanced dashboard features.

---

## Required Grants

To create and edit dashboards, the following grants must be enabled for your role:

- **Create Pages and Apps —** Create new dashboards in Domo.
- **Edit Pages —** Edit existing dashboards and their card layouts.

Learn more about [grants](/s/article/360043438973).

## Create a Dashboard

1. From the top navigation, select **<i className="icon-plus sm" aria-hidden="true" /> New** > **Dashboard**.
2. Choose a layout template or start from a blank canvas.
3. Add cards by searching for existing ones or creating new ones inline.

See [Get Started with Dashboards](/s/article/360043428553) for a full walkthrough and [Creating Domo Stories](/s/article/360043428433) for the Stories layout format that locks card positions across web, mobile, and print.

## Dashboard Features

- **Dashboard Filters —** Filters applied at the dashboard level that cascade to all cards powered by the same DataSets. Capitalize "Dashboard Filters" when referring to this feature. See [Filtering your dashboards](/s/article/360042923914).
- **Sub-dashboards —** Nest dashboards inside a parent dashboard for hierarchical navigation. See [Get Started with Dashboards](/s/article/360043428553).
- **Scheduled Reports —** Send a snapshot of the dashboard to email recipients on a schedule. See [Scheduled Reports](/s/article/360043437773).
- **Drill paths —** Let viewers click a card to drill into a more detailed view. See [Drilling into Data](/s/article/360042923994).

## Share a Dashboard

Dashboards can be shared with individual users, groups, or made available via a publication or embed. See [Share and Collaborate Overview](/s/article/Share-and-Collaborate-Overview) for the full sharing options.

## FAQ

<AccordionGroup>

<Accordion title="What is the difference between a dashboard, a page, and a Story?">
  In Domo's current interface, the primary container for cards is called a dashboard. Older Domo documentation uses "page" as a synonym. "Domo Stories" refers specifically to the Stories layout format—a structured grid layout that keeps card sizes consistent across web, mobile, and print. All three terms refer to the same general concept of a card container; Stories is a specific layout style within it.
</Accordion>

<Accordion title="How are Dashboard Filters different from card-level filters?">
  Card-level filters apply only to the individual card they are set on. Dashboard Filters apply to every card on the dashboard that is powered by the same DataSet columns used in the filter—they are cross-card and visible to everyone viewing the dashboard.
</Accordion>

<Accordion title="Can I add cards from multiple DataSets to one dashboard?">
  Yes. A dashboard can contain any number of cards, each powered by a different DataSet. Dashboard Filters only affect cards whose DataSets include the filtered column; cards from unrelated DataSets are unaffected.
</Accordion>

<Accordion title="Can I schedule a dashboard to be sent by email?">
  Yes. Use Scheduled Reports to send a PDF snapshot of the dashboard to any email address on a daily, weekly, or monthly cadence. See [Share and Collaborate Overview](/s/article/Share-and-Collaborate-Overview) for details.
</Accordion>

</AccordionGroup>
