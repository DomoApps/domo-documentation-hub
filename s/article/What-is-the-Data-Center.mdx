## Intro

The Data Center is Domo's command center for all DataSets. It gives you a searchable, filterable list of every DataSet in your instance with real-time status indicators showing whether each DataSet is running, succeeded, failed, or overdue. From the Data Center you can create new DataSets, manage connector accounts, take bulk actions on DataSets, and navigate to the Data Warehouse view for more advanced operations. This article explains what the Data Center is, how to access it, and points to the key reference and management articles.

---

## Required Grants

To access and use the Data Center, the following grants must be enabled for your role:

- **Can Create DataSets —** Create new DataSets and manage DataSets you own.
- **Manage All DataSets —** View and manage DataSets owned by any user in the instance (typically an Admin-only grant).

Learn more about [grants](/s/article/360043438973).

## Access the Data Center

Select **Data** from the top navigation, then select **Data Center**. The Data Center opens to your list of DataSets.

## What You Can Do in the Data Center

- **Search and filter DataSets —** Filter by owner, connector type, status, tag, or last-run result to find the DataSet you need.
- **Monitor update status —** At a glance, see whether each DataSet ran successfully, failed, or is running right now.
- **Take DataSet actions —** Use the Options menu on any DataSet to run, edit, share, tag, export, or delete it.
- **Manage connector accounts —** View and share the connector credentials that power your DataSets.
- **Add new DataSets —** Select **+ Add DataSet** to open the Connector Library and connect a new data source.

## FAQ

<AccordionGroup>

<Accordion title="Can I see DataSets owned by other users?">
  By default, you see only the DataSets you own or that have been shared with you. Users with the Manage All DataSets grant (typically Admins) can see every DataSet in the instance. See [Data Center Layout](/s/article/360047553253).
</Accordion>

<Accordion title="What do the DataSet status colors mean?">
  Green indicates the last run succeeded. Red indicates the last run failed. Yellow or amber indicates the DataSet is overdue (the expected update window has passed without a successful run). Gray indicates the DataSet has never run or its schedule is manual. See [Data Center Layout](/s/article/360047553253) for the full reference.
</Accordion>

<Accordion title="How do I find out which cards use a specific DataSet?">
  Open the DataSet's details from the Data Center and select the **Cards** or **Lineage** tab. This shows every card, DataFlow, and other object that depends on the DataSet. See [Viewing the Impact of Changes to DataSets](/s/article/360042926234).
</Accordion>

</AccordionGroup>
