### Scope

Only EN chart-type catalog articles are matched here — articles whose frontmatter title contains "Chart" or "Graph" *and* whose body has ≥5 cells with the chart-thumbnail pattern (`<td><p>name</p><p><img inline></p></td>`). Detected non-catalog articles are filtered out.

**Localized articles (de/es/fr/ja) are not in this report.** They reference the same image filenames as their EN counterparts, so the migration script will apply the approved EN mapping to every locale automatically.

### How matching works

Each article chart name is fuzzy-matched against the JS table's display names (e.g., "Vertical Grouped Bar with Line graph" → "Grouped bar + line"), then the display name resolves to a sprite class via the badge in the JS source. The matcher also handles axis swapping — if a chart shows up in a Vertical section but its display is registered for Horizontal, the matcher will swap to the corresponding vertical sprite if one exists.

Confidence is Jaccard similarity, with a `+0.5` boost when a chart is named just "Bar" / "Line" / "Area" / "Pie" / "Donut" and a `Single X` display exists (the basic-variant disambiguator).

- 🛠️ — **manual override**; the matcher's proposal is replaced by an explicit entry in `scripts/chart-thumbnail-overrides.json`. The migration uses this value, not the proposal.
- ✅ — high confidence; almost certainly correct
- ⚠️ — review; check that the proposed match is right
- ❌ — low confidence; needs a manual choice
